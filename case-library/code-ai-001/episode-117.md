# 第117集｜跨境AI模型流动安全审查规范

适用：模型权重出境、跨境API调用、境外模型入境部署、开源模型跨境分发、私有化模型跨境交付。管控拆分业务规避审查、权重夹带境内敏感数据特征、境外模型预埋后门、实质跨境以本地注册套利、审查后模型二次迭代不重审。本卷优先适用，冲突以此为准，联动法典全部前置卷宗；承接115开源、116闭源卷宗，专门规制跨司法辖区模型流动。
一、核心定义
跨境AI模型流动：包含两类形态，权重/镜像实体出境入境、跨境API远程调用。模型权重可留存训练数据隐性特征，数据出境与模型出境合并审查。AI仅为推演辅助工具，跨境申报、风险自评估、境外接收方核验、卷宗维护权责归属场景运营主体，责任不得转嫁境外接收方。
穿透式审查：不以注册地、服务器位置判定，以模型研发源头、训练数据来源、实际控制主体判定归属，防范变更主体规避审查。
模型隐性数据风险：权重经逆向、特征提取还原境内敏感信息、地理、政务、个人数据的潜在风险。
入境模型安全核验：境外模型进入境内部署，必须完成风险定级、后门与指令注入测试，不得直接落地商用。
二、分级管控
低风险跨境流动：轻量小模型，无敏感训练数据，仅科研非商用，提交自评估报告，简化备案。
中风险跨境流动：行业商用模型，有限能力，开展出境自评估，核验境外接收方安全能力，半年复核。
高风险跨境流动：基座大模型、关键决策模型，权重出境或入境部署，强制独立第三方安全审查、专项申报、季度复核、跨境熔断管控。
三、底层原则
1. 模型跨境流动实施分级事前审查，API远程调用与权重实体出境同等纳入监管，不可拆分规避。
2. 穿透认定实质归属，不得依靠变更注册地、离岸主体、业务拆分来逃避安全审查。
3. 模型出境审查同时核验两点：模型本身安全能力，权重内嵌入的隐性数据泄露风险。
4. 境外模型入境必须核验后门、对齐偏向、越权能力，高风险境外模型未经审查禁止落地商用。
5. 审查完成后模型发生权重、数据集、安全护栏重大迭代，必须重新申报跨境评估，审查资质不可永久沿用。
四、全流程核心管控
1. 出境申报与自评估
主体提交跨境流动卷宗，含模型风险定级、SHA-256哈希、训练数据溯源、隐性数据风险评估、境外接收方资质与安全承诺；高风险模型须第三方专项审查。
2. 境外接收方核验
核查接收方所在区域法规、数据保护能力、出口管制约束；签订法律协议，约定禁止二次无授权分发、禁止逆向提取境内敏感特征；留存履约凭证。
3. 入境模型强制核验
境外模型进入境内部署，开展红队测试，排查隐藏后门、指令劫持、价值偏见；高风险境外模型必须完成国内备案与灰盒测评。
4. 审查后变更管控
模型权重、训练数据集、安全对齐策略重大更新，无论是否已经跨境获批，必须重新开展风险评估；仅提示词模板微调留存变更记录。
5. 跨境链路日志留存
跨境模型调用、分发、版本流转全程留痕，日志留存不少于六个月；监管可随时调取核验，禁止跨境链路销毁记录。
6. 熔断机制
检出拆分业务套利、权重夹带敏感数据、境外模型存在未披露后门、审查后重大迭代不重报，立即阻断跨境传输、关停跨境API接入；存量跨境模型启动风险排查，整改复测通过后方可恢复。
五、多方权责
境内模型运营主体：跨境申报、自评估、接收方核验、版本变更申报、卷宗留存第一责任人。
境外接收方：按协议约束模型使用，禁止逆向提取敏感特征、违规二次分发。
独立安全测评方：跨境模型安全审计、隐性数据风险、后门检测，出具客观审查结论。
监管审计：穿透核查模型跨境行为，查处拆分、离岸主体规避审查、隐瞒隐性数据风险。
六、禁止性规则
1. 禁止拆分业务、变更离岸主体，以形式手段规避跨境安全审查。
2. 禁止高风险模型权重出境、境外高风险模型入境商用，未完成专项审查。
3. 禁止模型权重夹带境内重要数据、敏感信息特征，未经隐性数据风险评估跨境流转。
4. 禁止跨境审查通过后，模型重大迭代不重新申报评估，沿用旧审查资质。
5. 禁止境外接收方未经许可逆向解析权重提取境内敏感数据，二次无授权分发。
6. 禁止销毁跨境流转日志、模型哈希、申报卷宗，隐匿跨境流动痕迹。
七、治理谬误
1. 仅API远程调用，权重不出境，无需跨境审查谬误。
2. 公司注册在境外，模型归属境外主体，不受境内跨境监管谬误。
3. 模型一次跨境审查通过，后续迭代无需再次评估谬误。
4. 境外开源模型免费下载，入境使用无需安全核验谬误。
5. 权属快照确权等同于跨境模型流动合规。
全局铁律
跨境AI模型流动分级事前审查，API调用与权重出境一体管控；执行穿透式认定，杜绝离岸主体、业务拆分套利；出境审查兼顾模型安全与权重隐性数据泄露风险；境外模型入境强制后门与安全测评；模型重大迭代必须重审；跨境协议约束境外接收方，全程链路留痕；不得以架构、注册地形式要件，规避法典跨境安全审查底线。
