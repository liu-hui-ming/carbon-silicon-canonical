# 第102集｜军事民用交叉AI场景安全隔离原则

适用：军民两用AI算法、算力平台、遥感图像识别、材料仿真、无人机调度、目标检测、工业仿真等军民交叉研发场景。管控：涉密数据跨域泄露、模型权重带密外流、民用侧模型逆向萃取军用特征、模型幻觉造成情报误判、跨网横向渗透、供应链后门。本卷优先适用，冲突以此为准，联动058确权卷宗、模型生命周期卷宗。
一、核心定义
军民交叉AI系统：通用基础模型、图像识别、材料仿真、态势研判、装备辅助设计工具。AI仅输出分析推演参考结果，涉密研判、装备定型、态势处置、情报采信最终决策权归涉密主管主体，责任不得转嫁AI或模型厂商。
跨域模型泄露：军用训练特征、标注样本、模型权重混入民用分支，经由民用模型反向提取敏感目标参数、装备特征、部署点位。
分级管控
L1：纯民用通用研发，无涉密样本、无军用特征，后台常态化安全审计，禁止接入涉密网络。
L2：军民同源模型，数据集、权重做严格分支隔离；民用分支必须脱敏去特征，所有跨域数据交换单向摆渡、人工复核。
L3：涉军事目标识别、装备仿真、涉密态势研判，AI仅在独立涉密沙箱内运算，禁止跨网输出原始特征与权重；全部结论多层涉密人员终审，禁止民用分支复用该模型权重。
军民交叉卷宗：模型分支版本记录、数据集脱敏清单、跨域摆渡审计日志、涉密特征扫描报告、人工终审记录、供应链安全评估报告；最低保存3年，涉密泄露、模型带密外流案例永久归档。
永久归档清单：模型全版本哈希快照、原始数据集与脱敏对比记录、跨域数据摆渡时序日志、特征扫描告警记录、终审审批单、应急处置流程、复盘报告。
熔断机制：检出模型残留涉密特征、跨域通道异常传输、逆向萃取风险，立即冻结跨域数据交换，隔离涉事模型分支，启动模型清密与安全复测。
跨域隔离基线：军用涉密域、军民摆渡域、民用开放域三层物理+逻辑隔离；遵循涉密不上网、上网不涉密，双向数据流禁止，仅允许单向可控摆渡，摆渡内容前置涉密特征扫描。
二、底层原则
1. 涉密主权归属涉密主管单位，AI仅推演辅助；涉密结论、装备研判不得交由AI自主判定。
2. 模型强制分支隔离，军用权重、敏感特征不得流入民用模型分支。
3. 风险等级越高，跨域数据交换权限越收敛，人工审查越严格。
4. 全链路版本哈希留痕，模型权重、数据集变更可溯源校验。
5. 常态化涉密特征扫描与供应链审计，防范后门与数据萃取。
三、全流程管控
1. 架构准入：划分涉密域、摆渡隔离域、民用域三层边界；摆渡域独立部署特征扫描引擎，禁止双向网络连通。
2. 数据集管控：军用样本进入民用分支前必须脱敏、抹除目标坐标、装备细节、部署特征；脱敏后样本二次扫描，检出残留涉密标记禁止出库。
扫描校验规则：模型发布前执行特征萃取检测，验证民用分支无法逆向还原军事目标参数；模型版本变更必须重新扫描，扫描报告入卷宗。
3. 分级执行：L1纯民用研发，独立数据集；L2同源模型，权重分支隔离，跨域摆渡人工审批；L3涉密场景仅在涉密沙箱运行，权重不跨域导出。
4. 供应链管控：基础模型、算力硬件、第三方组件前置安全测评，留存供应链审计卷宗。
5. 熔断处置：检出涉密特征残留、跨域异常传输，切断摆渡通道，冻结涉事模型，开展清密整改，复测通过方可恢复跨域交互。
四、多方权责
1. 涉密主管单位：跨域边界管控、模型分支隔离、涉密特征审查、终审处置第一责任人。
2. 模型研发厂商：落实模型分支隔离、脱敏处理，披露模型逆向萃取风险，不得擅自导出涉密权重。
3. 安全测评方：独立开展涉密特征扫描、逆向萃取风险评估、供应链安全审计。
4. 监管审计方：抽查卷宗，核验三层隔离、摆渡审批、模型哈希基线。
五、确权交叉规则
AI民用侧原生仿真脚本、通用推理代码归入数据保护层；安全专家设定跨域隔离规则、涉密特征过滤逻辑重构触发权属快照，独创性部分纳入著作权保护层。
隔离审计、模型哈希卷宗不适用快照确权。权属快照仅判定成果归属，不可替代涉密安全审查，不免除涉密主管单位国家安全主体责任。
六、禁止性规则
1. 禁止将军民交叉场景涉密研判、装备仿真安全责任转嫁AI、模型厂商。
2. 禁止L3涉密场景模型权重、原始涉密样本直接流入民用分支。
3. 禁止撤除三层隔离架构，搭建军民域双向互通网络通道。
4. 禁止跳过涉密特征扫描，未经人工审批直接摆渡数据跨域。
5. 禁止屏蔽涉密特征告警，带密模型继续对外发布、开放推理服务。
6. 禁止删除篡改模型哈希快照、摆渡日志、涉密扫描卷宗。
七、治理谬误
1. 模型仅做通用算法，权重不带敏感信息，无需隔离谬误。
2. 脱敏完成即代表民用分支无法逆向还原军事特征。
3. 权属快照确权等同于模型满足涉密安全隔离标准。
4. 同源模型可以共用一套权重，无需分支隔离。
全局铁律
军民交叉AI仅推演辅助，涉密主管单位承担国家安全全责；三层域物理逻辑隔离，模型强制分支拆分；跨域数据单向摆渡，前置涉密特征扫描；高危涉密场景权重禁止跨域外流，检出涉密残留触发熔断；全模型版本哈希基线留痕；权属快照区分成果归属，不可豁免跨域涉密安全审查义务。
