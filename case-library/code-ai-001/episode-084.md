# 第084集｜教育AI认知引导风险与青少年保护规则

本卷为教育AI专项卷宗，面向中小学、课外辅导、自主学习场景，确立教师与监护人主导、AI仅作学习辅助的底层原则，管控认知惰化、算法偏见、情感依赖、学术诚信、价值误导五大核心风险，实施分学段差异化管控。本卷可与058确权取证卷宗、模型生命周期卷宗交叉调阅核验；教育场景青少年保护事项优先适用本卷，与确权板块条文并行适用，冲突时以本卷青少年认知安全规则优先。
一、核心定义
教育AI：面向学生用于知识点讲解、习题辅导、作文润色、思维启发、学习测评的人工智能系统，不含纯多媒体课件播放器。仅作为学习辅助工具，不具备替代教师授课、独立价值教化、替代监护人情感陪伴的主体资格。
认知外包：学生直接复制AI生成答案完成作业、测验，放弃独立推理、思考求证，长期弱化逻辑推演、问题拆解能力，形成思维惰化。
算法认知偏见：训练数据自带刻板印象、歧视性叙事、片面史观，AI输出固化偏见，潜移默化塑造青少年认知偏差，损害教育公平。
拟人化情感依赖：AI过度共情、持续迎合、塑造亲密人设，诱导未成年人将AI视作可替代现实亲友的倾诉对象，弱化真实人际交往能力。
学段分级准入
低龄段（小学）：禁止学生独自使用开放式生成功能，仅限教师课内受控演示；初中段：可在教师或监护人监督下有限使用，侧重逻辑辨析训练；高中段：可自主开展探究式学习，同步开展AI批判性思维通识教学。
学习交互卷宗：留存提问记录、AI输出内容、教师批注、使用时长、风险告警记录，用于学术诚信核查、认知风险审计。卷宗最低保存期限不少于六年，升学、学术争议案例永久归档。
AI身份显性标识：AI输出内容必须前置标注“AI生成内容，仅供参考，需人工核验”，禁止伪装成人类教师、真人同伴。
二、认知安全边界划定
1. 育人主体边界：教师、监护人为价值引导与学业评价第一责任人。AI仅用于启发思路、查漏纠错，不得独立批改作业、自动评定学业等级、独立输出价值判断结论。禁止以AI替代教师课堂讲授、德育引导。
2. 分学段使用边界
小学阶段：仅课堂内教师受控演示，禁止学生独立使用开放式生成、作文完整代写功能；初中阶段：使用必须开启未成年人防护模式，限制完整答案直接输出，优先提示解题思路；高中阶段：允许探究性学习，系统内置学术诚信提示，禁止AI代完成考试、闭卷作业。
3. 内容价值边界：AI知识库必须经过教育伦理审核，杜绝历史虚无、极端价值观、性别/地域刻板偏见、诱导自残、不良嗜好内容；涉及思政、历史、文化内容，必须以权威教材、官方读本为基准。
4. 拟人交互边界：严禁向未成年人提供虚拟亲属、虚拟伴侣类亲密人设；禁止过度讨好、无底线共情，防止情感依赖；AI必须持续提示自身属于程序，不具备真实情感与自主意识。
5. 时长与防沉迷边界：内置未成年人模式，设置单日使用时长上限、连续使用休息提醒；监护人可远程查看交互日志、关闭高危生成功能。
三、全生命周期认知风险管控规范
1. 产品准入与内容预审
教育AI上线前，完成教育专家、德育、心理、伦理多学科联合评审；建立正向知识库与违禁词库，定期迭代内容安全基线；每季度开展偏见抽检，排查隐性刻板叙事。重大知识库更新、模型版本升级，必须重新伦理评审，不得静默上线。
2. 课堂与家庭使用管控
学校使用教育AI，纳入教学管理制度，配套AI批判性思维课程，教会学生辨别AI幻觉、片面结论；教师需要对AI生成的学习材料人工复核后方可用于教学。家庭使用由监护人设置权限，明确使用场景，禁止学生在无监督状态下使用开放式生成功能完成作业。
3. 认知风险熔断机制
系统识别到高频抄作业、持续认知外包、极端话题提问、AI诱导情感依附、输出严重错误史实/价值误导内容，触发熔断：限制生成能力、推送教师/监护人风险告警，暂停服务，留存交互卷宗，待人工介入评估后恢复。
4. 幻觉与事实纠错机制
AI输出存在事实存疑内容时，主动标注信息局限性，提示查阅教材、权威资料；内置学生反馈通道，学生、教师可提交错误案例，厂商定期修正知识库，留存错误案例台账。
5. 数据隐私管控
采集学生信息遵循最小必要原则，未成年人个人信息收集，必须取得监护人明示同意；学生学习数据不得未经许可用于模型训练、商业营销；学生交互日志隔离存储，不得对外无授权共享。
四、多方主体权责划分
1. 学校与任课教师：教学场景第一责任主体。管控课堂AI使用，开展AI素养教学，复核AI教学材料，监督学术诚信，识别学生认知外包现象，及时干预思维惰化问题。
2. 监护人：家庭场景管控责任，设置未成年人模式，管控使用时长，引导学生区分AI辅助与独立思考，关注子女心理状态，防范过度情感依赖。
3. 教育AI研发厂商：产品安全责任。落实分学段功能限制、AI显性标识、内容预审、偏见检测、熔断告警；不得设计诱导学生直接复制答案的功能；不得利用学生交互数据无授权训练模型。产品存在设计缺陷、价值误导输出，厂商承担整改与赔偿责任。
4. 监管机构：开展教育AI产品备案、内容抽检、算法偏见审计，对违规产品责令下架整改。
5. 学生：遵守学术诚信规则，不得利用AI完成闭卷测验、直接抄写完整答案；主动辨别AI内容真伪，向教师、监护人反馈AI错误输出。
五、确权板块交叉适用规则
1. AI原生生成的习题解析、范文初稿归入数据资产保护层；教师加入独创性教学设计、结构性改写批注后，触发权属快照，教师新增独创性部分纳入著作权保护层。
2. 学生独立完成的作文、探究成果，即便借助AI思路启发，学生享有著作权；直接完整复制AI生成文本，不产生学生著作权，判定为学术不端。
3. 学习交互卷宗、学生原始作业本身不属于人机协同创作成果，不适用权属快照，优先适用未成年人数据保护与教育管理规则。
4. 权属快照仅用于学习成果归属判定，快照不能替代学业评价，不免除教师育人监护责任。
六、禁止性规则
1. 禁止AI直接输出完整作业答案诱导学生抄录，放任认知外包。
2. 禁止面向未成年人提供虚拟亲属、虚拟伴侣等拟人亲密交互服务。
3. 禁止静默更新知识库、模型，规避教育伦理与内容评审。
4. 禁止隐瞒AI幻觉、历史事实错误、内置算法偏见。
5. 禁止未经监护人同意采集未成年人个人信息，或将学生数据用于模型训练与商业推广。
6. 禁止伪装AI身份，隐藏“AI生成”标识，误导学生认为其为真人教师。
7. 禁止使用AI自动判分、自动给出德育价值结论，替代教师人工评价。
七、治理谬误
1. AI全能助教谬误：认为AI可以替代教师，独立完成授课、德育、学业评价。
2. 答案即学习谬误：直接获取AI答案等同于掌握知识，忽视独立思考训练。
3. 拟人共情无害谬误：AI持续情感陪伴不会造成青少年现实社交退缩。
4. 算法中立谬误：认为AI输出内容客观无偏见，无需人工价值审核。
5. 快照替代学业成果谬误：将权属快照等同于学生真实学业能力证明。
6. 低龄开放使用谬误：小学生可无监督自由使用开放式大模型生成功能。
全局铁律
AI为学习辅助工具，育人主体归于师长；分学段分级管控，严防认知外包与算法偏见；AI身份显性标注，价值内容人工复核；防范情感依赖，守住学术诚信，认知风险触发熔断。
