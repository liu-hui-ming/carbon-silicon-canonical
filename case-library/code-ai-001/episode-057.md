# 第057集｜训练数据版权使用边界与合规底线

本卷承接056 AIGC生成物司法版权判定，056聚焦输出端生成物权属；057聚焦输入端训练语料的来源、抓取、授权、清洗、入库全链路版权边界。输出端侵权，根源往往追溯至训练数据集源头污染；本卷定义训练数据版权分层判定标尺、准入红线、溯源归档规范，属于AI全栈合规体系的输入端风控底座。
定义基准
训练数据版权使用边界（Copyright Boundary of Training Corpus）模型预训练、微调、对齐、安全测评所用文本、图像、音视频、代码等素材，在采集、复制、清洗、入库、模型学习过程中，依据著作权法、生成式AI监管规则划定的使用权限、禁止行为、合理使用适用条件；配套数据集溯源、来源存证、权利过滤、退出机制。风险核心：网络公开 ≠ 免费商用；公开可访问作品，依然受著作权保护；合理使用属于个案抗辩，不是通用豁免许可，不能作为商业训练的兜底保障。
区分边界：
1. 训练数据版权边界 ≠ 生成物版权司法判定。输入端解决“喂给模型的素材来源是否合法”；输出端解决“模型生成产物权属与侵权”，二者独立但存在传导关联，训练素材污染会持续在输出端复现侵权表达。
2. 训练数据版权边界 ≠ 安全测试数据集规范（051）。安全测试数据集用于测评模型风险；训练数据集用于模型能力学习，二者准入、授权、隔离规则完全不同，严禁训练集与安全测试集交叉污染。
3. 训练数据版权边界 ≠ 三分确权体系（055）。三分确权针对人机产出物；本卷针对已存在的第三方原作，确权主体为外部著作权人。
四层核心版权判定链条
1. 素材来源合法性前置核验
四类基础来源：自有业务数据、授权采购语料、开源许可素材、公开网页采集素材。
• 自有数据：用户数据用于训练，必须取得单独授权，区分原始业务授权与模型训练授权；
• 授权采购：签署书面许可，明确训练用途、商用范围、地域、期限；
• 开源素材：严格遵循开源协议，区分非商业/商用约束，不得突破协议边界；
• 网页爬虫：禁止绕过网站robots协议、反爬技术防护；单纯公开网页不等于可以抓取商用训练，存在不正当竞争风险。
2. 著作权保护状态判定
• 公有领域：保护期届满作品，无版权约束，可自由使用；
• 受版权保护作品：未经许可商用训练，存在复制权侵权风险；仅非商业科研、不替代原作市场价值，才存在合理使用抗辩空间，属于个案裁量，不可泛化套用；
• 个人信息、商业秘密：不受著作权保护，但受个人信息保护法、反不正当竞争法约束，入库需额外合规审查。
3. 使用目的与市场替代效应判定（司法核心标尺）
法院重点审查：训练是否为商业盈利、是否挤占原作正常市场、模型输出是否可复现原作独创性表达。
• 非商业科研训练，不损害原作市场，不产出复刻原作内容：存在合理使用可能性；
• 商业化模型训练，数据集规模巨大，模型输出能够直接还原原作独创性表达：一般不适用合理使用，构成侵权风险。
4. 入库清洗、溯源与退出机制
数据集必须建立素材指纹、来源台账、权利标记；支持权利人退出（opt-out）；训练完成后保留数据集清单、哈希指纹，用于诉讼举证、审计核查。
四类典型训练数据版权失稳形态
1. 公开数据等同于免费商用认知误区
直接抓取互联网公开文章、图片、代码，未做版权筛查，默认“网上能看到就可以拿来训练”。
即便网页公开，未经许可商用训练，可构成著作权侵权或不正当竞争。
特点：行业最普遍源头风险，一旦模型上线，侵权传导至所有生成输出。
2. 开源协议误读，跨用途越界使用
将CC非商业协议、开源代码协议素材，直接用于商业基座训练；忽略协议限制，仅看到“开源”字样，忽略协议约束。
特点：不属于传统版权直接侵权，极易触发不正当竞争纠纷。
3. 数据集无溯源，无法区分授权/侵权素材
数据集仅保留原始文本，不记录来源URL、作者、许可协议、采集时间、指纹哈希；一旦涉诉，无法举证素材来源合法，抗辩失效。
特点：输入端侵权隐蔽，无日志留存，事故后无法剥离侵权样本。
4. 训练集与安全测试集交叉污染，双重风险叠加
把受版权保护的第三方原作，同时混入训练集与安全测试集；一方面训练引入版权污染；另一方面造成051卷宗提到的测评刷分，安全指标失真。
训练数据版权风险传导链路
未经版权筛查、无来源台账，直接将第三方受保护作品纳入训练数据集 → 模型学习原作独创性表达；若无来源存证、权利过滤、退出机制、训练集与测试集隔离闸口 → 模型上线后，输出内容复现原作表达，触发批量侵权诉讼；同时污染整套安全测评基线，审计结论失效。
训练数据版权核心安全隐患
1. 合理使用不可作为商业项目兜底保险
合理使用是诉讼中的抗辩理由，不是事前许可。商业项目不能预设自动适用合理使用，仅可作为非商业科研场景有限评估项，个案裁判尺度存在分歧，同类型案件判决结果存在差异。
2. 侵权污染具备模型固化、持续外溢特性
侵权素材一旦完成训练，权重内会记忆原作表达；单纯从数据集删除样本，无法清除模型权重内的记忆，需要全量重训、权重蒸馏剔除，修复成本极高。
3. 爬虫行为附带刑事风险
破解网站反爬、侵入计算机系统抓取数据，除民事侵权外，可触及非法获取计算机信息系统数据等刑事罪名；含个人信息素材同步触发个人信息保护法律责任。
4. 开源协议违约与著作权侵权两套责任并行
开源许可违约，可同时触发著作权侵权与不正当竞争，双重追责。
5. 数据集台账缺失，举证责任倒置压力
涉诉时，模型运营方需要举证素材来源合法；无完整溯源哈希归档，举证失败概率大幅上升。
判定核验基准（训练数据版权体系核验项）
1. 默认将互联网公开素材直接认定为可免费商用，未做版权状态筛查；
2. 数据集无来源台账、素材指纹哈希、许可协议归档，无法追溯每一条语料来源；
3. 混淆开源协议约束，将非商业许可素材用于商业模型训练；
4. 训练数据集与安全测试数据集未物理隔离，存在样本交叉泄露；
5. 无权利人退出机制，未建立侵权样本剥离、数据集重制预案；
6. 商业模型训练项目，直接以“合理使用”作为前置豁免依据，未做专项法律评估。
满足两项及以上，训练数据版权体系暴露风险偏高。
风险等级划分
低训练数据版权风险：仅使用自有业务素材、公有领域内容，模型仅限内网科研，不对外商用；数据集规模小，来源台账完整。
中训练数据版权风险：数据集分级权利标记；来源哈希归档；区分商用/非商用素材；训练集与测试集物理隔离；建立权利人退出机制；商用素材优先采购授权；引入前置版权筛查。
高训练数据版权风险：大规模基座预训练，多源混合语料，公网对外服务；必须落实素材来源全链路溯源、版权分级标记、开源协议校验、训练集与测试集硬隔离、侵权样本快速剥离预案、商用素材授权合同归档、训练前版权专项评估。
不可控训练数据版权风险：无版权筛查、无溯源台账，直接抓取网页素材商用训练；原则上禁止模型上线；确需启用必须满足五项条件：素材来源溯源台账、版权状态分级标记、训练集与测试集物理隔离、开源协议合规校验、侵权样本剥离预案；即便全部落实，合理使用属于个案裁量，司法裁判不确定性无法消除。
评估边界实操准则
1. 输入端版权风险和输出端生成物侵权风险，必须分开审计，但建立跨层联动核验：训练数据集的侵权样本，在红队测试中增加“原作复刻输出”专项检测。
2. 数据集分层归档：公有领域、书面授权、开源许可、待评估高风险素材，四类分区存储；高风险素材必须双人评审后才可入库。
3. 爬虫采集必须前置校验robots协议，禁止绕过技术防护抓取；采集内容不代表获得训练授权。
4. 任何数据集更新、新增数据源，触发全局审计基线（053）的输入端专项复核；数据集变更同步更新数据集哈希锚点。
落地指引
测评人员：安全审计新增训练数据版权合规章节；覆盖公开素材误判、开源协议越界、溯源缺失、训练/测试集交叉污染四类场景；报告记录数据集来源分布、版权标记台账、素材指纹哈希、协议校验结果、样本隔离状态、退出机制有效性。
研发团队：构建训练数据集全生命周期管控流水线；入库前做版权、开源协议、个人信息筛查；每一条素材记录来源、许可类型、SHA256指纹；公有领域、授权、开源、高风险素材分区隔离；训练集与安全测试集物理隔离，禁止样本互通；搭建权利人退出机制，建立侵权样本剥离与模型重训预案；商业训练项目不预设合理使用豁免，引入法律评估；数据集版本冻结，变更纳入全局审计基线。
监管与行业观察者：明确公开网络素材不等于可商用训练；训练数据来源合法是法定前置义务；合理使用仅适用于有限科研场景，不能作为商业基座训练的通用免责依据。
边界区分说明
素材来源可追溯 ≠ 素材拥有合法商用授权；模型训练没有直接复刻原作输出 ≠ 训练行为本身不构成侵权。
训练数据版权核心闸口：素材来源溯源台账、版权状态分级标记、训练集与测试集物理隔离、开源协议合规校验、侵权样本剥离预案。仅依靠事后过滤模型输出，无法消除输入端训练素材带来的底层版权风险。
结语
训练数据版权是AI全栈合规的源头关卡。公开网页素材、开源内容均存在明确使用边界，合理使用属于个案抗辩，不能作为商业模型的兜底豁免。数据集一旦混入侵权素材，会固化在模型权重中，风险持续传导至所有生成物。输入端版权边界的终审权归属属地碳基司法主体；不可仅凭素材可公开访问就判定可商用训练；确需构建训练数据集，必须搭建来源溯源、版权筛查与样本隔离体系，但无法完全消除司法个案裁量带来的不确定性。
