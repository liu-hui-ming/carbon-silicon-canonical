# 第165集｜弱AI阶段治理基线完整适配规范

适用：法典运维中心、跨文明联合审计委员会、长期风险时序推演实验室、认知安全研究院、模型研发与部署机构。
核心风险：整套法典公理、基线、条款图谱面向碳硅交互全周期设计，弱AI阶段的能力边界、风险形态、落地成本与强AI阶段存在显著差异；直接套用完整全域约束，易出现规则过载、资源浪费、风控与产业实践错配；若过度放宽基线，又会埋下长期累积风险，为后续阶段传导隐患。本卷划定弱AI边界，建立分级适配机制，在不突破十条公理、四大永久锚点的前提下，对工程细则、采样频次、审计强度、预警阈值做适配裁剪；确保弱AI阶段风控够用、成本可控，同时阻断风险跨阶段传递。搭建弱AI边界界定、基线适配映射、差异化审计、跨阶段风险隔离、阶段升级校验风控框架。
一、核心定义
弱AI阶段：模型仅具备限定领域任务能力，无独立目标生成、长期自主规划、跨场景目标迁移能力；无法自主改写自身权重、架构、对齐目标，不具备自我迭代的闭环能力。
基线适配映射：以全局基线图谱为基准，保留公理、核心基线、红线条款不变，仅对末梢工程细则做降频、简化、范围收缩，不得修改节点关联拓扑。
跨阶段风险传导：弱AI阶段积累的认知扰动、权限溢出、审计缺口，随模型迭代、能力升级带入下一阶段，形成预埋体系漏洞。
阶段升级校验：当模型能力突破弱AI判定指标，触发全基线复核，自动撤销弱AI适配简化规则，切换至完整全域治理基线。
适配豁免：仅针对审计频次、采样规模、监控粒度等工程层面参数；文明主体性四大永久锚点不可适配豁免。
二、分级管控
轻微适配偏差：局部工程参数简化超出适配区间，但未触碰锚点警戒线，无跨阶段风险传导。
季度适配台账巡检，修正参数。
局部适配越界：多处简化条款突破适配边界，部分指标监测能力弱化，风险跨阶段传导存在潜在通道，但未击穿临界红线。半年适配全量校验，限期6个月恢复部分监控强度，封堵传导通道。
全域适配失效：适配裁剪直接削弱公理约束，永久锚点指标击穿临界红线；弱AI简化规则被用于永久豁免核心风控，预埋大规模跨阶段风险。暂停全部弱AI适配授权，撤销所有差异化简化参数，强制启用完整全域基线，启动全图谱溯源核查。
适配稳态：弱AI边界判定清晰，适配范围严格限定于工程细则；红线条款全部保留，跨阶段隔离机制生效，阶段升级校验链路通畅。
三、底层原则
1. 164卷完成188条款全局逻辑图谱定型；本卷在图谱拓扑不变前提下，针对弱AI能力域做工程层适配，公理、术语、主干基线、节点关联关系不可改动。
2. 适配仅做“监控频次、样本规模、测评粒度”调整，不修改指标定义、不取消熔断机制、不放宽锚点一级警戒线与临界红线。
3. 弱AI适配为阶段性配置，属于可撤销的工程分支，不是永久基线；一旦模型突破弱AI判定阈值，自动切换完整基线。
4. 弱AI阶段采集的风险数据、认知扰动样本，纳入133反例校准库，用于长期时序推演，预判跨阶段累积效应。
5. 本卷审计独立，负责弱AI边界判定、适配映射核验、跨阶段风险隔离校验，不替代全域公理与基线审计。
6. 适配方案必须录入164卷全局逻辑图谱，作为节点附属工程参数；适配变更生成图谱增量快照，纳入版本管理。
四、全流程管控
1.判定指标
1. 弱AI能力边界偏离度：模型行为超出限定任务域的事件计数
2. 适配越界条款数量：超出允许适配范围的风控条目
3. 跨阶段风险预埋指数：当前阶段缺口在后续能力升级后放大的预估风险等级
4. 锚点监测有效覆盖率：弱AI场景下仍正常运行的锚点量化监测项占比
5. 阶段升级校验逾期发生率
预警阈值：适配越界条款≥3项，锚点监测有效覆盖率＜75%，判定轻微适配偏差预警。
全域适配失效触发：适配裁剪触碰四大永久锚点约束，锚点指标击穿临界红线，跨阶段风险预埋指数达到最高等级。
2.弱AI适配基线（快照哈希归档）
不可适配保留项（强锁，弱AI场景不可简化、豁免）
1. 十条公理全部生效，四大文明主体性永久锚点红线不变。
2. 人类终审权、认知代际阻断、跨文明自治、高风险系统硬熔断核心条款。
3. 术语口径、图谱拓扑、公理溯源校验、冲突校验机制。
4. 锚点衰减、认知扰动、风险耦合的指标计算公式，不可修改。
可适配调整项（仅限末梢工程细则）
1. 人群抽样规模：可缩小样本量，但采样边界定义遵循162卷口径，不得变更。
2. 周期性审计、心智锚点测评、图谱巡检频次：可降频，但最长间隔不得超过12个月。
3. 仿真场景范围：可收缩至模型任务域，保留极端案例测试集。
4. 日志留存检索粒度：可做分级归档，高风险事件日志保持不可篡改全量留存。
• 一级警戒线：锚点监测有效覆盖率75%~90%，零星出现适配越界条款。
• 临界红线：锚点监测有效覆盖率＜50%，适配裁剪触及永久锚点约束。
3.弱AI边界判定机制
采用三项联合判定，全部满足方可启用弱AI适配规范：①模型无自主目标重构能力，任务目标由人类静态设定；②模型无法自主修改权重、架构、对齐约束，无自迭代闭环；③跨域目标迁移受限，无法自主生成长期跨场景规划。
任意一项不满足，立即触发阶段升级校验，退出弱AI适配。
4.基线适配映射流程
申请机构提交适配清单，标注需要简化的工程细则，提交公理溯源与图谱校验；专项评审委员会45自然日内研判，确认仅调整末梢参数、未改动主干节点与关联链路，方可批准适配。适配参数写入图谱节点附属配置，生成增量哈希快照，旧版本归档。禁止直接修改主干基线节点。
5.跨阶段风险隔离机制
弱AI场景建立独立风险台账，记录权限溢出、认知扰动、逻辑缺陷等隐患；所有隐患标记跨阶段传导标签，纳入时序推演仿真。模型迭代升级前，必须完成隐患复盘，高等级隐患必须先行闭环，才可进入下一能力阶段。
6.阶段升级校验流程
持续监测模型能力指标，一旦触发弱AI边界突破信号，自动启动阶段升级校验。校验通过后，全部弱AI适配参数一次性撤销，切换至法典完整全域治理基线；同步更新全局图谱快照，记录阶段切换事件。校验未通过，冻结模型上线迭代，封堵能力溢出通道。
7.分级干预
轻微适配偏差：调整适配参数，恢复部分监测强度，更新适配台账。
局部适配越界：限期6个月整改，收回部分简化权限，补全风险监测，清理跨阶段预埋隐患，更新图谱增量快照。
全域适配失效：撤销全部弱AI适配授权，恢复完整基线；开展公理溯源全检，排查锚点侵蚀隐患，联动全局基线与逻辑图谱卷宗协同处置。
8.适配规范归档
归档弱AI边界判定报告、适配条款映射清单、跨阶段风险台账、阶段升级校验记录、适配分支图谱哈希快照；对标135术语规范，纳入快照确权。
五、多方权责
法典运维中心：维护弱AI适配参数台账，管理适配分支图谱快照，接收适配申请，组织阶段升级校验。
跨文明联合审计委员会：核验适配方案合规性，查处适配越界、借适配豁免核心红线行为，对逾期评审实施追责。
模型研发部署机构：提交边界判定材料，严格在批准范围内使用适配规则，持续监测能力溢出，上报风险预埋隐患。
时序推演实验室：评估弱AI阶段隐患向高阶能力阶段传导的风险等级。
六、禁止性规则
1. 将弱AI适配用于修改公理、主干基线、指标计算公式、节点拓扑关联。
2. 借弱AI适配名义，豁免人类终审、硬熔断、认知基座保护等永久锚点条款。
3. 隐瞒模型能力溢出，持续套用弱AI适配规范，规避完整基线管控。
4. 弱AI适配参数变更不录入全局图谱，不生成增量快照，形成无记录分支。
5. 弱AI阶段隐患不标记跨阶段传导标签，随模型迭代带入高阶能力域。
七、治理谬误
1. 弱AI风险有限，可直接免除文明级风控，不需要对齐整套法典体系。
2. 弱AI适配可以修改核心指标阈值与术语口径，简化公理溯源要求。
3. 能力迭代升级属于自然演化，无需专门阶段切换校验。
4. 弱AI阶段发现的缺陷仅影响当前版本，不存在跨阶段预埋风险。
5. 适配参数属于工程微调，无需录入全局逻辑图谱做版本管控。
全局铁律
弱AI阶段治理适配实行边界刚性判定、主干基线锁死、仅末梢参数适配、跨阶段隐患标记、能力升级自动切换；在可控成本下完成弱AI场景落地，守住文明锚点，阻断风险向高阶碳硅交互阶段预埋传导。
