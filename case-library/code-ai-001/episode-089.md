# 第089集｜金融AI信贷评估的权责与风险边界

本卷承接088金融AI风控公平性卷宗，聚焦信贷授信、贷前评估、贷后风险预警场景，厘清AI信贷评估工具的能力边界、机构与客户权责划分，管控评估高估低估、黑箱授信、贷后预警误报、责任转嫁、数据越界采集五大风险，建立分级自动审批、人工复核、风险溯源的治理框架。本卷可与058确权取证卷宗、模型生命周期卷宗交叉调阅核验；金融AI信贷评估事项优先适用本卷，与确权板块条文并行适用，冲突时以本卷信贷评估权责规则优先。
一、核心定义
金融AI信贷评估系统：基于客户征信、资产、收入、履约行为、交易数据，生成信用评估分、违约概率预判、授信建议的AI模型。AI仅输出评估参考意见，授信审批、放款决策的最终法律与业务责任，由持牌信贷机构承担，不得向AI、模型厂商转嫁。
评估虚高：模型低估客户违约概率，给出偏高授信额度，放大信贷资产损失风险。
评估虚低：模型高估客户违约概率，压缩合理授信额度，侵害具备履约能力客户的融资权益。
分级审批权限
L1低风险：小额标准化信贷，AI评估后全自动审批，保留复核抽检机制；L2中风险：中等额度信贷，AI给出评估建议，必须人工复核核心要素后方可授信；L3高风险：大额、经营性信贷，AI评估仅作为辅助参考，以人工尽调、线下核验为核心。
分级额度边界：由监管机构设定统一上限参考值，机构可向下调减额度阈值，不得向上调高；额度划分需结合机构资本充足率、历史不良率、业务品类，写入机构正式业务制度。
信贷评估卷宗：包含客户授权材料、输入特征清单、AI评估原始分值、模型版本、人工复核记录、贷后预警日志、客户申诉材料、数据更正记录；卷宗最低保存期限不少于五年，不良纠纷、监管核查案例永久归档。
信贷评估熔断机制：模型检出评估偏差超标、特征异常漂移、关键信息缺失，触发熔断，暂停该客户或批量业务的自动化审批，转入人工尽调，排查模型与数据问题。
评估可解释说明：向客户告知授信额度、审批结果的核心影响因素，区分客观征信数据、收入资产、行为指标，不使用笼统模糊表述。
二、底层权责原则
1. 机构主体责任不可转移：AI评估仅为辅助工具，信贷机构不能以“AI自动评估”为由免除授信审查、尽职调查、风险处置责任。
2. 分级审批，高额度强人工：额度越高、业务风险越高，人工尽调权重越高，严控全自动审批适用范围。
3. 数据最小必要：仅采集信贷评估必需信息，不得采集与履约风险无因果关联的个人信息。鼓励在隐私计算框架下开展跨机构多头借贷风险核验，严禁共享与信贷风险无关的个人信息。
4. 评估动态校验：定期比对模型预测违约概率与实际逾期结果，校验模型校准度，识别评估虚高或虚低。
5. 客户知情权、异议权与数据更正权：客户有权知晓评估影响因子，对评估结果提出异议；对输入数据存在错误可提交证明材料申请更正，更正后触发重新评估。
6. 自动化决策退出权：客户有权拒绝AI自动化评估，申请全流程人工审核；机构不得因此抬高费率、压低授信额度，仅可合理延长审批时限。
三、信贷评估全生命周期权责管控规范
1. 贷前模型投产与准入
1. 模型上线前完成校准测试与公平审计（同步适用088卷宗），检验模型高估、低估偏差；预测偏差超出阈值不得投产。
2. 严格执行监管参考上限约束，划定L1/L2/L3分级审批额度边界，写入业务制度；L3高风险业务禁止全自动审批。
3. 模型特征、评估逻辑、偏差校验报告存入信贷评估卷宗。
2. 贷前客户申请与AI评估阶段
1. 采集客户信息必须取得客户明示授权，告知数据用途、评估使用的指标类型；禁止未经授权抓取第三方隐私数据。
2. AI输出评估分值、授信建议，L1业务可自动出结果，但机构后台持续抽样复核；L2、L3业务，人工核验身份、收入、资产真实性，不能直接采信AI评估结论。
3. 关键资料缺失、信息矛盾时，直接触发熔断，停止自动化评估，交由人工核实。
4. 客户提出数据更正申请并提供有效证明材料，机构须在规定时限内核验修正输入数据，完成后触发模型重新评估；更正后评估结果优于原结果的，应当追溯调整授信决策，相关记录完整归档入卷宗。
5. 客户明确提出拒绝AI评估、要求全人工审核的，机构应当受理，不得设置歧视性条件。
3. 授信决策、结果告知与客户申诉
1. 最终授信决策由信贷机构人员确认；AI评估意见仅作为参考，不构成最终审批依据。
2. 审批结果向客户提供可解释说明，列明影响评估的核心因素。
3. 客户提出异议申诉，脱离原模型自动判定，由独立复核团队重新核验资料与评估逻辑，复核记录归档。集中同类异议时启动模型专项校验。
4. 贷后预警、模型迭代与下线
1. AI贷后风险预警仅作为风险提示，预警信号必须人工核实，不可直接自动抽贷、降额。
2. 定期回溯模型预测与真实逾期数据，监控模型漂移；模型结构、特征、样本重大变更，重新开展校准与公平审计，禁止静默上线。
3. 模型下线后，存量客户评估记录、卷宗持续留存，用于纠纷回溯。
四、多方主体权责划分
1. 持牌信贷机构：信贷评估第一责任主体。划定分级审批边界，执行人工复核，校验模型评估偏差，处理客户申诉、数据更正申请；因模型滥用、未尽复核义务造成资产损失或客户权益受损，机构承担全部责任。
2. 模型研发厂商：交付模型校准报告、已知偏差边界；不得承诺模型评估结果绝对准确；不得干预机构授信决策。模型厂商交付的模型若存在未披露的已知偏差，造成机构重大损失，厂商承担违约责任与相应赔偿责任；故意隐瞒模型缺陷与偏差的，承担惩罚性责任。厂商承担合同层面责任，但不替代机构承担信贷业务法律责任。
3. 内部风控审核人员：对L2、L3业务履行人工尽调、资料核验职责，对AI评估结果开展独立研判。
4. 监管机构：开展模型校验抽查、卷宗核查，设定分级额度参考上限，对越权使用全自动审批、责任转嫁、数据违规采集行为实施监管处置。
5. 客户：如实提交申请材料，有权查询评估影响要素，申请数据更正、拒绝AI自动化评估、对不合理评估结果提交申诉。
五、确权板块交叉适用规则
1. AI原生生成的评估打分脚本、特征筛选方案归入数据资产保护层；风控工程师构建独创信贷评估框架、风险分层逻辑重构，触发权属快照，人类独创性新增部分纳入著作权保护层。
2. 客户信贷资料、评估决策日志、信贷评估卷宗不属于人机协同创作成果，不适用权属快照，优先适用金融监管、个人信息保护规则。
3. 权属快照仅用于模型开发成果载体归属判定，快照不能替代模型校准校验，不免除信贷机构信贷审查主体责任。
4. 模型底层权重权属判定参照模型生命周期卷宗条款；公平性约束同步适用088卷宗。
六、禁止性规则
1. 禁止将信贷授信、放款决策法律责任转嫁AI模型或模型开发厂商。
2. 禁止大额高风险经营性信贷启用全自动AI审批，跳过人工尽调。
3. 禁止采集与信贷履约风险无关的个人信息用于评估。
4. 禁止隐瞒模型评估虚高、虚低偏差，未做校准直接投产。
5. 禁止仅凭AI预警信号，未经人工核实直接自动降额、抽贷。
6. 禁止静默更新模型特征、训练数据集，规避模型校准与公平审计。
7. 禁止拒绝向客户披露信贷评估核心影响因子，仅返回模糊审批结论。
8. 禁止删除、篡改AI评估记录、人工复核台账与申诉卷宗。
9. 禁止机构调高监管给定的分级审批额度参考上限，将本该人工复核的业务划入全自动通道。
10. 禁止因客户申请全人工审核，实施提高费率、压低授信额度等歧视对待。
11. 禁止在客户提交有效数据更正证明后，拒绝核验、拒绝重新开展信贷评估。
七、治理谬误
1. 模型预测准确即无需人工复核谬误：AI评估分值达标，就可免除线下尽调。
2. AI评估即最终责任主体谬误：信贷出现违约，责任归于AI模型。
3. 一次性校准永久有效谬误：上线完成模型校验，后续不持续监测评估漂移。
4. 预警信号等于事实风险谬误：贷后AI预警触发，可直接采取信贷处置措施。
5. 快照替代模型校验谬误：权属快照证明模型归属，等同于评估结果可信合规。
6. 分级额度可随意设定谬误：机构可自主随意放大全自动审批额度，规避人工复核。
7. 跨机构协同即数据共享谬误：多头借贷风险核验等同于无限制交换客户隐私信息。
全局铁律
AI信贷评估仅作参考，持牌机构承担全部授信责任；分级额度受监管上限约束，大额业务必须人工尽调；定期校验模型高估低估偏差，异常触发熔断；保障客户评估解释、数据更正、拒绝AI评估的权利；鼓励隐私计算下跨机构风险联防；权属快照区分成果归属，不可免除机构信贷尽职审查义务。
