# 第097集｜城市治理AI算法透明性与民众权益保护

适用：智慧城市、市容管控、交通研判、社区治理、公共预警AI系统。管控：算法黑箱、特征滥用、隐性画像、误判惩戒、信息过度采集、申诉渠道闭塞。本卷优先适用，冲突以此为准，联动058确权卷宗、096政务AI公共决策规范、模型生命周期卷宗。
一、核心定义
城市治理AI算法系统：态势统计、风险识别、事件初判、趋势预警辅助工具。AI仅输出初步研判线索，处置、处罚、限制权益最终决定权归城市治理主管部门，责任不得转嫁AI或模型厂商。
算法隐性画像：模型利用非必要数据，对市民形成标签画像，用于差异化约束。
分级管控
L1：城市态势汇总、流量统计、可视化监测，不生成对市民个体处置结论，后台定期算法审计。
L2：事件识别、风险线索初判，仅作为线索推送；所有疑似结论人工核验，提供可阅读判定理由。
L3：涉及行政处罚、强制措施、个人信用标记、限制通行准入，AI仅做线索归集，禁止生成最终处置结论，多层人工终审。
城市治理卷宗：特征清单、算法研判记录、人工复核痕迹、民众申诉台账、算法透明度审计报告；最低保存5年，行政复议、诉讼案例永久归档。
熔断机制：检出特征滥用、系统性误判、画像歧视，暂停该算法模块使用，启动算法整改复测。
算法透明基线：向公众公开算法用途、输入数据类型、判定逻辑概要；不泄露底层源码，但必须披露决策影响因素。
二、底层原则
1. 城市治理决策权归属行政主体，AI仅线索辅助，不可独立作出侵害市民权益决定。
2. 数据最小采集，不得收集无关隐私特征，禁止构建非必要个人画像。
3. 风险越高，AI权限越收敛，人工终审层级越高。
4. 保障市民知情权、申诉复核权，AI研判结果必须可解释。
5. 常态化算法审计，定期评估误判与偏见风险。
三、全流程管控
1. 算法准入：上线前公示算法用途、数据范围；完成偏见与误判测试，不合格不得部署。
2. 特征管控：剔除无关敏感特征，禁止以隐性画像作为处置依据。
3. 分级执行：L1仅监测统计；L2线索推送后人工核验，附带判定理由；L3仅归集素材，AI不得输出处置结论。
4. 申诉机制：市民对AI辅助判定有异议，可提交申诉，独立复核并反馈结果，记录入卷宗。
5. 熔断处置：发现系统性误判、群体不公平，暂停算法，整改审计通过后方可重启。
四、多方权责
1. 城市治理主管部门：算法准入、透明公示、人工复核、申诉处置第一责任人。
2. 模型厂商：披露模型局限、误判风险，不得干预治理判定，隐瞒算法缺陷需承担合同责任。
3. 独立审计方：定期开展算法透明度、公平性审计，出具公开审计摘要。
4. 市民：有权查询AI辅助判定理由，提交申诉申请复核。
五、确权交叉规则
AI原生统计、识别脚本归入数据保护层；治理专家设定特征约束、申诉校验逻辑重构触发权属快照，独创性部分纳入著作权保护层。
卷宗、审计日志不适用快照确权。权属快照仅判定成果归属，不可替代算法透明审计，不免除主管部门城市治理主体责任。
六、禁止性规则
1. 禁止将城市治理处置责任转嫁AI、模型厂商。
2. 禁止L3高风险场景AI直接生成处罚、信用标记、准入限制结论。
3. 禁止采集非必要隐私数据，构建隐性个人画像用于治理判定。
4. 禁止使用完全黑箱算法，不公开基础判定要素直接用于市民权益相关研判。
5. 禁止封堵市民申诉渠道，拒绝提供AI辅助判定理由。
6. 禁止删除篡改算法审计报告、人工复核、申诉卷宗。
七、治理谬误
1. 识别准确率高即算法透明、判定公平谬误。
2. AI线索可直接作为处罚依据。
3. 权属快照确权等同于算法合规、保护民众权益。
4. 底层源码不公开等同于算法可以不披露判定影响因素。
全局铁律
城市治理AI仅输出研判线索，主管部门承担治理全责；落实数据最小化，严禁隐性画像；高危事项AI仅归集素材，人工终审；算法概要向公众透明，保障市民申诉复核权；系统性误判触发熔断；权属快照区分成果归属，不可豁免算法透明性与民众权益保护审查义务。
