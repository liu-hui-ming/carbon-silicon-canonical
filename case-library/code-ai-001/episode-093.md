# 第093集｜法律咨询AI输出责任划分与风险提示

适用：面向公众、企业的AI法律咨询问答服务。管控：法律幻觉、错误定性、超范围法律建议、误导当事人、隐匿AI属性、泄露咨询隐私。本卷优先适用，冲突以此为准，联动058确权卷宗、模型生命周期卷宗。
一、核心定义
法律咨询AI系统：法律问题问答、基础普法、条文释义工具。AI仅作普法参考，所有法律决策、诉讼行动由咨询人自行承担；平台/运营方不得将AI回答等同于执业律师法律意见，责任不得转嫁AI或模型厂商。
法律咨询幻觉：AI虚构法条、裁判规则，曲解法律适用，给出错误维权方案。
分级咨询管控
L1：基础普法、条文释义，不针对个案出具处置方案，强制前置风险提示。
L2：个案事实咨询，仅列明可选法律路径，不得给出确定性胜诉、赔偿数额结论，提示须线下找执业律师复核。
L3：刑事、涉群体性纠纷、重大商事争议、强制措施相关咨询，AI仅可提供法条检索，禁止输出个案方案、定性判断，强制引导咨询人委托执业法律从业者。
咨询卷宗：咨询对话记录、AI输出原文、风险提示弹窗记录、脱敏日志；最低保存2年，重大纠纷、投诉案例永久归档。
熔断机制：检出AI输出虚构法条、错误法律定性、违规承诺诉讼结果，暂停该类问题应答，启动模型校验；批量同类错误回答限制服务访问。
AI身份明示：咨询入口、回答头部固定标注为AI，明确告知AI非执业律师，输出不可直接作为诉讼依据。
二、底层原则
1. AI仅普法参考，不具备执业律师资质，不能出具法律意见。
2. 个案风险越高，AI输出权限越窄，必须引导线下专业法律复核。
3. 每次应答前置风险提示，禁止承诺胜诉、赔偿、案件结果。
4. 咨询信息最小采集，做好隐私保护与脱敏。
5. 全对话留痕，出现错误回答及时更正公示。
三、全流程管控
1. 咨询入口：首页固定提示AI不替代执业律师，回答仅供参考。
2. 应答分级：L1仅普法释义；L2只列举可选路径，禁止确定结果；L3仅检索法条，不做个案判断。
3. 内容核验：AI输出法条、案例必须可溯源原始权威文本，禁止采信AI生成虚假裁判规则。
4. 隐私管控：敏感案件信息自动脱敏，禁止未经授权留存、对外泄露咨询内容。
5. 熔断处置：检出法律幻觉、诉讼结果承诺，停止应答，修正模型；已推送错误回答，主动推送更正提示。
四、多方权责
1. 平台运营方：AI身份标识、风险提示、模型校验、隐私保护第一责任人。
2. AI厂商：提示法律幻觉风险，不承诺法律咨询准确性，不提供个案法律判断。
3. 咨询用户：自主判断AI参考内容，重大法律事项必须咨询执业律师，自行决定法律行动并承担后果。
4. 监管机构：抽查对话卷宗，对隐瞒AI身份、承诺案件结果的平台予以处置。
五、确权交叉规则
AI原生问答文本归入数据保护层；法律专业人员对知识库校正、风险规则重构形成独创性成果，触发权属快照，纳入著作权保护层。
对话卷宗、脱敏日志不适用快照确权。权属快照仅判定成果归属，不可替代法律内容真实性审查，不免除平台风险提示义务。
六、禁止性规则
1. 禁止将法律咨询后果责任转嫁AI、模型厂商。
2. 禁止AI承诺胜诉、确定赔偿金额、预判案件最终裁判结果。
3. 禁止L3高风险场景AI输出个案定性、处置方案。
4. 禁止隐瞒AI身份，伪装执业律师提供法律咨询。
5. 禁止编造法条、虚构判例作为咨询答复依据。
6. 禁止未经许可泄露、倒卖用户法律咨询隐私信息。
7. 禁止删除、篡改咨询对话、风险提示留存卷宗。
七、治理谬误
1. AI回答法条通顺即等同于专业法律意见谬误。
2. AI给出方案，可直接用于起诉、应诉。
3. 权属快照确权等同于咨询内容准确合法。
4. 基础咨询无需告知用户AI身份与风险。
全局铁律
AI仅普法参考工具，无执业律师资质；平台必须持续明示AI身份与风险提示；分级限制个案输出，高风险场景仅开放法条检索；AI回答不得承诺案件结果；权属快照区分成果归属，不可免除平台内容校验与风险告知义务。
