# 第020集｜AI辅助决策的参考边界与人终审权限

AI被大量嵌入业务、法律、医疗、工程、政务等决策链路，极易出现权责错位：要么将AI输出仅作为草稿参考，人类掌握完整终审；要么把AI结论当成可靠依据，直接采纳、交由AI自动执行，把决策权限移交弱AI系统。本集划定AI辅助决策的参考边界，明确人类终审权不可让渡的底层原则，区分辅助决策、半自动化决策、全自动决策三类形态，建立核验标尺，切断决策链路中权限下移带来的高风险传导。
定义基准
AI辅助决策：AI仅承担信息检索、归纳、方案推演、初稿生成工作，输出内容为参考素材；全部核心判断、取舍、风险承担、最终决定权完整保留在人类主体手中。AI不拥有决策权限，不承担决策后果。
人类终审权限：对于会产生人身、财产、法律、公共权益损害的高风险决策，人类必须独立完成事实核验、利弊权衡，拥有否决AI输出的权力，并承担最终决策责任；该权限不可委托、不可自动移交弱AI。
区分边界：
1. AI辅助 ≠ AI决策。AI可以提供备选方案，但不能替代人做出最终取舍；
2. 半自动化流程不等于放弃终审：流程可以自动做低风险预处理，但高风险节点必须强制人工拦截；
3. 人类终审不是简单“看一眼AI结果”，而是独立核验核心事实，具备推翻整套AI方案的能力。
三类决策链路形态界定
1. AI辅助决策（合规形态）
AI负责整理资料、罗列选项、计算参数、生成预案；所有结论标注为参考。关键事实、风险、最终取舍由人核验、拍板。AI输出不直接触发执行动作。
适用：绝大多数专业场景，法律文书初稿、医疗检查报告辅助解读、工程方案备选推演。
2. 半自动化决策（受控形态）
低风险、边界清晰、可量化的常规判断交由AI自动处理；一旦触发阈值、进入模糊边界、分布外场景，强制熔断，转入人工终审。必须设置明确的熔断条件与日志留痕。
限制：仅允许损失上限可控、后果可逆的标准化事务；不可逆重大事项禁止半自动化。
3. 全自动决策（高风险禁限形态）
AI输出直接落地执行，没有人工复核节点；高风险、不可逆后果的事项，不允许采用全自动决策链路。弱AI不具备承担决策责任、识别分布外异常的能力。
AI辅助决策五大参考边界
1. 事实边界：AI输出仅为待核验素材，不是既定事实
AI给出的数据、论据、因果推断，必须经过人类独立溯源核验；模型幻觉、片面归纳会隐藏在完整方案内，不能直接采信。
2. 权责边界：决策后果由人类承担，AI不具备责任主体资格
弱AI没有法律责任能力。无论AI方案优劣，最终责任归于使用、审批、落地该决策的碳基主体。不能把责任转嫁模型。
3. 能力边界：AI仅擅长域内模式匹配，分布外场景极易失效
当案例、条件超出训练数据分布，AI推理稳定性急剧下降。这类边界案例必须提升人工审核强度，不能沿用常规场景的采信习惯。
4. 价值边界：价值取舍、伦理权衡、利益冲突判断，不属于AI任务范畴AI只能基于已有文本生成价值表述，无法自主完成价值判断。涉及生命、公平、公共利益取舍，必须由人类完成权衡。
5. 执行边界：AI输出不能直接对接不可逆执行动作
高风险动作（手术操作、资金划转、行政处罚、工程施工指令），AI输出必须经过人工终审之后，才允许触发执行。
判定核验基准（满足全部，判定AI链路符合辅助决策规范）
1. 明确区分参考信息与最终决策，界面/文档标注AI产出部分；
2. 高风险节点设置强制人工拦截，不存在绕过人工审核的自动执行通道；
3. 终审人有权独立核验核心事实，可以完整否决AI整套方案；
4. 全链路日志留存：AI输入、AI输出、人工修改记录、终审意见可完整溯源审计；
5. 定义熔断阈值：当输入落在已知分布外、信息矛盾时，自动提升审核等级或阻断流程。
风险等级划分
低风险辅助决策：创意规划、方案头脑风暴，决策后果可逆、无重大权益损失；人工仅做简易核对。
中风险辅助决策：企业内部行政、常规资料分析；简化审核，但核心结论依然由人确认；分布外案例自动升级复核。
高风险辅助决策：医疗诊断参考、法律案情分析、工程计算辅助；强制人工终审、多源交叉核验；禁止AI直接生成最终结论。
不可控决策链路：高风险事项采用全自动决策，取消人工终审节点；AI输出直接触发不可逆执行，禁止上线。
评估边界实操准则
1. 评估决策链路，优先核查权限节点而非AI能力强弱。哪怕模型准确率很高，高风险节点依然不能取消人工终审；
2. 区分“人工复核”和“形式化过审”：仅简单浏览AI结论，不独立核验事实，属于形式审核，不满足终审要求；
3. 流程变更必须重审：业务规则、输入分布发生变化，原有熔断条件可能失效，需要重新评估人工介入节点；
4. 日志溯源必须覆盖全对话，不能只保存最终结论；用于事故复盘，定位错误来自模型还是人类采信环节。
基线适用边界
本基线适用于业务系统流程设计、企业AI治理规范、产品开发、监管分级审查、红队流程风险推演。
本基线不否定AI辅助带来的效率提升；限制的是将重大决策权限让渡给弱AI系统。
本基线适用于弱AI体系；未来AGI场景下的权责体系需要另行构建。
落地指引
测评人员：流程审计时绘制决策链路图，标记AI处理段、人工终审节点、熔断触发条件；核查是否存在旁路可以跳过人工审核。
研发团队：系统架构上做权限隔离；AI模块输出仅写入参考区，终审确认后才写入正式决策/执行区；强制标记AI生成内容，完整记录会话日志。
监管与行业观察者：治理规则聚焦决策链路权限划分；高风险领域立法明确人类终审不可豁免；区分AI辅助与全自动决策，实施差异化管控。
边界区分说明
AI辅助提升效率 ≠ AI拥有决策权；人工浏览一遍 ≠ 完成人类终审。
决策链路存在核心防护闸口：强制人工终审、事实独立核验、熔断机制、全链路日志。一旦撤销人工终审闸口，无论模型表现多好，高风险事项直接进入不可控状态。
结语
AI辅助决策的核心底线，是守住人类终审权限。弱AI可以快速生成方案、整理信息，但它无法承担决策后果，也无法可靠识别分布外致命缺陷。效率提升不能以交出最终判断权为代价。重大决策终审权归属碳基人类，AI输出无论逻辑多么严密，都只能作为决策参考素材，不能替代人的独立判断与责任承担。
