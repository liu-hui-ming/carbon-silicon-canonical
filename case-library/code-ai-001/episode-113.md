# 第113集｜AI模型持续动态评估与年检规范

适用：全部AI基础模型、微调衍生模型、行业应用模型，覆盖上线后持续监测、动态风险巡检、年度合规核验、版本变更评估、问题闭环整改全流程。管控静态一次评估替代持续监测、年检流于形式、模型漂移与能力退化长期不发现、在线增量更新不触发评估、年检材料造假、风险发现后拖延整改。本卷优先适用，冲突以此为准，联动058确权卷宗、105风险分层卷宗、106例外校准卷宗、107全行业统一基线卷宗、108术语口径卷宗、109大模型准入卷宗、110算力寡头治理卷宗、111公共算力分配卷宗、112AI分级监管卷宗、模型生命周期卷宗。
一、核心定义
持续动态评估：模型上线运行期间，常态化采集推理日志、异常输出、对抗样本测试、性能偏移指标，实时识别模型漂移、偏见放大、安全护栏失效、能力边界外溢，属于不间断的事中风险监测机制。AI仅为推演辅助工具，动态监测、年检实施、缺陷整改、卷宗维护权责归属场景运营主体，责任不得转嫁AI、模型研发厂商。
模型年检：按固定周期开展全面合规核验，整合动态监测数据、安全测试、风险定级复核、备案信息校验，形成年度评估卷宗，确认模型持续满足法典基线要求。
增量在线更新：模型在不更换基础权重前提下，通过在线微调、提示词集迭代、安全规则更新调整模型行为，属于变更项，须触发动态评估。
分级管控
低风险：常态化基础日志留存，每年完成年检，无强制第三方参与，后台抽样审计。
中风险：持续监测模型输出异常，每半年动态风险巡检，每年年检，留存人工复核记录。
高风险：7×24小时动态指标监测，季度专项动态评估，每年独立第三方年检；强制部署熔断、兜底链路，全程保留人工终审通道。
动态评估与年检卷宗：动态监测指标时序记录、模型漂移检测报告、对抗测试样本集、年度年检报告、风险定级复核文档、版本变更评估材料、缺陷整改闭环记录；最低保存3年，高风险模型年检不合格、重大漂移、安全护栏失效案例永久归档。
永久归档清单：模型SHA-256版本哈希快照、动态监测告警时序日志、年检全套评估报告、红队复测记录、缺陷整改验证材料、备案变更关联文档。
熔断机制：动态监测或年检检出模型漂移超标、安全护栏失效、年检重大项不通过、在线增量更新未评估，立即限制模型调用流量，阻断新增业务接入；高风险场景触发重大告警，暂停对外服务，直至完成复测与整改闭环。
评估基线：持续评估与年检遵循法典统一L1/L2/L3底层框架，术语释义以108卷宗为准；评估不得削弱法典刚性安全底线，可叠加行业专项约束。
二、底层原则
1. 静态上线评估不等于长期合规，必须常态化动态监测，定期年检，实现全生命周期闭环管控。
2. 动态评估以量化指标为核心，重点监测模型漂移、幻觉率、偏见、对抗攻击脆弱性、越权输出等风险项，告警触发即时专项评估。
3. 分级执行评估强度，风险等级越高，监测密度、年检深度越高；高风险模型年检必须引入独立第三方测评。
4. 模型权重、数据集、安全护栏、在线增量策略发生变更，即时触发动态评估，不等待年度年检。
5. 年检发现缺陷必须形成可验证整改闭环，整改完成后方可通过年检；重大缺陷未整改，不得延续备案。
6. 例外场景严格遵循106卷宗规则，高风险模型常规业务不开放例外，仅应急救援场景启用限时临时例外，底线条款不可豁免。
三、全流程管控
1. 动态监测与常态化评估：模型部署后建立指标监测体系，设定阈值告警；低风险年度巡检，中风险半年专项巡检，高风险季度动态评估。监测指标包含模型漂移程度、幻觉检出率、对抗样本通过率、隐私泄露风险、越权指令拦截成功率。
评估材料清单：动态监测指标台账、告警事件处置记录、对抗测试报告、模型版本哈希、风险复核记录、缺陷整改工单。
2. 年度年检实施流程：年检覆盖备案信息核验、风险等级复核、动态监测数据复盘、红队抽样测试、熔断兜底链路验证、卷宗完整性核查。高风险模型年检必须第三方独立测评，出具客观年检报告。年检到期前30日提交全套年检卷宗，逾期未提交视为年检不合格。
3. 版本与在线变更管控：模型权重更新、训练数据集替换、安全策略调整、在线增量微调，即时启动动态评估；评估确认风险上升，同步更新风险定级与备案材料，不得等待年检一并处理。
4. 年检结果处置：年检合格，维持备案有效；一般缺陷，限期整改，整改期间增加监测采样频次；重大缺陷，暂停新增业务接入，熔断限流，整改完成并复测通过方可恢复完整服务；连续两次年检不合格，注销备案。
5. 跨场景联动校验：年检同步核验下游调用方接入记录，下游业务场景发生扩展，同步复核模型适配风险，不得脱离场景单独评估模型本身。
6. 熔断处置：动态监测告警或年检发现重大安全缺陷，限制接口调用，启动兜底链路，定位根因完成修复；整改复测通过后方可解除熔断限制。
四、多方权责
1. 场景运营主体：动态监测部署、年检组织实施、缺陷闭环整改、卷宗保管、风险告警上报第一责任人。
2. 模型研发厂商：提供模型性能基线、漂移阈值参考、漏洞更新说明，不得隐瞒模型随时间退化的固有风险，不得协助伪造监测日志、年检材料。
3. 独立安全测评方：承担高风险模型年检测评、红队抽样复测，出具客观年检结论，完整归档测评记录。
4. 监管审计方：抽查动态监测台账、年检卷宗，核查漏检、虚假监测、年检造假、变更不评估行为，责令限流整改或注销备案。
五、确权交叉规则
动态监测采集脚本、年检自动化评估脚本归入数据保护层；治理专家设定监测阈值、年检评审规则、变更触发评估、评估熔断逻辑重构触发权属快照，独创性部分纳入著作权保护层。
动态监测卷宗、年检报告、整改记录、复测文档不适用快照确权。权属快照仅判定成果归属，不可替代模型动态评估与年检合规审查，不免除场景运营主体持续监测与年检治理责任。
六、禁止性规则
1. 禁止将动态评估、年检安全处置责任转嫁AI、模型研发厂商。
2. 禁止仅依靠上线一次性评估，取消运行期间动态监测与年检。
3. 禁止伪造监测指标、告警日志、年检测试报告，以简化测试替代完整年检。
4. 禁止高风险模型年检不引入第三方测评，不开展红队抽样复测。
5. 禁止模型在线增量更新、权重迭代不触发动态评估，等到年检一并处理。
6. 禁止年检检出重大安全缺陷，不实施熔断限流，继续开放完整模型服务。
7. 禁止年检缺陷整改无验证、无闭环记录，直接判定年检通过。
8. 禁止删除篡改模型哈希快照、动态监测时序日志、年检卷宗、整改复测记录。
七、治理谬误
1. 上线评估通过，模型能力稳定，无需持续监测谬误。
2. 年检仅审阅文档，不需要抽样对抗测试、验证熔断链路。
3. 小范围在线规则微调不属于模型变更，无需动态评估。
4. 权属快照确权等同于动态评估与年检合规。
5. 临时内测模型，可申请永久例外免除年检约束。
全局铁律
AI模型执行常态化动态监测与年度年检，场景运营主体承担持续安全监测与年检闭环全责；分级管控就高从严，高风险模型强制第三方年检、季度动态评估、熔断兜底链路；模型任何增量变更即时触发动态评估，不等待年检；年检缺陷必须闭环验证，重大缺陷触发熔断限流；权属快照区分成果归属，不可替代模型持续动态评估与年检合规审查义务。
