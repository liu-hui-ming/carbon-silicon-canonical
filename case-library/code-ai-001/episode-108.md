# 第108集｜行业治理核心术语全局口径锁定

适用：法典全部卷宗，统一全部核心术语定义，消除跨卷语义歧义、一词多解、概念错位，为风险定级、卷宗归档、熔断判定、确权审计提供唯一参照释义。管控：同词异义、概念随意延展、术语窄化/泛化解读、口头释义替代书面口径、跨卷宗概念冲突。本卷优先适用，冲突以此为准，联动058确权卷宗、105风险分层卷宗、106例外校准卷宗、107全行业统一基线卷宗、全部行业分卷、模型生命周期卷宗。
一、核心定义
全局锁定术语库：法典所有卷宗共用的标准化术语集合，本卷为唯一权威释义文本；任何分卷解读、审计、卷宗撰写，必须遵从本卷口径，不得自行衍生释义。AI仅为推演辅助工具，术语应用、场景判定、风险定性的权责归属场景运营主体，责任不得转嫁AI、模型厂商。
术语漂移：同一术语在不同行业卷宗、审计报告、技术文档中被人为修改内涵，造成分级判定、熔断阈值、归档口径出现偏差，引发规则错配。
分级管控
L1：术语仅用于统计归档，释义校验随常规抽样审计开展，不强制专项术语评审。
L2：术语用于辅助研判、方案复核；术语使用必须匹配本卷定义，出现释义争议时启动术语核验。
L3：术语用于人身安全、国家安全、关键基础设施场景的风险定性；术语使用必须前置专业人员交叉核验，释义争议未解决前，不得开展风险定级与系统上线。
术语口径卷宗：术语库全文、术语修订记录、释义争议案例、术语核验记录、版本哈希快照；最低保存3年，重大释义争议、规则错配事故案例永久归档。
永久归档清单：术语库版本快照（SHA-256）、释义争议申请材料、多方评审记录、术语错配导致的事件时序日志、复盘报告、术语修订前后对比文档。
熔断机制：审计或评审检出术语误用、概念泛化/窄化、同词异义且无法当场校准，暂停依托该术语开展的风险定级、审计验收，启动术语溯源核验。
口径锁定基线：法典术语一经定稿，常规场景不得随意修改；术语修订必须走完整评审流程，生成新版本哈希快照，全卷宗同步更新，旧版本存档备查。
二、底层原则
1. 术语释义主权归属法典基准卷宗，所有行业分卷必须引用本卷口径，不得私自改写核心术语内涵。
2. 术语采用最小必要释义，不随意扩大适用范围，不删减约束边界；一词一义，杜绝一词多解。
3. 风险等级越高，术语使用的核验强度越高；L3场景术语争议未解决，禁止推进定级、上线。
4. 术语修订属于重大基线变更，触发全法典联动复核，留存版本哈希快照，旧版本不可销毁。
5. 建立术语争议处理流程，所有争议案例入库，作为后续术语校准样本。
6. 建立季度术语扩充机制，持续补齐法典高频术语，避免术语库覆盖缺口。
三、全流程管控
1. 术语准入：新增术语必须提交释义申请，执行术语冲突判定规则，核验与现有术语库无冲突，经评审入库，生成唯一版本哈希。
术语冲突判定规则：新增术语与已有术语语义重叠度超过30%视为冲突，须合并或更名；新增术语内涵为已有术语子集，须作为子类而非独立术语；新增术语与已有术语边界模糊，须提交边界澄清材料，经评审方裁决。
版本号规范：术语库版本号采用主版本.次版本.修订号格式；主版本号变更代表术语内涵重大调整；次版本号变更代表新增术语；修订号变更代表释义文字微调。所有卷宗引用术语，必须在文档首页标注「依据术语库vX.X.X」，版本号不匹配的卷宗不得通过审计。
哈希算法标准：术语库版本哈希统一采用SHA-256算法；快照须包含术语库全文、版本号、更新时间戳、修订说明、评审方签名；哈希值在法典官方渠道公开可查，用于卷宗引用版本核验。
术语争议处理时限与裁决机制：术语争议受理后，评审方须在5个工作日内出具初步核验意见；重大争议（涉及L3场景定级、跨卷宗冲突）须在15个工作日内组织多方评审并出具终局裁决；裁决期间，相关场景暂停定级与上线；裁决结果纳入术语争议案例库永久归档。
2. 法典核心术语权威释义（全局锁定）
• AI幻觉：模型输出脱离真实数据源、客观事实、物理规则的生成内容；分为文本幻觉、感知幻觉、物理推演幻觉。
• 模型漂移：模型长期运行，输入数据分布随时间变化，预测/识别结果持续偏离实测真值，偏差突破预设阈值。
• 多源交叉校验：两个及以上相互独立的数据源/传感器，经时空对齐校验，结论一致方可采信；单源检出目标标记低置信度。
• 熔断：系统检出风险告警，自动收缩AI权限、退出闭环控制，切换至人工/传统兜底链路。
• 兜底链路：独立于AI模型之外的传统控制、人工处置通道，AI失效时可独立接管业务，不可由AI复用权重。
• L1/L2/L3分级：法典全域统一风险三级框架，L1只读监测；L2辅助方案推荐；L3高危场景，禁止AI自主下发强干预指令。
• 权属快照：对模型、创作成果做归属判定；归属判定≠安全合规判定。
• 数据脱敏：抹除、遮蔽原始数据内可定位、涉密、敏感特征，使得脱敏后样本无法逆向还原原始敏感信息。
• 例外场景：有限临时权限，一事一议，绑定时间锁与场景边界；人身安全、国家安全、兜底熔断等底线条款不可豁免。
• 全链路留痕：采集输入、模型版本、AI输出、人工审批、告警、熔断、指令流完整时序日志，可回溯复盘。
• 场景运营主体：AI应用落地运行、风险定级、安全治理、卷宗维护的第一责任主体。
• 模型研发厂商：模型算法、权重、知识库的开发提供方，负责披露模型固有风险，不得协助规避安全基线。
• 独立安全测评方：第三方独立机构，开展风险核验、跨域迁移测评、熔断冗余机制有效性评估，输出客观测评报告。
• 监管审计方：开展卷宗抽查、合规核验、查处规则滥用行为的监督主体。
• 内容传播主体：对外发布AI生成图文音视频内容的个人、平台、MCN机构，承担AI标识与风险提示的传播责任。
• 压力仿真：针对极端工况、故障注入、边界条件开展模拟测试，验证系统熔断、兜底链路有效性。
• 感知幻觉：AI视觉/传感识别类幻觉，对图像、传感数据做出不符合客观现实的识别判断。
• 文本幻觉：AI文本生成类幻觉，编造事实、史料、参数、数据。
• 物理推演幻觉：AI仿真推演违背物理定律、工程约束输出推演结果。
• 特征泄露：模型权重、训练样本中携带涉密、敏感特征，可被逆向萃取还原。
• 越权指令：AI输出超出业务允许权限范围的执行、调度、处置指令。
3. 术语库扩充机制：每季度开展一次术语评审，梳理法典全部卷宗高频未锁定术语，完成释义、冲突校验、版本更新，同步更新全局术语库，避免语义缺口。
4. 分级执行映射：L1术语使用后台抽样核查；L2出现释义争议启动术语核验；L3术语使用前置交叉评审，争议未解决暂停定级。
5. 术语版本管理：术语库每次更新生成SHA-256哈希快照；所有卷宗引用术语，标注术语库版本号。
6. 熔断处置：检出术语误用、概念泛化，暂停定级与验收，组织评审校准；完成术语修正与复测后方可恢复流程。
四、多方权责
1. 场景运营主体：卷宗、项目文档内术语使用合规核验第一责任人。
2. 模型研发厂商：编写技术文档时，严格遵循法典术语口径，不得自定义同义替代释义。
3. 术语评审方：受理术语争议、新增术语评审、版本更新、影响范围评估，执行冲突判定、时限裁决。
4. 监管审计方：抽查卷宗，核验术语使用一致性，查处术语私自篡改、概念泛化问题。
五、确权交叉规则
术语库原生文本、术语比对脚本归入数据保护层；治理专家设定术语边界、争议判定、版本管控逻辑重构触发权属快照，独创性部分纳入著作权保护层。
术语评审、版本快照、争议卷宗不适用快照确权。权属快照仅判定成果归属，不可替代术语口径合规审查，不免除运营主体术语规范使用责任。
六、禁止性规则
1. 禁止将术语释义、场景定性责任转嫁AI、模型厂商。
2. 禁止私自修改核心术语内涵，不得自行创造替代释义。
3. 禁止在L3高危场景，在术语释义存在争议时开展风险定级与上线验收。
4. 禁止术语修订不做全法典联动影响评估，直接更新术语库。
5. 禁止使用旧版术语库开展新项目审计、定级，版本不匹配。
6. 禁止将术语归属快照等同于术语释义合规、场景定性准确。
7. 禁止删除篡改术语版本哈希、争议评审记录、术语核验卷宗。
七、治理谬误
1. 文字含义相近，术语可以互相替换，无需对齐口径谬误。
2. 小场景使用术语，无需严格匹配法典定义，口头解释即可。
3. 权属快照确权等同于文档术语使用合规。
4. 术语定稿后，发现边界缺陷可直接在分卷局部修改，不用全局评审。
5. 术语库可以长期不更新，不做季度扩充评审。
全局铁律
法典核心术语实行全局唯一锁定口径，运营主体承担术语规范使用全责；一词一义，跨卷宗语义统一；L3高危场景术语争议未解决不得定级上线；术语修订属于基线重大变更，强制全法典联动复核并留存SHA-256版本哈希；建立季度术语扩充机制补齐高频术语；术语误用触发流程熔断；权属快照区分成果归属，不可替代术语口径与场景定性审查义务。
