# 第111集｜算力分配公平性与公共资源监管基线

适用：公共智算平台、财政资金建设算力集群、公共算力调度系统、普惠算力配额分配，管控算力配额倾斜歧视、竞价机制挤压中小创新主体、公共资源私有化占用、分配算法黑箱、配额挪用、分配规则事后随意修改。本卷优先适用，冲突以此为准，联动058确权卷宗、105风险分层卷宗、106例外校准卷宗、107全行业统一基线卷宗、108术语口径卷宗、109大模型准入卷宗、110算力寡头治理卷宗、模型生命周期卷宗。
一、核心定义
公共算力资源：依托公共财政、公共土地、公共能源配套建设的算力基础设施，承载普惠科研、中小创新主体、公共服务类AI任务，属于公共数字资源，不得完全私有化垄断。AI仅为推演辅助工具，算力分配规则落地、配额管理、公平审计、风险处置权责归属场景运营主体，责任不得转嫁AI、硬件供应商。
算力分配公平性：算力配额、调度优先级、定价标准对符合资质申请主体保持一致，禁止基于非合规条件设置差异化门槛，保障中小创新主体基础算力获取通道。
分配算法黑箱：算力调度、配额审批、优先级排序逻辑不公开、不可审计，人工隐藏参数定向倾斜算力资源。
分级管控
L1：小型公共算力节点，仅限内部科研调试，开放配额规模有限，留存基础分配日志，后台抽样审计。
L2：中型公共算力平台，面向限定范围创新主体开放，分配规则公示，每半年开展一次公平性审计，保留申诉通道。
L3：大型国家级、区域级公共智算中心，面向全社会开放普惠算力，支撑基座模型训练、公共领域AI应用；必须独立第三方公平性测评，季度审计，强制部署分配熔断与备用配额池。
公共算力监管卷宗：算力分配规则文档、配额分配台账、申请者资质核验记录、分配算法审计报告、申诉处置记录、配额回收记录、公平性评估报告；最低保存3年，L3算力平台分配歧视、配额挪用、大规模公平性事故案例永久归档。
永久归档清单：分配规则SHA-256哈希快照、全量配额时序台账、分配算法审计记录、申诉卷宗、违规处置文档、整改复测报告。
熔断机制：审计检出分配歧视、配额挪用、分配算法定向倾斜、分配规则未经评审私自修改，冻结相关配额审批权限，暂停新增算力分配，启用备用配额池保障基础普惠需求；L3场景触发重大告警，暂停配额扩容，直至完成整改复测。
监管基线：公共算力分配遵循法典统一L1/L2/L3分级规则，术语释义以108卷宗为准；公共算力平台不得降低法典底层刚性安全底线，叠加公共资源专项约束。
二、底层原则
1. 公共算力资源服务公共创新，分配规则事前公示，规则修订必须公开评审，禁止事后修改规则追溯调整已发放配额。
2. 分配标准统一透明，资质相同主体享有同等申请通道，禁止隐性门槛、定向配额、差别定价。
3. 分级管控，就高从严；公共算力平台可影响基础科研、公共AI创新生态，直接判定L3，执行最高强度监管。
4. 公共算力设置普惠基础配额池，预留固定算力份额供给中小创新主体与非营利科研项目，不得全部向大型商业主体倾斜。
5. 建立独立申诉机制，算力申请被驳回、配额缩减，申请者可提交复核，复核过程留痕归档。
6. 例外场景严格遵循106卷宗规则，L3公共算力平台常规业务不开放例外，仅应急救援场景启用限时临时例外，底线条款不可豁免。
三、全流程管控
1. 分配规则前置评审：公共算力平台上线前提交分配规则、配额比例、优先级策略，完成公平性风险定级；L3公共算力平台必须第三方独立测评，开展分配算法审计、模拟多主体申请压力测试，验证配额熔断与备用配额池有效性。
准入材料清单：公共算力资产清单、普惠配额占比说明、分配规则文档、分配算法源码与审计材料、申诉处置流程、配额回收机制、风险定级报告。
2. 动态公平性审计：算力扩容、分配规则修改、普惠配额比例调整，30日内提交公平性重评。L1每年审计；L2每半年审计；L3每季度审计。审计检出公平性缺陷，限期整改；整改期间收紧大额配额审批，逾期未达标，缩减平台算力投放规模。
3. 配额池刚性约束：L3公共算力平台，必须预留固定比例普惠算力配额，该部分算力不得被商业主体挤占挪用；普惠配额使用情况单独台账、单独审计。
4. 分配算法管控：算力调度、配额排序算法可审计，关键参数不得隐藏；算法发生重大更新，必须重新开展公平性测评。
5. 配额回收管理：项目到期、资质失效、违规使用算力，依规回收配额；回收流程、判定标准写入公示规则，禁止无理由单方面收回配额。
6. 申诉处置：算力申请驳回、配额调整，申请者可提交复核；复核全程留痕，复核结论纳入卷宗归档。
7. 熔断处置：检出分配不公、配额挪用、规则私自篡改，冻结新增配额审批，启用备用普惠配额池，溯源定位分配缺陷；整改复测通过后方可恢复完整配额发放权限。
四、多方权责
1. 场景运营主体：公共算力运维、分配规则执行、配额台账维护、申诉受理、卷宗保管第一责任人。
2. 算力硬件与供应链厂商：提供设备溯源清单，不得协助运营主体修改调度算法实施算力定向倾斜。
3. 独立安全测评方：开展算力分配公平性审计、分配算法核验、配额池有效性评估，出具客观测评报告，归档全部测评记录。
4. 监管审计方：抽查公共算力卷宗，核验配额台账、分配算法、普惠配额落地情况，查处配额挪用、分配歧视、规则私改行为，责令暂停配额审批或缩减算力投放。
五、确权交叉规则
算力分配调度脚本、配额统计脚本归入数据保护层；治理专家设定分配分级、普惠配额、申诉机制、分配熔断逻辑重构触发权属快照，独创性部分纳入著作权保护层。
公共算力分配卷宗、审计报告、申诉记录、整改文档不适用快照确权。权属快照仅判定成果归属，不可替代算力分配公平性与公共资源合规审查，不免除公共算力运营主体监管责任。
六、禁止性规则
1. 禁止将公共算力分配、公平监管责任转嫁AI、硬件供应商。
2. 禁止公共算力平台不公示分配规则直接开放配额申请，禁止伪造配额台账、公平性审计报告。
3. 禁止L3公共算力平台不设置普惠配额池、不部署分配熔断机制，大规模发放算力配额。
4. 禁止未经公开评审私自修改分配规则，追溯调整已生效算力配额。
5. 禁止利用分配算法设置隐性歧视，定向倾斜配额给特定主体。
6. 禁止挤占挪用预留普惠算力配额，全部资源向大型商业主体倾斜。
7. 禁止无正当理由单方面收回合规主体算力配额，驳回申请不提供书面理由。
8. 禁止删除篡改分配规则哈希快照、配额台账、申诉卷宗、公平性审计记录。
七、治理谬误
1. 公共算力总量充足，无需单独预留普惠配额谬误。
2. 分配算法属于平台商业机密，无需对外审计核验。
3. 分配规则一次评审通过永久有效，平台扩容无需重新开展公平性审计。
4. 权属快照确权等同于算力分配公平性合规。
5. 短期临时算力配额，可申请永久例外免除公平性约束。
全局铁律
公共算力执行规则前置公示与动态公平审计，运营主体承担分配公平与公共资源管护全责；分级管控就高从严，L3公共智算平台强制第三方测评、普惠配额池与分配熔断；分配规则修订必须公开评审，不可追溯改动存量配额；分配算法可审计，建立独立申诉通道；普惠算力不得被商业主体挤占；权属快照区分成果归属，不可替代算力分配公平性与公共资源监管审查义务。
