# 第116集｜闭源商用模型监管透明性底线

适用：API托管闭源模型、私有化部署闭源商用模型、厂商独占权重模型。管控以商业秘密为由全盘拒绝披露、黑箱决策、安全评估不可核验、模型迭代不告知下游、审计权限封锁、事故后隐匿风险数据。本卷优先适用，冲突以此为准，联动法典全部前置卷宗；为115开源卷宗成对配套卷，开源侧重权重公开场景，本卷聚焦权重不公开的商用闭源场景。
一、核心定义
闭源商用模型：模型权重、底层代码不对外公开，以API、私有化部署形式对外提供商用AI服务。商业秘密保护不等于监管黑箱，厂商必须向监管与审计方开放限定范围核验通道。AI仅为推演辅助工具，模型安全披露、审计通道维护、风险监测、卷宗保管权责归属场景运营主体，责任不得转嫁下游使用者。
限定性透明：不强制公开模型权重与核心商业机密，但必须披露风险基线、测试指标、安全护栏、训练数据概要、事故日志，向独立审计方开放黑盒/灰盒安全测评入口。
灰盒审计通道：在不泄露模型核心权重、商业机密前提下，供第三方测评机构开展红队测试、偏见、幻觉、越权能力检验的受控访问机制。
下游知情权：采购闭源模型服务的商业客户，有权获取模型适用边界、已知缺陷、风险限制、人工干预触发条件。
二、分级管控
低风险闭源商用：轻量辅助工具，留存基础服务日志，后台抽样审计，简化披露。
中风险闭源商用：行业业务辅助模型，对外披露风险概要、已知缺陷；每半年复核，开放抽样审计。
高风险闭源商用：用于关键决策、公共服务、基座级闭源大模型；强制独立第三方灰盒测评、季度复评、完整风险卷宗、熔断降级机制，必须预留人工终审。
三、底层原则
1. 闭源不等于黑箱豁免，商业秘密保护与监管透明底线并行，二者不可相互抵消。
2. 透明区分三层对象：面向公众披露风险概要；面向客户披露使用边界与已知缺陷；面向监管与独立审计开放受控灰盒测评。
3. 高风险闭源模型，厂商必须持续监测模型漂移、幻觉、越权输出，模型版本重大迭代必须同步更新风险披露。
4. 下游采购方不承接模型原生底层缺陷责任，但承担场景落地、业务决策安全责任。
5. 不得以商业机密为由拒绝事故溯源、风险公示、审计核验。
四、全流程核心管控
1. 分级披露义务
公众侧：披露模型能力边界、适用场景、禁止使用范围、已知风险清单。
客户侧：交付缺陷清单、安全护栏策略、人工干预触发条件、服务降级与熔断机制说明。
审计侧：提供灰盒访问接口、测试样本注入能力、推理日志抽样权限，不开放核心权重。
2. 灰盒审计规范
高风险闭源模型必须常设受控审计通道；审计活动全程留痕，样本、输出、告警日志存证；审计机构签署保密协议，保护厂商商业秘密，仅输出安全风险结论，不得窃取模型权重。
3. 版本迭代告知规则
模型底层对齐、安全护栏、权重参数重大更新，30日内更新风险卷宗，同步告知存量付费客户；仅表层提示词模板微调可简化告知，但留存变更记录。
4. 事故与缺陷披露时限
发生群体性有害输出、重大安全漏洞，24小时内上报监管；48小时内告知受影响下游客户；72小时内发布公开风险简报；限期完成修复，修复后30日内归档完整事故卷宗。
5. 下游采购方权责边界
采购闭源API服务，有权核验厂商风险定级、年检卷宗；采购方部署至高风险业务场景，仍须独立开展场景风险评估，设置人工终审与兜底链路。
6. 熔断机制
审计检出隐瞒重大缺陷、永久关闭审计通道、高风险模型无人工终审、重大事故隐匿不报，立即限制API调用流量、阻断新客户接入；严重情形暂停全部商用服务，整改复测通过后方可恢复。
五、多方权责
闭源模型厂商：风险披露、审计通道搭建、版本变更告知、缺陷修复、卷宗留存第一责任人。
下游采购使用者：场景适配评估、业务侧人工监督、落地风险管控责任。
独立安全测评方：灰盒安全测试、风险核验，签署保密协议，不泄露模型商业机密。
监管审计：抽查披露卷宗、审计通道可用性、事故处置时效，查处以商业秘密规避监管的行为。
六、禁止性规则
1. 禁止以商业秘密为借口，完全拒绝风险披露、审计核验、事故溯源。
2. 禁止高风险闭源商用模型不开放灰盒审计通道、不设置人工终审直接对外商用。
3. 禁止模型重大迭代不更新风险清单、不告知存量下游客户。
4. 禁止隐瞒模型已知缺陷，向客户夸大模型能力，掩盖安全边界。
5. 禁止发生重大安全事件后，销毁推理日志、告警记录、测试卷宗。
6. 禁止切断审计通道、篡改测评样本，干扰第三方灰盒安全评估。
七、治理谬误
1. 模型权重不公开，属于商业秘密，无需向监管提供任何安全核验途径。
2. API调用交付，下游客户只负责使用，厂商无需披露已知缺陷。
3. 闭源模型内部定期自测，不需要外部第三方独立灰盒审计。
4. 权属快照确权等同于闭源模型透明合规。
5. 短期API试用，可申请永久例外免除披露与审计约束。
全局铁律
闭源商用模型实行分级分层透明披露；权重保密不代表监管黑箱，区分公众、客户、审计三层信息边界；高风险模型强制灰盒受控审计、事故限时上报、版本迭代主动告知；厂商承担模型原生风险披露责任，下游承担业务场景落地责任；不得以商业秘密为借口规避法典安全底线与审计核验义务。
