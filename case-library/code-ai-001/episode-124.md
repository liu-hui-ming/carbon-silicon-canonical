# 第124集｜公共领域AI算法公开与脱敏边界

适用：政务审批、公共救助、医保智能审核、公共资源分配、公共安防、公共教育分诊等公共领域AI系统。管控两种极端风险：一是强制全量开源权重、源码引发模型越狱、对抗攻击、商业技术资产流失；二是借商业秘密名义完全屏蔽公众知情权，算法决策无任何可解释文本，公共决策黑箱化。本卷优先适用，冲突以此为准，联动全部前置卷宗；承接123 AI事故追责卷宗，前卷确立事故取证与追责机制，本卷划定公众摘要公开、监管全量审计、敏感信息脱敏三层差异化透明边界，平衡公共知情权、知识产权、模型安全三者关系。
一、核心定义
公共领域AI算法：由公权力机构采购、部署、运维，用于公共资源分配、资格审核、民生判定、公共治理的AI决策系统。AI仅为推演辅助工具，公开文本编制、脱敏处理、信息分级披露、卷宗留存权责归属运营主体；第三方开发厂商承担技术保密与脱敏校验责任。
三层披露边界：面向社会公众的脱敏摘要；面向监管与持证审计机构的灰盒完整审计入口；仅限厂商内部的核心专有技术、模型权重、防御后门。
算法脱敏：剔除可直接用于逆向破解、模型投毒、对抗越狱的敏感技术参数；保留决策目标、特征维度、打分规则、偏见评估结果，保障公众监督。
最小必要公开原则：公开范围以实现公共监督为限，不额外披露足以被恶意利用实施攻击的底层技术细节。
二、分级管控
低风险公共AI：公共信息展示、内容检索类辅助系统；公开基础运行原理，无需开放决策特征明细，年度复核公开文档。
中风险公共AI：公共服务预约、基础分诊、资源排队分配；公开决策特征清单、打分逻辑摘要、偏见评估结论，半年复核；用户可查询单条决策核心归因要素。
高风险公共AI：救助资格审核、医保智能风控、公共准入、重大公共资源分配；强制完整公开决策规则摘要，向持证高级审计机构开放灰盒归因审计；季度复核，建立专项异议申诉通道。
三、底层原则
1. 公共领域算法不适用“完全源码、权重全公开”，但不得以商业秘密、模型黑箱为由，完全豁免公众知情权。
2. 信息分级隔离：公众获取脱敏摘要；监管与持证审计机构获取完整审计能力；核心权重、专有训练工艺、防御密钥属于脱敏豁免项，不予对外公开。
3. 脱敏不能削减可监督性：脱敏后仍必须证明决策目标、特征来源、群体公平性，不得借脱敏掩盖偏见、歧视逻辑。
4. 公共利益优先：当算法持续造成系统性权益侵害、重大公共风险，监管可启动公共利益审查，扩大审计披露范围。
5. 公开文档与实际运行模型必须对齐，禁止“公示一套规则，后台另一套逻辑”，审计可核验版本一致性。
四、全流程核心管控
1. 三层披露内容清单
① 公众脱敏公开内容（强制公示）：算法用途、决策目标、纳入评估的特征大类、排除特征清单、公平性评估摘要、已知风险、用户异议入口；禁止出现专业技术密钥、完整权重、训练原始数据集、对抗漏洞细节。
② 监管与持证审计机构披露内容：完整特征集、决策阈值、SHAP/LIME归因接口、训练数据质量报告、偏见分组测试结果、模型迭代记录、安全漏洞清单；签署保密协议，仅限合规审计使用。
③ 脱敏豁免项，不向公众披露：模型完整权重、底层源码、专有训练优化方案、安全防护后门、算力调度密钥、可直接触发越狱的漏洞细节。
2. 脱敏刚性校验标准
脱敏交付文档必须通过独立审计核验，满足四项约束：① 公开摘要无法逆向还原模型权重与核心参数；② 公开信息不能直接构造对抗样本、提示注入攻击；③ 公众可见的特征维度与后台实际参与计算特征保持一致；④ 禁止删减受保护特征的偏见评估数据，不得隐瞒群体差异超标结论。
3. 版本对齐与迭代同步机制
公共AI模型发生特征集、决策阈值、打分逻辑重大迭代，30日内同步更新公众公开文档，同步报送监管备案；轻量化性能优化仅内部留痕，无需对外更新。
每次更新后，第三方审计核验公示文本与在线模型逻辑一致性，防止公示与后台两套规则。
4. 个体决策解释权
高风险公共AI作出对公民不利判定，当事人有权获取本次决策的脱敏归因说明，列明影响本次结果的核心特征，不泄露模型底层参数；解释文本通俗化，避免纯专业术语。
5. 公开卷宗与哈希存证
对外公示文档、脱敏报告、版本更新记录、审计一致性核验报告完整留存不少于36个月；每版公开文档做哈希快照固化，防止事后篡改公示文本。
6. 熔断机制
检出公示规则与后台模型不一致、借脱敏掩盖系统性歧视、公开信息泄露模型核心攻击面、拒绝向监管审计机构开放灰盒核验，立即暂停该公共AI对外决策权限；重新完成脱敏与第三方审计，核验通过后方可恢复服务。
五、多方权责
公共运营主体：算法公开、脱敏编制、文档更新、版本对齐第一责任人。
第三方技术厂商：配合审计核验，区分可公开信息与专有技术，不得隐瞒后台算法逻辑。
持证AI审计机构：校验脱敏效果、文档与模型一致性、公平性评估，出具独立核验报告。
监管机构：审查公开内容边界，核查版本一致性，裁决公共利益场景下的披露扩容。
六、禁止性规则
1. 禁止以商业秘密为由，完全屏蔽公共领域AI的决策原理、特征大类、公平评估摘要。
2. 禁止对外公开模型权重、底层密钥、可直接用于越狱攻击的漏洞细节，造成模型安全风险。
3. 禁止公示文档与后台实际运行算法两套逻辑，欺骗公众监督。
4. 禁止借脱敏操作删减、隐瞒偏见检测结果，掩盖群体歧视。
5. 禁止重大算法迭代后，逾期不更新公开说明文档。
6. 禁止篡改、删除公示文档、脱敏报告、版本哈希快照。
七、治理谬误
1. 公共领域AI必须完整开源源码与模型权重才算合规透明。
2. 只要标注商业秘密，公共治理算法就可以完全不对外解释。
3. 公开摘要可以简化修改后台特征，无需与真实模型保持一致。
4. 权属快照确权等同于算法公开与脱敏流程合规。
5. 低风险公共辅助AI，可永久不公开任何基础原理。
全局铁律
公共领域AI算法执行分级有限透明，采用公众脱敏摘要、监管灰盒审计、核心技术豁免三层边界；公开以保障公共监督为最低限度，脱敏以防范模型攻击为底线；公示文本必须与后台运行模型保持版本对齐；高风险公共决策赋予个体脱敏归因解释权；重大迭代同步更新公开材料并审计核验；严禁两套规则、借脱敏掩盖偏见，也禁止无差别全量开放权重源码；公开卷宗长期哈希存证，公共算法透明置于法典比例原则约束之下。
