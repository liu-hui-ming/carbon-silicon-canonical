# 第118集｜跨境算力调度数据出境风险管控

适用：跨境智算调度、跨境任务分发、境外算力承接境内AI训练/推理、境内算力承接境外任务、调度平台负载均衡。管控调度自动漂移隐匿数据出境、拆分任务规避审查、原始数据随计算任务偷渡、境外算力节点窃取数据样本、调度规则动态切换跨境节点、只申报模型而忽略输入输出数据。本卷优先适用，冲突以此为准，联动全部前置卷宗；承接117跨境模型流动卷宗，117管模型权重跨境流转，本卷管控算力调度场景下的数据跨境。
一、核心定义
跨境算力调度：调度平台将AI训练、推理任务分配至境外算力集群，或境外任务导入境内算力执行；算力调度不等于模型跨境，但会驱动输入样本、中间张量、推理日志、输出结果跨境传输。AI仅为推演辅助工具，调度策略审核、数据分级隔离、节点准入、链路存证权责归属场景运营主体，责任不可转嫁算力服务商。
任务拆分规避：把完整数据集切分成微小分片，分批调度至境外算力，规避整体数据出境审查。
张量隐性风险：模型中间计算张量、梯度片段携带原始数据信息，可逆向还原敏感内容。
算力节点白名单：仅经过安全核验、纳入备案清单的境外算力节点，才可承接境内任务。
二、分级管控
低风险跨境算力调度：非敏感离线计算，无个人/重要数据，仅科研场景，提交自评估报告，简化备案；自评估报告须法定代表人签字担责，监管随机抽查比例不低于10%，虚假申报取消简化资格，三年内禁止再次申请。
中风险跨境算力调度：行业商用推理，有限个人数据，核验境外算力节点安全能力，半年复核；原始敏感数据禁止出境，仅允许预处理特征输出。
高风险跨境算力调度：基座大模型训练、关键业务推理，含重要数据或大规模敏感个人信息；强制第三方安全评估、专项出境申报、季度复核、算力节点白名单、数据隔离网关、跨境熔断。
三、底层原则
1. 算力调度以数据属地优先；模型权重不出境，不等于输入数据、梯度、张量不跨境，任务调度与数据出境一体审查。
2. 穿透审查调度编排逻辑，禁止分片拆分、动态切换节点、任务迂回路由规避审查。
3. 原始重要数据、敏感个人信息原则不得出境；确需跨境算力处理，必须完成数据出境安全评估，原始数据与中间张量做脱敏隔离。
4. 境外算力节点必须前置安全核验，节点资质纳入白名单；调度平台不得随机自动路由至未备案境外机房。
5. 调度策略、路由规则、数据过滤逻辑发生重大修改，必须重新开展风险评估，旧备案不可复用。
四、全流程核心管控
1. 调度编排前置审核
提交卷宗：数据分级清单、任务分片策略、跨境路由拓扑、境外算力节点信息、数据脱敏方案、张量防护机制；高风险场景须第三方专项评估。调度系统禁止自动无限制跨境漂移。
2. 数据隔离与张量防护
原始敏感数据留在境内；出境仅允许脱敏特征、计算指令、最终输出结果。
张量防护技术规范：①梯度裁剪——上传梯度须执行范数裁剪，裁剪阈值由第三方审计方核定；②差分隐私注入——梯度须注入经数学论证的噪声，隐私预算ε值不超过监管核定上限；③安全聚合——多参与方梯度须在加密状态下聚合，单节点梯度不可被单独解析；④中间张量脱敏——出境中间层输出须执行特征模糊化处理，防止通过激活值反推输入数据；⑤防逆向验证——审计方有权对防护机制执行梯度反演攻击测试，验证还原率是否低于安全阈值。
3. 境外算力节点准入与白名单动态管理
境外算力节点纳入白名单，核验安全防护、访问权限、数据擦除机制；签订协议，禁止留存、复制、逆向解析境内输入数据，任务结束按约定彻底清除本地缓存。
白名单动态管理：①白名单节点每季度接受一次安全复核，复核不合格立即移除；②节点发生数据泄露、违规留存、逆向解析等行为，立即移出白名单并列入黑名单；③黑名单节点永久禁止承接境内任务；④白名单及黑名单向监管备案，调度平台不得向非白名单节点分发任何任务。
4. 境外算力服务商违约追责
协议须约定违约金与损害赔偿条款，违约金不低于任务价值的三倍；发现违约行为，立即启动熔断，隔离该节点并追溯已执行任务的数据泄露风险；将违约服务商列入黑名单，禁止境内任何主体与其合作；造成重大数据泄露的，依法追究刑事责任。
5. 调度策略变更管控
路由算法、分片规则、数据过滤策略重大更新，30日内重评风险；仅任务负载阈值微调留存变更记录，无需重申报。
6. 链路日志留存约束
任务分发、数据传输、节点调度、数据回收全链路日志留存不少于六个月。
日志留存约束：①跨境调度日志必须在境内服务器留存完整副本；②日志须采用防篡改存储，哈希值同步存证至监管节点；③日志须包含任务ID、数据分级、调度时间、目标节点、传输数据量、张量防护状态、数据回收确认；④境外服务器可同步留存，但境内副本为监管调取唯一有效来源。禁止自动删除跨境调度痕迹。
7. 熔断机制
检出任务分片规避审查、敏感原始数据偷渡出境、未备案境外节点承接任务、张量防护失效，立即切断跨境任务分发、隔离境外算力节点；存量任务终止执行，启动全链路审计，整改复测通过后方可恢复。
五、多方权责
调度平台运营主体：调度策略审核、数据分级隔离、节点白名单维护、链路存证、卷宗留存第一责任人。
境外算力服务商：按协议限制数据留存，禁止私自复制、逆向解析境内数据，承担违约赔偿责任。
独立安全测评方：评估调度路由、数据隔离、张量防护、跨境泄露风险，出具客观评估结论。
监管审计：穿透核查调度编排逻辑，查处分片拆分、动态路由隐匿数据出境行为。
六、禁止性规则
1. 禁止通过任务分片、动态路由、迂回节点，拆分数据规避跨境安全审查。
2. 禁止高敏感原始数据未经评估，随AI任务调度出境至境外算力集群。
3. 禁止调度平台自动路由至未备案、未核验的境外算力节点。
4. 禁止境外算力节点永久缓存、复制、逆向解析境内输入数据、梯度与张量。
5. 禁止调度编排、数据过滤规则重大变更不重新评估，沿用旧备案资质。
6. 禁止销毁跨境任务调度日志、数据传输记录、节点访问卷宗。
七、治理谬误
1. 模型权重保留境内，仅任务调度到境外算力，不存在数据出境风险谬误。
2. 任务切分成微小分片，不属于批量数据出境，无需申报。
3. 算力调度属于基础设施，平台不负责调度路由带来的数据泄露风险。
4. 权属快照确权等同于跨境算力调度合规。
5. 短期测试任务，可申请永久例外免除调度审核与数据出境评估。
全局铁律
跨境算力调度实行数据与任务一体管控；算力调度不等于模型流动，重点防范输入样本、梯度、中间张量隐性出境；穿透核查调度编排，杜绝分片拆分、动态路由规避审查；敏感原始数据原则不出境，境外算力节点实施白名单准入与动态黑名单机制；调度策略重大变更必须重评；张量防护落实梯度裁剪、差分隐私、安全聚合等技术手段；全链路日志境内防篡改存证；不得以“算力外包”的形式绕开法典数据出境安全底线。
