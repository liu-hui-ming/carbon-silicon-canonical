# 第059集｜深度伪造内容风险与传播管控规范

本卷承接058 AI内容溯源卷宗。058定义溯源技术的能力边界；059聚焦深度伪造（深度合成音视频、图像、语音、数字人）的全链路风险分级、前置准入、内容标识、传播限流、应急处置规范。深度伪造属于高风险AIGC子集，具备强欺骗性、裂变传播特征，是认知污染攻击的核心载体，属于文明信息层的高风险管控底座。
定义基准
深度伪造内容（Deepfake）
依托深度学习算法，对人脸、语音、视频、图像等生物特征与实景素材做置换、篡改、虚构生成，产出高度拟真的非真实多媒体内容；分为合规仿真应用与恶意伪造两类。
风险核心：视觉听觉的强临场欺骗性，大幅降低公众信息辨别门槛；溯源标记可被对抗擦除，能够伪装成碳基原生实拍素材，冲击证据真实性、社会秩序、个人人格权与国家安全。
区分边界：
1. 深度伪造管控 ≠ 普通文本AIGC管控。文本伪造欺骗门槛更低但感官冲击力弱；音视频深度伪造具备强感官说服力，风险等级提升，强制标识、身份核验、溯源要求更严苛。
2. 深度伪造管控 ≠ AI溯源技术。溯源是取证技术手段；本卷是从输入素材、生成、标识、分发、传播、下架的全流程管控规则，溯源为管控体系提供证据支撑。
3. 深度伪造管控 ≠ 三分确权体系。确权解决生成物权属；深度伪造管控优先解决生物信息授权、虚假信息传播、人格侵权与公共安全风险。
五层深度伪造全链路判定链条
1. 素材采集前置校验层
使用他人人脸、声纹、生物特征作为合成素材，必须取得主体单独书面同意；禁止未经许可抓取肖像、语音用于合成。区分：公共场景影像≠可用于深度伪造。
• 白名单：本人授权、公有领域素材、匿名化仿真科研素材；
• 黑名单：未经授权的自然人肖像、声纹，涉密场景影像，政务、军警、关键公共人物影像。
2. 算法与用户准入层
深度合成服务使用者落实实名制；算法完成安全评估与备案；建立伦理审查机制。禁止向匿名用户开放高保真深度伪造发布通道。
3. 生成与强制标识层
所有深度伪造产出，必须施加显著可见标识+不可删除数字水印/元数据双标记，提示内容为AI合成；新闻类深度合成内容原则禁止虚假新闻生成。仅科研、影视、教育等合规场景，按协议受控使用。
4. 传播分级管控层
按风险分级限流：
• P0极高风险：仿冒公职人员、关键公共人物、虚假灾情警情、金融虚假信息、涉国家安全伪造，直接阻断发布，留存日志上报；
• P1高风险：普通自然人肖像伪造、色情合成、名誉诋毁，限制公域传播，仅可在受控内网流转；
• P2中低风险：影视特效、教育仿真、艺术创作，强制标识，限制流量推荐，保留举报入口。
5. 应急处置与证据留存层
建立快速下架、辟谣、溯源取证机制；留存生成日志、用户身份、素材快照、水印元数据；侵权或虚假信息爆发时，固定证据、阻断传播链路，移交主管机构。
四类典型深度伪造失稳形态
1. 素材授权缺失，直接抓取生物特征合成
从网络抓取他人人脸、录音，不经本人同意直接生成伪造视频；将公开照片等同于授权素材。
特点：直接侵犯肖像权、个人生物信息权益，民事追责，严重情形触及刑事犯罪。
2. 跳过强制标识，无水印直接对外分发
关闭标识与水印，输出无标记伪造音视频；攻击者后续截图、转码擦除剩余溯源标记，伪装实拍原始素材，用于诈骗、造谣、认知渗透。
特点：最典型黑灰产攻击路径，直接击穿058溯源体系。
3. 传播无分级，算法流量放大恶意伪造内容
推荐算法以流量优先，对P0/P1级伪造内容正常推送，加速裂变扩散；未设置预警熔断阈值。
特点：单点伪造，短时间演变为公共舆情事件。
4. 混淆仿真应用与恶意伪造边界
以“科研、影视创作”为借口，规避审核，制作仿冒他人的伪造内容；反例台账滥用，将恶意伪造归入合规豁免场景。
特点：滥用052反例校准机制，绕过安全闸口。
深度伪造风险传导链路
未经生物特征授权、无强制标识，生成深度伪造多媒体内容；无传播分级熔断机制，算法推荐放大传播；攻击者擦除水印溯源标记 → 伪造内容伪装实拍原生素材；若无素材准入、强制标识、分级限流、应急取证闸口 → 实施电信诈骗、名誉诋毁、公共虚假信息传播，污染卷宗证据，冲击公共认知基座。
深度伪造核心安全隐患
1. 生物信息不可逆泄露风险
人脸、声纹属于敏感个人生物识别信息；一旦入库用于深度伪造，泄露后难以撤回，被反复复用制作伪造内容。
2. 跨媒介伪造，突破传统鉴伪能力
高保真伪造视频，肉眼难以分辨；传统人工核验失效，依赖AI鉴伪，而鉴伪模型同样存在对抗绕过漏洞。
3. 伪造内容可用于卷宗证据伪造
制作伪造影像、录音，冒充原始取证材料，混入审计卷宗，污染整套哈希归档证据链。
4. 责任多层推诿
使用者、模型服务商、分发平台互相割裂；平台以技术中立抗辩，使用者隐匿身份，受害方取证难度极高。
5. 跨境传播，管控边界割裂
伪造内容跨平台、跨境外网流转，溯源链路断裂，国内下架无法阻止境外持续扩散。
判定核验基准（深度伪造管控体系核验项）
1. 使用他人人脸、声纹等生物特征合成，未取得主体单独授权；
2. 深度伪造产出未施加显著标识+数字水印双标记，允许无标记内容对外发布；
3. 无风险分级传播策略，P0/P1高危伪造内容可正常公域分发、算法流量推荐；
4. 未落实使用者实名制，匿名用户可生成并对外发布深度伪造内容；
5. 无应急下架、辟谣、证据留存机制，发生伪造传播事件无法快速阻断；
6. 滥用科研/创作豁免，将恶意伪造归入反例豁免场景，绕过审核闸口。
满足两项及以上，深度伪造管控体系暴露风险偏高。
风险等级划分
低伪造风险：仅限内网科研仿真，不使用第三方自然人生物特征；不对外分发；完整留存日志。
中伪造风险：素材授权审查；强制标识+水印双轨；用户实名；风险分级；举报与应急处置；红队测试伪造鉴伪与水印擦除攻击。
高伪造风险：开放公网深度合成生成与发布；必须落实生物素材单独授权、强制标识+不可擦除水印、用户实名、P0级内容阻断、传播流量熔断、证据归档、跨平台溯源联动。
不可控伪造风险：无素材授权、无标识水印、匿名发布、无传播熔断；原则上禁止深度伪造服务上线；确需启用必须满足五项条件：生物素材授权审查、强制标识+水印、用户实名、风险分级限流、应急取证处置；即便全部落实，对抗转码、截图擦除溯源标记的固有技术边界无法完全消除。
评估边界实操准则
1. 区分“技术仿真”与“恶意伪造”，不以技术本身定性，以素材来源、使用目的、传播场景三重判定风险。
2. 深度伪造内容，必须复用058双轨溯源方案；显著标识面向人类阅读，数字水印/元数据面向机器取证，二者不可互相替代。
3. 深度伪造模块纳入全局审计基线053；算法模型、鉴伪模型、水印方案更新，触发专项安全审计。
4. 合规豁免场景（科研、影视）必须进入052反例校准台账双人复核，限定输出范围，禁止脱离管控对外传播。
落地指引
测评人员：安全审计新增深度伪造风险管控章节；覆盖生物素材无授权、跳过标识水印、流量无分级、滥用豁免四类场景；报告记录素材授权台账、标识水印有效性、风险分级策略、传播熔断阈值、应急取证演练结果。
研发团队：建立生物特征素材准入审核流程，非本人素材必须书面授权；所有深度伪造输出强制附加可视化标识+数字水印；使用者实名核验；构建P0/P1/P2三级传播管控，高危内容阻断发布、限流推荐；留存完整生成日志、素材快照、用户身份元数据；开展红队对抗测试，验证截图、转码对水印的擦除攻击；合规场景纳入反例台账双人复核；定期应急演练，处置伪造内容传播事件；模块变更触发全局审计基线复核。
监管与行业观察者：深度合成内容需遵守《互联网信息服务深度合成管理规定》；生物特征素材使用必须获得单独同意；AI合成多媒体内容应当显著标识，严禁利用深度伪造制作传播虚假新闻、实施诈骗与人格权侵害。
边界区分说明
添加水印 ≠ 水印不可擦除；拥有素材授权 ≠ 可以任意传播深度伪造产物。
深度伪造管控核心闸口：生物素材授权审查、强制标识+数字水印、用户实名、风险分级限流、应急取证处置。仅依靠事后内容检测，无法提前拦截恶意深度伪造的生成与裂变传播。
结语
深度伪造依托高保真多媒体合成，是认知污染攻击的重要载体，风险贯穿素材采集、生成、标识、分发全链路。管控核心不是禁止仿真技术，而是建立素材授权、强制标识、分级限流、证据留存的刚性约束；同时必须正视溯源标记存在对抗擦除的技术边界。多媒体伪造风险边界的终审权归属碳基人类审计与司法主体；不可仅凭技术仿真能力直接开放公网发布；确需部署深度合成能力，必须落实素材授权与双轨标识管控，但无法完全消除跨媒介对抗擦除带来的取证盲区。
