# 第095集｜智能制造AI决策容错与人工终审机制

适用：智能制造工厂、柔性产线、数字孪生、工艺优化AI决策系统。管控：模型漂移、决策偏差、容错阈值滥用、人工终审虚设、故障连锁传导、责任甩锅。本卷优先适用，冲突以此为准，联动058确权卷宗、094工业大模型接入规范、模型生命周期卷宗。
一、核心定义
智能制造AI决策系统：工艺调优、排产调度、设备健康预判、质量缺陷识别辅助工具。AI仅输出决策候选方案，生产变更、设备干预、质量处置最终决策权归人工终审人，安全责任不得转嫁AI或模型厂商。
AI决策漂移：工况变化后模型分布偏移，输出决策持续偏离工艺安全区间。
分级决策+容错阈值
L1：排产规划、趋势监测、质量统计，只读分析，容错阈值宽松；无需人工终审，但后台抽样审计。
L2：工艺小幅参数微调、设备预防性维护建议，设置固定容错边界；超出阈值必须人工终审确认方可执行。
L3：产线重大参数改动、设备启停、高危工况切换，AI仅提供备选方案，无任何自动执行权限，强制人工终审+现场确认；容错阈值设为零，不允许AI自主越界决策。
智能制造决策卷宗：工况数据、AI候选决策、容错阈值配置、人工终审签字、漂移告警记录、故障复盘记录；最低保存1年，安全事故、批量质量事故永久归档。
熔断机制：决策超出预设容错区间、模型漂移超标、连续多轮异常输出，自动冻结AI决策执行通道，切至纯人工模式，启动模型校验。
人工终审：具备工艺资质人员独立核验AI方案，判断工况、风险、容错边界，留存确认记录，不得简单一键放行。
二、底层原则
1. 决策主权归于人，AI仅提供候选方案；高风险场景无AI自主执行权限。
2. 容错阈值预先固化，不得临时随意放大容错边界。
3. 风险等级越高，容错空间越小，人工终审约束越强。
4. 所有AI决策、终审操作全链路留痕，可复盘追溯。
5. 定期校验模型漂移，动态复核容错阈值有效性。
三、全流程管控
1. 前置配置：投产前划定L1/L2/L3分级，写入容错阈值；阈值修改必须专项审批并入卷宗。
2. AI方案输出：L1仅数据分析；L2方案一旦越容错边界直接拦截，推送人工终审；L3仅作参考，禁止自动执行。
3. 人工终审：终审人独立研判，不能直接采信AI结论；复核工况、安全约束、容错边界，确认后才允许落地。
4. 漂移监测：持续比对AI决策结果与真实生产结果，漂移超标触发熔断。
5. 故障复盘：出现质量或安全事件，调取卷宗复核AI决策、容错设置、终审记录。
四、多方权责
1. 生产企业/工艺负责人：分级规则、容错阈值、人工终审、安全生产第一责任人。
2. 模型厂商：提供模型误差边界，不承诺决策绝对可靠，不可篡改容错配置。
3. 现场终审人员：独立核验AI方案，拒绝虚审、一键放行，对终审结论负责。
4. 安全审计方：抽查卷宗，核查容错阈值、人工终审落实情况。
五、确权交叉规则
AI原生决策方案、排产算法归入数据保护层；工艺专家设定容错边界、安全约束、终审判定逻辑重构触发权属快照，独创性部分纳入著作权保护层。
生产日志、终审卷宗不适用快照确权。权属快照仅判定成果归属，不可替代决策风险校验，不免除企业人工终审与安全生产主体责任。
六、禁止性规则
1. 禁止将智能制造决策安全责任转嫁AI、模型厂商。
2. 禁止随意调高容错阈值，放宽AI决策安全边界。
3. 禁止L3高危工况启用AI自动执行，跳过人工终审。
4. 禁止人工终审流于形式，一键确认AI方案不做独立研判。
5. 禁止屏蔽模型漂移告警，在超标状态下继续启用AI决策。
6. 禁止删除篡改决策日志、终审记录、容错配置卷宗。
七、治理谬误
1. 仿真验证通过，容错阈值可永久不变谬误。
2. AI方案输出合理，人工终审可以省略。
3. 权属快照确权等同于AI决策满足生产安全要求。
4. 容错机制等于允许AI无限制自主调整工艺。
全局铁律
智能制造AI仅输出候选方案，企业承担生产安全全责；分级设定容错阈值，高危场景容错归零；越界决策强制人工终审，模型漂移触发熔断；全链路决策留痕复盘；权属快照区分成果归属，不可豁免人工终审与生产风险校验义务。
