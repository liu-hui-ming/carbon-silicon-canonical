# 第110集｜AI算力资源集中化寡头风险治理

适用：智算集群、GPU算力池、算力调度平台、算力租赁服务商、跨区域算力网络，管控算力资源高度集中形成寡头垄断、算力锁死、差别定价、拒绝公平接入、算力供给单点失效、供应链风险传导。本卷优先适用，冲突以此为准，联动058确权卷宗、105风险分层卷宗、106例外校准卷宗、107全行业统一基线卷宗、108术语口径卷宗、109大模型准入卷宗、模型生命周期卷宗。
一、核心定义
算力寡头风险：单一主体或联合主体掌握区域内高比例高端算力资源，凭借算力支配地位抬高行业准入门槛、实施差别待遇、限制跨平台迁移、切断下游创新主体算力供给，形成产业单点依赖，一旦算力集群故障、断供将引发大模型训练与服务系统性瘫痪。AI仅为推演辅助工具，算力集群运营、集中度监测、公平接入、风险处置权责归属场景运营主体，责任不得转嫁AI、硬件供应商。
算力集中度：特定区域或赛道内，单一主体可控可用高端算力总量占市场有效算力的比例，作为寡头风险判定核心指标。
算力单点依赖：下游模型研发、大模型服务主体全部算力供给仅由一家算力服务商提供，缺少可快速切换的备用算力资源。
分级管控
L1：小型离线算力节点，仅用于内部研发调试，不对外提供算力租赁与调度服务，留存基础运维日志，后台抽样审计。
L2：中型算力集群，有限对外开放算力租赁，算力集中度处于安全区间；定期开展集中度评估，每半年复评，保障基础算力迁移通道。
L3：大型智算中心、跨区域算力调度网络，算力集中度突破阈值，支撑基座大模型训练或关键基础设施AI业务；必须独立第三方测评，季度集中度复评，强制部署多源算力兜底链路与算力供给熔断机制。
算力寡头治理卷宗：算力资产清单、算力集中度测算报告、供应链溯源材料、公平接入核验记录、算力迁移演练报告、熔断与备用算力验证记录、集中度预警处置记录；最低保存3年，L3算力集群断供事故、滥用支配地位案例永久归档。
永久归档清单：算力资产SHA-256哈希快照、历次集中度测算报告、供应链风险评估文档、公平接入审计记录、算力切换演练时序日志、安全事件处置复盘材料。
熔断机制：监测检出算力集中度突破红线、恶意锁算力、无正当理由切断下游算力供给、算力集群大面积故障，立即启动算力供给熔断，强制开放备用算力调度通道，限制寡头主体新增算力扩容审批；L3场景触发重大告警，暂停新增算力租赁业务，直至完成整改复测。
治理基线：算力寡头治理遵循法典统一L1/L2/L3分级规则，术语释义以108卷宗为准；算力运营主体不得降低法典底层刚性安全底线，可叠加算力行业专项约束。
二、底层原则
1. 算力集中事前监测、动态评估，防止算力资源过度寡头化；算力运营主体承担集中度管控、公平接入、供应链安全全责。
2. 算力供给不可形成单一依赖，L3相关业务必须保有可切换的备用算力链路，规避单点断供风险。
3. 分级管控，就高从严；算力集中可影响公共创新、关键基础设施AI业务，直接判定L3，执行最高强度管控。
4. 算力扩容触发集中度重评，集中度超标时限制新增算力建设，推动算力资源多元主体布局。
5. 算力公平接入为刚性底线，不得利用算力支配地位捆绑销售、差别定价、无故拒绝合规主体算力申请。
6. 例外场景严格遵循106卷宗规则，L3算力集群常规业务不开放例外，仅应急救援场景启用限时临时例外，底线条款不可豁免。
三、全流程管控
1. 算力准入与集中度评估：新建、扩容智算集群上线前执行算力集中度测算，判定风险等级；L3算力集群必须第三方独立测评，开展供应链风险审计、算力迁移演练，验证多源兜底算力与熔断机制有效性。
准入材料清单：算力资产清单、算力集中度测算报告、芯片与服务器供应链溯源、公平接入服务协议模板、算力迁移预案、熔断与备用算力验证记录、风险定级报告。
2. 动态监测与定期复评：算力资产大规模扩容、跨区域算力并网，30日内提交集中度重评。L1每年复评；L2每半年复评；L3每季度复评。集中度超标，限期整改；整改期间限制算力对外租赁规模，逾期未达标，暂停扩容审批。
3. 公平接入管控：算力服务商不得针对合规申请主体设置不合理门槛，不得凭借算力优势强制绑定模型、数据、平台服务；留存算力申请、审批、拒绝理由完整日志，供审计核验。
4. 下游算力依赖管控：大模型研发与运营主体，开展L3级模型业务，不得将全部算力托管至单一算力服务商；必须储备备选算力资源，完成跨服务商算力迁移演练。
5. 境外算力供应链管控：境外算力硬件、算力服务接入境内AI业务，执行同等集中度、安全评估、日志留存要求，不得豁免；供应链单点集中风险纳入审计范围。
6. 算力供给熔断处置：触发集中度超标、恶意断供、集群重大故障告警，启用备用算力通道，限制寡头主体新增算力扩容，溯源定位风险；整改复测通过后方可恢复完整算力扩容与租赁权限。
四、多方权责
1. 场景运营主体：算力集群运维、集中度监测、公平接入落实、算力迁移演练、卷宗保管第一责任人。
2. 算力硬件与供应链厂商：提供设备溯源、供应链风险清单，不得隐瞒硬件断供隐患，不得协助算力运营主体实施算力锁闭。
3. 独立安全测评方：开展算力集中度评估、供应链审计、算力迁移与熔断机制验证，出具客观测评报告，归档全部测评记录。
4. 监管审计方：抽查算力卷宗，核验集中度测算、公平接入日志、算力迁移演练记录，查处算力垄断、无故断供、隐瞒集中度风险行为，责令限制扩容或暂停算力租赁业务。
五、确权交叉规则
算力调度脚本、算力资产统计脚本归入数据保护层；治理专家设定算力集中度分级、扩容评估、公平接入、算力熔断逻辑重构触发权属快照，独创性部分纳入著作权保护层。
算力集中度卷宗、测评报告、复评记录、事件处置文档不适用快照确权。权属快照仅判定成果归属，不可替代算力集中度风险审查与公平接入合规审查，不免除算力运营主体治理责任。
六、禁止性规则
1. 禁止将算力寡头风险治理、算力供给安全处置责任转嫁AI、硬件供应商。
2. 禁止新建大型算力集群跳过集中度评估直接投产扩容，禁止伪造算力资产清单、集中度测算报告。
3. 禁止L3算力集群不部署多源备用算力、熔断机制，对外大规模提供算力租赁。
4. 禁止算力集中度超标主体继续无限制扩容算力资产。
5. 禁止算力服务商利用算力支配地位捆绑服务、差别对待合规申请者、无正当理由切断下游算力供给。
6. 禁止L3大模型业务主体完全依赖单一算力服务商，不储备备选算力资源。
7. 禁止供应链单点集中风险不申报，隐瞒境外算力硬件断供隐患。
8. 禁止删除篡改算力资产哈希快照、集中度测算记录、公平接入日志、算力迁移演练卷宗。
七、治理谬误
1. 算力仅服务内部研发，少量对外出租，无需评估集中度谬误。
2. 算力集群本身合规，下游企业算力依赖不属于算力寡头治理范畴。
3. 一次集中度评估通过永久有效，后续算力扩容无需复评。
4. 权属快照确权等同于算力集中度治理合规。
5. 短期算力租赁，可申请永久例外免除公平接入约束。
全局铁律
算力资源执行事前集中度评估与动态监测，算力运营主体承担算力供给与公平接入全责；分级管控就高从严，L3智算集群强制第三方测评、多源备用算力与熔断机制；算力大规模扩容触发集中度重评，超标主体限制扩容；下游L3大模型业务禁止单一算力服务商完全依赖；算力寡头不得利用资源优势实施捆绑、差别待遇；权属快照区分成果归属，不可替代算力集中度风险与公平接入合规审查义务。
