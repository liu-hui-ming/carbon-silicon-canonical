# 第087集｜科研AI论文辅助写作学术合规边界

本卷承接086科研AI仿真卷宗，专门规制AI辅助论文撰写场景，划定AI辅助的合法边界与学术不端红线，管控文本幻觉、引用造假、数据捏造、隐性代笔、署名与披露缺失风险，建立分级使用、全链路留痕、同行可核验的学术写作治理框架。本卷可与058确权取证卷宗、模型生命周期卷宗交叉调阅核验；科研论文AI辅助事项优先适用本卷，与确权板块条文并行适用，冲突时以本卷科研学术合规规则优先。
一、核心定义
科研论文辅助AI：用于文献检索、文字润色、逻辑梳理、句式改写、摘要草拟、参考文献格式化的大模型系统。AI仅作为文字辅助工具，研究构思、实验设计、数据分析、科学结论与核心论证的最终责任由论文作者承担。
引用幻觉：AI编造不存在文献、虚假卷期页码、伪造作者名称，或歪曲真实文献原文观点，形成虚假学术支撑。
隐性代笔：AI生成论文核心论证段落、研究方案、结论主体，作者仅小幅文字修改，未开展独立学术研判，却不披露AI深度参与。
AI写作交互卷宗：留存提示词、AI原始输出、作者修改痕迹、参考文献核验记录、AI使用披露文档；卷宗最低保存期限不少于十年，存在学术争议、撤稿案例永久归档。
分级AI使用
L1轻度辅助：语法校对、句式润色、参考文献格式排版，不改动核心论点与论证逻辑；L2中度辅助：草拟摘要、段落框架、文献综述初稿，作者完成大规模重写、事实核验；L3深度辅助：生成研究方案、核心论证段落、图表说明，必须完整披露，逐条核验全部事实与引用，机构伦理审查备案。
AI披露声明：论文、预印本、学位论文中，明确标注AI介入环节、使用模型名称与版本，区分润色、框架草拟、初稿生成；不得模糊、隐瞒AI参与程度。
二、学术合规底层原则
1. 作者主导，AI为辅：论文的科学观点、实验设计、数据分析、结论推导必须由人类作者独立完成，AI不可替代作者完成核心学术论证。
2. 事实逐条核验原则：AI产出的文献、数据、理论陈述，作者必须人工核验原始来源，不可直接采信AI生成内容。
3. 分级披露原则：AI参与深度越高，披露信息越详尽；L3深度辅助必须在论文致谢或附录完整写明，接受评审核查。
4. 修改痕迹可追溯：AI初稿与作者修订版本分开留存，区分AI原生文本与人类独创性改写内容。
5. 禁止AI伪造证据：严禁AI编造实验数据、图表、引用文献，不得篡改已有文献原意。
三、论文写作全流程合规管控规范
1. 选题与文献梳理阶段
1. AI可用于文献检索、关键词拓展、文献摘要快速阅读，但AI总结的文献观点必须核对原文，防范引用幻觉。
2. AI生成文献综述初稿，归入L2或L3分级；作者需要通读原始文献，修正AI歪曲、遗漏、虚构内容，留存核验记录并入AI写作交互卷宗。
3. 禁止AI虚构文献条目，禁止直接使用AI生成的文献列表不经核验直接写入参考文献。
2. 正文撰写、图表与论证阶段
1. L1轻度辅助：仅语法、语句流畅度优化，不改动科学观点，可简化披露。
2. L2中度辅助：AI生成段落框架与初稿，作者必须重写核心表述，核对全部事实、公式、数据，留存初稿与修订对照记录。
3. L3深度辅助：AI参与核心论证、研究方案撰写，事前在课题组备案；所有AI产出内容逐条核验，完整披露AI使用情况。
4. 图表、公式、实验描述禁止直接采信AI生成结果；AI生成图像、仿真图必须标注AI生成，严禁伪装成实测实验图像，遵循086卷宗仿真数据标识规则。
3. 投稿、同行评审与披露
1. 投稿前完成AI使用披露，不得隐瞒AI参与写作环节；期刊、学位评审机构有权调取AI写作交互卷宗。
2. 评审阶段，作者必须回应评审人针对AI辅助内容提出的事实、引用质询；无法提供核验记录的，评审方可拒稿。
3. 预印本系统、学位提交系统同步填写AI使用声明，与正式稿件保持一致，禁止一稿双标。
4. 卷宗归档
AI写作交互卷宗包含提示词、AI原始输出文本、多版本修订稿、文献核验台账、AI披露声明；最低保存十年，争议案例永久归档。
四、多方主体权责划分
1. 论文作者：学术诚信第一责任人。核验AI生成全部事实与引用，如实分级披露AI使用，留存写作交互卷宗；AI生成内容引发引用造假、结论错误，由作者承担学术不端责任。
2. 科研课题组与科研机构：开展AI科研写作培训，建立L3深度AI辅助备案机制；收到学术质疑时，组织卷宗核查。
3. AI厂商：产品层面提示AI引用幻觉风险；保留模型版本追溯能力，不得静默更新模型，导致同一提示词生成内容发生无告知变更。
4. 期刊、学位评审单位：有权要求作者提供AI写作卷宗用于核验；对隐瞒AI深度参与、引用造假的稿件执行拒稿、撤稿，记入学术诚信档案。
5. 学术诚信监管机构：受理学术不端举报，核查卷宗完整性，认定AI辅助写作相关失信行为。
五、确权板块交叉适用规则
1. AI原生生成的初稿文本、参考文献列表归入数据资产保护层；作者加入独立学术论证、理论推导、结构性改写、观点创新，触发权属快照，人类独创性新增部分纳入著作权保护层。
2. AI写作交互卷宗、原始实验数据、文献清单不属于人机协同创作成果，不适用权属快照，优先适用科研诚信、档案留存规则。
3. 权属快照仅用于文本成果载体归属判定，快照不能替代事实核验，不豁免作者学术诚信责任。
4. 论文中仿真相关内容，权属与真实性判定同步适用086科研AI仿真卷宗条款。
六、禁止性规则
1. 禁止AI生成论文核心论证、研究结论，作者仅小幅润色，不做完整披露，构成隐性代笔。
2. 禁止直接采信AI生成参考文献、文献观点，不核对原始文献，放任引用幻觉。
3. 禁止AI编造实验数据、图表、观测结果，伪装成实测科研成果。
4. 禁止在投稿、学位提交环节隐瞒L2、L3等级AI深度辅助。
5. 禁止删除、篡改AI原始输出、版本修订痕迹，销毁写作交互卷宗。
6. 禁止AI改写论文以规避查重检测，掩盖抄袭或伪造内容。
7. 禁止将AI生成完整论文直接作为学位论文、期刊投稿稿件。
七、治理谬误
1. 润色即无风险谬误：仅做文字润色，无需关注AI夹带的事实错误与引用偏差。
2. AI初稿等于作者成果谬误：AI生成初稿，简单修改即认定为独立原创研究。
3. 查重通过即合规谬误：查重率合格，代表不存在引用幻觉、隐性代笔问题。
4. 披露形式化谬误：简单一句“本文使用AI辅助写作”，不区分AI参与深度，不提供核验记录。
5. 快照替代学术核验谬误：权属快照证明文本归属，等同于论文事实、引用真实可信。
全局铁律
人类作者掌握核心学术构思与论证，AI仅作文字辅助；分级使用分级披露，AI产出必须逐条核验；严防引用幻觉与隐性代笔，版本痕迹完整入卷宗；权属快照区分文本归属，不可免除作者学术诚信核验义务。
