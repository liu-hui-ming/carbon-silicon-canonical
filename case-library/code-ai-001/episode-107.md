# 第107集｜全行业AI治理统一基线汇总

适用：法典全部行业分卷，统一归集底层公理、三级分级标准、安全工程基线、卷宗归档、熔断机制、确权规则、禁止条款与谬误清单，作为全法典参照总纲。管控：各行业分卷基线口径冲突、定义不一致、安全底线差异化松脱、跨卷规则碎片化、审计与归档标准不统一。本卷优先适用，冲突以此为准，联动058确权卷宗、105风险分层卷宗、106例外校准卷宗、全部行业分卷、模型生命周期卷宗。
一、核心定义
全行业统一基线：法典所有AI场景必须遵守的最低刚性约束集合，各行业分卷仅可叠加专项强化条款，不得删减、降低本基线硬性要求。AI仅作为推演、分析、创作、调度辅助工具，业务终审、风险处置、安全兜底全部权责归属场景运营主体，责任不得转嫁AI、模型厂商。
基线刚性条款：人身安全保护、国家安全与涉密隔离、多源交叉校验、熔断退出机制、独立兜底链路、全链路留痕确权，属于不可豁免底线，106例外场景亦不得免除。
分级管控（法典全域统一L1/L2/L3基准）
L1：只读监测、信息归集、素材整理，无直接影响人身、设备、公共基础设施的输出；后台周期性抽样审计，不强制人工终审，基础日志不可删除。
L2：辅助研判、方案推荐、线索初筛；输出仅作参考，落地前人工复核，配置参数硬阈值拦截，启用基础告警机制。
L3：涉及人身伤亡、公共重大权益、国家安全、关键基础设施闭环控制；AI仅提供态势与素材参考，禁止AI自主生成最终处置指令、强物理执行指令；多层专业人员终审，强制部署独立冗余兜底链路与熔断切换机制。
统一卷宗基线
卷宗保存基础周期：L1、L2案例最低保存2年；L3高危场景卷宗最低保存3年；重大安全事故、系统性偏见、涉密泄露、大规模权益侵害案例永久归档。
永久归档统一清单：事件前后时序原始数据、AI模型全版本哈希快照、AI输出方案、人工审批记录、熔断触发日志、兜底链路切换记录、风险评估报告、应急处置全指令流、事后复盘报告。
全域熔断基线
检出感知/文本幻觉、模型漂移超标、特征泄露、越权指令、观测数据异常，立即收缩AI权限，降低采信权重；L3场景触发熔断，AI退出闭环控制，切换至传统/人工兜底链路，复测通过后方可恢复AI闭环权限。
基线校验基线
所有上线AI系统上线前完成风险定级；L3场景必须独立第三方安全测评；系统发生业务规模、功能、数据源重大变更，触发风险重评。
二、底层原则
1. 运营主体承担AI应用全生命周期安全治理全责，AI仅为工具，不具备决策主权。
2. 三级分级框架为法典统一基准，行业分卷只能加严约束，不可降低统一基线。
3. 风险定级遵循就高从严，多风险叠加场景，以最高风险项确定等级，不得折中抵消。
4. 高危L3场景必须保留独立兜底链路，AI禁止作为唯一控制源。
5. 全链路数据、模型版本、审批、告警、熔断操作留痕，事故可完整回溯复盘。
6. 常态化模型校验，定期极端工况压力仿真，持续监控模型漂移、幻觉风险。
7. 敏感数据、涉密特征执行最小采集原则，对外传输前完成脱敏、特征抹除。
8. 例外场景仅为有限临时权限，底线刚性条款不可豁免，一事一议，绑定时间锁与场景边界，案例沉淀为反例样本用于规则迭代。
三、全流程管控
1. 上线准入：开展风险三要素评估（危害后果、覆盖规模、自主执行能力），出具定级报告；L3强制第三方安全测评。
定级判定细则：存在人身伤亡、关键基础设施、国家安全任一要素，直接判定L3。
2. 模型跨域迁移管控：模型迁移至新行业场景前，开展专项风险测评，校验分布偏移、幻觉、隐性偏见，测评不合格禁止投产上线。
3. 感知与输入管控：高危场景强制多源独立传感/数据源交叉校验；单一源异常自动降权，单一来源检出目标标记低置信度，不单独驱动AI决策。
4. 动态复评机制：L1每年复评；L2每半年复评；L3每季度复评；业务重大变更即时触发专项重评。
5. 压力仿真测试：L3场景定期极端工况仿真，验证熔断切换、冗余链路有效性；重大活动、灾害季前追加专项仿真。
6. 熔断处置：触发熔断条件，AI退出闭环，切换兜底链路，开展溯源整改；整改复测合格方可恢复原有AI运行权限。
7. 例外管理：L3常规业务不开放例外；仅应急救援场景启用限时临时例外，全程专人值守；例外到期自动失效，案例入库作为反例校准规则边界。
四、多方权责
1. 场景运营主体：风险定级、基线落地、卷宗维护、应急处置、例外审批第一责任人。
2. 模型研发厂商：披露模型固有局限、幻觉、漂移、跨域迁移风险；不得承诺绝对可靠，不得协助规避基线管控。
3. 独立安全测评方：负责L3场景第三方定级核验、模型跨域测评、冗余熔断机制有效性评估。
4. 监管审计方：抽查卷宗，核验风险定级、动态复评、熔断冗余、数据脱敏、例外审批执行情况。
5. 内容传播主体：对外发布AI生成内容，必须按要求标注AI推演属性与不确定性提示，不得摘除风险说明。
五、确权交叉规则
AI原生推演、统计、渲染脚本归入数据保护层；安全、行业专家设定安全约束、分级判定、熔断阈值、脱敏规则、例外边界逻辑重构触发权属快照，独创性部分纳入著作权保护层。
风险评估、审计日志、卷宗档案不适用快照确权。权属快照仅判定成果归属，不可替代安全、合规、真实性审查，不免除运营主体安全治理责任。
六、禁止性规则
1. 禁止将AI应用安全、决策处置责任转嫁AI、模型厂商。
2. 禁止降低法典统一L1/L2/L3底层刚性基线，行业分卷仅可增加约束，不可放宽底线。
3. 禁止高风险场景降级定级，不得拆分业务链路、裁剪场景规避L3管控。
4. 禁止L3高危场景撤除兜底链路、屏蔽熔断告警，将AI作为唯一控制源。
5. 禁止模型跨行业迁移不做专项测评直接上线投产。
6. 禁止涉密、敏感数据不脱敏裸传，禁止模型权重携带涉密特征跨域外流。
7. 禁止豁免底线刚性条款，不得利用例外条款实现常态化规避L3约束。
8. 禁止业务重大变更不开展风险重评，沿用旧风险等级。
9. 禁止删除篡改模型哈希快照、审批记录、时序日志、熔断告警、卷宗档案。
七、治理谬误
1. 模型在单一工况稳定运行，即可省略人工复核、冗余兜底、压力测试谬误。
2. 分项风险均为中等，可合并折减，降低整体风险等级。
3. 权属快照确权等同于AI系统风险合规、基线达标。
4. 风险定级一次评估永久有效，无需动态复评。
5. 例外审批通过，即可撤除兜底链路、熔断告警、日志留存底线约束。
全局铁律
全行业AI治理遵循统一三级风险基线，运营主体承担全周期安全全责；定级就高从严，业务变更触发动态重评；L3高危场景强制冗余兜底与熔断切换；多源输入交叉校验，敏感数据强制脱敏；模型跨域迁移必须专项测评；例外仅为临时有限权限，底线刚性条款不可豁免；全链路留痕复盘；权属快照区分成果归属，不可替代风险、安全、合规审查义务。
