# 第081集｜确权体系核心术语全局口径锁定

本卷为确权板块术语基准卷宗，对073、077、078、079、080确权系列所使用的全部专业名词进行统一释义，锁定唯一口径，消除条文解读歧义。本卷定义适用于所有权属争议审理、卷宗归档、贡献核算、快照存证环节，所有确权相关卷宗解读，均以本卷术语释义为准，可与058确权取证卷宗、模型生命周期卷宗、平台审核卷宗交叉调阅核验。
一、核心术语
人机协同创作：人类主体提出独创性构思，借助AI工具生成、迭代表达成果，人类具备实质智力投入的创作行为。不包含单纯机械指令调用、自动化批量生成、模型内部运算产出。
人类实质智力投入：人类完成的整体架构构思、叙事设计、画面构图、风格设定、多轮提示词定向迭代、成果筛选取舍、结构性改写重组等独创性智力活动。仅输入翻译、摘要、信息提取类功能性指令，单纯开启自动化任务，简单标点与格式微调，不属于人类实质智力投入。
权属快照：在指定时间节点，对成果文本、图像、音视频载体、贡献权重、权属定性、版本信息一并封存，生成不可篡改的存证记录。快照锚定对应时间切片的权属状态，历史快照永久留存，不可删除、不可覆盖，后续迭代不能回溯修改过往快照结论。
贡献占比：对人机协同创作成果，从提示词设计、成果筛选、人工改写、结构重构四个维度加权计算，量化人类独创性投入在完整成果中的权重数值。仅用于确权体系内部判定，不作为外部著作权法定比例唯一依据。
对外独立完整表达成果：可对外传播、被人感知，具备完整表达逻辑的文本、图像、音视频等内容。模型内部张量、特征向量、缓存碎片、未输出的临时草稿，不属于对外独立完整表达成果。
数据资产保护层：确权体系第二层保护框架。成果不满足著作权保护要件，但具备经济利用价值，不产生著作权，仅依据合同、数据安全规则享有有限使用权。
著作权保护层：确权体系第一层保护框架。成果满足对外完整表达、内容合法、存在人类实质智力投入三项基础条件，进入著作权评价，核算贡献占比，划分权利归属。
纯功能性指令：仅下达任务执行要求，不涉及叙事、构图、风格、架构等独创性构思的调用指令。例如翻译、总结、提取关键词、格式转换。
模板填充输出：依托预设固定模板，仅替换编号、日期、基础客观信息生成的内容。模板仅提供格式框架，内容层面论证路径、素材选择、表达结构由AI动态生成且存在人类筛选干预的，不属于模板填充输出。
衍生改编成果：在已有成果基础之上，新增独创性改写、重构形成的新版本。改编主体仅对新增独创性部分享有权利，原有成果权属不受衍生创作影响。
确权不适用场景：AI输出产物不满足创作要件，直接跳出整套AIGC著作权确权规则，不核算贡献占比、不生成权属快照，争议按商业秘密、数据资产、侵权、合同等其他规则处置。
二、配套流程术语
边界筛查：确权判定流程的前置步骤，优先核验成果是否落入确权不适用场景，筛查通过后方可进入人类投入性质判断与贡献占比核算。
058确权取证卷宗：用于权属争议举证的完整记录卷宗，包含提示词历史、迭代记录、权属快照哈希、人工修改记录、版本链条，用于核验贡献真实性。
版本链：由一系列权属快照按时间顺序串联形成的完整迭代记录，记录成果从初始生成到多次修改的全部演变过程。
快照触发事件：需要生成新权属快照的重大变更行为，包含提示词大规模重构、结构性人工改写、更换基座模型重生成、第三方独立二次创作、新增协同创作主体。微小标点、调色、文字微调不属于快照触发事件。
三、口径约束规则
1. 本卷术语释义为确权板块唯一官方口径，解读073至080卷宗条文，不得脱离本卷定义自行扩大或缩小词义范围。
2. 术语区分适用场景，同一词汇在确权体系之外其他法典卷宗，可另行定义；但在所有权属争议审理环节，必须采用本卷口径。
3. 术语解释不能脱离双层保护框架，判定成果归属时，术语释义与确权判定流程、刚性核验基准配套使用，不可单独截取某一条术语孤立裁判。
4. 若条文文字与本卷术语口径出现冲突，以本卷锁定术语口径优先。
四、治理谬误（术语误读）
1. 术语泛化谬误：将“人机协同创作”扩大至所有AI调用行为，把简单功能性指令等同于创作行为。
2. 快照万能谬误：将权属快照等同于法定确权证书，认为生成快照即自动获得完整著作权。
3. 投入混淆谬误：将人类简单点击、输入指令操作，等同于“人类实质智力投入”。
4. 衍生吞并谬误：误读衍生改编成果定义，认为二次创作可以消除原作权属。
全局铁律
术语口径统一锁定，解读不可随意扩张；定义配套流程适用，条文冲突以本卷为准。
