# 第101集｜文旅AI内容创作真实性治理规范

适用：景区、文博场馆、文旅平台、MCN、数字文旅项目AI图文、视频、数字人、文物复原、景点宣传、旅游攻略生成。管控：景点AI照骗、历史叙事臆造、文物复原失真、虚假文旅引流、歪曲非遗典故、隐匿AI标识、误导游客消费。本卷优先适用，冲突以此为准，联动058确权卷宗、模型生命周期卷宗。
一、核心定义
文旅AI创作系统：文旅文案、景点图像、虚拟场景复原、数字人导览、旅游路线规划辅助工具。AI仅产出创作初稿与虚拟推演素材，对外发布宣传内容、历史叙事、文物复原成果的真实性与合规责任，由发布主体/文博文旅运营方承担，不得转嫁AI或模型厂商。
文旅AI幻象：AI虚构景点景观、编造历史典故、篡改文物原貌、生成不存在的古迹场景，将推测性复原内容伪装成原生实景。
分级管控
L1：图片调色、文案润色、基础景点信息汇总，不改动景观原貌、史实，人工复核后发布。
L2：虚拟场景渲染、文物残损部位推测性复原、旅游攻略初稿；推测内容必须标注“AI虚拟复原/AI推演”，史实、景点开放状态、票价逐条核验权威来源。
L3：历史人物数字人演绎、文物核心原貌复原、景区官方宣传主视觉、重大文博展览叙事，AI仅素材归集，禁止直接生成定论式历史叙事，文博专业人员多层终审。
文旅创作卷宗：原始实景素材、AI生成版本、史实核验台账、专家审核记录、AI标识记录、游客投诉台账；最低保存2年，虚假宣传、历史叙事失真、重大文博项目案例永久归档。
永久归档清单：原始实景素材、AI生成全版本、史料/文物档案核验记录、文博专家终审意见、AI标识留存记录、投诉处置记录、复盘报告。
熔断机制：检出虚构实景、篡改文物原貌、歪曲历史典故，暂停该AI内容对外发布，启动史实复核与模型知识库整改。
AI内容标识基线：凡AI生成的虚拟景观、数字人、推测复原画面，必须在画面持续标注AI生成，时长≥总时长10%；推测复原内容必须明确区分“史实原貌”与“AI推演复原”，禁止混同。
二、底层原则
1. 文旅内容真实性主权归发布运营主体，AI仅创作辅助，不可将推测渲染等同于真实实景与原生文物样貌。
2. 文物复原、历史叙事区分“史实原貌”和“AI推测复原”，不得把推演内容伪装成真实遗存。
3. 风险越高，AI创作权限越收敛，文博、历史类内容必须前置专业人员终审。
4. 禁止利用AI生成虚假景观图片虚构景点引流，误导游客消费。
5. 建立史实、实景交叉核验机制，常态化校验知识库时效性。
三、全流程管控
1. 素材输入：训练素材优先采用官方文博档案、实景实拍素材；网络非权威素材入库前核验，剔除虚假景点图片、错误典故。
2. 内容生成：L1仅美化润色；L2虚拟复原强制标注推演属性，景点开放状态、票价、路线核验权威数据源；L3文博叙事AI仅整理素材，定论叙事由文博专家独立撰写。
3. 事实交叉核验：景点信息调用官方实时数据源；历史典故、文物形制采用典籍、考古报告、馆藏档案多源比对，单一来源信息不得采信。
4. 发布标识：AI虚拟场景、数字人、推测复原画面强制添加AI标识；攻略、宣传文案中AI推演内容单独说明，不得隐瞒。
核验规则：景点开放状态、门票、路线信息，必须对接景区官方API，AI静态知识库不得作为唯一依据；知识库至少每月更新一次。
5. 熔断处置：检出虚构景观、篡改文物形制、编造历史叙事，拦截发布；已上线内容立即下架，公示更正说明，更新知识库。
四、多方权责
1. 文旅/文博运营方、内容发布主体：史实核验、AI标识、内容终审、游客维权第一责任人。
2. AI厂商：披露知识库局限、历史与实景幻觉风险，不承诺生成内容史实绝对准确。
3. 文博专家审核方：对文物复原、历史叙事做真实性、文化伦理独立复核。
4. 监管审计方：抽查卷宗，核查AI标识、史实核验、虚假宣传治理落实情况。
5. 游客：有权对虚假AI文旅宣传提交投诉，申请复核。
五、确权交叉规则
AI原生文案、渲染画面、路线脚本归入数据保护层；文博专家设定史实约束、复原边界、叙事校验逻辑重构触发权属快照，独创性部分纳入著作权保护层。
卷宗、核验台账不适用快照确权。权属快照仅判定成果归属，不可替代史实真实性审查，不免除文旅发布主体内容真实性责任。
六、禁止性规则
1. 禁止将文旅宣传、文物叙事真实性责任转嫁AI、模型厂商。
2. 禁止L3文博重大叙事场景，直接采信AI生成定论式历史叙事。
3. 禁止AI生成虚构景点、夸大景观效果，伪装实景照片用于引流宣传。
4. 禁止将AI推测文物复原画面不加标注，直接等同于文物原生原貌对外传播。
5. 禁止歪曲历史典故、恶搞非遗、篡改文物叙事，传播历史虚无内容。
6. 禁止隐匿AI生成标识，隐瞒虚拟复原属性。
7. 禁止删除篡改素材档案、史实核验记录、专家终审卷宗。
七、治理谬误
1. AI画面视觉精美即等同于实景真实、文物原貌无误谬误。
2. AI生成复原图可直接作为文物原生样貌对外宣传。
3. 权属快照确权等同于文旅内容史实准确合规。
4. 虚拟复原无需标注，观众可以自行区分推演与史实。
全局铁律
文旅AI仅内容创作辅助，发布主体承担内容真实性全责；区分实景原貌与AI推测复原，文博高危叙事强制专业终审；AI虚拟内容必须显性标注，景点信息对接官方实时数据源；虚构景观、篡改史实触发熔断下架；权属快照区分成果归属，不可豁免文旅内容真实性与文化伦理审查义务。
