# 第077集｜AI确权争议取证流程与证据标准

本卷承接073数据资产权属卷宗，打通AIGC权属争议的取证、固证、核验、举证分配全链路。
与074使用者过失、075研发隐性责任、076平台审核卷宗体系同源对齐，统一沿用058卷宗链上哈希存证、时间锚、因果三档贡献框架，解决确权诉讼三大痛点：创作过程黑箱、事后复现无效、证据采信标准模糊。
一、核心定义
AI确权争议：人机协同生成成果，发生著作权归属、在先素材侵权、仿冒抄袭、权属标记篡改之争。
058确权取证卷宗：独立卷宗，记录创作时序、提示词迭代、参数、底稿、版本快照、哈希值、时间戳、存证凭证，与模型生命周期卷宗、平台审核卷宗三卷宗相互独立，必要时交叉核验。
取证核心铁律：事前存证优于事后取证；原始生成痕迹优于事后模拟复现；人类实质性智力贡献是确权核心标尺。
二、四层证据采信分级标准（刚性量化）
一级证据｜推定真实（庭审优先采信）
链上司法存证原始生成卷宗
内容包含：提示词全迭代版本、参数配置、中间草稿、多轮输出取舍记录、最终成果文件哈希、可信时间戳，同步上链固化。
效力：核验哈希无断裂，推定上链后未篡改；对方欲推翻，须提交相反实质性证据。
二级证据｜补强证据（不能单独定案，需交叉印证）
本地原始工程文件、分层源文件、创作日志、平台原生生成日志、录屏公证、第三方中立机构取证报告。
限制：仅本地文件，无链上时间锚，可被质疑事后修改，不可单独作为确权唯一依据。
三级证据｜辅助参考证据
AI检测概率报告、相似比对报告、作品发布时间记录、沟通记录。
限制：AI检测报告仅作线索，不得单独判定是否AI生成、是否侵权，必须搭配一级/二级证据。
四级证据｜无效证据
事后对照成品反向模拟生成、无日志无底稿的单次复现、无存证的截图、单方口头陈述。
铁规：事后反向复现，不具备原始创作证明效力，直接不予采信。
三、确权必备证据清单（主张权属一方举证）
主张享有权利，必须证明两项核心事实：
1. 人类实质性智力投入：提示词迭代设计、多轮筛选取舍、参数调控、后期修改、构思底稿，证明人的选择对最终表达形成决定性影响；仅简单关键词单次生成，不足以认定独创性贡献。
2. 创作时序与素材来源：证明生成时间、训练/输入素材具备合法来源，未挪用在先他人原创成果。
最低证据包（缺一不可）
①多轮提示词迭代记录；②版本快照与中间草稿；③最终成果哈希；④生成时间锚；⑤素材溯源清单。
四、取证全流程四阶刚性流程
阶段1：事前同步固证（最优路径）
AI生成的同时，自动写入058确权取证卷宗，计算每一轮提示词、中间输出、最终作品的哈希，推送司法区块链加盖时间戳。
高价值成果强制执行事前存证；中低价值成果可选择第三方可信时间戳。
阶段2：侵权发生时的即时保全
发现权属被侵害，立即固定：侵权页面快照、访问录屏、侵权文件哈希、发布时间、主体身份信息；同步封存己方原始058确权卷宗，禁止修改卷宗内任何记录。
铁规：取证环境必须清洁，不得在被篡改风险的设备中操作。
阶段3：证据核验与交叉调阅
庭审阶段，可申请调取三类卷宗交叉核验：
• 058确权取证卷宗（创作侧）
• 058模型生命周期卷宗（模型研发侧，075）
• 058平台审核卷宗（平台运营侧，076）
模型研发方、平台方负有卷宗提交协助义务；无正当理由拒不提交，推定不利于该方的事实成立。
阶段4：质证与独创性核验
区分两层核验：
1. 证据真实性核验：哈希、时间戳、存证链路；
2. 独创性核验：评估人类贡献占比，判定是否构成受保护作品。
五、举证责任分配规则（对齐法典整体体系）
1. 谁主张，谁举证：主张AIGC成果享有著作权，由主张方提交058确权卷宗，证明人类实质性智力投入、创作时序。
2. 举证缓和（技术黑箱例外）：主张模型训练萃取己方原作的，权利人仅需证明在先作品、实质相似；模型研发方负有举证义务，出示训练数据集、训练日志、模型卷宗，证明素材来源合法；拒不提交卷宗，推定萃取侵权成立。
3. 下游仿冒抄袭：主张对方AI生成成果抄袭己方原作，提交在先作品+058确权卷宗；由对方举证其生成过程独立、未接触在先作品。
六、三类权属边界定性（与073对齐）
1. 人机协同独创性成果：人类存在实质性智力投入、完整创作痕迹、058卷宗存证 → 人类使用者享有对应著作权。
2. 纯AI自动生成，无人类实质性创作干预：不构成著作权法意义作品；可按数据资产、反不正当竞争规则保护，适用073。
3. 基于他人原作微调、洗稿生成：无论是否经过AI迭代，落入实质相似，构成侵权；AI工具不能成为侵权免责盾牌。
七、取证三大红线（触发即证据失效）
1. 事后补卷宗：作品生成完成很久之后，反向补录提示词、伪造版本日志，卷宗哈希断裂，证据直接失效。
2. 创作痕迹裁剪：刻意删除多轮迭代记录，仅保留最终成品与单条提示词，无法证明人类创造性取舍，不足以支撑权属主张。
3. 取证环境不洁：取证设备存在可篡改环境、未隔离，无清洁性证明，电子证据真实性不予采信。
八、多方主体权责刚性切割
1. 成果创作使用者：承担生成过程取证、建立058确权卷宗、素材溯源的首要义务，主张权属时为主举证方。
2. 模型研发方：被诉训练萃取侵权时，需提交058模型生命周期卷宗，证明训练素材合规；拒不提交，推定过错。
3. 平台运营方：留存用户生成日志，收到取证申请，依法提供原始生成记录；不得单方面删除、篡改用户生成痕迹，适用076。
4. 抄袭侵权方：需举证自身生成链路独立；无法提供完整创作卷宗，推定接触+实质相似成立。
九、证据瑕疵过错梯度
轻微瑕疵：卷宗缺少少量中间草稿，但核心哈希、时序完整，可补强。
一般过错：未事前链上存证，仅有本地日志，权属证明力下降，需大量二级证据补强。
重大过错：伪造058确权卷宗、篡改哈希、删除创作痕迹，证据直接作废，同时推定权属主张不成立、构成虚假举证。
十、四类治理谬误击穿
1. 成品即权属谬误：拿到AI输出图片/文本，就天然享有著作权；忽略人类实质性贡献与创作痕迹。
2. 事后复现等同原始创作谬误：打官司时现场重跑一遍模型，就等同于原始创作过程；本卷直接否定。
3. AI检测报告定权属谬误：仅凭AI检测概率，直接判定是否侵权、是否属于AI作品；仅作为线索，不可单独定案。
4. 平台日志万能兜底谬误：平台后台记录完全替代创作者独立058确权卷宗；平台日志仅为辅助，创作者仍需自建确权卷宗。
十一、五项刚性核验基准
任意一项成立，权属主张证据不足：
1. 无多轮提示词迭代、无中间版本取舍痕迹，仅单次简单关键词生成；
2. 缺失058确权卷宗，无哈希、无可信时间锚；
3. 仅提交事后反向模拟复现，无原始生成痕迹；
4. 素材溯源缺失，无法证明输入素材具备合法授权；
5. 卷宗哈希断裂、存在篡改痕迹，无法核验时序。
十二、边界铁律
事前存证锁定时序，原始痕迹高于事后复现；人类实质贡献判定独创性，AI检测仅作线索；卷宗交叉核验查清事实，拒不提交卷宗推定不利事实。
结语
本卷补齐AIGC确权争议取证与证据标准，完成数据资产权属（073）→确权取证（077）闭环。
十卷疆域扩容为十一卷：源头层3卷｜运营层1卷｜使用层6卷｜权属取证层1卷三元碳基终审体系，证据链从模型训练、平台审核延伸至创作确权争议，全链路卷宗化、全链路可司法核验。
AI确权争议的终审权归于碳基创作主体与属地知识产权法治体系。AI只是创作工具；权属判定，以人类贡献、原始痕迹、链上卷宗为唯一锚点。
