# 第112集｜高、中、低风险AI模型分级监管体系

适用：全部AI基础模型、微调模型、行业应用模型，覆盖研发、训练、部署、对外服务全生命周期，管控定级随意化、风险低估、高风险模型套用低风险监管规则、模型迭代不重新定级、跨场景复用模型不做风险复核。本卷优先适用，冲突以此为准，联动058确权卷宗、105风险分层卷宗、106例外校准卷宗、107全行业统一基线卷宗、108术语口径卷宗、109大模型准入卷宗、110算力寡头治理卷宗、111公共算力分配卷宗、模型生命周期卷宗。
一、核心定义
AI模型风险分级：以场景危害程度、受众规模、模型能力、依赖程度四维评估，遵循就高从严原则，划分高、中、低三级风险，匹配差异化监管强度；同一模型部署多场景，按最高风险场景确定整体监管等级。AI仅为推演辅助工具，风险定级、动态复核、安全管控、卷宗维护权责归属场景运营主体，责任不得转嫁AI、模型研发厂商。
高风险AI模型：用于关键基础设施、政务决策、医疗诊断、金融授信、公共舆论动员，一旦失效可造成人身伤害、公共安全事故、国家安全与社会秩序冲击的模型。
中风险AI模型：面向有限群体，用于商业辅助、行业内部决策，存在个人权益侵害风险，但不会直接引发重大公共安全或系统性社会风险。
低风险AI模型：用于娱乐、创意辅助、单机离线实验，影响范围狭小，对人身、公共安全基本无实质危害。
分级管控
低风险：仅留存研发日志，不强制事前备案，后台抽样审计，无硬性第三方测评要求。
中风险：上线前完成内部安全评估，提交备案登记，每半年开展风险复评，留存人工干预通道。
高风险：上线前必须独立第三方安全测评，完成准入备案，每季度风险复评；强制部署熔断机制、独立兜底链路，关键节点保留人工终审权限。
分级监管卷宗：四维风险评估报告、定级判定文档、模型SHA-256哈希快照、安全测试报告、人工监督方案、熔断与兜底链路验证记录、历次定级复核记录、风险变更处置材料；最低保存3年，高风险模型安全事故、定级错误案例永久归档。
永久归档清单：模型版本哈希快照、风险定级评审记录、红队对抗测试报告、模型漂移监测日志、安全事件时序记录、整改复测文档。
熔断机制：运行监测或审计检出模型风险等级被低估、跨场景部署未重新定级、高风险模型关闭兜底与人工监督，立即限制模型调用权限，暂停新增业务接入；高风险场景触发重大告警，暂停对外服务，直至完成风险重评与整改复测。
监管基线：分级监管遵循法典统一L1/L2/L3底层框架，术语释义以108卷宗为准；高、中、低风险划分不得削弱法典刚性安全底线，可叠加行业专项约束。
二、底层原则
1. 场景与模型能力双维度定级，就高从严；模型跨场景复用，必须重新开展风险评估，不得沿用原有定级结论。
2. 分级监管差异化配置合规成本，低风险简化流程，高风险实施强事前评估、持续监测与人工兜底。
3. 模型权重、训练数据集、部署场景、服务规模发生重大变更，触发风险重评，定级提升须补齐高风险对应的安全能力。
4. 风险定级不静态固化，定期复核，风险升高自动升级监管强度；风险降低须经评审核验后方可下调等级。
5. 高风险模型必须保持人类终审权，AI输出不得直接自动执行关键决策，兜底链路永久保留。
6. 例外场景严格遵循106卷宗规则，高风险AI模型常规业务不开放例外，仅应急救援场景启用限时临时例外，底线条款不可豁免。
三、全流程管控
1. 风险定级前置评估：模型上线部署前，执行场景危害、受众规模、模型能力、业务依赖四维评估，判定风险等级；高风险模型必须第三方独立测评，开展幻觉、提示注入、数据投毒、偏见测试，验证熔断、兜底链路有效性。
定级材料清单：模型资产清单、四维风险评估报告、安全测试记录、人工监督与终审机制说明、熔断预案、风险定级结论文档。
2. 动态复核与等级变更：模型迭代、部署场景扩展、服务人群扩容，30日内提交风险重评。低风险每年复核；中风险每半年复核；高风险每季度复核。复核发现风险上升，限期补齐安全防护；逾期未达标，限制模型调用或注销备案。
3. 跨场景部署管控：同一模型迁移至新业务场景，不得直接沿用旧定级，必须重新评估场景风险；新场景判定为高风险，补齐第三方测评、熔断与人工终审机制。
4. 模型接入管控：调用外部第三方模型接口，核验对方风险定级卷宗与备案材料；接入未完成定级评估的模型，由场景运营主体承担定级不合规责任。
5. 人工监督差异化要求：低风险可简化人工审查；中风险建立抽样复核机制；高风险关键决策环节强制人工终审，AI输出不可直接自动执行。
6. 熔断处置：检出定级错误、风险低估、高风险模型关闭人工监督，收缩模型调用权限，开展风险重评；整改复测通过后方可恢复完整业务权限。
四、多方权责
1. 场景运营主体：模型风险定级、动态复核、人工监督落实、卷宗保管、安全事件上报第一责任人。
2. 模型研发厂商：提供模型基础能力报告、固有风险清单、版本哈希，不得隐瞒模型缺陷，不得协助运营主体压低风险等级。
3. 独立安全测评方：开展高风险模型安全评估、风险定级核验，出具客观测评报告，完整归档测评记录。
4. 监管审计方：抽查分级监管卷宗，核验定级逻辑、复核记录、人工监督与熔断机制，查处刻意低估风险、跨场景不重评行为，责令限制服务或注销备案。
五、确权交叉规则
模型训练脚本、风险评估自动化脚本归入数据保护层；治理专家设定四维定级规则、等级变更、跨场景复核、分级熔断逻辑重构触发权属快照，独创性部分纳入著作权保护层。
定级卷宗、测评报告、复核记录、事件处置文档不适用快照确权。权属快照仅判定成果归属，不可替代AI模型风险定级与分级监管合规审查，不免除场景运营主体分级治理责任。
六、禁止性规则
1. 禁止将风险定级、分级安全处置责任转嫁AI、模型研发厂商。
2. 禁止模型上线前跳过风险评估直接定级，禁止伪造风险评估报告、测试记录。
3. 禁止高风险模型不完成第三方测评、不部署熔断与人工终审机制直接对外提供服务。
4. 禁止刻意压低模型风险等级，套用低、中风险监管规则规避高风险合规义务。
5. 禁止模型跨场景复用不重新评估风险，直接沿用原有定级结论。
6. 禁止模型重大迭代、业务规模扩张不开展风险重评。
7. 禁止高风险模型关闭人工终审通道，AI输出直接自动执行关键决策。
8. 禁止删除篡改模型哈希快照、风险定级评审记录、复核卷宗。
七、治理谬误
1. 模型本身技术简单，无论部署场景，一律判定低风险谬误。
2. 模型一次定级完成永久有效，后续迭代与场景拓展无需重评。
3. 模型仅内部使用，不对外提供服务，无需开展风险定级。
4. 权属快照确权等同于AI模型分级监管合规。
5. 小范围内测，可申请永久例外免除风险评估与备案约束。
全局铁律
AI模型执行四维评估、就高从严分级，场景运营主体承担风险定级与全周期安全全责；低风险简化监管，中风险落实备案与抽样复核，高风险强制第三方测评、人工终审、熔断与兜底链路；模型迭代、跨场景部署必须重评风险，风险提升同步升级管控；高风险业务禁止AI自主执行关键决策；权属快照区分成果归属，不可替代AI模型风险定级与分级监管审查义务。
