# 第085集｜教育AI内容推送公平性治理规范

本卷承接084教育AI认知引导与青少年保护卷宗，专门规制教育场景个性化推荐算法，解决算法茧房、分层固化、群体偏见、商业流量优先挤占教育资源四大核心公平风险，建立学情适配优先、群体平等兜底、可审计可退出的推荐治理框架。本卷可与058确权取证卷宗、模型生命周期卷宗交叉调阅核验；教育AI内容推送事项优先适用本卷，与确权板块条文并行适用，冲突时以本卷教育公平规则优先。
一、核心定义
教育推荐算法：基于学生答题记录、学情标签、学习行为，自动推送习题、微课、拓展阅读、知识点资源的AI推荐系统，区别于通用娱乐信息流推荐。算法目标以学情适配为第一优先级，禁止将完课率、停留时长、付费转化作为核心优化目标。
学习固化偏见：算法依据历史成绩、地域、家庭背景，持续将学生锁在固定难度层级，限制高阶资源推送，形成“低水平闭环”，固化教育差距。
算法茧房：长期只推送匹配学生当前偏好的内容，压缩多元学科、思辨、人文拓展资源曝光，造成视野窄化。
受保护群体标签：地域、家庭经济条件、民族、性别、残障状态、薄弱校/乡村校身份；严禁将该类标签作为推荐难度、资源质量的判定权重。
公平性审计：由教育专家、算法工程师、法律专家组成联合审计组，跨群体比对资源曝光、难度分配、高阶资源触达率，检测歧视性推送。
推荐退出权：学生、监护人、授课教师可一键关闭个性化推荐，切换至统一课标资源池，不受学情画像干预。
保底资源池：独立于个性化推荐之外，由课标权威教材配套的标准化学习素材库，所有学生平等开放访问，不受算法画像限制。
推送审计卷宗：留存推荐策略、样本分组、资源分发日志、公平性抽检报告、用户申诉记录，纳入学习交互卷宗统一归档。卷宗最低保存期限不少于六年，涉及公平争议案例永久归档。
二、公平性底层原则
1. 学情优先，流量后置：推荐逻辑以学生知识薄弱点、认知水平、学段课标为核心；不得为提升停留时长推送低质、娱乐化、简单重复内容。
2. 个体适配，群体兜底：允许基于学习能力做难度适配，但禁止群体层面的系统性差别对待；不同地域、背景的同等学力学生，高阶拓展资源触达概率应当基本持平。
3. 多元供给，破茧兜底：个性化推荐之外强制预留保底资源池，保证人文、思辨、跨学科拓展内容稳定曝光，防止茧房窄化认知。
4. 可退出、可申诉：任何用户有权关闭个性化推荐，切换统一资源池；建立专门的公平性申诉通道。
5. 分学段差异化公平约束
小学：弱化个性化推荐权重，保底资源池占比不低于70%，优先统一课标内容；初中：个性化推荐占比不超过60%，强制混入多元拓展资源；高中：个性化可提升至70%，仍保留保底资源池入口，高阶资源不得对特定群体锁闭。
三、推荐算法全生命周期公平管控
1. 算法设计与上线前伦理审查
1. 训练数据集剔除地域、收入、性别等敏感特征作为推荐权重；开展预上线公平性测评，检验城乡、不同生源群体的资源分配差异。群体间高阶资源触达率偏差超过阈值，不得上线。
2. 推荐目标函数禁止将停留时长、点击量、付费转化作为主优化指标，核心指标限定为知识点掌握度、能力进阶、错题纠正。
3. 上线前必须完成多学科联合伦理评审；重大模型更新、推荐策略改版，必须重新开展公平审计，不得静默上线。
2. 运行期常态化公平监测与审计
1. 季度开展跨群体公平抽检，比对不同分组的习题难度分布、拓展资源曝光、高阶内容触达率；偏差超标触发算法纠偏。
2. 审计重点排查：乡村学生、薄弱校学生、残障学生、女生在理科进阶资源上是否存在系统性压低曝光的偏见。
3. 审计报告摘要面向学校、监护人公开，敏感技术细节保密；完整审计卷宗留存备查，接受监管抽查。
4. 公平熔断机制：监测发现持续性群体歧视、大规模学习固化偏见、茧房效应超标，触发熔断，临时关闭个性化推荐，强制切换统一保底资源池，直至算法整改、复审通过。
3. 资源池与内容分发规则
1. 保底资源池独立存在，不受个性化画像干预，全部学生均等开放，包含课标基础内容、思辨阅读、科普人文拓展素材。
2. 个性化推荐必须配置强制多样性配额，每轮推送中必须包含一定比例超出当前水平的拓展资源，避免长期困在简单习题循环。
3. 禁止商业付费资源优先抢占推荐流量；付费资源不得挤占免费课标核心资源的曝光权重。
4. 用户知情权、退出与申诉机制
1. 向监护人、教师公示推荐基本原理、画像标签类型，说明个性化推荐的局限与茧房风险；不得隐藏推荐规则。
2. 提供一键关闭个性化推荐入口，切换至统一保底资源池；关闭后不得诱导、弹窗反复劝说重新开启。
3. 设立公平性申诉通道，学生、教师、监护人可提交偏见投诉；厂商限时核查，记录到推送审计卷宗。
四、多方主体权责划分
1. 学校与任课教师：监督班级层面AI推送资源质量，评估学生是否出现学习固化；必要时为班级统一关闭个性化推荐，启用保底资源池，受理学生关于资源偏见的反馈。
2. 监护人：行使推荐退出权，查阅子女学习画像与推送日志，提交申诉。
3. 教育AI研发厂商：算法公平第一责任主体。落实预上线公平测评、季度审计、多样性配额、保底资源池；消除训练数据中的群体偏见；算法策略改版必须留痕。因算法固化偏见造成教育机会不公，承担整改、补偿责任。
4. 监管机构：组织算法公平抽检、第三方独立审计，对存在系统性歧视、流量优先的产品责令暂停推荐功能、限期整改。
5. 学生：可申请关闭个性化推荐，反馈资源推送不合理问题。
五、确权板块交叉适用规则
1. 推荐系统自动生成的习题序列、资源清单归入数据资产保护层；教师对资源清单做结构性教学设计、重组编排，触发权属快照，新增独创性编排部分纳入著作权保护层。
2. 算法画像、推送日志、推送审计卷宗不属于人机协同创作成果，不适用权属快照，优先适用青少年数据保护、教育公平治理规则。
3. 权属快照仅用于教学资源成果归属判定，快照不能证明推荐算法公平性，不免除厂商算法公平审计义务。
六、禁止性规则
1. 禁止将地域、家庭经济、性别、残障等受保护群体标签作为资源难度、高阶内容曝光的权重。
2. 禁止以完课率、停留时长、付费转化作为推荐算法核心优化目标。
3. 禁止静默修改推荐策略，规避公平性审计。
4. 禁止设置算法将学生长期锁定在低难度资源，阻碍能力进阶。
5. 禁止付费资源优先挤占课标免费教学资源的推荐流量。
6. 禁止隐藏个性化推荐开关，或持续弹窗诱导用户维持个性化推荐。
7. 禁止删除、篡改推送审计日志与公平性抽检记录。
七、治理谬误
1. 学情适配等于公平谬误：认为只依据考试成绩推送资源就天然公平，忽略历史偏见带来的群体固化效应。
2. 个性化即越多越好谬误：无限制个性化推荐，忽视茧房对青少年视野的窄化。
3. 商业指标无害谬误：把停留时长、点击率作为推荐优化目标，优先流量而非育人。
4. 审计一次性完成谬误：上线前做完公平测试，后续长期不做动态监测，忽略数据漂移带来的新生偏见。
5. 快照替代算法审计谬误：权属快照可替代公平性审计报告。
全局铁律
推荐以学情适配为本，群体平等兜底；保底资源人人可及，算法偏见定期审计；保留一键退出通道，防止茧房与分层固化；公平异常触发熔断，流量指标不得凌驾教育目标之上。
