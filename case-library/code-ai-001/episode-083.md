# 第083集｜医疗AI数据隐私保护与脱敏规范

本卷为医疗AI配套专项卷宗，承接082医疗AI辅助诊断卷宗，确立医疗敏感数据全生命周期管控、分级脱敏、权限隔离、泄露应急处置规则。本卷条文与082配套协同，可与058确权取证卷宗、模型生命周期卷宗交叉调阅核验；医疗AI场景下数据隐私事项优先适用本卷，与确权板块条文并行适用，冲突时以本卷医疗隐私安全规则优先。
一、核心定义
医疗敏感数据：患者病历、影像、检验指标、基因、生物特征、就诊记录等健康个人信息，属于《个人信息保护法》定义的敏感个人信息，处理需单独同意。
原始医疗数据：未脱敏、可直接识别特定自然人的完整病历、影像、身份关联信息；临床实时推理场景可使用原始数据，严禁直接导出用于模型训练、外部共享。
去标识化：参照GB/T 39725健康医疗数据安全指南，移除唯一身份标识，对间接识别字段泛化处理；处理后仍属于个人信息，仅限受控环境内部使用，不可对外无限制流通。
匿名化：经技术处理，无法直接或借助外部数据集重新识别特定自然人，处理后不再属于个人信息，可用于模型训练、科研共享；匿名化必须留存评估报告，验证不可逆。
数据不出院原则：原始患者医疗数据优先在医疗机构本地/私有云环境完成AI推理；原始数据不得随意跨机构外发至厂商公有云。
数据分级
一级（极高敏感）：基因、生物识别、传染病隐私记录、未成年人核心医疗档案；二级（高敏感）：完整病历、带身份标识医学影像、住院全套诊疗记录；三级（一般医疗数据）：聚合统计、已完成匿名化的病例集合。
数据泄露事件：医疗敏感数据被未授权访问、复制、外传、篡改，包含内部越权调取、外部入侵、违规导出。
二、全生命周期隐私管控规范
1. 采集与知情同意
1. 采集遵循最小必要原则，仅采集AI辅助诊断必需字段，禁止超范围采集无关身份、家庭、社会信息。
2. 医疗敏感数据用于AI推理，按082卷宗分级知情同意执行；若原始数据拟用于模型训练、科研二次利用，必须取得患者单独书面同意，明确告知用途、数据范围、存储期限、脱敏方式。
3. 法定豁免情形：公共卫生应急、传染病防控等法律规定场景，可按法规豁免单独同意，但仍需执行脱敏、留痕审计。
2. 存储与访问权限
1. 原始医疗敏感数据实行分级访问控制，岗位最小权限，双人审批调取一级极高敏感数据；所有访问、查询、导出操作全链路日志留存。
2. 存储介质隔离，AI推理缓存不得长期留存原始影像与身份关联信息，会话结束自动清理临时缓存。
3. 存储期限：原始病历数据按医疗法规留存；用于AI训练的脱敏数据集，在约定目的达成后，按协议销毁，销毁过程留痕核验。
3. 脱敏分级应用规则（医疗AI专用）
1. 临床实时推理：院内本地推理可保留原始医疗数据，不强制脱敏；但禁止将原始数据外传至厂商公网服务器。
2. 模型训练、科研、外部共享：◦ 一级极高敏感数据：必须完成匿名化，出具匿名化有效性评估，方可用于训练；◦ 二级高敏感数据：至少完成去标识化，在受控隔离环境内使用，禁止直接对外传输；◦ 三级聚合统计数据：可按协议流通。
3. 脱敏不可逆校验：去标识化/匿名化完成后，开展重识别风险评估；单条数据不可被反向定位到具体患者。
4. 禁止伪脱敏：仅简单删除姓名身份证号，保留病历号、完整出生日期、影像特征等可间接定位字段，不认定为合规脱敏。
4. 模型训练、数据共享与跨境传输
1. 原始患者数据，未经单独同意与伦理审查，不得用于AI模型训练。
2. 跨机构数据合作：优先采用“数据可用不可见”隐私计算、联邦学习，原始数据不出本地；确需外发数据集，必须完成脱敏、伦理审批、签署数据安全协议。
3. 医疗敏感数据出境：严格遵守数据出境安全评估、标准合同、个人信息保护认证制度；一级极高敏感医疗数据原则上禁止出境。
5. 数据销毁与回溯清理
项目终止、患者撤回授权时，按约定销毁对应原始数据与衍生副本；脱敏数据集区分处理：匿名化数据集可继续保留，去标识化数据集按患者要求删除对应记录。销毁操作生成哈希存证记录，纳入AI诊疗卷宗。
三、多方主体权责
1. 医疗机构：医疗数据第一责任主体。负责数据分级、脱敏实施、权限管控、知情告知、访问审计、泄露应急处置；对院内AI系统数据流转全流程监管。
2. AI研发厂商：不得私自缓存、抓取、留存患者原始医疗数据；接收数据集前核验脱敏报告；建立内部数据安全审计，严禁将医疗数据挪作其他模型训练。
3. 医师与操作人员：禁止私自复制、截图、导出患者原始影像病历，禁止将原始医疗数据输入公共大模型。
4. 监管机构：开展医疗数据安全抽查、脱敏效果核验，对违规跨机构流转、伪脱敏行为开展处罚。
5. 患者：有权撤回二次利用授权，申请查阅本人数据在AI系统中的使用记录。
四、泄露分级应急处置
Ⅰ级泄露（一级敏感数据大规模外泄）：立即启动应急预案，2小时上报监管机构，通知受影响患者，封存系统日志，溯源止损；Ⅱ级泄露（二级敏感数据少量外泄）：24小时上报，排查泄露路径，采取补救措施；Ⅲ级泄露（一般数据、内部越权访问未外传）：7日内完成内部核查、整改、风险评估。
所有泄露事件处置记录并入AI诊疗卷宗，永久归档。
五、确权板块交叉适用规则
1. 脱敏、匿名化处理后的数据集本身，归入数据资产保护层；数据集不产生著作权，仅受数据安全、合同约束。
2. 基于合规脱敏医疗数据训练生成的AI模型权重，权属按模型生命周期卷宗判定；模型权重不得反向还原患者原始隐私信息。
3. 患者原始病历、影像本身不属于确权板块人机协同创作成果，不适用权属快照规则，优先适用医疗隐私保护。
六、禁止性规则
1. 禁止未经单独同意，抓取患者原始病历用于AI模型训练。
2. 禁止使用伪脱敏数据集对外共享、模型训练。
3. 禁止原始医疗敏感数据无审批直接上传公有大模型。
4. 禁止隐匿数据访问日志、删除脱敏评估报告。
5. 禁止利用模型反向推理、还原脱敏数据中的患者身份信息。
6. 禁止以科研、算法优化名义，无限期留存患者原始诊疗数据。
七、治理谬误
1. 删名即脱敏谬误：仅删除姓名证件号，保留其他可关联信息，误认为完成合规脱敏。
2. 院内数据无限制使用谬误：临床推理可使用原始数据，等同于可以直接拿来训练模型。
3. 匿名化永久有效谬误：不持续评估重识别风险，数据集叠加外部信息后造成身份还原。
4. 厂商云端缓存豁免谬误：AI厂商可在公有云留存患者原始影像作为推理缓存。
5. 数据集确权混淆谬误：脱敏医疗数据集直接套用著作权确权快照规则。
全局铁律
原始数据守住不出院底线，分级脱敏匹配使用场景；临床推理与模型训练数据通道隔离，敏感数据二次利用必须单独授权；泄露分级上报，全程审计留痕，禁止伪脱敏与反向识别。
