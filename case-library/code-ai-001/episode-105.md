# 第105集｜行业AI通用风险分层适配规则

适用：法典全系列各行业AI场景统一定级、风险映射、管控规则复用、跨行业模型迁移、风险动态重评。管控：跨行业套用规则失配、风险定级偏低、模型跨域迁移引入隐性风险、分级标准不统一、静态定级脱离业务演变、熔断基线与卷宗归档口径不一致。本卷优先适用，冲突以此为准，联动058确权卷宗、前序全部行业分卷、模型生命周期卷宗。
一、核心定义
行业AI风险分层体系：统一定级框架，用于所有行业AI应用的风险判定、管控规则匹配、安全基线配置。AI仅作为工具载体，风险定级、业务终审、安全处置权责归属场景运营主体，责任不得转嫁AI、模型厂商。
跨域迁移风险：模型在A行业训练完成，迁移至另一行业场景，训练分布、约束边界失效，产生幻觉、偏见、控制失效等非预期风险。
分级管控（法典统一L1/L2/L3三级基准，各行业分卷在此基准上叠加行业特有约束）L1：监测统计、信息汇总、素材归类，只读类分析，无直接影响个体、设备、基础设施的输出；后台周期性抽样审计，无强制人工终审要求。
L2：辅助研判、方案推荐、线索初筛；输出结果仅作参考，落地前人工复核，设置参数上下限约束，建立基础告警机制。
L3：影响人身安全、公共权益、国家安全、关键基础设施；AI仅提供态势与素材参考，禁止AI自主生成最终处置/强执行指令，多层专业人员终审，配套冗余兜底链路与熔断切换机制。
风险定级三要素（就高从严原则）：危害后果严重程度、影响覆盖规模、系统自主执行能力；存在任一高风险要素，直接升级至更高层级，不做加权折减。
行业AI卷宗：风险定级评估报告、三要素判定记录、行业基线适配清单、跨域迁移测评记录、定期复评记录、整改台账；最低保存2年，L3重大安全事故、系统性偏见、数据泄露案例永久归档。
永久归档清单：定级评估全版本文档、风险三要素原始测评数据、跨行业模型迁移测试报告、冗余/熔断机制验证记录、历次复评记录、事故时序日志、复盘整改报告。
熔断基线通用规则：检出幻觉、模型漂移超标、特征泄露、越权指令，立即收缩AI权限，降低采信权重，切换至人工/传统兜底链路；L3场景熔断触发后禁止恢复AI闭环控制，复测通过方可重启。
分层适配基线：定级完成后，自动匹配对应层级的人工复核、多源交叉校验、数据脱敏、压力仿真、卷宗留存、审计频次；行业特有风险在通用基线之上追加专项约束，不降低通用基线底线。
二、底层原则
1. 业务运营主体承担风险定级与安全治理全责，三级框架为全法典统一基准，各行业分卷不得放宽L1/L2/L3底层约束，仅可叠加行业专项强化条款。
2. 风险定级动态化，业务规模、功能、场景发生重大变更，必须重新开展风险评估，更新层级与管控基线。
3. 模型跨行业迁移必须开展专项风险测评，验证幻觉、漂移、偏见风险，未通过测评禁止上线新行业场景。
4. 风险就高从严，多风险叠加场景，以最高风险项确定最终等级，不抵消、不折中。
5. 全生命周期审计，定期复评，L3场景强制高频压力测试，验证冗余、熔断机制有效性。
三、全流程管控
1. 定级准入：上线前完成三要素评估，出具定级报告；L3场景独立第三方安全测评，报告存入卷宗。
定级判定细则：危害后果分为财产损失、权益侵害、人身伤亡、公共安全、国家安全；覆盖规模分为局部小范围、区域级、全国大范围；自主能力分为只读输出、建议输出、物理闭环执行。只要存在人身伤亡、关键基础设施、国家安全任一要素，直接判定L3。
2. 跨行业迁移管控：模型迁移新行业前，执行领域适配测试，校验数据分布偏移、隐性特征萃取、幻觉风险；迁移测评不合格禁止投产。
3. 分级执行映射：L1只读分析，后台抽样审计；L2方案建议强制人工复核，设置参数硬阈值拦截；L3禁止AI自主强干预指令，冗余兜底链路常驻待命，多层专业终审。
4. 动态复评机制：L1每年复评；L2每半年复评；L3每季度复评；业务功能、规模、数据源发生重大变更，即时触发专项重评。
5. 熔断处置：触发通用熔断条件，收缩AI权限，切换兜底模式，开展风险溯源整改；整改完成并复测通过，方可恢复原有运行权限。
四、多方权责
1. 场景运营主体：风险定级、动态复评、基线落地、卷宗维护、应急处置第一责任人。
2. 模型研发厂商：披露模型固有局限、跨域迁移风险，不得承诺跨场景无失效。
3. 独立安全测评方：负责L3场景第三方定级核验、跨行业迁移风险测评，出具独立评估报告。
4. 监管审计方：抽查定级卷宗，核验分级匹配度、动态复评、熔断冗余机制有效性。
五、确权交叉规则
AI原生统计、推演脚本归入数据保护层；安全治理专家设定三级风险约束、跨域迁移校验、动态复评逻辑重构触发权属快照，独创性部分纳入著作权保护层。
定级评估、审计、复评卷宗不适用快照确权。权属快照仅判定成果归属，不可替代风险定级与安全基线审查，不免除运营主体安全治理责任。
六、禁止性规则
1. 禁止将风险定级、安全处置责任转嫁AI、模型厂商。
2. 禁止降低法典通用L1/L2/L3底层约束，行业细则只可加严，不可放宽基线。
3. 禁止高风险场景降级定级，不得通过拆分业务、缩小评估范围规避L3管控要求。
4. 禁止模型跨行业迁移不做专项测评直接上线。
5. 禁止L3场景撤除冗余兜底链路、屏蔽熔断告警，以AI作为唯一控制源。
6. 禁止业务发生重大变更，不开展风险重评，沿用旧等级管控。
7. 禁止删除篡改定级评估、跨域迁移测评、动态复评卷宗。
七、治理谬误
1. 模型在A行业稳定运行，迁移其他行业无需重新风险评估谬误。
2. 分项风险均为中等，可合并降低整体风险等级。
3. 权属快照确权等同于AI风险定级合规、基线达标。
4. 静态定级一次评估永久有效，无需定期复评。
全局铁律
行业AI风险分层采用统一三级基准，运营主体承担风险治理全责；定级遵循就高从严，业务变更触发动态重评；跨行业模型迁移必须专项风险测评；L3高危场景强制冗余兜底与熔断机制；各行业分卷仅可叠加专项约束，不得降低通用基线；权属快照区分成果归属，不可替代风险定级与安全适配审查义务。
