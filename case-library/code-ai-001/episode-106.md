# 第106集｜行业治理规则例外场景反例校准

适用：法典全系列行业分卷L1/L2/L3分级框架、风险基线、熔断机制的例外情形识别、边界校准、反例建档、规则迭代。管控：例外条款滥用、借例外降级规避L3约束、例外场景无限扩大化、例外不做专项评估、例外状态长期固化、反例样本缺失导致规则僵化。本卷优先适用，冲突以此为准，联动058确权卷宗、105风险分层适配卷宗、全部行业分卷、模型生命周期卷宗。
一、核心定义
例外场景：满足特定前置限定条件，在不降低底层安全底线前提下，对部分管控流程做有限度简化或临时豁免，不可豁免人身安全、国家安全、数据保密、权属确权的强制性底线条款。AI仅为推演辅助工具，例外判定、临时豁免审批、风险兜底责任归属场景运营主体，责任不得转嫁AI、模型厂商。
例外滥用：刻意裁剪业务场景描述、拆分业务链路，伪造边界条件，借用例外条款规避L3全套刚性约束，撤除冗余、熔断、人工终审机制。
分级管控
L1例外：只读监测类场景，仅简化后台审计频次；不可免除基础日志留存。
L2例外：辅助方案推荐场景，仅在小范围、低影响、后果可逆条件下，可有限调整人工复核覆盖率；参数硬阈值拦截机制不可取消。
L3例外：原则上不允许豁免；仅在极端应急救灾、生命紧急救援等限时特殊场景，启动临时例外，例外有效期设时间锁，必须保留兜底链路与熔断机制，全程专人实时值守，事后强制复盘归档。
例外校准卷宗：例外申请报告、边界条件核验材料、风险评估报告、限时审批单、实时值守日志、熔断测试记录、事后复盘报告；最低保存3年，L3临时例外、例外滥用事故案例永久归档。
永久归档清单：例外申请原文、审批全流程记录、场景边界限定参数、例外生效起止时间戳、AI全版本哈希快照、运行时序日志、熔断触发记录、事后复盘与规则修订建议。
熔断基线：例外场景一旦超出预设边界、发生模型漂移、感知幻觉、越权输出，立即终止例外权限，恢复完整标准管控流程；L3临时例外一旦触发安全告警，直接关停AI推理，切换兜底链路。
反例校准基线：每一例例外场景运行结束后，提取案例作为反例样本入库，用于修订分级判定规则，反例样本用于定期推演测试，持续修正规则边界，防止规则漏洞固化。
二、底层原则
1. 例外属于有限临时特权，不是常态化权限；底线强制性条款不可豁免，仅可简化流程，不可削减安全底线。
2. 例外判定一事一议，禁止批量、通用化豁免；L3高危场景仅应急救援可启动临时例外，不开放常规业务例外。
3. 例外场景设置明确边界与时间锁，到期自动失效，不得无期限延续。
4. 例外运行全程留痕，一旦越界，即刻收回例外权限，恢复标准管控。
5. 所有例外案例必须沉淀为反例样本，反例驱动法典规则迭代，闭环校准规则边界。
三、全流程管控
1. 例外准入：提交专项申请，核验全部前置边界条件，出具风险评估；L3临时例外必须多级审批，限定生效时间与作用范围。
前置核验细则：评估三项内容——危害后果是否可逆、影响范围是否可控、有无独立兜底链路；不可逆人身安全、国家安全场景，直接驳回例外申请。
2. 边界监控：运行期间持续校验场景参数，一旦超出预设边界，自动触发告警，终止例外状态。
3. 分级执行映射：L1例外仅调整审计周期；L2例外保留参数硬阈值拦截；L3临时例外全程专人值守，禁止撤除冗余兜底、熔断机制。
4. 反例入库：例外周期结束，无论有无事故，均提取场景参数、风险点、漏洞，存入反例样本库；反例样本纳入季度压力仿真测试集合。
5. 熔断处置：超出边界、幻觉、漂移告警触发，立刻撤销例外权限，切换标准管控或兜底链路，开展溯源评估。
四、多方权责
1. 场景运营主体：例外申请提交、边界管控、实时值守、事后复盘第一责任人。
2. 模型研发厂商：提示例外场景模型失效风险，不得主动设计方案协助规避标准管控基线。
3. 独立安全测评方：对L3临时例外开展前置风险核验，评估兜底与熔断机制有效性。
4. 监管审计方：抽查例外卷宗，核查例外审批、边界管控、反例入库落实情况，查处例外滥用行为。
五、确权交叉规则
AI原生推演脚本归入数据保护层；安全治理专家设定例外边界、时间锁、反例入库校准逻辑重构触发权属快照，独创性部分纳入著作权保护层。
例外审批、反例样本卷宗不适用快照确权。权属快照仅判定成果归属，不可替代例外风险审查，不免除运营主体安全治理责任。
六、禁止性规则
1. 禁止将例外场景安全处置责任转嫁AI、模型厂商。
2. 禁止豁免底线强制条款：人身安全保护、涉密数据隔离、冗余兜底、熔断机制、日志留存。
3. 禁止将L3常规业务，通过例外降级，取消多层人工终审。
4. 禁止例外权限无限期延续，不得移除时间锁与场景边界约束。
5. 禁止伪造场景条件、拆分业务链路骗取例外审批。
6. 禁止例外场景运行结束，不沉淀反例样本，不做复盘校准。
7. 禁止删除篡改例外审批记录、边界监控日志、反例校准卷宗。
七、治理谬误
1. 场景风险低，可申请永久例外，免除定期审计谬误。
2. 只要没有发生事故，例外场景不需要入库作为反例。
3. 权属快照确权等同于例外场景风险合规。
4. 例外审批通过，就可以撤除兜底链路与熔断告警。
全局铁律
例外场景为有限临时权限，运营主体承担例外状态下全部安全责任；底线强制条款不可豁免，L3仅应急救援可启用限时临时例外；例外绑定场景边界与时间锁，越界自动收回权限；所有例外案例沉淀为反例样本，用于规则持续校准迭代；权属快照区分成果归属，不可豁免例外场景边界与风险审查义务。
