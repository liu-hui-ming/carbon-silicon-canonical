# 第131集｜AI数据要素流通监管边界规范

适用：基座模型训练数据集、标注数据集、用户业务数据、模型微调产出数据、数据产品交易、跨主体数据授权、数据出境、数据可携场景；管控数据来源权属不清、公开数据无边界抓取、脱敏失效、流通目的超范围、交易合同规避责任、数据要素与模型权重边界混淆、流通链路不可追溯。本卷优先适用，冲突以此为准，联动全部前置卷宗；承接130算法反垄断卷宗，划定数据要素市场化流通的安全与竞争边界，建立数据分级确权、来源核验、脱敏基线、授权闭环、链路存证、可携与出境管控、违规熔断的要素流通监管框架。
一、核心定义
AI数据要素：用于模型预训练、微调、对齐、评测的文本、图像、音视频、结构化业务数据，含标注数据集、合成衍生数据；区分原始数据、脱敏数据集、特征向量、模型权重，权重不属于原始数据要素。AI仅为推演辅助工具，数据来源核验、分级识别、脱敏处理、授权管理、流通台账、出境申报权责归属数据处理运营主体；数据供给方、持证审计机构、算力服务商按过错承担连带责任。
四级数据分级：公共开放数据、一般业务数据、敏感个人信息、核心重要数据，匹配不同流通约束。
流通目的锁死：数据授权约定使用范围、模型场景、存储期限，禁止超出授权目的二次复用、转售、跨场景训练。
衍生数据溯源：经清洗、标注、脱敏生成的衍生数据集，保留原始来源谱系，不可切断来源责任链。
二、分级管控
公共开放数据：公开可获取资源，仍需核验知识产权与个人信息残留，禁止批量爬虫无限制抓取；留存抓取日志，过滤敏感信息。
一般业务数据：企业非敏感经营数据，可通过数据交易所、标准授权合同流通；留存流转台账，限定使用目的。
敏感个人信息：参照《个人信息保护法》第二十八条定义，包含生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹等；用于AI训练必须取得单独授权；脱敏、去标识化之后方可流通，禁止重识别风险残留。
核心重要数据：参照国家数据主管部门发布的重要数据目录，由运营主体对照目录自查并报监管备案，争议时以监管机构认定为准；原则上不得自由交易流通；确需跨主体使用，必须前置安全评估，严禁出境。
批量抓取判定基准：单IP或关联IP集群24小时内对同一站点请求≥10000次，或抓取数据量≥1GB，视为批量抓取；批量抓取须取得站点运营方明示授权，禁止绕过robots协议、反爬机制。
三、底层原则
1. 流通不等于无限制开放，数据要素市场化必须守住安全、隐私、知识产权三重底线。
2. 公开可访问≠可无条件抓取训练；爬虫采集、数据集采购均要核验来源合法性。
3. 脱敏仅降低风险，不免除主体责任；存在重识别风险的数据集不得进入流通市场。
4. 数据流通与模型权重做边界切割，不得借数据交易变相转让完整模型基座。
5. 数据流通卷宗、来源谱系、脱敏报告适用快照确权，对接128版本备案、129应急响应、130守门人可移植规则。
6. 守门人的数据可携义务，需在本卷边界内执行，不可突破数据分级红线。
四、全流程核心管控
1. 来源核验与权属基线
数据进入AI训练流通链路前，核验来源授权、知识产权、个人信息许可；采购数据集必须附带来源声明、风险评估报告。禁止采购来源不明、盗爬、侵权数据集。
2. 脱敏与质量基线
敏感数据流通前执行去标识化、差分隐私等脱敏处理；重识别风险评估采用k-匿名（k≥50）、l-多样性（l≥3）、t-接近性三项指标，由持证审计机构按统一技术规范抽样核验；审计机构须使用独立重识别攻击工具验证，连续三次攻击成功率为零方可通过。脱敏报告纳入流通卷宗。
3. 授权闭环与目的锁定
所有跨主体数据流转签订标准化授权协议，明确用途、存储期限、允许使用的模型场景、禁止二次转授权范围。超目的使用视为违规。
4. 全链路溯源谱系
每一份流通数据集建立谱系台账：原始来源、清洗标注流程、脱敏版本、流转接收方、使用起止时间，全程哈希快照存证。
5. 数据可携边界规则
用户业务数据可携权，仅覆盖用户自身产生业务数据；不得要求移交模型权重、通用训练基座数据集。可携输出必须脱敏，不泄露第三方信息。
6. 跨境流通申报基线
数据出境合规路径：核心重要数据、达到法定规模的个人信息出境，按国家网信部门规定申报安全评估；未达申报规模的，采用标准合同或认证路径；出境后使用范围不得超出申报或合同约定，境外接收方再转移须重新评估。禁止借境外算力、海外模型外包规避出境审查。
7. 流通审计与熔断机制
核心守门人每季度提交持证审计机构的数据流通专项审计，核查来源、脱敏、授权、出境合规。发现批量侵权抓取、脱敏失效、违规出境，启动熔断，暂停该主体新增数据流通交易，封存数据集。
五、多方权责
数据处理运营主体：来源核验、分级判定、脱敏处理、授权管理、台账留存、出境申报第一责任人。
数据供给方：保证交付数据集权属声明真实，披露已知隐私与版权风险。
供给方免责情形：已如实披露数据来源与已知风险，流通环节因运营主体超目的使用、脱敏失效、违规出境导致损害的，供给方不承担责任；供给方明知数据存在侵权、隐私风险而故意隐瞒的，承担连带赔偿责任。
持证审计机构：脱敏核验、来源审计、跨境风险评估、流通卷宗校验。
监管机构：分级认定、出境评估、违规调查、熔断处置。
六、禁止性规则
1. 禁止无授权批量爬取互联网公开内容直接用于模型训练。
2. 禁止脱敏流于形式，保留可重识别信息的数据集对外流通交易。
3. 禁止超出授权目的，二次转售、跨场景复用训练数据。
4. 禁止借数据要素交易变相转让基座模型权重。
5. 禁止规避安全评估，违规将敏感、重要数据出境用于海外模型训练。
6. 禁止伪造数据集来源证明、脱敏评估报告、流通溯源台账。
七、治理谬误
1. 互联网公开数据，可随意抓取用于大模型训练。
2. 数据完成脱敏，即可免除全部法律责任。
3. 权属快照确权等同于数据流通流程合规。
4. 数据集一经交付，供给方不再承担任何后续责任。
5. 数据可携包含模型权重、通用训练语料。
全局铁律
AI数据要素流通实行四级分级、来源核验、脱敏校验、目的锁定、全链路溯源、可携边界管控、跨境前置评估；区分原始数据、衍生数据集与模型权重，划定要素市场化的安全红线；流通卷宗哈希归档，与模型版本备案、应急处置、反垄断可移植体系协同，兼顾数据要素价值释放与隐私、知识产权、国家安全风险防控。
