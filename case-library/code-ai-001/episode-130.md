# 第130集｜算法垄断识别标准与反垄断治理基线

适用：基座大模型、API模型服务、推荐排序算法、算力调度算法、智能体调度系统；覆盖算法合谋、算法自我优待、数据-算力-算法锁死、人为抬高迁移成本、隐匿式流量歧视、集中式模型并购。管控算法垄断隐蔽化、传统反垄断指标失效、技术中立掩盖排他行为、并购事前评估缺失、竞争损害事后补救成本过高。本卷优先适用，冲突以此为准，联动全部前置卷宗；承接129AI应急响应卷宗，在安全风险处置体系之外，建立相关市场界定、守门人分级、垄断行为识别、事前申报、结构性与行为性救济、动态竞争监测的算法反垄断基线，补齐AI体系的竞争秩序防线。
一、核心定义
算法垄断：经营者依托算法、训练数据、算力集群、模型权重形成市场控制力，通过自动化程序实施排除、限制市场竞争的行为；区分结构性市场集中与算法实施的排他行为，技术本身不天然构成垄断。AI仅为推演辅助工具，市场地位评估、垄断行为识别、并购申报、竞争监测权责归属运营主体；持证审计机构、算力供应商、模型研发方按过错承担连带举证责任。
AI守门人：在模型服务、算力供给、数据接口市场，具备强网络效应、高用户锁定效应、上下游高度依赖，可实质性阻碍新主体入场的经营者。
四类典型算法垄断行为：算法自动合谋、算法自我优待、算法驱动差别待遇、算法锁闭（切断接口、抬高迁移成本、拒绝公平授权）。
竞争损害前置评估：不等待实际损害完全显现，评估算法架构、数据闭环、算力壁垒产生潜在排除竞争的高风险。
二、分级管控（守门人三级认定基线）
普通经营者：市场份额未达阈值，无强数据算力闭环；按常规事后反垄断监管，年度竞争自评估。
准守门人：相关市场份额达到阈值，掌握核心模型/数据/算力，存在显著锁定效应；每半年开展第三方竞争评估，开放基础接口、保障可移植性。
核心守门人：市场份额达标，同时控制模型、大规模训练数据集、高等级算力池，上下游高度依赖；强制事前并购申报、算法影响评估、非歧视基线，季度第三方竞争审计。
法典基准判定指标：相关市场份额、活跃调用占比、训练数据独占规模、算力供给控制力、用户切换成本、多栖可行性、潜在竞争者入场壁垒。不能仅以市场份额单一指标判定，必须结合数据闭环、算力壁垒、算法权限综合研判。
三、底层原则
1. 技术中立不等于行为豁免，算法自动化执行的排他行为同样纳入反垄断规制。
2. 区分效率增益与竞争损害，算法优化、技术迭代带来的合理创新不认定为垄断。
3. 高集中度AI市场实行风险前置评估，避免赢者通吃固化后，事后纠正成本不可承受。
4. 结构性壁垒（算力、数据、模型）与算法行为分开审查，救济方案兼顾市场开放与创新激励。
5. 反垄断卷宗、算法影响评估报告适用快照确权，与122审计、128版本备案、129应急体系打通。
6. 救济措施不得破坏127算力安全、123事故追责、129应急响应的安全底线。
四、全流程核心管控
1. 算法垄断识别四维度标准
①市场控制力：是否掌握模型、数据、算力入口，能够单方面影响流量、定价、接入条件；②算法行为：是否存在自动化自我优待、差别待遇、算法协同定价、切断接口锁闭；③壁垒强度：新竞争者获取数据、算力、模型权重的成本，用户迁移与多栖使用成本；④竞争损害：压制创新、压缩中小服务商生存空间、损害用户选择权，区分短期效率与长期创新抑制。
2. 经营者集中事前申报基线
核心守门人实施模型并购、算力池收购、数据集收购，达到阈值必须事前提交算法竞争评估报告，报告包含：算法架构、数据流转、算力依赖关系、并购后市场壁垒变化、潜在排他风险。
未申报不得完成交割。
3. 守门人强制性非歧视基线
核心守门人提供模型API、算力接入、接口服务时，禁止算法隐匿差异化对待；同等条件下，对第三方主体提供一致接口、调用规则、计费标准。自营业务不得利用算法优先分配流量、算力资源。
4. 数据与模型可移植底线
守门人应当提供标准化、安全可控的数据导出接口；模型微调产物、用户业务数据，保障用户可迁移至其他合规模型服务商，不得利用算法、权重加密刻意抬高迁移成本；迁移过程必须满足124公共算法脱敏、隐私保护要求。
5. 动态竞争监测与算法审计
核心守门人每季度提交持证审计机构出具的算法竞争影响审计；审计范围包含排序逻辑、流量分配、接口准入、定价算法。监管可随机盲测，核验算法实际运行结果与申报文档一致性。发现隐匿算法歧视，启动调查。
6. 救济处置与熔断
认定构成算法垄断行为，分级采取行为救济：整改算法逻辑、开放标准化接口、解除排他协议；严重结构性垄断，可实施业务拆分、资产剥离。
竞争秩序熔断：算法行为造成市场严重封闭、大量竞争者被迫退出，监管可临时限制算法权限、暂停新增算力扩容与版本上线，同步开展调查；熔断处置不得损害基础AI安全基线。
五、多方权责
运营主体：市场地位自评估、并购申报、算法竞争审计、接口开放第一责任人。
持证审计机构：独立竞争评估、算法盲测审计、出具竞争损害报告。
监管机构：守门人认定、并购审查、反垄断调查、裁决救济措施。
算力/模型供应商：不得配合实施算法锁闭、排他性算力绑定。
六、禁止性规则
1. 禁止依托算法自动实施协同定价、市场分割等算法合谋。
2. 禁止利用排序、流量分配算法系统性自我优待自营业务，无正当理由差异化对待竞品。
3. 禁止通过算法、加密、接口限制刻意制造锁闭，恶意抬高用户与第三方迁移成本。
4. 禁止并购交易规避事前申报，隐瞒算法、数据、算力带来的市场壁垒。
5. 禁止篡改算法审计日志、隐藏算法运行真实结果，美化竞争评估报告。
七、治理谬误
1. 算法属于技术，技术中立，不存在垄断问题。
2. 市场份额不高，就不存在算法锁闭与竞争损害。
3. 权属快照确权等同于反垄断竞争评估流程合规。
4. 只要合同自愿，就可以签订排他算力、模型授权协议。
5. 垄断仅看短期价格，不需要评估长期创新壁垒。
全局铁律
算法反垄断实行守门人分级、四维识别标准、并购前置申报、非歧视基线、可移植保障、季度算法审计、动态竞争监测；不否定算法创新，只规制算法驱动的排他行为；反垄断评估与算力安全、模型版本备案、应急风险处置体系协同联动；审计卷宗哈希快照存证；防止数据-算力-算法三位一体形成赢者通吃的固化壁垒，维护AI产业长期创新竞争秩序。
