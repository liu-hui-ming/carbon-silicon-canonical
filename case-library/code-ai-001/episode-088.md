# 第088集｜金融AI风控模型公平性与算法反歧视

本卷面向信贷、保险准入、授信评级、反欺诈等金融AI风控场景，确立风险真实定价优先，禁止群体算法歧视核心准则，管控代理歧视、特征代际传导、样本历史偏见、黑箱决策、拒绝理由模糊五大风险，建立模型全生命周期公平审计、申诉复核、熔断处置框架。本卷可与058确权取证卷宗、模型生命周期卷宗交叉调阅核验；金融AI风控公平性事项优先适用本卷，与确权板块条文并行适用，冲突时以本卷金融算法公平规则优先。
一、核心定义
金融AI风控模型：用于客户准入、信用评分、授信额度、保险保费定价、理赔审核、欺诈识别的机器学习与大模型风控系统。AI仅作为风险测算辅助工具，信贷与保险业务的最终授信、承保决策责任由持牌金融机构承担。
代理歧视：模型不直接使用受保护标签，但借助高度关联替代特征，间接复刻地域、性别、户籍等群体偏见，造成差异化拒贷、抬升费率。
历史样本偏见：训练数据集承袭过往不合规业务实践，使模型对特定群体系统性高估风险，形成固化不公平结果。
受保护群体标签：性别、民族、户籍地域、婚姻状况、残疾状态、特定年龄区间；该类标签原则上禁止直接作为风控准入、定价权重。
模型公平审计：由金融合规、算法工程、风控专家组成联合审计组，跨分组对比通过率、授信额度、保费水平、拒件率，检验群体层面系统性差异。
客户解释权：风控模型拒绝授信或抬高定价时，向客户提供清晰、可理解的决策因子说明，不得仅返回“综合评分不足”模糊结论。
风控模型卷宗：包含特征清单、训练数据集描述、公平性测评报告、模型版本、决策日志、客户申诉记录、模型变更审批材料；卷宗最低保存期限不少于五年，涉及监管处罚、重大纠纷案例永久归档。
公平熔断机制：审计检出超出阈值的系统性群体差异，触发熔断，暂停模型自动化决策权限，降级人工复核，直至模型整改、复审通过后方可恢复。
二、底层公平原则
1. 风险为本，禁止差别对待：模型只能基于真实履约风险、损失概率做定价与准入判断；不得在同等风险水平下，对不同群体设置差异化授信、费率标准。
2. 特征最小化原则：仅保留与真实风险具备因果关联的特征，剔除仅具备相关性、易引发代理歧视的特征。
3. 事前预审+持续监测：模型上线前完成公平性测评；上线后常态化跨群体监测，防范样本漂移带来新增偏见。
4. 可解释与可申诉：自动化风控决策必须输出可理解决策理由，建立独立申诉复核通道。
5. 模型变更留痕：特征调整、样本更新、版本迭代，必须重新开展公平审计，不得静默上线。
三、风控模型全生命周期公平管控规范
1. 模型设计与上线预审阶段
1. 特征筛选环节排查受保护标签，评估各候选特征的代理关联风险；高代理风险特征若无强业务因果依据，予以剔除。
2. 训练数据集清洗，校正历史样本偏见；上线前开展分组公平性测试，若同等风险群体间授信通过率、拒件率偏差超出预设阈值，模型不得上线。
3. 模型架构、特征清单、公平测评报告纳入风控模型卷宗，完成内部合规审批后方可投产。
2. 上线运行与常态化监测阶段
1. 持续采集跨群体业务指标，定期开展公平性抽检，监测拒贷率、额度分布、保险费率、理赔驳回率的群体差异。
2. 监测样本漂移，客户群体结构变化时重新评估公平性；出现系统性群体不公平结果，触发公平熔断，自动关闭全自动审批，所有相关业务转入人工复核。
3. 所有自动化决策日志完整留存，记录每一笔业务的输入特征、模型得分、决策结果，不可单方面删除。
3. 决策解释、客户申诉与复核
1. 自动化风控拒绝客户申请或提高定价，必须向客户披露核心影响因子，禁止黑箱式结论。
2. 设立独立申诉通道，客户可提交异议；申诉案件脱离原模型自动判定，由人工复核团队独立重审，复核结果记入风控模型卷宗。
3. 申诉集中指向同一群体系统性不公时，启动专项公平审计。
4. 模型迭代、下线与归档
1. 模型特征、样本、算法结构重大修改，必须重新执行公平审计，审批留痕，禁止静默更新模型。
2. 模型下线后，卷宗按保存期限持续留存，用于纠纷回溯与监管核查。
四、多方主体权责划分
1. 持牌金融机构：算法风控第一责任主体。负责特征管理、公平审计、客户解释与申诉处理；因算法歧视造成客户权益损害，机构承担主体责任。
2. 风控模型研发方：提交模型偏见评估报告，标注已知代理风险；不得刻意设计特征，诱导产生群体差异化歧视结果。
3. 监管机构：组织算法公平抽查、现场卷宗核验，对存在系统性算法歧视的模型责令暂停使用、限期整改。
4. 客户：有权获取决策理由，对不公平风控结果提交申诉。
五、确权板块交叉适用规则
1. AI原生生成的评分脚本、特征筛选方案归入数据资产保护层；风控工程师加入独创风险框架、业务逻辑重构，触发权属快照，人类独创性新增部分纳入著作权保护层。
2. 模型决策日志、客户业务档案、风控模型卷宗不属于人机协同创作成果，不适用权属快照，优先适用金融监管、数据合规规则。
3. 权属快照仅用于模型开发成果载体归属判定，快照不能替代公平审计，不免除机构算法反歧视合规义务。
4. 模型底层权重权属判定参照模型生命周期卷宗条款。
六、禁止性规则
1. 禁止直接将受保护群体标签作为风控准入、授信额度、保险定价的计算权重。
2. 禁止利用代理特征间接对同等风险客户实施群体差别对待。
3. 禁止模型上线前跳过公平性测评，或隐瞒群体差异测试结果。
4. 禁止静默更新模型特征、训练样本，规避公平审计。
5. 禁止仅返回模糊结论，拒绝向客户提供自动化风控决策的关键影响因子。
6. 禁止删除、篡改风控决策日志、公平审计报告。
7. 禁止使用模型自动化决策替代全部人工复核，规避合规审查。
七、治理谬误
1. 数据客观即公平谬误：训练数据取自历史业务记录，就天然不存在算法偏见。
2. 不直接使用保护标签即合规谬误：剔除敏感标签，忽略替代特征带来的代理歧视。
3. 模型一次性审计永久有效谬误：上线前测试完成，后续业务分布漂移不再持续监测公平性。
4. 评分结果即最终事实谬误：模型输出分数等同于真实风险，无需人工复核。
5. 快照替代合规审计谬误：权属快照证明模型归属，等同于模型满足公平反歧视要求。
全局铁律
风控评估锚定真实风险损失，严控代理特征隐性歧视；上线预审加持续监测，群体差异超标触发熔断；客户享有决策解释与申诉权；模型迭代必须审计留痕；权属快照区分成果归属，不可豁免金融机构算法公平合规责任。
