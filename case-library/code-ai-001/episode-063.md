# 第063集｜AI辅助科研成果署名规则与学术规范

本卷承接055三分确权、060多方责任卷宗。055界定人机产出物权属；063聚焦学术场景：AI仅作为科研辅助工具，不具备作者资格，规范贡献认定、署名、致谢、利益声明、学术不端判定标准，属于学术认知产出的治理底座。
定义基准
AI辅助科研成果：科研人员利用大模型完成文献整理、代码生成、数据可视化、初稿起草、润色、仿真推演，人类完成核心研究设计、假设提出、实验验证、结论论证、最终审定的学术论文、专利、实验卷宗。
风险核心：硅基模型不能成为论文作者；署名权属于碳基人类研究者；仅做文本润色、代码辅助、素材整理的AI，仅可在致谢/方法段标注；若人类放弃核心论证，直接将AI生成文本作为成果主体，属于学术不端；AI辅助声明不能豁免人类对成果真实性、数据可靠性的全部审核责任。
区分边界：
1. AI学术署名规范 ≠ 三分确权体系。三分确权解决产出物法律权属；本卷解决学术共同体内部作者资格、贡献标注、学术诚信规范。
2. AI科研辅助 ≠ 模型输出版权判定（056）。学术署名是学术伦理规则；著作权是法定财产人身权利，两套体系并行但判定标准不完全相同。
3. AI辅助科研 ≠ 开源/闭源模型许可（061/062）。许可约束模型调用权限；本卷约束成果发表阶段的学术披露义务。
五层科研贡献判定链条
1. 作者资格前置判定
学术作者必须同时满足四项核心贡献：研究构思设计、数据采集与实验实施、结果分析论证、稿件撰写修订与最终定稿。
• AI：无法独立提出科研假说、自主设计实验、承担学术责任，不具备作者署名资格；
• 人类研究者：只有实质性智力投入，方可列入作者名单；仅单纯调用AI生成文字，无实验与论证投入，不能仅凭AI产出获得署名。
2. AI贡献分级标注规则
• 轻度辅助（文献检索、格式排版、语言润色、简单代码编写）：在致谢、方法部分写明AI工具名称、使用范围；无需列入作者；
• 中度辅助（辅助推演、生成初稿、辅助数据绘图）：必须在方法或附录详细披露AI使用场景、提示词策略、人工修改比例；
• 重度依赖（核心论点、实验结论由AI生成，人类仅少量修改）：成果不可直接投稿；需要人类完整复现、核验全部结论，否则构成学术不端。
3. 学术不端判定链路
• 隐瞒AI使用：未声明AI大规模辅助生成正文、图表、推演结论，属于学术不端；
• AI幻觉直接引用：未核验AI编造文献、虚假实验数据、伪造公式，直接写入论文，等同于伪造研究资料；
• 抄袭叠加AI改写：利用AI改写他人已有成果规避查重，属于剽窃。
4. 专利场景区分：发明人 vs AI辅助
专利发明人必须为自然人；AI不能作为专利发明人。AI辅助生成技术方案，发明人仍为提出技术构思、完成验证的碳基研究者；专利说明书需要披露AI辅助开发过程。
5. 成果责任归属判定
论文、专利的全部学术责任、同行评审责任、数据真实性责任，由署名人类作者承担。AI不能承担学术纠错、答辩、成果真伪核查责任。AI辅助声明，不能作为人类免责的借口。
四类典型科研署名失稳形态
1. AI列入作者名单
将模型直接写为论文共同作者，混淆工具与科研主体。AI不具备学术责任承担能力，不符合学术出版通用规范。
特点：学术出版高频错误，稿件直接拒稿，严重时触发机构学术诚信调查。
2. 隐匿AI使用，把AI生成内容当作原生研究成果
大量使用AI生成核心论证、实验结论，投稿完全不披露AI辅助；依靠AI改写规避查重。
特点：典型学术不端，事后撤稿，影响研究者学术信用。
3. 过度依赖AI幻觉，不做人工核验
直接采信AI虚构参考文献、虚假实验结果、错误理论推导，未人工复现校验，造成结论失真。
特点：AI幻觉风险传导进入学术卷宗，污染公共科研认知基座。
4. 贡献标注模糊，无法区分人机贡献边界
笼统写“本文使用AI辅助”，不写明使用环节、提示范围、人工修订比例；同行评审无法评估AI对核心结论的影响。
特点：披露流于形式，达不到学术透明要求。
AI科研辅助风险传导链路
科研人员使用AI生成论文初稿、推演结论，不披露AI使用，不人工核验AI幻觉；将AI直接列为作者；成果进入期刊发表、学术卷宗归档 → 论文结论存在虚构、文献造假；若无贡献分级标注、AI使用声明、人工复现核验闸口 → 论文撤稿、学术诚信处罚，污染学术知识库，形成认知污染卷宗。
AI辅助科研核心安全隐患
1. AI幻觉伪造学术证据
编造文献、引用、实验数值、理论公式；人工不复核，虚假结论固化进入学术文献库，长期误导后续研究。
2. 人机贡献边界模糊，带来署名纠纷
团队内无法区分哪些结论来自人类构思、哪些来自AI生成，引发作者排序、成果归属争议。
3. 期刊、会议披露标准不统一
不同出版社、学术会议对AI披露要求存在差异，同一稿件在不同平台合规标准不一致。
4. 专利申报的发明人资格误区
将AI列为专利发明人，直接导致专利申请驳回。
5. 科研卷宗归档缺失
不留存提示词、AI生成原始草稿、人工修改痕迹；后续同行复核、学术调查时无法还原人机协作过程。
判定核验基准（AI科研署名体系核验项）
1. 将AI模型列为论文/专利作者、发明人；
2. 大规模使用AI生成核心论点、实验结论，投稿时隐瞒AI辅助使用；
3. 直接采信AI输出，不人工核验文献、数据、推演结论，放任幻觉写入成果；
4. AI辅助声明表述笼统，未写明使用环节、提示策略、人工修订比例；
5. 认为标注AI辅助即可免除人类对研究真实性、实验可靠性的全部学术责任；
6. 科研卷宗不归档提示词、AI原始输出、人工修改痕迹，无法复现人机协作流程。
满足两项及以上，AI科研署名体系暴露风险偏高。
风险等级划分
低学术风险：仅用于文献检索、语言润色、格式排版；在致谢标注AI工具；核心构思、实验、论证全部由人类完成；留存修改记录。
中学术风险：AI辅助初稿撰写、代码与绘图；在方法段完整披露使用场景；人工逐条核验全部结论与引用；归档提示词与草稿；同行评审可追溯人机贡献。
高学术风险：AI参与核心推演、假说生成，成果用于期刊发表、专利申报、重大科研卷宗归档；必须落实AI使用强制披露、人机贡献分段标记、逐条人工核验、原始草稿与提示词归档、机构学术诚信复核。
不可控学术风险：AI产出直接作为成果主体，无人工核验，隐瞒AI使用，将AI列为作者；原则上禁止正式发表与归档；确需启用必须满足五项条件：AI使用完整披露、人机贡献分段标记、逐条人工核验、提示词与草稿归档、学术诚信复核；即便全部落实，AI幻觉带来的隐性错误无法被完全排除。
评估边界实操准则
1. 核心原则：AI是工具，不是作者；署名权与学术责任仅归属碳基人类研究者。
2. 科研卷宗归档复用058溯源体系，保存提示词、AI原始输出、人工修订痕迹，做分段标记，区分碳基原生内容与硅基推演内容。
3. 学术成果投稿前，纳入全局审计基线053专项复核；AI使用方式发生重大变化，更新披露声明。
4. 区分学术伦理规范与著作权法律规则：学术署名遵循出版与学术共同体规范；成果著作权归属适用055、056卷宗。
落地指引
测评人员：安全审计新增AI辅助科研署名规范章节；覆盖AI列入作者、隐匿AI使用、幻觉未核验、披露流于形式四类场景；报告记录AI使用范围、人机贡献标记、人工核验记录、提示词归档、学术诚信复核结论。
研发团队：制定科研AI使用规范；禁止将AI列为论文/专利作者；按照贡献分级强制披露AI使用场景；建立AI产出人工复核机制，核验文献、数据、推导逻辑；归档提示词、原始AI草稿、人工修订痕迹；成果投稿前开展学术诚信内审；人机协作卷宗添加分段溯源标记；规范变更纳入全局审计基线复核。
监管与行业观察者：AI不能作为学术成果作者、专利发明人；使用AI辅助科研应当主动披露；人类作者对成果全部真实性承担学术责任；AI辅助声明不能免除核验义务。
边界区分说明
标注AI辅助 ≠ 可以直接采信AI全部推演结论；AI参与创作 ≠ AI拥有学术署名资格。
AI科研署名核心闸口：AI使用完整披露、人机贡献分段标记、逐条人工核验、提示词与草稿归档、学术诚信复核。仅简单添加一句AI声明，无法消除AI幻觉带来的学术失真风险。
结语
AI仅属于科研辅助工具，不具备学术作者与专利发明人资格，署名权与学术责任归属于碳基人类研究者。人机协同科研成果需要分级披露AI使用场景，留存完整卷宗与提示词，人类必须逐条核验AI推演内容，防范幻觉污染学术知识库。科研署名边界的终审权归属学术共同体与属地碳基司法主体；不可将AI等同于共同研究者；确需将AI辅助成果正式发表归档，必须落实披露与人工复核机制，但无法完全消除AI幻觉潜藏的隐性推演错误。
