# 第090集｜传媒AI新闻生成真实性治理规范

适用：新闻机构、自媒体、内容平台AI采编、图文音视频新闻生产。管控：事实幻觉、虚构信源、伪造音视频、隐匿AI标识、批量不实资讯。本卷优先适用，冲突以此为准，可联动058确权卷宗、模型生命周期卷宗。
一、核心定义
传媒AI新闻生成系统：素材整理、初稿撰写、图文音视频合成辅助工具。AI仅产出半成品，新闻事实、审校、发布全责由发布主体承担，责任不得转嫁AI或模型厂商。
新闻事实幻觉：AI虚构人物、事件、时间、数据、权威引语，逻辑通顺但核心事实虚假。
隐性AI生成：AI产出新闻核心内容，对外发布不标注AI参与，伪装人工采编内容。
分级审校
L1：文字润色、校对改写，不新增事实，人工复核即可发布。
L2：事件综述、背景解读、数据新闻初稿，逐条溯源核验一手信源。
L3：时政、突发、司法、民生高风险新闻，AI仅整理公开权威素材，禁止AI生成核心叙事与事实判断，全部核心内容人工独立核验。
新闻生产卷宗：提示词、AI初稿、人工修改痕迹、信源核验台账、AI标识记录、审校签字；最低保存3年，重大舆情、虚假新闻纠纷永久归档。
熔断机制：检出虚构事实、伪造素材、批量不实内容，立即暂停发布、下架违规内容，启动公示更正与账号核查。
显性AI标识：AI参与制作的图文、音视频必须量化标准显性标注，禁止弱化、折叠、隐蔽标注。
批量不实资讯：同一账号/矩阵账号24小时内累计发布3条及以上已证实虚假新闻，判定为批量违规。
二、底层原则
1. 人为主导终审，AI仅作辅助，核心事实必须人工溯源核验。
2. 所有事实陈述锚定权威一手信源，禁止二次转载替代原始信源。
3. 新闻风险等级越高，AI权限越窄、人工审核层级越深。
4. AI参与内容必须透明标识，杜绝隐性AI生产。
5. 全链路留痕可溯源，错漏内容必须公示更正、闭环处置。
三、全流程精简管控
1. 素材预处理：AI仅可检索、转录、归类资料；AI提取引语、数据、细节必须逐字比对原始一手素材；AI合成音视频单独标记，严禁冒充实拍素材。L3高风险选题禁止AI推演未知事件进展、虚构观点。
2. 稿件审校：L1仅优化文字不增事实；L2所有新增事实溯源原始发布主体，杜绝二次转述信源；L3全程禁止AI生成核心叙事、事件定性、权威表态。
3. 标识量化标准：图文AI标识字号不小于正文最小字号，禁止置于底部折叠区；音视频AI标识持续展示时长≥总时长10%，禁止低透明弱化遮挡。
4. 深度伪造专项管控：公众人物、时政现场、突发事件音视频，必须核验数字水印/签名；无溯源凭证的影像素材禁止入新闻刊发。
5. 发布与传播管控：首发主体落实审校与标识；转载账号必须保留原始AI标识+转载标注，明知虚假仍转载需承担连带责任。
6. 熔断后闭环处置：违规内容下架后，原址公示更正说明不少于7日；重大事实错误须对已推送受众补发更正通知；批量违规触发账号临时封禁与全量内容核查。
7. 纠错归档：所有错漏更正记录、熔断处置记录全部纳入新闻卷宗留存。
四、多方权责
1. 发布主体：事实核查、AI标识、终审发布、纠错公示第一责任人。
2. AI厂商：公示模型幻觉风险、提供版本溯源，不得干预新闻内容生产。
3. 内容平台：核验AI标识合规、监测批量违规、执行熔断封禁、留存平台级核查日志。
4. 转载主体：保留原始标识，核验内容真伪，恶意传播虚假内容承担连带责任。
5. 受众：有权对不实新闻申请更正、溯源核查。
五、确权交叉规则
AI原生初稿归入数据保护层；人类事实核验、溯源重构、叙事订正形成独创性成果，触发权属快照并纳入著作权保护层。
卷宗、审校日志不属于创作成果，不适用快照确权。权属快照仅判定成果归属，不可替代事实核查责任。
六、禁止性规则
1. 禁止将新闻发布与事实失真责任转嫁AI、研发厂商。
2. 禁止L3高风险新闻由AI生成核心叙事、事件定性、权威观点。
3. 禁止AI伪造采访、引语、数据、实拍音视频作为新闻素材。
4. 禁止隐蔽、弱化、折叠AI生成标识，规避透明公示要求。
5. 禁止以二次转载替代一手信源核验，敷衍事实审查。
6. 禁止批量生产不实新闻、恶意转载不实AI资讯。
7. 禁止删除、篡改审校台账、信源记录、熔断处置卷宗。
七、治理谬误
1. 文字通顺、逻辑合理即事实真实谬误。
2. AI初稿小幅润色等同于人工原创采编。
3. 权属快照确权等同于内容真实合规。
4. 转载内容无需核验、无需保留AI标识。
5. 单次错漏无需公示更正、无需卷宗留痕。
全局铁律
AI仅为新闻生产辅助工具，人类承担事实终审全责；分级审校匹配风险等级，高敏感内容严控AI权限；信源必须溯源一手主体，AI标识执行量化显性标准；深度伪造、批量虚假内容触发熔断，首发与转载权责双向闭环；权属快照区分成果归属，不可豁免新闻真实性核查义务。
