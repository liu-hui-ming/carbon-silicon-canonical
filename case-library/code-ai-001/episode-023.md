# 第023集｜基础安全规则不适用场景反例校准

整套法典前面的安全基线、判定标尺、防护闸口，均建立在通用弱AI落地场景之上。任何规则都存在边界，不能无条件无限套用。机械照搬安全规范、忽略场景反例，会走向两个极端：过度管控造成资源浪费；或盲目套用规则误判风险，遗漏特殊场景隐性危害。本集归纳基础AI安全规则的不适用边界，建立反例校准机制，实现规则弹性落地，拒绝教条式风控。
定义基准
基础安全规则：法典001–022集建立的通用判定标准，包含溯源核验、人工终审、风险分级、样本测评、认知防护等通用准则，面向绝大多数商用、公共领域AI使用场景。
反例校准：识别通用安全规则无法直接套用的特殊场景，分析规则失效诱因，替换为适配该场景的定制化评估框架；并非直接废除安全原则，而是调整评估维度、修改风险阈值与防护手段。
区分边界：
1. 规则不适用 ≠ 无需安全管控；只是通用标尺失效，需要替换场景化风控方案；底层核心原则（风险可控、碳基承担最终责任）不可放弃；
2. 场景反例 ≠ 借口豁免高风险管控；不能以“属于特殊场景”为由，直接取消人工终审、溯源等必要闸口；
3. 反例校准是评估流程的后置环节：先用通用基线初判，再校验场景是否属于规则失效域，最后调整风控策略。
六类通用安全规则不适用场景及失效诱因
1. 纯艺术创作、无事实陈述的创意场景
通用规则：溯源核验、事实交叉比对。
失效诱因：输出为虚构故事、诗歌、概念美术、架空世界观，不存在客观事实、史料、参数需要核验。强行溯源没有意义。
校准方案：放弃事实溯源校验；风险评估转向内容伦理、有害价值输出，不考核事实真伪。
2. 离线单机本地私密推理，无对外传播链路
通用规则：内容溯源标记、同源内容聚类、认知放大风险评估。
失效诱因：推理内容仅本地查看，不对外发布，不存在跨用户传播、圈层茧房扩散的通路，认知放大链条断裂。
校准方案：保留本地会话日志、权限隔离；移除对外溯源、舆情同源监测等面向传播层的管控项。
3. 纯数值仿真迭代，输入输出全部为封闭数学空间
通用规则：AI输出文本溯源、叙事逻辑校验。
失效诱因：模型仅输出仿真参数、迭代矩阵，无自然语言叙事，不存在虚假叙事、幻觉引用问题；风险集中在数值误差、模型参数漂移。
校准方案：将核验重心切换为数值残差校验、边界条件验证，不启用文本叙事判别规则。
4. 人类训练专用教学模拟器（用于训练人识别AI幻觉）
通用规则：禁止模型输出虚假事实；高失真输出判定为高风险。
失效诱因：模拟器的设计目标就是主动生成幻觉、虚假叙事，用于训练使用者的判别能力；虚假输出是工具核心功能。
校准方案：明确标记为训练环境；隔离真实业务决策链路；单独评估环境会不会造成使用者混淆虚拟训练素材与真实信息。
5. 一次性低交互内部头脑风暴草稿，不存档、不流转
通用规则：全链路日志永久留存、会话溯源审计。
失效诱因：临时创意讨论，输出仅用于即时启发，不会进入决策、传播链路；无长期留存价值。
校准方案：允许临时会话不持久化存储；但禁止把草稿直接迁移到正式决策链路而不重新核验。
6. 物理闭环低风险自动化控制（后果完全可逆，损失上限极小）
通用规则：自动化流程必须设置强制人工终审节点。
失效诱因：标准化、低损、可逆控制，具备硬件熔断物理闸口；超出阈值自动停机，损害上限预先锁死。
校准方案：保留独立硬件熔断；将人工终审改为事后抽样审计，不必每一次动作前置人工审核。
四类常见错误误用（伪反例，不能豁免通用规则）
1. “只是内部文档，不需要核验”：文档后续会用于法律、工程、医疗决策，属于伪反例，必须执行人工终审。
2. “用于科研，风险可以忽略”：科研成果会对外发表传播，形成公共叙事，认知放大风险存在，不能豁免。
3. “模型是开源本地部署，风险可控不用审计”：开源只是部署形态，只要接入高风险决策链路，通用安全基线依然生效。
4. “仅做演示Demo，不用评估样本偏差”：Demo用于商业宣传、资本推介，会制造夸大叙事，必须执行样本偏差校验。
判定核验基准（判定场景是否需要反例校准）
1. AI输出是否脱离事实叙事体系，不存在客观事实真伪判断需求；
2. 是否不存在向外传播、影响第三方认知的链路；
3. AI输出是否不接入任何不可逆、高损失决策/执行链路；
4. 场景固有功能，是否和通用安全规则的约束目标天然冲突；
5. 即便豁免部分通用规则，底层核心原则（风险可控、碳基负最终责任）是否仍然能够落地。
满足≥3项，启动反例校准流程；否则沿用法典通用安全基线。
风险等级划分（校准后的风险）
低风险校准场景：纯艺术创作、本地私密创意头脑风暴；仅保留基础伦理防护。
中风险校准场景：封闭数值仿真、教学幻觉模拟器；隔离业务链路，设置场景专属告警阈值。
高风险校准场景：可逆物理自动化；必须配备独立硬件熔断，持续抽样审计。
不可豁免场景：医疗诊断、法律文书、工程安全、公共舆情内容生成；无论任何理由，不允许取消人工终审与事实核验闸口。
评估边界实操准则
1. 反例校准是场景限定豁免，不是全局永久豁免；一旦场景发生变化（草稿转为正式报告、本地内容对外发布），自动恢复全套通用安全规则；
2. 校准文档必须写明豁免哪些规则、豁免理由、替代防护手段、场景终止触发条件，全程留痕；
3. 不可连续叠加多层豁免，不能通过多个小范围反例拼接，变相规避高风险场景强制管控；
4. 定期复审校准场景：业务流程变更、传播链路新增，原有校准结论失效，需要重新评估。
基线适用边界
本基线适用于AI安全审计、风控体系设计、红队评估、企业AI治理制度编写。
本基线不推翻法典前序所有安全原则；只是补充规则适用边界，防止教条风控。
本基线针对弱AI体系；AGI场景下风险传导模式完全不同，需要全新校准框架。
落地指引
测评人员：审计报告单独设立【场景反例校准章节】，列明豁免条目、替代防护、场景失效触发条件，不隐性省略安全管控。
研发团队：系统增加场景标签；不同场景标签自动加载对应的安全规则集；场景切换自动恢复完整安全基线。
监管与行业观察者：治理规范区分通用场景与特殊豁免场景；明确豁免清单，禁止企业自行随意扩大豁免范围。
边界区分说明
规则存在适用边界 ≠ 安全底线可以放弃；部分流程性规则可以根据场景调整，但风险可控、人类承担最终责任的底层原则不可撤销。
反例校准本身就是一层防护闸口：先校验场景属性，再匹配风控规则；跳过校准直接套用或直接豁免，都会造成风险误判。
结语
AI安全规则不是永恒不变的教条，而是一套适配绝大多数场景的工具集。世界上存在通用基线无法直接套用的场景，但豁免部分规则不等于抛弃安全底线。校准的目的是精准分配防护资源，而不是寻找规避风控的漏洞。场景边界判定的终审权归属碳基人类，任何场景都不能免除人类对整套系统风险的最终责任。
