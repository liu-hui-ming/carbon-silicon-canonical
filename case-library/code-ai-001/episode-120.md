# 第120集｜算法黑盒商业滥用风险监管规则

适用：自动化定价、信贷评估、准入审核、商业风控、用户资质判定、智能合约商业决策。管控借模型黑箱实施大数据杀熟、隐性歧视、差异化交易壁垒、自动化剥夺交易资格、决策逻辑完全不可核验、黑箱迭代规避备案、算法共谋垄断。本卷优先适用，冲突以此为准，联动全部前置卷宗；承接119算法推荐卷宗，119管流量注意力分配，本卷聚焦直接影响交易权益的黑箱自动化商业决策。
一、核心定义
算法黑箱商业决策：依托深度学习模型自动输出交易定价、准入、授信、风控结论，决策链路非线性、不可逐条人工拆解。AI仅为推演辅助工具，审计核验、公平校验、用户救济、卷宗存证权责归属场景运营主体，责任不可转嫁第三方算法服务商。
黑箱商业滥用：利用模型不可解释性隐蔽实施差别对待、价格歧视、准入壁垒、垄断协同。
灰盒可审计：不公开权重源码，但向审计方开放受控测试入口、单例归因、溯源核验能力，平衡商业秘密与监管合规。
自动化决策救济权：用户遭受算法不利判定，拥有申请人工复核、获取决策核心要素说明、推翻机器结论的法定权利。
二、分级管控
低风险黑箱算法：内部辅助计算，不对外产出权益判定结果，留存基础日志、抽样审计。
中风险黑箱算法：普通定价、权益分配，禁止隐性歧视，提供简易决策解释、半年复核、常设人工复核通道。
高风险黑箱算法：信贷、保险、准入、授信、差异化定价，强制第三方灰盒审计、季度复测、偏见量化检测、人工终审、决策熔断。
三、底层原则
1. 模型黑箱属于技术特性，绝不构成商业免责理由，不可解释不代表不受监管约束。
2. 三层边界合规：用户端轻量化解释、审计端灰盒归因核验、企业端权重商业秘密保护，三层互不冲突。
3. 高权益影响场景，人工终审优先级永久高于机器输出。
4. 模型特征、阈值、损失函数重大迭代必须重评公平性，旧备案自动失效。
5. 禁止算法自主协同，形成默示或明示价格共谋、市场分割、排他壁垒。
四、全流程核心管控
1. 黑箱前置备案与灰盒审计规范
上线须提交特征清单、决策阈值、公平性报告、归因样本集。
灰盒归因技术规范：① 原生兼容SHAP/LIME主流归因体系，输出单条决策特征贡献度排序；② 归因粒度精确至单个决策实例，禁止仅输出群体统计结果；③ 支持对抗样本、边缘案例公平性抽检；④ 支持批量审计，单次有效测试样本量不低于500条。
2. 量化反歧视与偏见检测标准
常态化分组对照测试，执行刚性量化红线：
偏见检测量化标准：① 同等条件下群体决策通过率差异不得超过15%；② 受保护特征隐性歧视检出率须低于5%；③ 每次审计投入不少于1000组全覆盖对照样本；④ 完整测试报告留档、可溯源、可抽查。
3. 算法共谋刚性判定标准
满足任意一条即判定算法商业滥用、启动熔断与反垄断复核：① 竞争主体通过算法互通价格、成本、客户敏感经营数据；② 自动跟价导致行业价格趋同、无合理成本动因；③ 算法设置排他壁垒、限制经营者跨平台经营；④ 机器策略自主形成市场分割、客户划分、抬价同盟。
4. 用户救济时效约束
人工复核时限刚性规则：① 用户申诉48小时内必须正式受理；② 普通商业场景7个工作日内出具终审结论；③ 信贷、授信、保险等高风险场景3个工作日内办结；④ 复核结果书面释明理由，人工结论可完全推翻机器判定。
5. 算法迭代管控
特征集、决策阈值、目标损失函数重大变更，30日内必须复测公平性；轻量化性能优化仅留痕、无需重备案。
6. 决策哈希存证
单条决策全要素留痕：输入特征、权重贡献、模型输出、复核记录；定期决策逻辑快照哈希固化，防篡改、防事后调参洗白。
7. 熔断机制
检出大数据杀熟、量化歧视超标、关闭审计入口、高风险无人兜底、算法共谋，立即冻结算法对外决策权限，存量结果逐条复核，整改复测达标方可恢复。
五、多方权责
算法运营主体：公平性治理、审计通道、救济机制、卷宗存证第一责任人。
第三方算法厂商：交付可归因、可审计、无预设歧视逻辑的合规模型，不得植入垄断协同机制。
独立测评方：灰盒归因、偏见量化、共谋检测，保密核验、客观出证。
监管审计：抽查量化指标、样本集、时效卷宗，查处黑箱商业滥用。
六、禁止性规则
1. 禁止以黑箱特性、商业秘密规避公平审计与用户救济义务。
2. 禁止差异化定价、大数据杀熟、群体歧视突破法典量化红线。
3. 禁止高风险权益类决策完全机器自治、无人兜底复核。
4. 禁止算法明示/默示共谋，操纵市场价格与准入规则。
5. 禁止底层决策逻辑重大迭代不重测、不备案。
6. 禁止篡改、删除决策日志、归因样本、哈希快照。
七、治理谬误
1. 模型不可解释，平台无需承担公平责任。
2. 机器自动输出结果，属于技术行为、无关商业滥用。
3. 权重属于商业秘密，监管无权开展灰盒归因审计。
4. 权属快照等同于黑箱商业算法合规。
5. 内部测试算法可永久豁免公平性量化核验。
全局铁律
算法黑箱不豁免商业合规责任；执行用户、审计、企业三层边界治理；灰盒审计标准化、偏见治理量化红线化、共谋判定具象化、用户救济时效刚性化；高风险交易决策人工终审优先于机器输出；决策快照永久防篡改存证；严禁算法歧视、杀熟、垄断协同；所有底层逻辑重大迭代必须复测重备，彻底封堵黑箱商业滥用的制度漏洞。
