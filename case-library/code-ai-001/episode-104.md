# 第104集｜气象AI预测输出风险提示与责任边界

适用：短临强对流预报、中长期气候推演、极端灾害预判、区域降水/风力/温湿度AI研判、气象灾害预警辅助系统。管控：气象幻觉、极端天气漏报误报、预报置信度隐匿、模型季节漂移、预测结论直接等同于官方预警、责任推诿。本卷优先适用，冲突以此为准，联动058确权卷宗、模型生命周期卷宗。
一、核心定义
气象AI预测系统：气象要素趋势统计、天气情景推演、灾害风险初判辅助工具。AI仅输出预测备选推演结果，气象预警发布、灾害处置、防灾调度最终决策权归气象主管机构，责任不得转嫁AI或模型厂商。
气象AI幻觉：模型生成不存在的天气系统，误判强对流、台风路径、暴雨落区，输出脱离真实大气观测的预测结论。
分级管控
L1：气象要素统计、历史数据复盘、气候趋势可视化，只读分析，后台抽样审计，不对外发布预测结论。
L2：常规天气推演、次一级灾害风险预研判；输出内容必须附带置信度区间，人工复核后方可作为内部参考材料，不可直接对外发布预警。
L3：台风、特大暴雨、强龙卷风、寒潮等重大极端灾害预判，AI仅做多情景推演，禁止直接生成官方预警结论，多层气象专业人员终审，必须和传统数值预报交叉比对。
气象AI卷宗：原始观测探测数据、AI多情景推演结果、置信度记录、人工复核痕迹、模型漂移告警、灾害复盘记录；最低保存3年，重大气象灾害漏报误报案例永久归档。
永久归档清单：灾害事件前后完整观测时序数据、AI多版本推演结果、置信度评估记录、人工评审意见、与传统数值预报比对记录、复盘报告。
熔断机制：检出观测数据异常、气象幻觉、模型漂移超标，暂停AI推演结果采信，以传统数值预报与人工研判为主。
置信度基线：所有AI气象推演输出必须标注置信度区间；置信度低于阈值的推演结果，不得作为灾害研判核心依据，严禁省略风险提示直接对外传播。
二、底层原则
1. 气象预警发布主权归属气象主管机构，AI仅推演辅助，AI结论不等于官方气象预警。
2. 多源观测数据交叉校验，单一探测源异常自动降权，杜绝单源数据驱动AI预报。
3. 风险等级越高，AI推演结论采信权重越低，人工终审与跨模型比对约束越强。
4. AI预测结果必须显性标注置信度与不确定性边界，禁止简化为确定性结论对外传播。
5. 随季节、气候态变化常态化校验模型漂移，定期开展极端气象场景仿真测试。
三、全流程管控
1. 数据准入：融合雷达、探空、地面站、卫星多源观测；单一探测设备故障，对应观测数据降权，不送入AI主推理链路。
交叉校验规则：同一天气系统，至少两类独立观测源佐证方可纳入模型输入；单源独有的异常回波标记低置信度，不生成灾害预判。
2. 分级执行：L1仅统计复盘；L2推演附带置信度，人工复核仅限内部参考；L3极端灾害场景AI输出多套情景，必须与传统数值预报交叉比对，不能单独采信。
3. 模型漂移判定：AI预报与实况要素平均偏差连续10天超出阈值、同类灾害预判误报率连续两周高于基准线，任一条件满足判定漂移超标触发熔断。
4. 对外传播管控：AI生成气象推演内容对外传播，必须明确标注【AI推演，非官方预警，存在不确定性】；禁止自媒体、平台摘除风险提示直接当作确定性预报扩散。
5. 熔断处置：观测失真、幻觉频发、漂移超标，降低AI结果权重，切换至传统预报体系主导研判，启动模型校准。
四、多方权责
1. 气象主管机构：预警终审、预报质量管控、不确定性提示、灾害处置第一责任人。
2. 模型厂商：披露模型局限、气象幻觉与季节漂移风险，不得承诺AI预报绝对精准。
3. 气象研发集成方：落实多源观测校验、置信度计算、漂移监控机制。
4. 监管审计方：抽查卷宗，核验置信度标注、交叉比对、漂移管控落实情况。
5. 传播主体：对外发布AI气象推演内容，保留原始风险提示，不得篡改、删除不确定性说明。
五、确权交叉规则
AI原生气象时序推演脚本、气候仿真代码归入数据保护层；气象专家设定预报约束、置信度阈值、不确定性提示逻辑重构触发权属快照，独创性部分纳入著作权保护层。
观测日志、预报评审卷宗不适用快照确权。权属快照仅判定成果归属，不可替代气象预报质量校验，不免除气象主管机构预警发布主体责任。
六、禁止性规则
1. 禁止将气象预警、灾害研判责任转嫁AI、模型厂商。
2. 禁止L3重大极端灾害场景，仅凭AI推演结果直接发布官方预警。
3. 禁止隐匿置信度，把概率性AI推演包装成确定天气结论对外传播。
4. 禁止单路观测数据直接驱动气象AI，缺少多源交叉校验。
5. 禁止摘除AI推演风险提示，将AI推演等同于国家官方气象预警。
6. 禁止屏蔽模型漂移、气象幻觉告警，在异常状态持续采信AI预报结论。
7. 禁止删除篡改观测时序、AI推演版本、人工评审卷宗。
七、治理谬误
1. 历史数据集拟合效果好，即可省略传统数值预报比对谬误。
2. AI输出预报结论，可直接作为官方预警发布。
3. 权属快照确权等同于气象AI预测结果可靠。
4. 概率推演的不确定性说明可以省略，方便公众理解。
全局铁律
气象AI仅输出多情景概率推演，气象主管机构承担灾害预警全责；多源观测交叉校验，极端灾害研判必须与传统数值预报比对；所有AI推演强制标注置信度与不确定性提示，检出模型漂移触发熔断；严禁将AI推演直接作为官方预警；权属快照区分成果归属，不可豁免气象预报风险与不确定性审查义务。
