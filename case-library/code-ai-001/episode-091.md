# 第091集｜短视频AI内容生态风险与内容管控

适用：创作者、MCN、平台AI短视频生产。管控：深度伪造仿冒、低俗擦边、模板同质化批量内容、虚假人设、隐匿AI标识、版权侵权。本卷优先适用，冲突以此为准，联动058确权卷宗、模型生命周期卷宗。
一、核心定义
短视频AI生成系统：文案、数字人、画面、配音、剪辑辅助工具。AI仅半成品，发布主体承担内容、肖像、版权、导向全责，不得转嫁AI/厂商。
数字泔水：模板化批量产出，套路重复、价值空洞，挤压原创生态。
AI虚假人设：AI换脸、语音克隆打造虚拟身份，冒充公众人物、当事人营销牟利、骗取捐赠。
分级审校
L1：字幕润色、简单画面修补，不改动核心叙事，人工复核发布。
L2：AI生成画面、配音、脚本初稿，人工核验导向、肖像权、版权，AI标识强制添加。
L3：涉时政、突发事件、公众人物、未成年人内容，AI仅素材整理，禁止AI生成核心叙事与人像合成，多层人工终审。
短视频生产卷宗：提示词、AI原始素材、修改痕迹、肖像授权、AI标识记录、审校记录；最低保存2年，侵权、诈骗、重大舆情案例永久归档。
熔断机制：检出深度伪造、批量低质、仿冒侵权、严重低俗，暂停发布；矩阵账号批量违规，限制流量、冻结发布权限。
AI量化标识：画面持续显示，时长≥总时长10%；不可半透明、小字折叠隐藏。
二、底层原则
1. 人为主导终审，AI仅作生产辅助。
2. 肖像、声音合成必须取得当事人明示授权。
3. 分级管控，涉公共人物、未成年人内容收紧AI权限。
4. AI参与内容强制显性标注，杜绝隐性AI内容。
5. 抑制模板化批量低质内容，保护原创创作者。
三、全流程管控
1. 素材制作：AI生成人像、语音，必须核验授权；禁止无授权换脸、克隆人声。L3高风险选题禁止AI合成人物画面。
2. 内容审校：L1仅优化画面字幕；L2核查版权、肖像、导向；L3严禁AI生成核心叙事与人像。
批量模板化内容增加原创度核验。
3. 发布标识：AI内容执行量化显性标注；转载AI短视频须保留原始AI标识，明知违规仍转发承担连带责任。
4. 平台流量管控：对同质化批量AI内容降低推荐权重；榜单、热门推荐禁止推送AI虚假人设内容。
5. 熔断处置：矩阵账号24小时内批量发布低质/违规AI短视频，触发熔断，限制发布并全量核查。
四、多方权责
1. 发布主体/MCN：内容导向、肖像授权、版权、AI标识第一责任人。
2. AI厂商：提示深度伪造风险，保留模型版本溯源，不得干预内容创作。
3. 平台：落实AI标识校验、识别批量模板内容、执行熔断处置、留存核查日志。
4. 受众：对仿冒、低俗、侵权AI短视频可提交举报。
五、确权交叉规则
AI原生脚本、画面素材归入数据保护层；人类原创叙事、镜头重构、价值校正触发权属快照，独创性部分纳入著作权保护层。
卷宗、审校日志不适用快照确权。权属快照仅判定成果归属，不可替代内容合规、肖像与版权审查。
六、禁止性规则
1. 禁止将短视频内容责任转嫁AI、模型厂商。
2. 禁止未经授权AI换脸、克隆他人语音，冒充他人人设营销。
3. 禁止AI生成低俗、暴力、邪典、侵害未成年人内容。
4. 禁止隐匿、弱化AI生成标识。
5. 禁止批量生产模板化低质数字泔水，矩阵账号大规模分发。
6. 禁止删除、篡改授权材料、审校、标识卷宗。
七、治理谬误
1. 添加AI标签即可规避内容侵权、导向责任谬误。
2. 模板批量生产属于正常创作，无需原创度审查。
3. 权属快照确权等同于内容合规、肖像授权完备。
4. 转载AI短视频，无需核验、无需保留原始AI标识。
全局铁律
AI仅短视频生产辅助，发布主体承担内容、肖像、版权全责；分级审校匹配风险，严控深度伪造与虚假人设；AI标识执行量化标准，平台抑制同质化批量低质内容；权属快照区分成果归属，不可豁免内容合规审查义务。
