# 第103集｜农业AI智能化应用安全与数据规范

适用：大田种植、设施农业、畜禽养殖、病虫害识别、灌溉施肥AI、农机自动驾驶、农情遥感、农产品产销预测AI系统。管控：农情感知幻觉、水肥参数误推荐、农机自主作业失控、土壤种质数据泄露、区域产量预判失真、气象耦合偏差、农田地理敏感信息外流。本卷优先适用，冲突以此为准，联动058确权卷宗、模型生命周期卷宗。
一、核心定义
农业AI智能系统：农情图像识别、长势研判、病虫害初判、水肥方案推荐、农机作业规划、产量预估辅助工具。AI仅输出参考方案与研判线索，田间作业执行、农资投入决策、农机自主作业、种质资源处置最终决策权归农业生产主体，责任不得转嫁AI或模型厂商。
农情感知幻觉：AI误判作物长势、病虫害类型、土壤墒情，输出错误灌溉、施肥、农药施用方案，造成减产、土壤污染。
分级管控
L1：农情遥感汇总、长势统计、产量趋势监测，只读分析，后台抽样审计，不输出作业执行指令。
L2：水肥调控建议、病虫害识别预警、农机路径规划方案；方案落地前人工复核，农资投入剂量设置上下限约束。
L3：大田农机全自动作业、种质资源AI筛选、大面积统防统治方案，AI仅提供态势参考，禁止自主下发作业强指令，强制人工终审，保留手动紧急接管通道。
农业AI卷宗：田间原始传感数据、图像采集样本、AI推荐方案、人工复核记录、告警日志、种质与地块信息脱敏记录；最低保存2年，大面积减产事故、种质数据泄露案例永久归档。
永久归档清单：事故前后连续7天传感时序数据、AI方案版本、人工审批记录、熔断切换日志、农机接管记录、复盘报告。
熔断机制：检出感知幻觉、参数越界、模型漂移超标、农机定位异常，终止AI自动作业指令，切至人工手动控制模式。
数据脱敏基线：地块精准坐标、种质基因数据、养殖场核心繁育数据对外上传前脱敏；原始敏感农业数据禁止裸传至公有大模型。
二、底层原则
1. 农业生产决策权归属生产经营主体，AI仅研判辅助，高危田间作业禁止AI自主闭环强干预。
2. 传感多源交叉校验，单一传感器异常自动降权，避免单点感知失效误导农事操作。
3. 风险越高，AI作业权限越收敛，人工复核约束越强。
4. 种质、农田地理敏感信息最小采集，脱敏后才可对外传输。
5. 常态化模型校验，针对极端气象、灾害场景开展仿真验证。
三、全流程管控
1. 架构准入：农机自动作业系统必须保留独立手动接管通道，AI不可作为唯一作业控制源。
2. 感知输入：土壤、气象、图像多源传感交叉校验；单一传感器故障时自动降权，不单独驱动AI决策。
交叉校验规则：同一农情目标，至少两类独立传感源（图像+土壤传感器/气象站）验证一致方可采信；单源检出异常标记低置信度，不生成作业建议。
3. 分级执行：L1仅监测统计；L2水肥、植保方案人工复核；L3全自动农机作业仅做态势展示，AI不自主下发作业指令。
4. 模型漂移判定：作物长势预判与实测产量偏差连续两周期大于20%、病虫害误判单日累计超30次，任一条件满足判定漂移超标触发熔断。
5. 熔断处置：感知异常、参数越界、定位漂移，切断AI作业指令链路，切换人工接管，启动模型复核。
四、多方权责
1. 农业生产经营主体：农事方案终审、农机安全运维、种质数据保护第一责任人。
2. 模型厂商：披露模型边界、农情幻觉风险，不承诺农事方案绝对适配多变田间工况。
3. 系统集成商：部署传感校验、参数阈值拦截、紧急手动接管机制。
4. 监管审计方：抽查卷宗，核查数据脱敏、农机应急接管、模型漂移管控有效性。
五、确权交叉规则
AI原生农情统计、产量预测脚本归入数据保护层；农业专家设定水肥约束、植保安全阈值、应急接管逻辑重构触发权属快照，独创性部分纳入著作权保护层。
田间传感日志、审计卷宗不适用快照确权。权属快照仅判定成果归属，不可替代农业生产安全校验，不免除农业生产主体农事决策责任。
六、禁止性规则
1. 禁止将田间作业、种质资源管理安全责任转嫁AI、模型厂商。
2. 禁止撤除农机手动接管通道，把AI作为农田作业唯一控制源。
3. 禁止L3高危场景AI自主下发植保、农机作业强执行指令。
4. 禁止单路传感数据直接驱动农事AI决策，缺少交叉校验。
5. 禁止种质、地块精准坐标等敏感数据不脱敏裸传外部大模型。
6. 禁止屏蔽感知幻觉、模型漂移告警，异常状态持续启用AI作业。
7. 禁止删除篡改传感时序、AI方案、人工复核卷宗。
七、治理谬误
1. 试验田仿真效果良好，大田工况无需人工复核谬误。
2. AI识别病虫害准确，可直接自动喷施农药。
3. 权属快照确权等同于农业AI满足田间作业安全标准。
4. 田间数据属于普通环境数据，无需脱敏保护。
全局铁律
农业AI仅输出农情研判与备选农事方案，生产主体承担农业生产与种质数据安全全责；农机作业保留手动应急接管通道，高危农事禁止AI自主闭环执行；多源传感交叉校验，模型漂移超标触发熔断；敏感农业数据强制脱敏；权属快照区分成果归属，不可豁免田间作业安全与农业数据保护审查义务。
