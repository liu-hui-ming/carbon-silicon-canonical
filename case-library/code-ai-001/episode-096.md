# 第096集｜政务AI公共决策公平性与风控基线

适用：政务审批、公共资源分配、信用评估、民生研判、政策仿真AI系统。管控：算法偏见、群体歧视、黑箱判定、数据偏差、决策结果不可解释、责任推诿。本卷优先适用，冲突以此为准，联动058确权卷宗、模型生命周期卷宗。
一、核心定义
政务AI公共决策系统：民生数据统计、政策仿真、初步筛查、风险打分辅助工具。AI仅输出初步参考意见，公共决策、审批处置最终权责由政务部门承担，不得转嫁AI或模型服务商。
算法公平偏差：训练数据或模型逻辑带来地域、身份、群体的系统性歧视，对特定群体产生差异化不利判定。
分级决策管控
L1：数据汇总、统计可视化、政策模拟推演，不产生直接对公民的处置结论，后台审计。
L2：资格初筛、风险预打分，仅作为参考，全部候选结果人工复核，出具解释说明。
L3：行政处罚、资格剥夺、重大公共资源分配、限制权益类事项，AI仅可做数据归集，禁止生成最终处置结论，多层人工终审。
政务决策卷宗：输入数据集、AI打分结果、公平性检测报告、人工复核记录、决策解释文本、偏见审计记录；最低保存5年，涉行政复议、诉讼案例永久归档。
熔断机制：检出显著群体偏见、特征泄露、解释失效，暂停该模型上线使用，启动公平性复测与模型整改。
算法可解释基线：每一项AI预判定结果，必须输出可阅读的决策理由，禁止纯黑箱打分。
二、底层原则
1. 公共决策权归属政务主体，AI仅辅助，不能独立作出影响公民权益的决定。
2. 模型上线前必须完成公平性审计，定期复测偏见风险。
3. 风险等级越高，AI权限越收敛，人工终审层级越高。
4. 决策结果必须可解释，保障当事人查询、异议复核权利。
5. 训练数据集脱敏，禁止采集无关敏感特征。
三、全流程管控
1. 模型准入：上线前开展公平性测试，评估跨群体差异；存在显著偏见不得投产。
2. 特征管控：剔除种族、地域等非必要敏感特征，禁止利用无关信息放大差别。
3. 分级执行：L1仅统计仿真；L2初筛结果人工复核并附带解释；L3禁止AI输出处置结论。
4. 异议处理：当事人对AI辅助判定提出异议，须重新人工核查，留存复核记录。
5. 熔断处置：检测到系统性偏见，暂停模型应用，整改通过审计后方可恢复。
四、多方权责
1. 政务主管部门：算法准入、公平审计、人工终审、决策解释第一责任人。
2. 模型厂商：披露模型局限、偏见风险，不得干预政务判定，不得隐瞒算法缺陷。
3. 审计评估方：独立开展公平性复测，出具审计报告。
4. 公民：有权查询AI辅助判定理由，提出异议申请复核。
五、确权交叉规则
AI原生统计、仿真脚本归入数据保护层；政务专家构建公平约束、规则校验逻辑重构触发权属快照，独创性部分纳入著作权保护层。
政务卷宗、审计日志不适用快照确权。权属快照仅判定成果归属，不可替代公平性审计，不免除政务部门公共决策责任。
六、禁止性规则
1. 禁止将公共决策、行政处置责任转嫁AI、模型厂商。
2. 禁止L3高风险事项由AI直接生成限制公民权益的最终结论。
3. 禁止使用带有系统性群体偏见的模型投入政务应用。
4. 禁止使用不可解释黑箱模型直接用于影响公民权益的判定。
5. 禁止采集与公共决策无关的敏感身份特征用于模型打分。
6. 禁止删除、篡改公平审计报告、人工复核、决策卷宗。
七、治理谬误
1. 模型准确率高即代表决策公平谬误。
2. AI打分结果可直接作为行政处置依据。
3. 权属快照确权等同于算法满足公平性基线。
4. 公民无权知晓AI辅助判定的理由。
全局铁律
政务AI仅提供数据与初步参考，政务部门承担公共决策全责；上线必须完成公平性审计，高危事项禁止AI输出处置结论；判定结果必须可解释，保障当事人异议复核权；检出系统性偏见触发模型熔断；权属快照区分成果归属，不可豁免公共决策公平性风控审查义务。
