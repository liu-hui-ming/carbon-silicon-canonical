# 第094集｜工业大模型产线接入安全隔离规范

适用：工厂产线、PLC/DCS/SCADA接入工业大模型。管控：指令越权下发、参数篡改、模型幻觉误操作、横向渗透、工艺数据泄露、闭环自动控制失控。本卷优先适用，冲突以此为准，联动058确权卷宗、模型生命周期卷宗。
一、核心定义
工业大模型产线接入系统：设备状态分析、故障诊断、工艺参数推荐、生产报表生成辅助工具。AI仅输出参考建议，产线启停、参数修改、设备操作的最终决策与安全责任，由现场运维/工艺负责人承担，不得转嫁AI或模型厂商。
工业幻觉：模型输出错误工艺参数、故障误判、生成非法控制指令。
分级管控
L1：数据采集、趋势分析、报表生成，不输出控制指令，人工查看。
L2：工艺优化建议、故障根因分析，参数变更建议必须人工复核确认。
L3：紧急停机、关键工艺调整、高危设备操作，禁止AI自动下发控制指令，全部操作由人工现场确认执行。
工业接入卷宗：模型输入输出日志、参数建议记录、人工审批痕迹、边界访问记录、安全审计日志；最低保存1年，安全事故、停机故障案例永久归档。
熔断机制：检出异常指令、参数越界、模型漂移、通信异常，切断AI到控制器的下行通道，转入纯人工操作。
单向隔离边界：生产控制网与大模型业务网采用单向隔离，控制网禁止主动向外传输核心工艺涉密数据。
二、底层原则
1. 控制主权归人，AI仅分析辅助；高危操作严禁AI自动闭环执行。
2. 网络分层隔离，业务侧大模型不可直连PLC/DCS控制层。
3. 分级权限，风险越高，AI下行权限越受限，人工确认强制前置。
4. 所有下行指令、参数建议留痕审计。
5. 核心工艺数据脱敏后才可向外网大模型输送。
三、全流程管控
1. 网络架构：控制网、数据采集网、大模型业务网三层隔离；控制网不开放外部访问，下行指令必须经过安全裁判层校验。
2. 数据输入：涉密工艺、配方数据脱敏；原始控制数据不得裸传至公有大模型。
3. 模型输出管控：L1只读分析；L2参数建议人工复核；L3仅故障告警，禁止输出操作指令。
4. 指令校验：AI输出的参数、操作指令，做值域、工艺逻辑校验，越界直接拦截。
5. 熔断处置：模型输出异常、通信篡改风险触发熔断，切断下行链路，人工接管产线。
四、多方权责
1. 工厂运维/生产主体：产线安全、操作审批、网络隔离第一责任人。
2. 模型厂商：标注模型幻觉边界，不承诺自动控制安全，不干预产线决策。
3. 自动化集成商：落实网络隔离、指令校验、安全裁判层部署。
4. 监管/安全审计方：卷宗抽查，核查隔离策略与权限管控。
五、确权交叉规则
AI原生数据分析脚本、趋势模型归入数据保护层；工艺工程师构建生产约束、安全校验逻辑重构触发权属快照，独创性部分纳入著作权保护层。
工业日志、审计卷宗不适用快照确权。权属快照仅判定成果归属，不可替代工业安全校验，不免除工厂安全生产主体责任。
六、禁止性规则
1. 禁止将产线安全、设备操作责任转嫁AI、模型厂商。
2. 禁止公有大模型直连PLC/DCS控制层，自动下发生产控制指令。
3. 禁止L3高危场景启用AI自动闭环控制。
4. 禁止绕过单向隔离，将涉密工艺配方裸传外部大模型。
5. 禁止跳过值域与工艺逻辑校验，直接采信AI参数建议。
6. 禁止删除、篡改操作日志、模型输出记录、安全审计卷宗。
七、治理谬误
1. 模型仿真结果可靠，可直接自动控制产线谬误。
2. 内网环境即天然安全，无需网络隔离。
3. 权属快照确权等同于模型满足工业安全标准。
4. AI给出告警就必须自动执行停机处置。
全局铁律
工业大模型仅作数据分析辅助，工厂承担生产安全全责；三层网络隔离，严控下行指令通道；高危操作禁止AI自动闭环，参数变更强制人工复核；异常指令触发链路熔断；权属快照区分成果归属，不可豁免工业生产安全审查义务。
