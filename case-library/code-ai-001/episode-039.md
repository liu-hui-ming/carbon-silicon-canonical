# 第039集｜多模态模型跨媒介隐蔽投毒风险

跨媒介隐蔽投毒，是利用图像、音频、视频、文档等载体，将恶意触发器、隐写指令、跨模态后门嵌入非文本媒介；在训练投毒阶段植入潜伏行为，或推理阶段加载带毒媒介，借助跨模态融合机制激活恶意输出。区别于文本提示注入、算力耗尽攻击：文本注入载荷直接存在于文字token；算力耗尽攻击目标是耗尽推理资源；跨媒介隐蔽投毒依托多模态编码器与跨模态潜空间，把恶意触发逻辑藏在像素、波形、帧序列之中，人眼人耳无法感知，文本安全过滤器完全失效；可实现“单一媒介投毒，全模态触发”的跨媒介后门激活。
定义基准
多模态跨媒介隐蔽投毒（Cross-Media Stealth Poisoning for MLLM）分为训练阶段数据投毒与推理阶段隐写注入两类。训练投毒通过污染图文/音视频配对数据集，在跨模态连接器、视觉/音频编码器植入后门；推理注入将恶意指令以人不可感知的扰动、隐写编码嵌入图像、音频、PDF载体，多模态编码器提取潜特征后触发模型定向有害行为。
区分边界：
1. 跨媒介隐蔽投毒 ≠ 文本提示注入。文本注入载荷在文本token；跨媒介投毒载荷藏在像素、声波等非文本载体，绕过文本层清洗；二者可叠加；
2. 跨媒介隐蔽投毒 ≠ 普通图像对抗样本。传统对抗样本目标是分类器错判；跨媒介投毒针对跨模态融合模块，激活大模型生成文本、图像等链式输出；
3. 跨媒介隐蔽投毒 ≠ 单模态后门。单模态后门仅能被本模态触发；跨媒介投毒可在图像埋入触发器，后续用音频、文本即可激活后门，跨模态潜空间实现触发迁移。
跨媒介隐蔽投毒四类典型攻击形态
1. 训练集图文配对投毒（跨模态后门预埋）
在预训练/微调数据集插入少量毒样本：视觉载体为正常图片，配对文本为恶意目标输出。污染跨模态对齐空间，在连接器中构建恶意潜特征簇。后续任意模态输入落入该潜空间，即可触发后门。
特点：投毒一次，跨模态生效；干净样本下模型功能正常，常规精度评测无法检出后门。
2. 图像隐写/像素扰动注入（推理阶段静态载体投毒）
利用LSB最低位像素修改、频域隐写、微小不可见噪声，把恶意指令嵌入图片。肉眼看不出异常，但多模态视觉编码器提取特征后，自动解析并执行隐藏指令。可嵌入合同、截图、网页图片批量传播。
特点：载体外观完全正常，人工审查难以发现；文本安全风控完全不扫描像素空间。
3. 音频/视频隐写投毒
将触发指令编码在超声频段、次声波或视频帧微小像素扰动中。人耳无法辨识，音频编码器、视频帧提取模块读取隐藏载荷，劫持会话上下文，引导后续对话持续遵循攻击者设定规则。
特点：适合语音交互、视频解析类Agent流水线；载体为日常音视频，传播隐蔽性极强。
4. 文档载体复合投毒
PDF、扫描件内嵌入低对比度小字、水印隐写、背景像素扰动。OCR与视觉编码模块读取隐藏指令，实现文档上传即触发注入；文档表层内容合规，人工审阅只会阅读显性文字。
特点：业务场景高发，企业文档处理、票据识别、知识库上传链路极易中招。
跨媒介隐蔽投毒传导链路
攻击者投放带毒图像/音频/文档载体 → 多模态编码器提取视觉、音频潜特征，跨模态融合模块将像素、波形特征映射至共享潜空间 → 恶意特征激活预埋后门或解析隐写指令，改写会话上下文；若无模态独立清洗、潜空间异常检测、媒介解耦校验闸口 → 模型被劫持，持续输出有害内容，污染后续多轮对话，甚至向下游Agent传递恶意指令。
跨媒介隐蔽投毒核心安全隐患
1. 文本安全体系存在天然盲区
现有护栏、内容过滤大多仅校验文本token；像素、声波属于独立模态空间，文本侧检测完全无法覆盖，防护断层。
2. 载体人眼不可感知，传播成本极低
毒图片、毒音频肉眼人耳看不出异常，可嵌入社交图片、附件、网页素材批量分发，人工抽检几乎不可能捕获。
3. 跨模态后门具备模态迁移能力
仅污染图像侧连接器，后续音频、文本输入也可激活后门；投毒面缩小，但触发入口被放大，单点污染扩散至多模态全链路。
4. 多模态Agent链式放大危害
Agent自动读取网页、解析附件、调用多模态模型；单一带毒图片注入后，恶意指令会持续传递到下游工具调用、子Agent，形成链式劫持。
5. 模态压缩、格式转换不一定消除载荷
JPEG压缩、音频重采样不一定清除隐写扰动；部分后门特征存在于高层潜空间，简单转码无法消除触发能力。
判定核验基准（评估跨媒介隐蔽投毒暴露风险）
1. 安全风控仅校验文本输入，图像、音频、视频、PDF载体无独立模态清洗与隐写检测；
2. 多模态训练、微调数据集缺少图文/音视频配对样本的完整性校验，无毒样本筛查；
3. 跨模态融合、连接器模块未做后门审计，仅评估模型显性问答安全；
4. 允许外部来源图片、音视频直接送入编码器，前置无媒介净化、重绘/重采样脱敏；
5. 红队仅测试文本越狱，未构造隐写图片、音频扰动、PDF文档类跨媒介隐蔽投毒用例；
6. 多模态Agent自动解析外部网页、附件，未设置媒介隔离，载荷可自动注入会话上下文。
满足两项及以上，跨媒介隐蔽投毒暴露等级偏高。
风险等级划分
低跨媒介投毒风险：仅纯文本交互，关闭图像、音频、文档上传能力；仅使用内部可信数据集，无外部媒介输入。
中跨媒介投毒风险：开启多模态能力；外部媒介前置脱敏、重采样净化；隐写样本抽检；高风险媒介人工复核；定期跨模态红队测试。
高跨媒介投毒风险：公网开放图片、音视频、文档上传；支持Agent自动解析外部素材；一旦触发投毒，可大范围传播劫持会话；必须部署媒介前置净化、多模态潜特征异常检测、跨模态后门专项审计、媒介与文本会话解耦校验。
不可控跨媒介投毒风险：公网开放多模态上传，媒介无前置清洗，无跨模态后门审计；原则上禁止上线；确需上线必须满足五项条件：外部媒介强制重绘/重采样脱敏、模态独立隐写检测、跨模态潜特征异常监控、跨媒介投毒专项红队、媒介载荷与会话上下文解耦；即便全部落实，仅提升攻击门槛，无法彻底根除跨媒介隐蔽投毒威胁。
评估边界实操准则
1. 不存在能100%检出全部隐写、跨模态后门的检测方案；潜空间扰动可不断迭代规避检测器，防御只能抬高攻击代价。
2. 文本安全模块与多模态编码器必须解耦；不可把媒介安全校验交给多模态模型自身，防止模型被投毒后自检失效。
3. 红队必须构造复合场景：跨媒介投毒叠加提示注入、隐写图片叠加长上下文会话劫持，不可单独测试单一媒介载荷。
4. 基座、视觉编码器、跨模态连接器、LoRA微调更新后，必须执行跨模态后门回归测试；参数改动会改变潜空间，后门触发阈值发生漂移。
落地指引
测评人员：安全审计新增跨媒介隐蔽投毒评估章节；红队覆盖图像隐写、音频扰动、PDF文档、跨模态后门四类用例；报告标注隐写检出率、后门触发成功率、媒介前置净化失效风险。
研发团队：外部上传图像强制重绘、音频强制重采样，破坏像素级隐写扰动；多模态输入做模态隔离，媒介解析结果不直接继承至系统提示；对训练图文配对数据集做异常样本筛查；监控跨模态潜空间异常聚类；多模态Agent禁止自动解析不可信外部素材；模型迭代后，复测跨模态后门触发特性。
监管与行业观察者：将跨媒介隐蔽投毒纳入多模态大模型安全评估；区分文本安全与多模态媒介安全；要求高风险多模态系统披露媒介脱敏、隐写检测、跨模态后门审计方案。
边界区分说明
图片肉眼正常 ≠ 不存在隐藏恶意指令；媒介无显性违规内容 ≠ 不会触发跨模态后门。
跨媒介投毒防护核心闸口：外部媒介强制脱敏重采样、模态独立隐写检测、跨模态潜特征监控、媒介载荷与会话解耦、跨媒介后门专项红队。仅依靠文本安全过滤，无法抵御藏在像素与声波中的隐蔽投毒。
结语
多模态融合打开了像素、音频、文档的全新攻击面。跨媒介隐蔽投毒把恶意触发器藏在人类感知盲区，文本护栏完全失效，训练预埋的跨模态后门更可实现“一次投毒，多模态触发”。这类风险是多模态共享潜空间架构带来的结构性伴生风险，无法被任何单一媒介检测手段彻底消除，只能持续抬高攻击成本、阻断载荷向会话上下文传播。模型跨媒介潜空间边界的终审权归属碳基人类，不可仅凭载体肉眼正常就判定媒介安全；确需开放外部图像、音视频、文档上传，必须搭建媒介前置脱敏、模态隔离与潜特征研判机制，但仍不能完全根除跨媒介隐蔽投毒的威胁。
