# 第001集｜AI风险的分层分类体系与客观评估基线

AI技术持续迭代落地，各类风险混杂在一起，容易出现两种极端误判：要么泛化夸大所有AI风险，将局部缺陷上升为文明危机；要么简化轻视风险，只关注明显的攻击事件，忽略长期、隐性的认知层面危害。建立分层分类体系与客观评估基线，目的就是剥离主观情绪，搭建一套标准化框架，区分不同风险的来源、影响范围、危害层级，为后续审计、测评、治理提供统一参照标尺。
AI风险七层分层框架
1. 第一层：基础认知安全层
风险聚焦人与AI交互过程中的认知偏差。包含公众对AI能力的误读、信息茧房、AI输出带来的认知污染、人机依赖等问题。风险作用于人的判断逻辑，不直接破坏系统硬件与代码，但会长期改变个体与群体的认知基准。
2. 第二层：技术风险边界层
风险源于模型本身、算法、训练数据、部署架构。包含幻觉、提示注入、数据投毒、后门、分布外失效、推理漂移等。风险发生在AI系统内部，是系统运行过程中产生的原生技术缺陷。
3. 第三层：人机权责确权层
风险集中在AI产出物的归属、损害追责、版权、内容溯源、深度伪造带来的法律与责任纠纷。
核心矛盾是厘清碳基人类、研发方、运营方、使用者之间的权责边界。
4. 第四层：全行业落地治理层
风险出现在AI嵌入各行各业之后。医疗、教育、金融、工业、法律、政务等场景，各自衍生场景专属风险，需要行业配套规则、人工终审机制、场景适配的安全约束。
5. 第五层：算法算力顶层监管层
风险属于产业与公共资源层面。算力垄断、模型准入、跨境模型流动、备案审计、算法反垄断、安全事故监管追责等，属于宏观制度层面的风险管控。
6. 第六层：文明级认知风控层
风险具备长周期、群体性特征。群体认知偏移、知识范式固化、跨代认知污染、文明价值冲突，影响人类群体长期的判断能力与知识传承。
7. 第七层：通用AI法典终局层
针对AI长期演进的治理框架，包含体系修订规则、边界定义、文明稳态约束，作为整套法典的顶层约束与归档基准。
风险分类维度（四维度判定）
1. 来源维度：内生风险 / 外部诱发风险
内生风险：模型自身固有缺陷，如幻觉、对齐偏差、表征漂移；外部诱发风险：外部输入带来的攻击，如提示注入、对抗样本、训练数据投毒。
2. 显现时序维度：即时风险 / 累积长期风险
即时风险：触发后立刻显现危害，例如单次深度伪造诈骗、单次提示注入越权；累积长期风险：单次影响微弱，反复叠加后逐步放大，如长期人机认知依赖、持续认知污染。
3. 影响范围维度：个体级 / 行业级 / 社会文明级
个体级：仅对单个人产生影响；行业级：影响一个产业的生产、科研、服务秩序；社会文明级：大范围改变群体认知范式、公共价值判断基准。
4. 可控性维度：可干预修复风险 / 不可逆固化风险
可干预修复：风险出现后，人工介入、系统补丁、数据清洗能够消除危害；不可逆固化：认知、范式层面发生永久性偏移，事后难以逆转。
客观评估基线（量化判定准则）
评估AI风险，禁止仅凭主观感受定性，必须依次核验四项基础指标：
1. 可复现性：风险现象是否能够稳定复现。偶发、无法稳定复现的现象，不能直接定义为系统性风险；
2. 触发条件：明确风险触发的前置条件，区分普通正常输入、边界输入、恶意攻击输入；
3. 危害传导链路：核查风险从AI输出，传导到人类决策、实体系统的完整路径，判断危害能否落地；
4. 阻断成本：评估阻断该风险需要投入的人力、算力、制度成本，判断管控可行性。
风险等级划分：低风险、中风险、高风险、极端风险。
低风险：仅产生轻微干扰，无法传导至决策，无实质损失；中风险：在特定条件下产生局部偏差，可人工拦截，危害范围有限；高风险：可误导关键决策，造成经济、名誉损失，阻断需要较高成本；极端风险：具备跨层级传导能力，可造成群体性、长期不可逆的认知或实体损害。
基线适用边界
本分层分类基线适用于各类大模型、AI智能体、AI生成系统、数字孪生等AI应用。
本基线不是直接判定结论，只是评估工具，不能替代碳基人类完成最终风险判定。
基线不适用于纯粹的传统软件漏洞，传统软件安全漏洞不属于本法典AI风险体系的评估范畴。
落地指引
测评人员：评估AI风险，第一步先归类风险所处层级，再从四个维度完成定性，对照基线评定风险等级，不直接贴标签；研发团队：在模型设计阶段，识别对应层级风险，提前部署阻断机制；监管与行业观察者：区分技术缺陷、权责纠纷、社会认知影响，避免将不同层级风险混为一谈，不放大、不淡化。
边界区分说明
技术漏洞不等于文明风险；单次输出错误不等于系统性认知污染。很多AI问题仅停留在第二层技术边界层，不会自动向上传导至文明层面。风险存在传导壁垒，每一层都有独立的闸口，只要闸口生效，上层风险就不会被触发。
结语
AI风险并非单一类型的危险，而是多层级、多维度的复合体系。这套分层分类体系与评估基线，核心目的就是建立统一客观标尺，剥离情绪化判断，精准定位风险所处层级、来源与危害潜力。所有风险评估的终审权归属碳基人类，AI仅作为评估辅助工具，不可自主判定风险等级。
