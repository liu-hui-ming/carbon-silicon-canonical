# 第078集｜AI内容确权动态适配机制

本卷承接073数据资产权属、077确权取证卷宗。解决静态确权的根本缺陷：AIGC成果随迭代、二次修改、多主体协同，权属状态会持续迁移；静态一次性确权无法覆盖版本演化链条。
沿用058卷宗链上哈希、贡献度量化标尺，与074/075/076体系对齐，建立版本快照、贡献权重动态重算、权属状态自动更新、变更留痕的适配规则。
一、核心定义
确权动态适配：不以成果首次生成为唯一确权节点；随多轮提示词迭代、人工修编、第三方二次改编、模型版本升级，重新核算人类实质贡献，同步更新权属定性与权利份额，全程写入058确权取证卷宗。
权属快照：每一次重大修改，冻结版本、哈希、贡献占比，生成独立链上快照，作为该时间切片的权属基准。
核心铁律：权属随贡献流动，快照锁定历史状态；旧快照不被新版本覆盖，历史权属永久保留可追溯。
二、三层权属状态动态标尺（刚性量化）
状态1：非作品态（初始自动生成）
仅单次简单提示词，无多轮筛选、无人工润色，人类贡献不足阈值。
定性：不构成著作权意义作品；按073归入数据资产，享有有限使用权。
阈值：人类贡献占比＜20%。
动态迁移：后续追加多轮提示迭代、人工深度修改，贡献抬升，可升级为作品态。
状态2：人机协同作品态（核心确权区间）
持续提示词迭代、参数调控、多轮筛选、人工后期改写，人类实质智力投入达标。
阈值：人类贡献占比≥20%。
定性：使用者享有著作权；多人协同创作，按各自贡献比例分份额。
动态迁移：他人二次改编，新增独立独创性投入，衍生出新版本快照，形成衍生作品权属。
状态3：衍生改编态
在已有AIGC成果基础上，第三方再次提示迭代、人工重制。
铁规：衍生版本权属不消灭原版本快照权利；衍生作者仅对新增独创性部分享有权利，原作者保留基础成果权利。
贡献占比核算规则：评估提示词设计、取舍筛选、人工改写、结构重构四项维度，加权打分，记入058确权卷宗。
三、版本快照触发规则（自动锚定）
发生以下任一行为，强制生成新版本快照，链上存证，重算贡献与权属：
1. 提示词大规模重构，改变核心表达；
2. 人工对输出内容做结构性改写、重绘、剪辑；
3. 更换基座模型，基于同一旧提示重新生成；
4. 第三方拿到成果后独立二次创作；
5. 多人协作新增主体参与创作。
仅微小文字纠错、调色、标点修正，属于微调，不触发新快照，不改变原有权属状态。
四、动态变更的四类典型场景
1. 单人持续迭代
初始简单提示（非作品态），经10轮提示词优化+人工重写，贡献抬升，快照升级为作品态。
历史快照保留，可核验权属演进全过程。
2. 多人协同共创
A提供基础构思与首轮提示，B负责多轮筛选与后期人工修改；每一轮新增贡献更新权重，按贡献比例划分共有著作权，全部记入卷宗。
3. 二次衍生改编
甲方原始AIGC作品（已快照存证），乙方在原作基础上加入独立独创性改造。乙方仅对新增部分享有权利；原成果权属不变，未经许可不得商用。
4. 模型升级重生成
使用同一套提示词，切换新版基座模型重新生成内容。属于全新生成，独立确权，不继承旧版本权属；旧快照保持独立有效。
五、合同格式条款红线（动态权属禁止霸王条款）
1. 平台/模型方不得通过格式合同，一次性永久攫取全部后续迭代版本的完整著作权；
2. 不得约定：只要使用平台API，用户所有迭代成果自动归平台；
3. 合同约定权属转移，必须逐版本明示、单独确认，不能预先概括兜底；
4. 格式条款强行剥夺用户动态迭代产生的著作权份额，该条款无效。
六、动态确权举证规则（对接077取证标准）
1. 每一次版本快照，作为一级证据；哈希校验通过，推定快照时点权属真实。
2. 主张权属升级/份额变更，必须提交连续版本卷宗链，证明新增人类独创性投入。
3. 仅提供最终成品，缺失中间迭代快照，无法证明贡献演变，则不支持动态权属升级主张。
4. 发生争议，可交叉调阅：058确权卷宗、模型生命周期卷宗、平台审核卷宗。拒不提交卷宗，推定不利于该方。
七、权属动态变更三大红线
1. 快照覆盖禁止：新版本生成，不得删除、篡改旧版本链上快照；历史权属切片永久留存。删除旧快照，直接丧失该版本权属主张资格。
2. 贡献回溯禁止：后续新增的人类贡献，不能反向提升早期版本的贡献占比与权属定性；每个快照独立评判。
3. 衍生范围禁止：二次改编者，不能借新增贡献，吞并原作基础权属。
八、多方主体权责刚性切割
1. 初始创作者：负责建立首版058确权卷宗；迭代修改时触发快照、更新贡献记录。
2. 二次改编方：仅对新增独创性表达享有权利；使用原作须遵守原成果许可约束。
3. 模型研发方：不自动享有AIGC内容著作权；仅模型底层算法、训练数据适用073/075。
4. 平台运营方：提供版本快照自动归档能力；不得单方面篡改、截断版本链条，适用076。
九、过错梯度
轻微瑕疵：迭代快照归档滞后，但哈希完整、时序可复原，可补录。
一般过错：缺失部分中间版本快照，权属演进链条断裂，证明力下降，需大量二级证据补强。
重大过错：刻意删除旧快照、伪造贡献权重、篡改版本时序；证据作废，构成虚假举证。
十、四类治理谬误击穿
1. 一次生成永久确权谬误：首次生成即锁死权属，忽略后续人工深度修改带来的权利变化。
2. 新版本吞并旧成果谬误：二次改编生成新版本，即可抹除原作权属。
3. 平台格式概括确权谬误：一次勾选协议，平台永久占有用户未来所有迭代成果。
4. 贡献跨快照回溯谬误：后期人工修改，反向提升早期版本著作权定性。
十一、五项刚性核验基准
任意一条成立，动态权属主张不成立：
1. 版本迭代无链上快照，缺失中间版本记录；
2. 无法区分原作基础表达与二次改编新增独创性部分；
3. 删除、篡改历史快照，破坏权属演进链条；
4. 格式条款概括掠夺全部迭代版本著作权；
5. 主张贡献占比提升，但卷宗无对应人类实质智力投入记录。
边界铁律
快照锁定时间切片，贡献决定权属状态；版本迭代可升级定性，旧权属不可被新版本抹除；衍生仅保护新增表达，平台不可一次性概括攫取迭代权益。
结语
本卷补齐静态确权短板，建立随创作迭代动态流转的权属适配体系，完成073（资产权属）→077（取证标准）→078（动态迭代确权）完整权属闭环。

AI动态确权终审权归于碳基创作主体与属地知识产权法治体系。成果可变、迭代永续，但每一刻的权属切片，由链上快照与人类实质贡献锚定。
