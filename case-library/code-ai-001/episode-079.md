# 第079集｜确权规则不适用场景反例校准

本卷承接073数据资产权属、077确权取证流程、078确权动态适配机制。确权体系建立正向判定标准之后，必须划定边界，明确哪些场景直接跳出整套AIGC确权规则，不适用著作权归属、贡献度核算、版本快照动态适配等条款。本卷以反例校准方式，厘清适用边界，避免确权规则无限扩张，防止将算法运行、自动化输出、工具内部数据、公共基础素材纳入权属争议评价范围。本卷宗与058确权取证卷宗、模型生命周期卷宗、平台审核卷宗保持卷宗体系互通，争议审理时可交叉调阅核验。
一、核心定义
确权规则适用范围：本法典权属系列条款，仅针对由人类主体发起、具备独创性智力投入、生成独立外部表达成果的人机协同创作行为。
确权规则不适用场景：AI系统运行产生的输出，不满足创作要件，不进入著作权确权评价，不执行贡献占比核算、版本快照动态更新等确权流程。此类输出可依据073数据资产规则、合同约定、隐私保护、知识产权其他分支规则处理，但不适用AIGC著作权确权体系。
核心铁律：有创作行为方有权属评价；仅为系统日志、中间计算数据、基础模板、自动化例行输出，不触发确权。
二、第一大类：模型内部运算产物，不适用确权规则
模型训练、推理过程中产生的内部中间张量、特征向量、注意力权重、缓存记忆片段、临时中间草稿，仅服务于模型内部运算，并未对外形成可供传播、感知的完整表达成果。
1. 模型推理阶段临时生成的碎片文本、局部图像色块，未输出给用户，仅作为内部过渡数据。
2. 训练阶段产生的损失值、梯度参数、嵌入向量、特征库，属于模型算法与数据载体本身组成部分。
3. 模型记忆缓存、检索索引、知识库片段，用于召回参考素材，不属于创作成果。
定性：该类产物属于模型运行的技术副产品，不存在面向外部的独立表达，不启动人类贡献度评估，不生成058确权快照。即便被意外泄露，也仅按照数据资产、商业秘密、隐私保护相关规则处置，不适用著作权确权。涉及跨境数据泄露的内部运算产物，权利人可依数据出境安全评估、跨境司法协助等规则寻求救济。
三、第二大类：例行自动化运维输出，无人类独创性干预
由预设定时任务、系统自动化脚本批量生成，不存在针对性提示词迭代、人工筛选取舍、结构重构等实质性智力投入。
1. 平台自动生成的报表、统计图表、日志摘要、系统告警文本、自动化标签。
2. 固定模板自动填充输出：固定模板，仅自动填入日期、编号、基础信息，表达形式完全预设，不存在独创性选择空间。若模板仅提供格式框架，内容层面的论证路径、素材选择、表达结构由AI根据输入动态生成且存在人类筛选干预，则不属于纯模板填充，应进入确权评价。
3. 系统自动备份、自动转码、自动格式转换生成文件，仅改变存储载体与文件格式，不产生新的独创性表达。
定性：仅执行预设流程，人类操作仅限于开启任务、设置基础参数，不存在创造性构思与表达取舍。不进入确权评价，不核算贡献占比。若模板本身存在独创性，模板著作权归模板创作者；自动填充后的成品不新增独立著作权。
四、第三大类：基础公共素材、通用基础信息输出
AI输出内容仅复述公共领域知识、法律法规条文、公开通用数据、通用公式、基础常识、通用历史事实，不存在独创性表达编排。
1. 直接复述法条、国家标准、公开统计原始数据、通用科学定理、基础时间地点事实。
2. 通用词典释义、基础名词解释，内容属于公有领域基础信息，不存在独创性选择与编排。
3. 简单清单、基础目录，仅罗列客观条目，无独创性结构安排。
定性：事实本身无著作权，AI复述客观基础信息形成的内容，不产生新著作权。若存在独创性的筛选、编排、整理，则编排部分单独评估。校准示例：单纯按时间/字母排序不构成独创性编排；存在个性化分类体系、叙事结构、视觉设计的编排，方可进入确权评价。
五、第四大类：提示词仅作为指令调用，无创作构思
提示词仅为功能性调用指令，仅告知AI执行一项机械任务，不存在构思、风格设计、表达架构等独创性智力投入。
1. 仅输入指令“翻译这段文字”“总结全文”“提取关键词”，无风格、叙事、构图、结构层面的创作设计。
2. 指令仅限定输出格式，不涉及内容表达层面的独创性选择。
区分校准：单纯功能性指令不触发确权；若提示词包含完整故事架构、画面构图、叙事风格、人物设定等独创性构思，则落入确权规则适用范围，按078动态适配机制评估人类贡献。
六、第五大类：安全管控、对抗校验类测试样本
用于模型红队测试、安全对抗、漏洞检测、内容审核压力测试生成的测试样本，目的仅为验证模型安全边界，不属于创作产出。
1. 研发、测评人员批量构造对抗提示，用于测试模型越狱、偏见、深度伪造风险。
2. 平台用于审核模型效果的测试集样本，仅用于校验识别准确率。
定性：生成目的为安全测评，不以产出独创性表达成果为目标，不适用AIGC确权规则。样本本身若挪用在先他人作品，单独评估侵权责任。安全测试中使用他人作品作为输入素材，须符合合理使用或法定例外情形；超出合理使用范围的测试输入，单独评估训练/输入端侵权责任。
七、第六大类：违法生成内容，直接排除确权保护
生成内容本身属于法律禁止创作、传播的内容，无论人类投入多少智力贡献，直接排除确权体系保护，不进行贡献度核算与权属快照登记。
1. 伪造公文证件、伪造司法文书、深度伪造用于诽谤、诈骗的音视频。
2. 内容侵害他人人格权、宣扬违法犯罪、危害国家安全，属于法律禁止的表达。
定性：不法成果不受著作权保护，不纳入AIGC确权评价。相关主体承担侵权、行政乃至刑事责任，适用法典责任体系相关条款。
八、边界校准判定流程
发生权属争议，第一步先做适用范围筛查，判定是否落入不适用场景。判定顺序：
1. 判断成果是否属于对外独立完整表达；无对外表达，直接排除确权。
2. 判断生成目的：是创作产出，还是运算缓存、运维报表、安全测试。
3. 判断人类投入性质：是独创性构思与表达取舍，还是单纯功能性调用指令。
4. 判断内容合法性：违法内容直接排除确权保护。
权属争议审理中，被诉方可援引本卷主张成果不属于确权适用范围；主张方须首先证明成果不属于本卷列明的不适用场景，方可进入贡献度核算阶段。
经筛查认定属于不适用场景，则终止确权流程，不再核算人类贡献占比、不生成版本快照。当事人的争议，依照数据资产、合同、侵权、商业秘密等其他规则处理。
九、多方主体权责刚性切割
1. 成果使用方：主张著作权保护，首先承担举证责任，证明成果不属于本卷列明的不适用场景，具备独创性表达与人类实质智力投入，提交058确权卷宗。无法证明，则确权主张不予支持。
2. 模型研发方：模型内部中间数据、缓存产物，由研发方管控，不对外自动生成确权快照，适用075模型隐性责任条款。
3. 平台运营方：自动报表、模板填充类自动化输出，平台无需启动确权存证流程；若平台错误对非创作产物标记著作权快照，该权属标记无效。
4. 争议相对方：抗辩时可援引本卷反例校准规则，主张成果不属于确权适用范围，阻断对方权属主张。
十、四类治理谬误击穿
1. 凡AI输出即有权属谬误：只要AI产生文本、图像文件，就自动进入AIGC确权评价，忽略内部运算数据、自动化报表、纯指令调用等例外场景。
2. 有人类操作即属于创作谬误：人类仅下达机械功能性指令，就认定存在独创性贡献，放大确权规则适用边界。
3. 快照万能登记谬误：无论何种AI输出，全部自动生成058权属快照，将技术副产品当作创作成果。
4. 违法成果享有权属谬误：只要投入提示词创作，即使生成违法伪造内容，依然主张著作权保护。
十一、五项刚性核验基准
满足任意一项，AIGC著作权确权规则不予适用：
1. 产物属于模型内部推理缓存、特征向量、梯度等中间运算数据，未对外形成完整独立表达。
2. 固定模板自动填充生成，仅替换基础信息，不存在独创性表达编排。
3. 输出内容仅复述公有领域客观事实、法条、基础常识，无独创性筛选与编排。
4. 提示词仅为功能性任务指令，无构思、风格、叙事、构图等独创性智力投入。
5. 生成内容属于法律禁止传播的违法内容。
边界铁律
先勘适用边界，再评权属贡献；内部运算无创作，机械输出无确权；违法成果不保护，基础事实无著作权。
