# 第092集｜法律AI文书辅助生成效力边界规范

适用：律师、法务、司法人员、当事人使用AI起草合同、诉状、答辩状、法律意见书。管控：法条幻觉、虚构判例、事实错漏、涉密泄露、隐瞒AI辅助、过度信赖AI结论。本卷优先适用，冲突以此为准，联动058确权卷宗、模型生命周期卷宗。
一、核心定义
法律AI文书辅助系统：法条检索、文书初稿、合同条款草拟、类案整理工具。AI仅产出参考初稿，文书签署、提交、法律适用的全部法律责任，由使用人/执业法律主体承担，不得转嫁AI或厂商。
法律幻觉：AI编造法条、司法解释、案号、裁判观点，引用虚假判例，法律条文释义失真。
分级文书管控
L1：格式校对、条文排版、文字润色，不改案件事实与法律定性，人工复核确认。
L2：简单合同、常规诉状初稿，逐条核验法条、判例，人工完成事实与法律研判。
L3：重大疑难案件、刑事文书、涉国家安全/群体性纠纷法律文件，AI仅限法条与类案检索，禁止AI生成法律定性、核心论证、裁判建议，全部核心内容由法律专业人员独立研判。
法律文书卷宗：提示词、AI初稿、人工修订痕迹、法条判例核验台账、涉密脱敏记录、AI辅助标注；最低保存3年，诉讼争议、错案、涉密案件永久归档。
熔断机制：检出虚构法条、虚假判例、涉密信息泄露，禁止文书提交；已提交法庭的，主动补正说明，接受司法核查。
AI辅助标注：向法院、合同相对方提交文书时，如实标注AI辅助范围，不得隐匿。
二、底层原则
1. 人为主导，AI仅工具；法律定性、事实认定必须由人独立判断。
2. AI输出法条、判例必须溯源核验原始权威文本，禁止直接采信。
3. 案件风险越高，AI权限越窄，专业人员实质审查义务越强。
4. 涉密案件材料不得直接输入AI，落实数据脱敏。
5. 提交司法机关的AI辅助文书，应当主动披露AI使用情况。
三、全流程管控
1. 素材输入：涉密、未公开案卷材料须脱敏后才可使用AI；禁止直接上传完整案件卷宗。
2. 文书生成：L1仅优化格式文字；L2初稿逐条核对法条、判例原文；L3禁止AI生成案件定性与核心法律论证。
3. 事实与法律核验：AI给出的案例、法条必须核对权威来源，不得采信AI编造裁判观点。
4. 提交与披露：提交法院、合同签约方，如实标注AI辅助范围；隐瞒AI辅助造成司法妨碍的，由提交人承担责任。
5. 熔断处置：检出法律幻觉、虚假案例，文书不得提交；已提交须主动更正说明。
四、多方权责
1. 文书使用/签署主体：事实核查、法律适用、AI披露第一责任人。
2. AI厂商：提示法律幻觉风险、保护用户数据，不提供法律意见，不替代专业法律判断。
3. 司法机关：有权核查AI辅助文书，对隐瞒AI辅助、提交虚假法律素材予以处置。
4. 当事人：不能以AI生成文书为由免除自身举证、陈述责任。
五、确权交叉规则
AI原生文书初稿归入数据保护层；人类独立事实梳理、法律论证、条款重构触发权属快照，独创性部分纳入著作权保护层。
卷宗、核验台账不适用快照确权。权属快照仅判定成果归属，不可替代法律事实、法条真实性审查，不免除文书签署主体法律责任。
六、禁止性规则
1. 禁止将文书法律责任转嫁AI、模型厂商。
2. 禁止L3高风险案件由AI生成法律定性、核心论证、量刑建议。
3. 禁止直接采信AI编造法条、虚构判例作为诉讼依据。
4. 禁止未经脱敏，将涉密案卷、隐私案件资料输入AI。
5. 禁止向法庭、签约对方隐瞒AI辅助文书的事实。
6. 禁止删除、篡改法条核验记录、修订痕迹、卷宗材料。
七、治理谬误
1. AI生成文书格式规范即法律结论正确谬误。
2. 判例由AI检索得出，无需核验原始裁判文书。
3. 权属快照确权等同于文书内容合法、法条真实。
4. AI辅助文书无需向司法机关主动披露。
全局铁律
AI仅法律文书辅助工具，文书签署人承担全部法律责任；分级管控匹配案件风险，重大疑难案件严控AI生成边界；AI产出法条判例必须溯源核验，涉密材料强制脱敏；提交司法文书须如实标注AI辅助；权属快照区分成果归属，不可豁免法律专业审查义务。
