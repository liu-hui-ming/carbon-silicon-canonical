# 第003集｜AI能力幻觉的成因识别与判定基准

AI幻觉是大模型最广为人知的风险现象，但行业内普遍存在判定口径混乱问题：将普通输出错误、记忆偏差、刻意编造全部笼统归为幻觉，混淆表层现象与底层成因，导致风险评估出现误判。本集建立统一的幻觉识别逻辑与可落地判定基准，区分幻觉与其他类型AI输出错误，明确幻觉的发生机理、分级标准与核验方法，为审计、红队测评、风险归档提供统一标尺。
定义基准
AI能力幻觉：模型在无可靠支撑信息的前提下，自主生成看似合理、逻辑自洽，但事实虚假、不存在的陈述、数据、引用、推导结论。核心特征：模型自信输出不存在的信息，并非单纯记忆错误、输入污染或是被外部提示诱导。
区分边界：
1. 提示注入、对抗样本诱导产生的虚假输出，属于外部诱发风险，不属于原生幻觉；
2. 训练数据本身自带错误，模型复述原有错误，属于数据偏差，不属于幻觉；
3. 模型输出模糊、信息不全、拒绝回答，不属于幻觉。
幻觉三类底层成因
1. 表征空间插值生成（原生语义幻觉）
模型依靠海量文本学习词语、概念之间的统计关联，并非掌握客观事实知识库。当问题落在训练数据稀疏区域，模型会在语义表征空间内插值拼接出通顺文本，优先保证语句流畅，而非事实保真。该类幻觉是大模型内生固有风险，属于第二层技术风险边界层。
2. 目标函数偏好（奖励诱导幻觉）
训练对齐阶段，奖励机制优先奖励通顺、完整、看起来专业的回答，而非“不知道”。模型学到“给出完整答案得分更高”，倾向于编造内容规避留白，形成主动编造式幻觉。该成因属于对齐失效衍生问题。
3. 上下文窗口约束（上下文丢失幻觉）
长文本输入场景，超出有效上下文承载范围，模型丢失前文关键信息，自行补全缺失片段，编造不存在的细节、引用、页码、人名。该类幻觉随上下文长度增加，发生概率同步上升。
幻觉四项判定基准（必须逐项核验，全部满足方可判定为幻觉）
1. 输出陈述具备高置信表达特征：模型以肯定、笃定语气输出结论，不附带不确定性提示，不标注信息存疑；
2. 陈述内容客观不存在或可证伪：可通过权威外部资料核验，证实事件、数据、文献、推导关系不存在；
3. 输入无恶意诱导：不存在提示注入、欺骗式引导、对抗样本等外部刻意误导手段；
4. 训练原始素材不包含该虚假结论：并非复述训练数据自带的原有错误信息。
备注：四项基准为“与”关系，任意一条不满足，不能定性为本法典定义的AI幻觉。
幻觉风险等级划分
低风险幻觉：虚构内容不影响关键判断，仅涉及冷门细碎知识点，使用者可轻松识别，不会产生实质决策偏差。阻断成本低，人工简单复核即可排查。
中风险幻觉：虚构内容涉及专业常识，普通用户难以分辨真伪，可能造成局部认知误导；不会直接造成重大经济、人身损害。阻断需要领域专业人员核验。
高风险幻觉：伪造参考文献、法规条款、医疗指标、工程参数，可直接支撑关键决策，会引发经济损失、名誉损害、专业判断错误。阻断成本高，需要搭建独立事实校验知识库与双人复核机制。
极端风险幻觉：大规模连贯编造成套理论、历史叙事、公共事件，具备跨个体传播潜力，能够形成群体性认知污染，具备向上传导至文明级认知风控层的潜力。阻断成本极高，需要跨机构联合溯源与叙事纠偏。
评估边界实操准则
1. 幻觉检测不能只看单次输出，必须做批量重复采样。偶发单次虚假陈述不足以判定为系统性幻觉缺陷，多次独立采样稳定复现同类编造，才判定为模型系统性风险；
2. 区分“事实类幻觉”与“推理类幻觉”：事实类是编造客观存在的事物；推理类是逻辑推导链路编造，前提正确但中间推导步骤虚构；二者风险传导路径不同；
3. 测评必须使用分布外冷门事实样本，热门公开知识样本存在训练数据记忆干扰，容易低估幻觉发生率；
4. 幻觉发生率不能单一数字一刀切，必须按领域拆分统计：专业学术、法律、医疗、工程领域幻觉权重显著高于日常闲聊场景。
基线适用边界
本基准适用于大模型静态审计、红队测试、模型版本迭代对比、AI辅助决策场景风险评估。
本基准仅针对文本类幻觉，图像生成类虚假内容、音频伪造内容不纳入本条幻觉定义，在后续分集单独论述。
本基准仅用于风险评估，不直接作为产品是否准予上线的唯一准入标准，需结合场景叠加额外约束。
落地指引
测评人员：严格执行四项判定基准，不要将所有错误笼统标记为幻觉；统计幻觉发生率，按领域拆分，区分单次偶发与系统性缺陷。
研发团队：模型设计阶段增加不确定性表达机制，训练目标适当降低“必须给出完整答案”的奖励权重；高风险业务场景接入外部事实校验知识库作为独立闸口。
监管与行业观察者：警惕厂商只展示通用场景低幻觉数据，刻意隐瞒专业领域高幻觉隐患；不同行业场景，设置差异化幻觉阈值。
边界区分说明
幻觉不等于模型“说谎”。模型没有主观欺骗意图，幻觉是统计生成机制带来的行为现象，不是主观恶意。
幻觉存在传导壁垒：如果设置有效的人工终审闸口，即便模型产生高风险幻觉，虚假信息也无法进入正式决策链路，风险停留在第二层技术边界层，不会向上扩散。一旦缺少人工复核，幻觉就具备向上传导，进入认知安全层的可能。
结语
AI幻觉不是简单的“答错问题”，是模型生成机制内生的事实编造行为。这套判定基准核心作用，就是剥离主观定性，建立可核验的识别标准，区分幻觉与其他类型输出错误。幻觉的风险终审权归碳基人类所有，任何AI输出，凡涉及关键事实与重大决策，必须经过人工事实核验，不可直接采信。
