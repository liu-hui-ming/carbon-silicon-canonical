# 第061集｜开源模型权重归属与商用权限边界

本卷承接057训练数据版权、060多方责任卷宗。057聚焦训练输入端素材版权；061聚焦模型权重本体的权属、许可效力、衍生微调权重、商用阈值、许可证违约后果。权重开放≠软件源代码开源，传统开源协议原生适配代码，直接套用至参数权重会产生法律错位，属于AI资产合规底座。
定义基准
开源模型权重：神经网络经过预训练、对齐、微调后形成的参数矩阵文件，包含预训练基础权重、LoRA适配器、量化衍生权重。权重开放，是权利人通过许可证有条件下放下载、推理、微调、分发权限；不代表放弃权属，不等于训练数据集、训练脚本、评估素材自动开放。
风险核心：“开源权重可商用”是许可条款赋予的合同权利，并非天然权利；大量自定义社区许可证设置营收/月活阈值，超过阈值必须另行签署商业授权；传统GPL/AGPL传染条款套用至权重衍生体，司法层面存在巨大不确定性，不可直接照搬软件开源逻辑。
区分边界：
1. 权重权属 ≠ 训练数据版权。权重是训练后的参数载体；训练数据是输入素材，两套独立客体，权重开源不代表训练语料合法。
2. 权重许可 ≠ 三分确权体系。三分确权针对人机生成物；本卷针对模型参数资产本身的授权流转。
3. 权重许可 ≠ 模型输出物版权。许可证约束权重本身，多数许可证不直接承诺模型生成内容的权属，输出物权属仍适用055、056卷宗规则。
五层权重判定链条
1. 原始权重权属主体判定
基础预训练权重的原始权属归属于训练投入方（法人/自然人）。
• 自研基座：投入算力、人力、资金的机构持有权重相关财产利益；
• 社区贡献联合训练：按贡献协议划分权属，无书面协议极易产生权属争议；
• 法律定性：权重能否构成著作权意义上作品存在争议；司法实践中，可依托反不正当竞争规则保护其商业价值，未经许可抓取、替换权重做商用替代可构成侵权。
2. 许可证类型分层校验
• OSI标准许可证（MIT/Apache2.0）：无营收/月活上限，允许商用、微调、权重再分发；仅保留版权声明与免责义务；
• 自定义社区许可：设置MAU、营收阈值，超过阈值必须获取商业授权；附带安全行为约束（OpenRAIL类责任许可）；
• 强传染类许可（GPL/AGPL）：软件场景要求衍生源代码开源；迁移到权重领域，“微调权重是否属于衍生作品”尚无统一司法定论，属于高风险灰色地带。
3. 衍生权重边界判定（微调/LoRA/蒸馏/量化）
• 量化、格式转换：一般视为原权重的副本，受原许可证约束；
• LoRA适配器：独立轻量参数分支，许可传染效力存疑；
• 全参数微调：改变基础参数，是否构成衍生作品，个案裁量；
• 蒸馏模型：从原模型提取能力，不直接复制权重文件，但仍可能落入许可约束与不正当竞争风险。
4. 商用行为定性判定
商用判定不以是否直接收费为唯一标尺，包含：对外API推理服务、嵌入产品销售、私有化部署交付、企业内部大规模降本替代原有闭源采购。
• 非商业科研：院校、内网封闭推演，一般满足宽松许可；
• 商业服务：面向客户提供推理、嵌入产品，触发许可证阈值校验。
5. 许可失效与违约后果判定
违反许可证条款，授权自动终止，继续使用、分发权重构成合同违约；同时可能触发不正当竞争追责。
许可条款中的安全禁止性义务（禁止生成有害内容），属于私约约束，不能替代公法层面的内容安全义务。
四类典型权重合规失稳形态
1. 权重开源等同于全资产开放认知误区
下载开源权重，默认训练数据集、训练脚本、全部衍生产物自动免费商用。权重开放与训练数据开放相互独立，权重开源无法解决底层训练素材版权污染风险，风险会传导至模型输出。
特点：行业高频误判，叠加057训练数据版权风险形成复合侵权。
2. 混淆标准开源许可与自定义社区许可
直接套用Apache/MIT宽松逻辑，忽略社区许可证内置月活、营收门槛；企业规模扩张后，未主动申请商业续约，持续商用。
特点：许可隐性违约，随业务规模扩大风险爆发。
3. 套用软件开源传染规则，无差别推定微调权重强制开源
将GPL/AGPL代码传染逻辑直接套用于大模型微调权重，认为只要基于GPL基座微调，全部新权重必须强制开源。权重不属于传统源代码，传染效力没有统一司法定论，不能作为绝对化判断。
特点：合规评估过度保守或过度乐观，两头踩坑。
4. 衍生权重无溯源、无许可标记
微调、蒸馏、量化后的衍生权重，不记录原始基座来源、许可证版本、修改点位；二次分发时，下游使用者无法校验原始许可约束，许可链条断裂。
特点：资产溯源失效，违反全局哈希归档基线。
权重许可风险传导链路
未经许可证校验，直接下载开源基座权重商用；忽略营收阈值、传染条款，衍生微调权重不标记来源与许可；基座底层训练数据存在版权污染 → 模型部署对外提供服务；若无权重来源台账、许可版本哈希归档、衍生权重审计闸口 → 触发许可违约、不正当竞争、输出端生成物侵权多重诉讼风险。
开源权重核心安全隐患
1. 许可证合同效力存在地域司法差异
AI自定义许可属于格式合同，不同属地法院对约束条款（月活上限、行为限制）的解读尺度不一致，存在裁判不确定性。
2. 基座底层污染无法通过权重许可消除
即便权重许可证允许商用，若原模型训练数据集存在侵权素材，衍生模型输出依然会复刻原作表达，触发057卷宗输入端版权风险。
3. 衍生权重权属链条断裂
多层二次微调、多模型权重融合，会形成复杂权属链条；缺少版本快照与许可记录，下游使用者难以追溯原始授权边界。
4. 许可安全条款不能豁免公法责任
许可证禁止用于深度伪造、有害推演，属于私约约束；使用者违规生成有害内容，模型提供方、部署方依然要承担060卷宗所述的公法与民事损害责任，许可证不能作为免责盾牌。
5. 跨境权重流转叠加出口管制风险
超大规模模型权重跨境下载、分发，需要同步审查出口管制规则，超出单纯版权许可维度。
判定核验基准（开源权重体系核验项）
1. 将权重开源等同于训练数据集、训练脚本自动开放商用；
2. 混淆标准开源许可与自定义社区许可，忽略月活、营收商用阈值；
3. 直接套用软件GPL/AGPL传染规则，绝对化判定微调权重强制开源；
4. 衍生量化、LoRA、蒸馏权重，不记录基座来源、许可证版本、修改快照；
5. 认为权重许可证可以豁免训练素材侵权、内容安全、个人信息保护等法定责任；
6. 权重资产无哈希归档，无法核验基座版本与许可链路。
满足两项及以上，开源权重体系暴露风险偏高。
风险等级划分
低权重合规风险：内网科研，仅MIT/Apache2.0小参模型，不对外商用分发；权重来源台账完整，不做大规模微调。
中权重合规风险：许可分类校验；基座与衍生权重版本快照+哈希归档；区分标准许可与自定义许可；评估微调/蒸馏衍生风险；训练素材来源独立筛查。
高权重合规风险：大规模基座商用部署、对外推理服务、衍生权重分发；必须落实权重权属台账、许可证逐条审核、商用阈值监控、衍生权重溯源归档、训练素材独立版权筛查、跨境出口管制评估。
不可控权重合规风险：不校验许可、无版本溯源，直接商用部署；原则上禁止上线对外服务；确需启用必须满足五项条件：权重权属台账、许可证逐条审核、商用阈值监控、衍生权重哈希归档、训练素材独立筛查；即便全部落实，微调衍生权重是否构成衍生作品，司法个案裁量不确定性无法消除。
评估边界实操准则
1. 核心隔离：权重许可约束参数文件；训练数据、模型输出物，适用独立合规卷宗，不可混同。
2. 所有基座、LoRA、量化、蒸馏衍生权重，纳入全局资产台账，每一个权重快照绑定SHA256哈希，记录原始许可证、修改点位。
3. 自定义社区许可，必须设置业务规模监控；达到营收/MAU阈值，停止商用并启动商业授权谈判。
4. 权重资产变更、基座替换、大规模微调，触发全局审计基线053资产专项复核。
5. 权重许可评估与训练数据合规评估，作为两个独立审计项并行核验，不可互相替代。
落地指引
测评人员：安全审计新增开源模型权重权属章节；覆盖权重资产误读、许可边界混淆、衍生权重溯源缺失、许可条款与法定责任混淆四类场景；报告记录权重来源清单、许可证逐条校验结果、商用阈值监控、衍生权重哈希归档、训练素材独立筛查结论。
研发团队：建立开源权重资产全生命周期管控；入库前区分MIT/Apache/自定义许可，逐条解析商用限制；基座、LoRA、量化权重留存版本快照与哈希；监控业务规模，触发阈值及时申请商业授权；独立筛查基座训练数据版权，不因权重许可合规而忽略输入端风险；建立衍生权重审计台账；模型基座变更纳入全局审计基线复核。
监管与行业观察者：权重开放不等于全栈开源；许可证是有条件合同授权，自定义许可中的营收、月活限制具备合同约束力；权重许可不能豁免训练素材、内容安全等法定义务；微调衍生权重的衍生关系认定在当前法律框架下存在不确定性。
边界区分说明
权重文件可下载 ≠ 拥有完整商用权利；许可证允许商用 ≠ 基座训练素材来源合法。
权重许可核心闸口：权重权属台账、许可证逐条审核、商用阈值监控、衍生权重哈希归档、训练素材独立筛查。仅校验权重许可，无法消除底层训练数据集带来的版权风险。
结语
开源模型权重属于新型数字资产，传统软件开源协议无法完美适配参数矩阵。权重开放是基于许可证的有条件授权，商用权限受许可类型、营收阈值约束；微调、蒸馏等衍生权重权属边界存在法律不确定性。权重许可仅约束参数资产，不能豁免训练素材版权、内容安全等法定义务。权重资产边界的终审权归属属地碳基司法裁判主体；不可仅凭权重公开下载即默认可商用；确需引入开源基座部署商用系统，必须建立权重溯源与许可审计体系，但无法完全消除衍生权重司法定性的不确定性。
