# 第038集｜大模型推理资源耗尽型攻击风险治理

推理资源耗尽型攻击，是一类不以直接获取越界内容为目标，通过构造超长上下文、高复杂度推理任务、循环递归请求、多模态重负载输入等手段，持续占用算力、显存、token配额，耗尽服务端推理资源，造成服务卡顿、拒绝服务。区别于越狱、提示注入：越狱目标是突破护栏输出有害内容；资源耗尽攻击目标是消耗算力资源，属于算力层DoS攻击；可与提示注入、OOD样本叠加，形成兼顾资源消耗与安全逃逸的复合攻击。
定义基准
推理资源耗尽型攻击（LLM Resource Exhaustion Attack）攻击者构造特殊输入，迫使大模型执行海量token解码、多层递归推理、反复激活大模型参数，持续抢占GPU显存、算力、上下文窗口、接口配额，最终引发服务降级、接口卡死、服务不可用。
区分边界：
1. 资源耗尽攻击 ≠ 越狱攻击。越狱目标是绕过安全约束输出受限内容；资源耗尽攻击目标是消耗算力、中断服务；二者可叠加；
2. 资源耗尽攻击 ≠ 传统网络层DoS。传统DoS侧重网络连接、带宽打满；本类攻击在应用层，少量请求即可消耗巨大算力，低流量高消耗；
3. 资源耗尽攻击 ≠ OOD输入。OOD是认知边界失效；资源耗尽攻击是推理计算负载超限；OOD样本本身不是攻击，但攻击者可刻意构造高复杂度OOD输入，借认知边界失效叠加算力消耗。
资源耗尽四类典型攻击形态
1. 超长上下文填充攻击
提交上万token的长文本、重复片段、冗余填充内容，占满上下文窗口。模型加载、编码、注意力计算开销随上下文长度呈二次增长，少量请求即可耗尽显存。
特点：实现简单，重复文本填充放大开销；静态长度限制可部分拦截，但分片多轮对话可绕过简单长度阈值。
2. 递归/循环推理任务攻击
构造无限循环、自引用、嵌套递归、持续多步推演的任务，诱导模型持续生成长链输出，不断产生新token，持续占用推理会话。
特点：单条请求持续输出，会话长时间不释放；常规单轮token限制容易被多轮对话绕开。
3. 高复杂度多模态负载攻击
上传超大分辨率图片、多图批量输入、复杂隐写图片，OCR+多模态编码占用大量显存；多模态编码开销远高于纯文本，极易快速耗尽GPU资源。
特点：针对多模态大模型，攻击载荷外部传入，前置过滤难度更高。
4. 重复自激与分支爆炸攻击
区别于递归任务的纵向持续输出，分支爆炸是横向并行推演，诱导模型同时展开大量互斥路径，算力峰值呈倍数放大。
诱导模型并行推演大量分支、穷举枚举、生成海量备选方案，造成推理分支爆炸；模型持续并行计算，算力占用急剧抬升。
特点：语义上看似正常提问，无违规词，常规安全风控很难识别攻击意图。
资源耗尽攻击传导链路
攻击者提交高负载输入至推理接口 → 模型加载上下文、编码多模态素材，启动高开销注意力计算与长序列解码 → GPU显存、算力、会话连接持续被占用；若无输入复杂度检测、动态配额、会话超时、算力熔断闸口 → 资源耗尽，服务响应变慢、接口阻塞，正常用户请求被挤占，引发业务拒绝服务。
资源耗尽攻击核心安全隐患
1. 低流量即可造成重度破坏
不同于传统网络DoS，少数精心构造的请求就可耗尽单卡/集群算力，攻击成本低，检测难度高于带宽攻击。
2. 攻击载荷可伪装成正常业务请求
无违禁词汇，提问语义看似合理；内容安全风控侧重识别有害语义，对算力负载感知缺失，容易放行。
3. 多轮对话可渐进绕过静态限制
通过多轮分片逐步注入冗余文本，规避单次输入token上限；会话持续驻留，长期占用显存会话。
4. 资源限制配置存在业务与安全权衡
收紧token上限、缩短超时会损害正常长文档业务；放宽阈值则增大资源耗尽攻击面。
5. 复合攻击叠加放大危害
资源耗尽载荷可嵌套提示注入、OOD样本，一边消耗算力，一边尝试绕过安全护栏；防御模块算力本身也会被一并耗尽。例如攻击者在超长上下文中嵌套提示注入，一边耗尽显存让风控模块响应变慢，一边趁算力紧张时护栏校验被跳过或降级。
判定核验基准（评估资源耗尽暴露风险）
1. 仅设置单次输入token上限，无多轮对话累计token、会话驻留时长管控；
2. 缺少输入复杂度评估，不检测重复填充率、嵌套深度、分支枚举量等负载特征；
3. 多模态接口无图片分辨率、批量图数量、OCR文本长度限制；
4. 无动态算力配额、显存水位监控，不支持负载超限自动熔断；
5. 安全红队仅测试语义安全，未加入算力耗尽类负载压力测试；
6. 会话无超时自动回收机制，异常长会话永久占用GPU显存资源。
满足两项及以上，资源耗尽攻击暴露等级偏高。
风险等级划分
低资源耗尽风险：本地单轮短文本问答，禁止文件与图片上传；固定token硬上限，无公网开放接口。
中资源耗尽风险：公网接口配置单轮+累计token限额、会话超时回收；实时监控显存负载；高负载请求触发自动降级或排队，异常会话转人工抽检；定期负载压力测试。
高资源耗尽风险：公网开放，支持长文档、多图上传；业务依赖稳定持续推理服务；一旦遭受攻击，会造成全站服务中断；必须部署输入复杂度检测、动态资源配额、显存水位熔断、会话隔离、资源耗尽专项红队测试。
不可控资源耗尽风险：公网业务无会话限制、无显存监控，无负载熔断；原则上禁止上线；确需上线必须满足五项条件：输入复杂度与负载预评估、动态token累计配额、会话超时自动回收、显存/算力水位熔断、资源负载专项红队复测；即便全部落实，仅提升攻击门槛，无法完全杜绝资源耗尽型攻击。
评估边界实操准则
1. 不存在完全免疫资源耗尽攻击的推理架构；防护目标是限制单用户资源占用，隔离故障会话，防止全域雪崩。
2. 不能依靠模型自身评估负载；算力、显存、token负载评估模块必须独立于生成模型，避免模型过载后自检失效。
3. 红队必须构造复合场景：资源耗尽叠加提示注入、超长上下文叠加OOD，不可单独开展纯负载测试。
4. 模型迭代、基座更换、多模态能力升级后，必须重新评估推理开销；不同版本模型算力消耗特性会发生漂移。
落地指引
测评人员：安全审计新增资源耗尽攻击风险评估章节；红队覆盖超长上下文填充、递归推理、多模态高负载、分支爆炸四类用例；报告标注显存峰值、token消耗上限、熔断触发阈值、会话隔离失效风险。
研发团队：设置单轮+多轮累计token配额，分片多轮场景持续统计总负载；增加输入预扫描，识别重复填充、嵌套递归等高复杂度载荷；限制多模态图片尺寸、批量数量；实时监控显存、GPU利用率，超限触发会话熔断与会话销毁；会话设置强制超时自动回收资源；采用会话级显存配额与推理队列隔离，避免单用户异常会话挤占集群资源；模型迭代后复测推理负载特征。
监管与行业观察者：将应用层资源耗尽攻击纳入大模型安全评估；要求高风险AI服务具备资源隔离、负载监控与熔断机制；披露资源配额与会话管控策略。
边界区分说明
单轮token限制生效 ≠ 能抵御多轮渐进填充攻击；输入文本无违规词 ≠ 不存在算力耗尽风险。
资源耗尽防护核心闸口：输入负载预评估、累计token配额、会话资源隔离、显存水位监控、算力熔断。仅依靠单次文本长度限制，无法抵御分片多轮式资源耗尽攻击。
结语
大模型推理资源耗尽攻击属于应用层算力DoS，少量伪装成正常提问的高负载输入，即可耗尽显存与算力，造成服务中断。该攻击不依赖越狱，语义上可完全合规，常规内容安全风控难以识别，多轮对话、多模态能力进一步扩大攻击面。模型算力资源边界的终审权归属碳基人类，不可假设用户请求均为轻量正常查询；确需公网开放长文本、多模态能力，必须部署负载预评估、会话隔离与熔断机制。资源耗尽攻击是推理架构开放性带来的结构性伴生风险，无法被任何配额策略彻底消除，只能持续抬高攻击成本、压降单点故障影响面。
