# 第135集｜顶层监管体系核心术语全局锁定

适用：法典全部卷宗（121–134），统一全体系术语定义，消除一词多义、概念混淆，解决跨卷宗解读偏差；本卷为术语基准卷宗，术语释义具备最高解释优先级，冲突以此为准，联动全部前置卷宗；承接134算法算力顶层监管全局基线汇总卷宗，建立术语唯一释义、分类归档、释义变更流程、歧义裁决、术语快照归档的全局术语管控框架。
一、核心定义
全局锁定术语：法典体系内固定释义名词，在所有卷宗中含义统一，不得随意引申、扩解。AI仅为推演辅助工具，术语落地解读、文档术语对标权责归属运营主体；持证审计机构负责核验材料术语使用一致性；监管机构负责术语释义发布、歧义裁决、释义版本更新。
术语释义冲突裁决：不同卷宗出现同一名词释义矛盾，以本卷条文为准；本卷未收录名词，由监管机构出具临时释义，后续纳入本卷更新。
术语快照归档：每一次术语库修订生成哈希快照，完整留存新旧版本对照记录，用于审计、案件回溯。
术语外延禁区：禁止在合规材料、试验报告、卷宗台账中，对锁定术语自行扩大或缩小内涵，规避法典约束。
二、分级管控
基础通用术语：全卷宗通用，强制统一释义，任何场景不可变更解读；包含主体、卷宗、快照确权、熔断、追责、最小必要等底层概念。
算力算法术语：算力集群、GPU小时、Token、模型基座、多模态模型、智能体、算力-算法耦合风险、逻辑隔离、物理隔离等。
数据要素术语：原始数据、衍生数据、特征向量、模型权重、敏感个人信息、核心重要数据、去标识化、差分隐私、重识别风险、数据可携、流通目的锁死。
监管机制术语：灰度场景、沙盒试验、正向退出、强制熔断、顶层监管例外、反例校准、守门人、基线冲突裁决。
事件审计术语：安全事件、有害输出、偏见风险、持证审计、盲测、台账、证据链、事故上报。
三、底层原则
1. 本卷收录术语释义优先级高于其他卷宗；其他卷宗仅可引用术语，不得改写定义。
2. 新增术语、释义修改必须经过完整评审，遵循132灰度成果转译、134基线版本管理流程，不可临时口头定义。
3. 所有上报材料、试验卷宗、审计报告必须使用本卷锁定术语，禁止自创替代名词规避监管识别。
4. 术语快照与基线版本同步归档，释义变更同步更新134全局基线。
5. 术语解读出现争议，由监管机构完成歧义裁决，裁决结果并入术语库新版本。
6. 灰度场景、顶层例外场景，术语释义同样适用本卷，不得单独创设一套术语体系。
四、全流程核心管控
1. 核心术语固定释义清单
1. 快照确权：对卷宗、台账、日志、报告、试验记录等材料生成哈希摘要归档，固化内容，用于核验材料是否被篡改；仅证明文档完整性，不等于业务流程合规。
2. 熔断：监管触发的强制性管控动作，包含暂停新增业务、冻结算力、封存数据集、冻结模型服务，配套调查追责。
3. 持证审计：取得监管资质的第三方审计机构，按法典基线开展抽样、盲测、风险核验、证据固定。
4. 最小必要：资源、权限、数据、算力、调用范围仅满足既定任务目标，不额外扩大边界。
5. 模型基座：预训练完成的基础大模型本体，不含单独微调数据集、业务提示词、用户私有参数。
6. 模型权重：模型训练生成的参数集合，不属于原始数据要素。
7. 衍生数据：经由清洗、标注、脱敏、合成处理后产出的数据集，保留原始来源谱系。
8. GPU小时：算力计量单位，单GPU持续运行一小时消耗算力。
9. Token：文本/多模态模型输入输出的基础解析单元，作为调用量计量指标。
10. 逻辑隔离：软件层面划分独立运行环境，资源访问权限隔离；物理隔离为独立硬件集群。
11. 灰度场景：技术原理、风险形态尚未完全探明，限定边界的可控试验，不属于法外豁免。
12. 顶层监管例外：基于法定公共利益、国家安全、重大应急的临时有限豁免，基础安全与追责义务持续生效。
13. 守门人：达到规模阈值，适用130卷高阶竞争与数据可携约束的AI运营主体。
14. 安全事件：算法、算力、数据链路引发泄露、有害输出、系统失控、侵害公众权益的风险事件。
15. 反例校准：汇总例外场景越界违规案例，反向修订准入标准与基线阈值。
2. 术语使用核验机制
持证审计在每一次审计中，同步核验文档术语使用规范性；出现自行篡改术语含义、自创名词替换锁定术语，判定为中度基线偏差，限期整改。
3. 术语新增与修订流程
• 申请来源：灰度沙盒案例复盘、例外场景反例、重大安全事故、跨卷宗规则冲突。
• 流程：提交术语修订提案→审计评估影响范围→监管评审确认→生成新版本术语快照→同步更新134全局基线，全卷宗同步生效。
• 修订记录永久留存，标注修订原因、生效时间。
4. 歧义裁决流程
材料、试验、案件中出现术语解读分歧：① 优先查阅本卷术语清单；② 本卷无收录，监管出具临时释义；③ 评估是否需要永久纳入术语库；④ 裁决结果写入术语快照，作为后续同类场景判定依据。
5. 术语对外使用规范
面向公众披露、用户协议、产品界面公示内容，引用法典相关概念，释义不得与本卷冲突；简化科普表述不得扭曲术语内核。
五、多方权责
运营主体：文档、台账、试验材料对标本卷术语规范使用。
持证审计机构：术语使用一致性核验，术语歧义案例收集，修订提案辅助评估。
监管机构：术语库维护、释义发布、歧义裁决、版本快照归档。
算力服务商：算力相关指标（GPU小时、Token）计量口径严格匹配本卷定义。
六、禁止性规则
1. 禁止在卷宗、报告、合同中篡改、曲解本卷锁定术语内涵，规避监管约束。
2. 禁止为规避基线阈值，自创名词替换法典标准术语。
3. 灰度、例外场景不得脱离本卷术语，单独建立私有的概念体系。
4. 未经完整评审流程，不得私自修改、新增法典术语释义。
5. 对外公示内容，不得以通俗化表述掩盖术语法定内核。
七、治理谬误
1. 术语字面近似，即可直接等同法典锁定定义。
2. 快照确权等同于术语解读、业务流程全部合规。
3. 专项卷宗可以自行修改本卷已锁定术语释义。
4. 灰度试验场景，术语标准可以放宽。
5. 临时口头释义可永久替代本卷术语库。
全局铁律
顶层监管体系核心术语实行分类归档、唯一释义、歧义裁决、版本快照、跨卷宗统一对标；锁定法典全部卷宗基础概念，消除跨文本解读偏差；术语修订纳入全局基线管理，所有场景、所有卷宗统一使用这套术语体系，保障全法典监管判定口径一致。
