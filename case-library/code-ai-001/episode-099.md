# 第099集｜招聘AI算法反歧视与用人公平治理

适用：企业、猎头、招聘平台AI简历筛选、候选人初评、人才打分系统。管控：算法偏见、隐性特征筛选、年龄性别地域歧视、黑箱打分、判定不可解释、责任甩锅。本卷优先适用，冲突以此为准，联动058确权卷宗、模型生命周期卷宗。
一、核心定义
招聘AI算法系统：简历归类、关键词检索、候选人初筛打分辅助工具。AI仅输出初选参考清单，录用、淘汰、面试邀约最终决定权归招聘方，责任不得转嫁AI或模型厂商。
招聘算法偏见：模型基于训练数据，对年龄、性别、地域、婚育背景形成系统性不利筛选，造成群体就业歧视。
分级管控
L1：简历归集、关键词检索、格式分类，不输出候选人优劣打分，后台定期审计。
L2：候选人初筛打分，仅作为参考；所有入围/淘汰名单人工复核，出具判定影响因素说明。
L3：批量人员招录、校招大规模筛选，AI仅做资料归集，禁止单独依据AI分数淘汰候选人，多层人工终审。
招聘算法卷宗：输入特征清单、AI打分记录、偏见检测报告、人工复核痕迹、候选人申诉台账；最低保存3年，劳动争议、歧视投诉案例永久归档。
熔断机制：检出显著群体偏见、违规特征筛选，暂停该筛选模型，启动复测与模型整改。
算法透明基线：向候选人告知AI参与筛选，可查询影响判定的核心因素，不得使用黑箱打分。
二、底层原则
1. 招聘用人决策权归属用工主体，AI仅初选辅助，不能单独决定录用或淘汰。
2. 模型上线前开展公平性审计，常态化复测偏见风险。
3. 风险规模越大，AI权限越收敛，人工复核覆盖率越高。
4. 数据最小采集，剔除婚育、年龄、地域等非必要敏感筛选特征。
5. 候选人享有知情权与申诉复核权。
三、全流程管控
1. 模型准入：上线前完成公平性测试，存在系统性群体偏见禁止投产。
2. 特征管控：移除无关敏感特征，禁止隐性提取间接特征实施筛选歧视。
3. 分级执行：L1仅归类检索；L2打分结果人工复核并说明理由；L3禁止仅凭AI分数淘汰候选人。
4. 申诉机制：候选人对AI辅助筛选结果提出异议，须人工独立复核并反馈结果，记入卷宗。
5. 熔断处置：检测到系统性歧视，暂停算法使用，整改审计通过后方可重启。
四、多方权责
1. 用工企业/招聘平台：算法准入、偏见审计、人工复核、申诉处置第一责任人。
2. 模型厂商：披露模型局限、偏见风险，不得干预招聘筛选判定，隐瞒缺陷承担合同责任。
3. 独立审计方：定期开展算法公平性检测，出具审计摘要。
4. 候选人：有权知悉AI筛选情况，提交申诉申请复核。
五、确权交叉规则
AI原生简历检索、打分脚本归入数据保护层；人力资源专家设定公平约束、反歧视校验逻辑重构触发权属快照，独创性部分纳入著作权保护层。
卷宗、审计日志不适用快照确权。权属快照仅判定成果归属，不可替代公平性审计，不免除用工主体招聘公平责任。
六、禁止性规则
1. 禁止将招聘筛选、用人决策责任转嫁AI、模型厂商。
2. 禁止L3大规模招录场景，仅凭AI分数淘汰候选人。
3. 禁止利用敏感特征、隐性间接特征实施就业歧视。
4. 禁止使用不可解释黑箱模型直接用于候选人淘汰判定。
5. 禁止隐瞒AI参与简历筛选，拒绝告知候选人判定影响要素。
6. 禁止删除篡改偏见审计报告、人工复核、申诉卷宗。
七、治理谬误
1. 筛选准确率高即用人判定公平谬误。
2. AI打分结果可直接作为淘汰候选人依据。
3. 权属快照确权等同于招聘算法无歧视合规。
4. 候选人无权知晓AI筛选的判定依据。
全局铁律
招聘AI仅作简历初选辅助，用工主体承担招聘公平全责；上线前完成反歧视审计，大规模招录禁止仅凭AI分数淘汰；剔除无关敏感特征，保障候选人申诉复核权；检出系统性歧视触发熔断；权属快照区分成果归属，不可豁免招聘公平审查义务。
