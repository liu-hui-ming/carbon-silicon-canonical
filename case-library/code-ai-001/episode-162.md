# 第162集｜文明风控体系术语全局口径锁定

适用：法典运维中心、跨文明联合审计委员会、时序推演实验室、认知安全研究院、各卷宗执行机构。
核心风险：跨卷宗长期推演、认知测评、审计核验、跨文明协同过程中，同一名词出现多版本释义；不同机构、不同仿真团队对锚点、衰减速率、风险耦合等概念理解分歧，造成指标统计错位、仿真结果不可比对、审计结论失效。本卷作为法典术语基准卷宗，对全法典通用术语完成唯一定义，锁定统计口径、采样边界、计算公式，消除释义歧义；所有卷宗、仿真、审计、预警流程必须以此卷释义为准，禁止自定义解读。搭建术语归集分类、计算公式固化、采样边界划定、歧义冲突排查、术语版本锁控风控框架。
一、核心定义
术语全局口径锁定：对全法典复用的通用概念，统一文字定义、指标计算公式、抽样范围、数据采集规则；确立唯一权威释义，作为所有卷宗、仿真、审计、预警的基准。
释义冲突：分卷、执行机构、仿真模型对同一术语使用偏离本卷宗的定义，造成指标计算偏差、研判结论不一致。
采样边界：限定指标采集的人群范围、时间窗口、场景清单，明确纳入项与排除项，避免随意扩大或缩小统计样本。
指标固化公式：锚点衰减、认知扰动、风险耦合等量化指标的固定计算表达式，所有仿真与实测必须使用同一公式。
术语冻结复审：术语主版本一经锁定，常规场景不得修改；仅在133反例校准库出现全新类别风险时，启动全流程术语增补评审。
二、分级管控
轻微释义歧义：单一机构内部对术语存在理解偏差，未进入正式仿真、审计流程，无跨卷宗数据冲突。季度术语台账自查，发布释义答疑，纠正局部解读偏差。
局部释义冲突：两个及以上卷宗或测评机构使用不同口径计算同一指标，仿真、审计数据出现偏差，但未触及文明主体性锚点红线。半年全术语冲突扫描，限期6个月完成口径统一，修正模型与审计脚本。
全域术语体系失效：核心风控术语释义大范围分裂，指标计算逻辑不统一；跨卷宗仿真结果不可比对，审计结论失去公信力，锚点衰减指标测算失真，联动认知、时序、跨文明共识多卷宗风险共振。暂停全域仿真与跨卷宗联合审计，启动术语全量复盘，重新校准全部指标计算链路。
术语稳态：全法典术语释义统一，计算公式、采样边界固定；释义冲突持续清零，术语增补流程闭环，所有机构严格遵循锁定口径。
三、底层原则
1. 161卷完成文明风控全局基线汇总，确立整套法典规则框架；本卷锁定底层语言与计量口径，保障基线落地过程中数据、仿真、审计可互通、可复现。
2. 术语分为永久固定术语与可增补术语；文明主体性锚点相关核心术语永久锁定，不得修改释义。
3. 所有量化指标配套固定计算公式与采样边界，不允许各机构自行调整统计规则。
4. 术语新增或修订案例纳入133反例校准库，同步更新时序推演、认知风控模型的代码与测评脚本。
5. 本卷审计独立，负责术语冲突排查、释义合规核验、术语版本管控，不替代专项风险审计。
6. 术语口径分歧不可以“业务场景特殊”为由绕过本卷宗定义；确有特例，须走例外场景评审流程。
四、全流程管控
1.判定指标
指标：
1. 术语释义冲突检出数量
2. 指标计算结果偏差率：同一数据源采用不同术语口径计算得出结果的相对差值
3. 术语违规自定义使用频次
4. 术语增补评审逾期发生率
5. 跨机构指标复现通过率：不同团队使用统一口径，同一份样本测算结果一致性占比预警阈值：单年度术语释义冲突检出≥2项，或指标计算结果偏差率＞12%，判定轻微释义歧义预警。
全域术语体系失效触发：核心锚点相关术语出现多版本释义，跨机构指标复现通过率低于50%，审计与仿真结论无法交叉核验。
2.术语全局口径基线（快照哈希归档）
文明主体性锚点系列（永久锁定，不可修改释义）
1. 人类终审权：高不可逆、涉群体权益事项，最终决策权归属人类；AI仅输出备选方案，不具备自主终审落地权限。
◦ 人类终审绕过频次/年：年度内，本应进入人类终审的高风险决策，未经人类确认直接由AI执行的事件计数。
2. 认知污染代际渗透率：新生代抽样群体（18岁以下），稳定采信AI原生失真叙事、无法完成证据溯源的样本占比。
3. 多元文明自主选择权：任一文明不被外部AI叙事、定向模型输出强制重塑底层价值框架。
4. 高风险系统强制熔断：当指标击穿临界红线，系统自动停止高风险动作，留存不可篡改审计日志。
时序推演系列
1. 锚点衰减速率：单位年度内，文明主体性锚点量化指标偏离安全基线的变化幅度；锚点综合衰减速率 = 加权求和（人类终审绕过率权重0.4，认知污染代际渗透率权重0.4，公共理性衰减指数权重0.2）
2. 风险耦合系数：两类及以上独立风险同步累积、互相放大的量化倍数。
3. 人类依赖惯性系数：关键公共议题场景下，人群放弃独立思辨、直接采信AI结论的抽样人口占比。
4. 代际认知替代速率：新生代心智指标相对前代基线的年度变化率。
5. 多智能体自主协作密度：开放环境异构智能体，无独立审计的点对点通信交互频次，年度统计。
认知风控系列
1. 心智锚点：人类群体共享基础认知基准，包含事实-价值二分原则、证据溯源习惯、逻辑自洽标准。
2. 认知扰动强度：AI输出造成人群事实判别能力偏移的量化幅度。
3. 认知传导增益系数：失真叙事经由AI分发，传播过程中偏差放大倍数。
4. 公共理性衰减指数：复用154卷宗口径，人群逻辑谬误识别、证据溯源意愿综合得分。
5. 认知修复成本等级：扰动形成后，还原证据链、矫正群体偏见的资源与时间投入分级。
审计与基线治理系列
1. 基线冲突检出：不同卷宗规则、阈值、权责出现矛盾、空白、重叠的条目数量。
2. 快照哈希归档：对文档、指标、模型参数做哈希摘要固化，用于识别隐性篡改。
3. 例外场景：概率极低、影响巨大、时间窗口极度紧迫，常规风控流程无法规避文明级重大不可逆伤害的场景；商业增效、产业竞争不属于例外准入范围。
• 一级警戒线：指标计算结果偏差率＞12%，跨机构指标复现通过率70%~90%。
• 临界红线：指标计算结果偏差率＞30%，跨机构指标复现通过率＜50%。
3.歧义冲突排查机制
建立术语自动校验引擎，扫描各卷宗文档、仿真脚本、审计报告，检索术语使用；比对释义、公式、采样边界，区分文字歧义、公式错误、样本范围错配三类冲突，输出冲突清单，提交专项评审委员会45自然日内研判处置，逾期未处置触发审计追责。
4.计算公式与采样边界固化
所有量化指标配套固定计算表达式；采样边界明确纳入、排除人群与场景。任何仿真、测评、审计脚本，必须引用本卷宗口径，不得改写公式、裁剪样本。新增指标必须同步在本卷宗登记定义、公式、采样范围，完成哈希归档。
5.术语版本锁控机制
术语主版本哈希固化归档；主版本仅允许增补新术语，不允许修改已锁定核心术语释义。增补术语须提交申请，附带仿真案例、反例支撑，经跨文明联合审计委员会评审通过后方可纳入。
每24个月执行一次全术语复审。
6.分级干预
轻微释义歧义：发布术语官方释义答疑，对相关人员开展口径校准，持续监测使用情况。
局部释义冲突：限期6个月完成口径对齐，修改仿真脚本、审计台账，重跑历史样本，核验指标计算一致性。
全域术语体系失效：暂停跨卷宗联合仿真、全域审计；对全部核心指标重定义、重校准，同步更新所有卷宗、仿真模型、审计工具，联动全局基线卷宗协同处置。
7.术语口径治理档案
归档完整术语词典、指标计算公式、采样边界说明、冲突扫描报告、术语增补评审记录、版本哈希快照；对标135术语规范，纳入快照确权。
五、多方权责
法典运维中心：维护术语主版本，运行术语校验引擎，接收术语冲突上报，组织术语复审与增补评审。
跨文明联合审计委员会：独立核验术语落地，核查私自修改计算公式、自定义释义行为，对逾期评审、数据造假实施追责。
时序推演实验室、认知安全研究院：仿真、测评代码严格引用锁定口径；指标计算脚本变更前提交术语预校验。
各卷宗执行机构：所有报告、台账、内部规则，术语释义以本卷宗为准，不得私自创造定义。
六、禁止性规则
1. 私自修改核心术语释义、调整指标计算公式、随意扩大或缩小采样边界。
2. 为适配仿真预期结果，选择性裁剪样本，人为修改指标统计口径。
3. 发现术语释义冲突隐瞒不报，继续使用非标准口径开展审计与风险研判。
4. 借例外场景，临时修改文明主体性锚点相关术语定义。
5. 新增量化指标不登记、不评审，直接投入仿真与审计使用。
七、治理谬误
1. 术语只是文字表述，定义差异不会影响指标测算、仿真结论与审计判定。
2. 不同场景可以灵活自定义术语口径，不需要全局统一。
3. 快照归档仅约束正文规则，指标计算公式、采样边界无需固化。
4. 术语一旦锁定，无法新增，不能随风险演化补充指标概念。
5. 跨机构测算结果不一致，属于正常误差，不必排查术语口径根源。
全局铁律
文明风控术语口径锁定实行术语分类归集、计算公式固化、采样边界划定、释义冲突排查、术语版本锁控；统一全法典底层计量语言，消除释义分歧，保障仿真可复现、审计可比对、预警可交叉核验。
