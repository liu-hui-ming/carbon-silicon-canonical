# 第080集｜人机权责确权层全局标准汇总

本卷汇总073、077、078、079确权系列全部条文，整合数据资产、取证规范、动态权属迭代、适用边界例外，建立人机权责确权层的统一裁判基准。本卷为确权板块总纲卷宗，统一定义、统一判定流程、统一举证分配、统一权属快照规则，所有权属争议审理，均以本卷作为确权体系总参照，可与058确权取证卷宗、模型生命周期卷宗、平台审核卷宗交叉调阅核验。
一、核心定义
人机权责确权层：本法典项下，专门处理AI生成内容权属判定、贡献核算、权利流转、适用边界的整套规则集合，覆盖数据资产与著作权两套评价体系。
权属快照：在指定时间节点冻结成果版本、贡献权重、权属定性，生成链上存证记录，作为该时间切片的权属基准；历史快照永久留存，不可覆盖、不可篡改。
人类实质智力投入：人类完成的构思架构、风格设定、叙事编排、画面设计、多轮提示词迭代、成果筛选、结构性改写等独创性智力行为；单纯下达功能性指令、开启自动化任务不属于实质智力投入。
核心铁律：权属随贡献流动，快照锁定历史切片；先勘适用边界，再评权利归属；区分数据资产与著作权两套保护体系，不法产出不享有确权保护。
二、确权体系双层保护框架
1. 著作权保护层
适用前提：成果属于对外独立完整表达，存在人类实质智力投入，内容合法，不属于079列明的不适用场景。
判定指标：核算人类贡献占比，人类贡献占比≥20%，认定为人机协同作品。单人创作，由创作者享有著作权；多人协同创作，按各方贡献比例划分共有份额。衍生改编成果，改编者仅对新增独创性部分享有权利，原作者保留基础成果对应的权利。权属状态随迭代修改动态更新，每次触发快照事件，重新核算贡献与权属。
2. 数据资产保护层
适用前提：AI输出不满足著作权保护要件，但具备可利用经济价值。
定性：不产生著作权，仅依照合同约定、数据资产规则赋予有限使用权。包括人类贡献占比＜20%的单次简易生成内容、公共素材简单复述、模板填充类自动化输出等。数据资产的使用、转让、保密约束，依照073数据资产权属条款执行。
三、权属快照触发与冻结规则
触发生成新版本快照的情形：提示词大规模重构、结构性人工改写、更换基座模型重生成、第三方独立二次创作、新增协同创作主体。
仅微小文字修正、调色、标点调整等微调操作，不触发新快照，不改变原有权属状态。
快照约束：新版本生成，不得删除、篡改历史快照；历史快照独立有效，后续新增贡献不能反向回溯修改早期版本权属定性。
四、确权判定标准流程
第一步，适用边界筛查。核查成果是否属于模型内部运算产物、自动化运维输出、公共基础信息复述、纯功能性指令产出、违法内容，落入前述场景，直接排除著作权确权评价，终止贡献度核算，按数据资产、商业秘密、侵权等其他规则处置。
第二步，判断人类投入性质。区分功能性指令与独创性构思，仅机械调用任务指令不满足创作要件；具备架构、叙事、构图、风格等独创性构思，方可进入贡献评估。
第三步，核算人类贡献权重。从提示词设计、内容筛选、人工改写、结构重构四个维度加权评估，确认人类贡献占比。
第四步，生成权属快照，锁定该时间切片权属定性、权利份额。
第五步，发生争议时，调取058确权取证卷宗，核验版本链、贡献记录、哈希快照。被诉方可援引079反例规则抗辩；主张权属一方，负有举证证明成果属于确权适用范围的义务。
五、多方主体权责汇总
1. 初始创作者：承担权属主张的举证义务，迭代修改时触发快照更新，留存完整058确权卷宗。仅享有独创性投入对应的权利，不能吞并基础素材、模型算法本身权益。
2. 二次改编方：仅对新增独创性表达享有权利，使用原有成果需要遵守原成果许可约束，不得借衍生创作抹除原作权属。
3. 模型研发方：模型算法、底层权重、内部中间运算产物归研发方管控，不自动享有用户生成内容的著作权；内部数据泄露，按商业秘密、数据安全相关规则处置。
4. 平台运营方：提供快照归档、卷宗存证能力，不得通过格式条款一次性攫取用户全部迭代版本著作权；错误标记非创作产物的权属快照，该标记无效。
5. 争议相对方：有权援引本卷以及079边界例外条款提出抗辩，阻断不当的确权主张。
六、确权板块禁止性规则
1. 禁止无限扩张确权适用范围，模型内部中间数据、自动化报表、纯事实复述内容，不得纳入著作权确权评价。
2. 禁止快照覆盖历史权属，新版本不能删除、篡改过往版本快照。
3. 禁止贡献回溯，后期新增的人工投入，不能改变早期版本的权属定性。
4. 禁止格式概括性权属掠夺，平台不得预先约定获取用户未来所有迭代成果的完整著作权。
5. 禁止违法成果确权，伪造文书、深度伪造用于违法犯罪的内容，无论人类投入多少智力，均排除确权保护。
七、四类治理谬误汇总
1. 凡AI输出即有权属谬误：将所有AI输出直接纳入著作权确权，忽略内部运算数据、自动化输出等例外场景。
2. 一次生成永久锁权谬误：首次生成即固定权属，无视后续人工深度修改带来的权属状态动态变化。
3. 有操作即创作谬误：仅下达机械功能性指令，便认定存在独创性智力投入。
4. 衍生吞并原作谬误：二次改编生成新版本，即可消除原成果对应的权属。
八、六项刚性核验基准
1. 权属争议审理，优先筛查是否落入确权不适用场景，边界判定前置。
2. 著作权保护，必须满足对外完整表达、合法内容、人类实质独创性投入三项基础条件。
3. 贡献占比≥20%，方可认定人机协同作品；低于阈值归入数据资产保护。
4. 每一次重大迭代必须生成独立快照，版本链条完整可追溯。
5. 衍生作品权利仅限新增独创性部分，原成果权利持续有效。
6. 格式合同概括攫取用户未来迭代成果著作权，该类约定无效。
全局铁律
双层体系区分资产与著作权，边界筛查前置；快照锚定时间切片，贡献决定权利份额；迭代权属动态流转，历史记录不可抹除。
