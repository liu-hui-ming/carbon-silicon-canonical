# 第086集｜科研AI实验仿真真实性风控标准

本卷为科研AI+仿真实验专项卷宗，面向计算仿真、材料模拟、分子动力学、流体力学、AI科学代理等科研场景，核心目标遏制方法学幻觉、选择性结果筛选、仿真参数暗改、伪造模拟数据、黑箱结论五大科研诚信风险，建立预注册、全链路存证、独立复现、异常熔断的真实性风控体系。本卷可与058确权取证卷宗、模型生命周期卷宗交叉调阅核验；科研AI仿真真实性事项优先适用本卷，与确权板块条文并行适用，冲突时以本卷科研真实性规则优先。
一、核心定义
科研AI仿真系统：依托AI大模型、AI代理、数值仿真引擎，完成建模、参数扫描、模拟推演、数据拟合、结果预测的科研计算系统；AI仅作为建模与计算辅助工具，科学假设、实验方案、结论论证的最终责任由科研人员承担。
方法学幻觉：AI生成虚假方程、不存在的边界条件、缺失的约束、隐性替换基准模型，代码可正常运行，但底层实验逻辑违背预设方案，表面输出合理数值，实质科学结论无效。
选择性结果筛选：多次仿真采样，仅挑选符合预期假设的结果上报，丢弃大量失败、反向、离散样本，隐瞒仿真不确定性。
仿真预注册：正式仿真运行前，锁定科学假设、模型拓扑、边界条件、参数空间、评价指标、样本量、终止判据，生成存证记录；后续不得随意修改预设方案，修改必须留痕说明。
探索性预实验：小规模试算，用于初步试探参数区间、验证代码可行性，不用于形成正式科学结论；量化边界：单任务迭代不超过20次、参数变量不超过5个可豁免预注册；超出阈值则判定为正式批量仿真，必须执行预注册。探索性试算所有运行日志、中间结果同样入仿真实验卷宗，接受机构抽检，不得拆分正式批量任务伪装成多次探索试算规避预注册。
AI代理自主权限等级
L1低权限：仅执行预设参数扫描、数据采集，无自主分支决策；L2中权限：可在预设参数区间内小幅自主寻优，分支变更自动告警记录；L3高风险权限：跨区间参数跳转、边界条件变更、新增实验分支，必须人工事前授权，操作前二次人工确认方可执行。
仿真实验卷宗：完整存证包，包含预注册文档、原始输入参数、代码脚本、容器环境镜像、随机种子、中间仿真快照、原始输出时序数据、人工后处理脚本、异常日志、复现验证记录；卷宗最低保存期限不少于十年，重大课题、存在学术争议案例永久归档。
可复现性：第三方使用完全一致代码、参数、环境、种子，能够复现核心仿真数值结果；可重复性：同一方案在独立新数据集/新采样下，结论趋势保持稳定，区分随机波动与系统性偏差。
仿真熔断机制：系统检出参数漂移、方法幻觉、数据矛盾、结果严重离群，触发告警，暂停仿真迭代，禁止直接导出结论用于论文撰写，等待科研人员人工核验。分级核验时限：一般告警48小时内完成人工核验；检出方法学幻觉等高严重度告警24小时内核验；超时未处置自动升级推送至机构学术诚信管理部门介入。
AI使用披露声明：论文、课题报告中必须如实写明AI参与环节，区分AI辅助建模、AI生成代码、AI后处理，严禁隐匿AI在仿真链路中的介入位置。
二、真实性底层原则
1. 假设先行，预注册锁定：正式批量仿真、AI代理L3高风险权限自主实验，必须执行预注册，固化研究方案，降低事后P-hacking与选择性筛选空间。探索性小试可豁免预注册，但全部运行记录仍需入卷宗留存。
2. 原始数据不可篡改，全链路可溯源：输入参数、原始仿真输出、中间状态独立存证；后处理脚本与原始仿真数据分离，禁止直接改写原始模拟输出。
3. 区分随机波动与系统性偏差：仿真必须开展多重复采样，报告误差区间与不确定性，不得仅展示单次最优结果。
4. 边界透明，禁止黑箱结论：AI生成的模型、方程、约束条件必须人工核验；AI推导的假设不能直接作为科学事实。AI代理启用L3高风险分支，必须留存事前人工授权记录。
5. 分级披露：所有论文、项目成果必须明确披露AI参与仿真的环节，不隐瞒AI代理自动执行的实验分支与权限等级。
三、仿真全生命周期真实性风控规范
1. 实验方案与预注册阶段
1. 正式批量仿真、AI代理L3高风险自主实验，必须执行预注册，固化假设、参数范围、评价指标、终止条件；方案重大变更需要提交变更说明，并入仿真实验卷宗。探索性预实验满足量化豁免条件可免预注册，但运行日志完整留存，纳入抽检范围，禁止任务拆分规避预注册。
2. 人工核验AI生成建模方案、控制方程、边界条件，排查方法学幻觉；AI输出的模型假设必须标注“AI生成，待人工验证”，不能直接采信。
3. 固定随机种子、容器镜像、软件版本、硬件环境，全部写入卷宗；云API类科研AI，锁定模型版本与接入端点，规避后台静默更新带来的仿真结果漂移。
4. 配置AI代理权限分级，L3高风险分支必须由项目负责人事前书面授权，代理无法自主触发跨边界参数改动。
2. 仿真运行与实时监测阶段
1. 全程自动采集日志：参数修改记录、AI提示词、每一轮仿真快照、中间输出、异常报错；每一次独立仿真任务生成独立哈希存证。
2. 异常监测与熔断触发条件：检出方法学幻觉告警、参数越界、多轮结果剧烈离散、数值不守恒、AI隐性替换基准模型，触发熔断，停止自动迭代，锁定当前卷宗，人工排查后方可继续；严格执行分级核验时限，超时自动升级至学术诚信部门。
3. 禁止自动择优：AI代理不得自动丢弃不符合预期的仿真样本；全部运行结果，无论成功失败，完整存入卷宗。如需筛选，筛选逻辑、筛选阈值必须人工定义、写入脚本，留存筛选前后全部数据集。
3. 后处理、结果校验与复现验证
1. 原始仿真输出与后处理结果物理隔离；后处理代码纳入卷宗，所有数据清洗、拟合、可视化操作脚本可审计。
2. 必须开展不确定性分析，报告误差、置信区间；单一数值结果不得省略波动说明。
3. 成果提交前，执行内部自复现；高价值课题必须安排独立第三方复现核验。
4. 仿真合成数据集必须明确标注“AI仿真生成数据”，严禁伪装成实体实验实测数据。
4. 成果发表与卷宗归档
1. 论文、项目报告附带AI使用披露声明，写明AI参与建模、代码生成、参数扫描或数据后处理环节，同步标注AI代理启用权限等级；不隐瞒AI代理自动执行仿真分支。
2. 仿真实验卷宗作为成果附件，向期刊、课题管理方开放核验接口；涉及涉密内容，可开放摘要、哈希校验与结论验证通道，原始数据隔离保管。
3. 模型、仿真引擎重大静默升级，未重新核验仿真结论，对应的旧成果必须标注版本风险提示。
四、多方主体权责划分
1. 项目负责人/科研人员：科研真实性第一责任人。核验AI建模方案、排查幻觉、留存完整卷宗，管控AI代理权限，不得选择性删减仿真样本；论文中如实披露AI使用情况。伪造、篡改仿真原始数据，承担科研失信主体责任。
2. 科研机构：主体管理责任，建立仿真卷宗归档、科研AI使用培训、学术诚信审查机制；对重大课题开展仿真结果抽查与复现核验，处理熔断超时升级的风险事项。
3. 科研AI与仿真引擎厂商：产品质量责任。明确标注模型版本、已知缺陷、随机波动边界；禁止后台静默更新模型、隐藏参数变更；因算法缺陷、隐性逻辑漏洞造成系统性仿真错误，厂商承担整改与披露责任。
4. 期刊、项目评审方：有权调取仿真卷宗、复现包，增加技术复现评审环节；预注册缺失、卷宗不全、无法复现、违规拆分任务规避预注册的成果，可不予接收。
5. 监管与科研诚信管理机构：开展科研AI仿真成果抽查，核查卷宗完整性，对仿真造假、隐匿AI使用、违规拆分任务规避预注册情形开展失信认定。
五、确权板块交叉适用规则
1. AI原生生成仿真代码、参数扫描方案归入数据资产保护层；科研人员加入独创性模型设计、理论推导、结构性方案重构，触发权属快照，新增独创性部分纳入著作权保护层。
2. 仿真原始数值输出、数据集、实验卷宗不属于人机协同创作成果，不适用权属快照，优先适用科研诚信、数据归档规则。
3. 权属快照仅用于科研成果载体归属判定，快照不能替代仿真真实性核验，不免除科研人员学术诚信责任。
4. 仿真模型权重、仿真引擎底层代码权属，参照模型生命周期卷宗条款判定。
六、禁止性规则
1. 禁止隐匿AI参与仿真建模、代码生成、自动实验流程，不做披露。
2. 禁止选择性丢弃负面仿真样本，仅挑选符合假设的结果上报。
3. 禁止AI自动替换基准模型、修改边界条件，产生方法学幻觉而不做人工校验。
4. 禁止将AI仿真合成数据伪装为实体实验实测数据。
5. 禁止静默升级仿真引擎、AI基座，不重新验证已有仿真结论。
6. 禁止篡改、删除原始仿真输出，仅修改后处理结果。
7. 禁止跳过预注册、跳过多重复采样，基于单次仿真直接提出强科学结论。
8. 禁止将正式批量仿真任务拆分为多组探索性试算，规避预注册约束。
9. 禁止AI代理未经事前人工授权，自主执行L3高风险跨边界仿真分支。
10. 禁止熔断告警触发后，超出分级时限不开展人工核验。
七、治理谬误
1. 代码可运行即真实谬误：仿真代码执行无报错，就认定底层科学假设成立，忽略方法学幻觉。
2. 择优采样无害谬误：剔除异常、不符合预期的仿真样本属于正常数据清洗。
3. 一次复现永久有效谬误：完成一次复现，后续模型静默更新后不再复核。
4. 仿真等同于实测谬误：AI仿真生成数据，可直接等同于实体实验测量结果。
5. 快照替代真实性审计谬误：权属快照哈希存证，等同于仿真结论科学可信。
6. 探索实验无需留痕谬误：探索性试算可以不保存全部失败仿真记录。
7. 代理自主决策天然合规谬误：AI代理可无限制自主修改仿真边界条件。
8. 熔断告警可无限搁置谬误：触发仿真熔断后，人工核验无时间约束。
全局铁律
预注册锁定研究方案，量化边界区分探索试算与正式仿真；AI代理分级授权，高风险分支必须人工确认；仿真全链路卷宗留痕，全部样本不可丢弃；AI建模必须人工核验，区分仿真数据与实体实测；检出幻觉与参数异常触发熔断，分级时限完成人工核查；权属快照不替代科研真实性审查。
