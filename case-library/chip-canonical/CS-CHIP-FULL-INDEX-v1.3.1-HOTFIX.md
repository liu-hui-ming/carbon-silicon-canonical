附录一：EP/BP分工铁律

EP = Evidence Package 证据包：只负责采集、记录、留存原始现象、实验数据、观测记录，不做最终定性结论，不做优劣评判。EP原文采集完成后哈希锁定，原始观测记录永不删改，后续勘伪仅新增批注，不修改原始观测文本。

BP = Boundary Package 审计包：只负责校验证据完整性、合规性、边界范围、统计置信度、流程合规性。BP无权修改EP原始数据，无权替代EP生成观测内容；BP审计结论同样可被勘伪挑战。BP发现违规项，标记BOUNDARY-BREACH/LIMITED/REJECT，写明理由，不直接删除条目。

附录二：NT系列风险锚点统一释义

NT1：基准失配，底层基线发生非预期漂移

NT2：语义漂移，跨域迁移后模型/工艺适用边界失效

NT3：静默补全，系统自动推断缺失信息，产生不可察觉错误

NT4：权限偷渡，边界隔离失效，发生越权访问与参数篡改

NT5：跨相共振，多域扰动耦合叠加，非线性放大风险

附录三：标记码全集定义

REJECT：证据存在硬缺陷，直接不予采信

LIMITED：证据可用，但存在明确边界约束，不可外推

BOUNDARY-BREACH：违反体系公理/流程规则，结论无效

HOLD：证据链存在缺口，待补充材料，暂不纳入终审

GOLDEN：金样本，独立复现通过，置信度最高

附录五：勘伪提报流程

1. 任何人可提交勘伪材料，附带原始反例、数据集、仿真记录；支持实名提交与匿名提交两种通道。匿名通道即EP182定义的匿名反报复举报通道，用于保护提报人免受报复。

2. 实名勘伪材料：自动分配独立编号与哈希，基准采信权重=1.0；创立人提交勘伪证据权重和外部提交者完全一致。匿名勘伪材料：初始采信权重降为0.5；若匿名提交的反例、数据集可被第三方独立复现验证，则采信权重恢复至1.0并纳入正式勘伪卷宗。匿名提交者无法溯源，伪造数据不追责，但低权重天然对冲灌水、虚假样本风险。

3. IAA独立审计小组接收材料，72小时内出具初审回执；完整复核周期根据证据复杂度确定。

4. 勘伪成立：开启新版本分支，修正体系内容，更新根哈希；旧版本原文完整保留，标注勘伪修订记录。

5. 勘伪不成立：出具详细驳回说明，勘伪材料同样归档留存，不得删除。
