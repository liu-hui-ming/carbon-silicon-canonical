22 批量回归测试框架（v0.4新增）

22.1 框架定位

批量回归用于IAA子系统持续迭代验证，每次修改附录八IAA相关代码/参数后一键重跑全部P0~P3跨载体用例；回归套件独立于主系统回归套件，可单独触发、单独冻结基线，不干扰主法典Golden Case。

Golden Case隔离规则：IAA回归Golden样本单独归档，独立哈希，不混入主系统Golden样本集。

22.2 回归入口脚本：twelve_pulse_baseline.sh

#!/bin/bash
# twelve_pulse_baseline.sh IAA批量回归启动脚本
# 支持Icarus Verilog / Vivado Simulator，跨载体仿真调度
SIM_MODE=$1
TEST_SET=$2
OUT_DIR="./regress_out/$(date +%Y%m%d_%H%M%S)"
mkdir -p ${OUT_DIR}

# 加载IAA附录八配置，不加载主系统顶层配置
source ./config/iaa_regress_config.sh

# 批量遍历P0/P1/P2/P3用例集合
for case in ${TEST_SET}; do
    echo "Running IAA Testcase: ${case}"
    ${SIM_MODE} -f ./testbench/iaa_filelist.f +TEST_NAME=${case} \
    -w ${OUT_DIR}/${case}.vcd > ${OUT_DIR}/${case}.log
done

# 调用自动报告引擎
python3 ./tools/iaa_report_builder.py --dir ${OUT_DIR} --golden ./golden/iaa_golden_set.json
# 计算本次回归整体哈希，存入回归归档
sha256sum ${OUT_DIR}/* > ${OUT_DIR}/regress_hash.log

22.3 回归用例管理规则

1. 用例集划分：冒烟集（快速3例）、全量集（P0-P3完整跨载体用例，含CMOS/光子/拓扑量子态异构场景）；

2. 增量回归：支持只跑变更关联用例，减少仿真耗时；

3. 基线冻结：每一个稳定附录八版本，冻结对应IAA回归Golden输出；后续回归结果与Golden做比对；

4. 比对判定：

◦ PASS：IAA表决输出、故障记忆记录、SVA断言结果与Golden完全一致；

◦ WARN：数值在允许噪声阈值内偏移，不改变故障等级与裁决结论；

◦ FAIL：裁决结果变更、断言失败、故障记录缺失，标记回归阻断；

5. 隔离约束：回归脚本不启动主系统仿真，仅实例化IAA子系统+观测激励源。

22.4 回归日志聚合器

聚合所有用例log、VCD波形摘要、SVA断言结果，输出结构化汇总JSON，作为自动故障报告的原始输入；原始波形文件可选择保留或自动清理，节省存储。

23 自动故障报告生成引擎（v0.4新增）

23.1 工具：iaa_report_builder.py

• 输入：批量回归聚合JSON、FailureMemory快照、探针观测数据、EP01/EP02/EP03三路原始判决；

• 输出两类报告：

1. 机器可读版：iaa_report_machine.json，带字段固定schema，支持AI/监管程序直接机读，包含故障哈希、溯源链路、置信度；

2. 人类可读版：iaa_report_human.md，结构化文档，含故障概述、分级、证据清单、根因推断、回归结论；

• 可配置模板：支持切换「工程审计模板」「学术勘伪模板」「硬件调试模板」，按需渲染；

• 证据锚定：报告内每一条故障结论，附带对应故障样本SHA256，可独立校验，满足可证伪要求。

23.2 报告强制字段（不可省略）

1. 报告版本、附录八版本哈希；

2. 故障唯一ID、时间戳、故障等级P0~P3；

3. R12四层探针原始观测；

4. EP01/EP02/EP03各自独立判决 + 三选二表决结果；

5. FailureMemory完整快照；

6. 根因推断标签与置信度；

7. 证据样本SHA256校验值；

8. 回归判定结果（PASS/WARN/FAIL）；

9. 报告生成时间戳与报告本身SHA256。

23.3 报告权限边界

报告引擎仅做整理、渲染、格式化，不修改原始故障数据与裁判结论；根因推断复用rootcause_infer.py输出，不会改写推断置信度；人工复核栏固定预留，所有自动生成结论必须留人工复核签章位，不输出“最终定论”表述，契合体系「结论零固化」原则。

24 回归基线与样本存证规范（v0.4新增）

24.1 IAA Golden样本集独立存证，单独默克尔哈希链，不属于主法典Golden基线；

24.2 每一次全量回归完成，自动打包本次所有报告、日志、摘要，生成归档包SHA256；归档哈希写入附录八版本元数据；

24.3 基线变更规则：修改IAA判决逻辑、探针过滤参数，必须重新跑全量回归；只有全部P0/P1冒烟用例PASS，才允许更新IAA Golden基线；

24.4 勘伪接口：第三方可下载对应版本Golden样本+回归激励，复现IAA全部裁决行为，满足体系可勘伪要求。

25 异常处置：回归失败分支规则

25.1 回归FAIL：禁止更新附录八版本哈希，冻结变更，需要定位故障；

25.2 WARN告警：自动标记，人工审核确认告警不影响IAA核心裁决后，可放行，告警记录永久写入版本备注；

25.3 IAA子系统自身SVA断言失败，直接判定FAIL，阻断版本发布流程。

26 跨载体仿真适配增强

26.1 批量回归脚本可调度多异构仿真后端：CMOS电路仿真、光子计算仿真、拓扑量子态仿真；同一套IAA RTL不变，仅切换观测激励源；

26.2 报告引擎自动区分载体类型，在报告元数据标记载体环境，便于对比不同物理载体下IAA裁判行为差异，用于碳硅跨域迁移研究。
