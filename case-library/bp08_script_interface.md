# bp08_script_interface.md v1.0-E0
BP08审计脚本接口契约文档
## 输入规范
1. 输入源：EP08样本记录
2. 输入格式：json，必须包含EP08定义全部必填字段
## 输出规范
1. 输出：BP08审计结果json，严格遵循BP08机读JSON模板
2. 输出路径：./out/audit_records/
## 进程退出码
0 = 审计成功
1 = 输入字段缺失 INCOMPLETE
2 = 格式错误 FORMAT_ERR
3 = 配置文件哈希校验失败
4 = 语义规则集哈希校验失败
5 = 未知异常
## 批量与并发规则
1. 批量审计自动生成manifest_bp08.sha256
2. 并发任务禁止修改原始EP08文件，只读运行
3. 批量结束自动校验Merkle根
## 变更说明
修改本文档不属于BP08基线正文升级；本文档自身必须保留独立sha256存证
