E0 概念提出 → E1 理论支持 → E2 结构证据 → E3 实验复现 → E4 器件功能 → E5 范式对比

E0：假设、框架、审计规则、判定体系完整闭环，无实测证据
E1：DFT热力学、动力学、分子动力学仿真收敛，模型自洽无矛盾
E1升级最低刚性门槛：所有仿真必须公开完整模型参数、边界条件、初始条件、迭代收敛标准、软件版本、脚本哈希、随机种子锁定方案。仅输出收敛结论、无复核复现材料、无参数公开记录，禁止升格E1。

随机种子哈希承诺铁律（绝杀仿真择优、隐性刷数据）
所有包含随机初始化、随机采样、随机排布、随机动力学迭代的仿真工况，必须在仿真启动前完成种子哈希公示、写入审计日志并绑定可信时间戳，生成SHA256前置承诺。
仿真启动后补公示、事后追加哈希一律判定为时序违规，该批次全部仿真数据直接标记 REJECTED、彻底作废，不得作为E1升格依据、不得归档采信。
仿真全部结束、数据定稿后，必须公开原始种子完整明文。明文哈希与预承诺哈希不一致、种子缺失、种子篡改、事后重刷择优，数据永久作废并记入审计异常。
本条彻底封死“跑百次择优留存、隐匿劣结果、事后补承诺”的全部时序与数据套利漏洞。

E2：XRD、TEM、STEM、EDS、EELS、XPS、Raman原子尺度表征锁定目标晶格结构稳定存在
E2结构判定门槛：必须证明目标C–Si–Cu耦合结构并非随机共存。至少需排除普通混合、宏观堆叠、独立相分离三种替代解释；若仅能确认元素存在而不能确认耦合组织形态，维持HOLD。

E3：多样本、多条件、多批次结果一致，数据可独立复现
E3独立复现最低刚性单位（杜绝伪复现）
E3独立复现核验必须满足差异化复现条件，至少覆盖不同批次样本、不同操作执行人员、不同测量硬件链路三者其一。
仅依靠同一设备、同一脚本、同一操作人员、同批次样本的重复单次流程输出，不构成独立复现，不得支撑E3证据升格，杜绝简单重复测试冒充有效复现。

E4：实测验证结构适配、场控稳态、内禀输运核心功能成立
E5：同等基线、同等约束、同等任务下，体系级优势具备统计显著性
四、证据状态机｜唯一判定语言 · 无模糊空间
全集状态：UNTESTED / HYPOTHESIS / SUPPORTED / CONDITIONALLY_SUPPORTED / REPLICATED / SYSTEM_SUPPORTED / PARADIGM_SUPPORTED / UNKNOWN / HOLD / CONTROVERSY / REJECTED / DOWNGRADED / ILP

状态转换刚性规则
新增合规有效证据逐级升格，可靠可复现反例直接触发对应等级降级。
UNKNOWN不等于PASS、不等于FAIL，统一标记HOLD，维持原级不升不降。
正反证据矛盾、结论无法统一，标记CONTROVERSY，双向证据永久归档留存，不偏袒、不抹除、不折中。
核心主张降级自动触发ILP九十日冷却锁定，冷却期内禁止同一主张重复升级申请。

HOLD状态复审刚性规则（杜绝隐性僵尸主张）
所有进入HOLD留白状态的科学主张，每十二个月必须启动一次公开状态复审。
复审周期内有新增合规有效复核证据，可按规则触发状态变更；无新增有效证据则维持HOLD。
连续二十四个月无任何有效证据迭代，自动遵循Claim Registry规则流转为STALE停滞或ARCHIVED归档，杜绝长期悬空、不升不降、不迭代的隐性僵尸主张。

CONTROVERSY争议解除法治化规则（避免状态机卡死）
体系出现正反证据对峙的CONTROVERSY状态后，不允许人工强制消争、强行定论。
仅当任意一方证据被独立合规复核，判定存在数据缺陷、方法失效、统计误用、不可复现、规则违规问题时，可剔除无效证据、解除争议、重置对应状态。
若正反双方证据均通过全维度合规复核、无违规缺陷，则争议永久维持CONTROVERSY状态，禁止强行合并结论、禁止人为终结争议，尊重客观证据对峙事实。

ILP冷却期完整补充规则
冷却期内允许提交、归档、公示新证据，但仅作观察性存档记录，不触发状态升级、不纳入定级证据、不允许对外宣称进展、不得作为结论依据。

ILP冷却证据静默铁律+封顶终局规则（防套利+防死循环）
冷却期内归档的所有观察性、阶段性、未终审证据，禁止以任何形式对外披露、解读、引用、暗示技术进展、预判结果、渲染优势。
一经查实违规传播，直接判定突破传播硬边界，触发NT4通道越权熔断，原有九十日冷却期自动翻倍延长。
冷却期翻倍延长不设触发次数上限，但单次叠加后总冷却期最高封顶为原始周期八倍（720日）。
若抵达最大冷却阈值后再次触发违规、仍无法完成合规静默，则对应科研主张自动转入ARCHIVED永久归档，彻底退出活跃迭代序列，杜绝状态机无限堆叠、长期悬空、违规成本过低的漏洞。

冷却期满后，所有存档证据必须经过独立合规复核，方可参与状态变更评审。

冷却期解除复核刚性身份约束
冷却期解除申请的第三方复核，必须由完全独立主体执行，满足未参与原实验设计、未共享实验设备、无项目关联、无专利关联、无合作关联。
复核报告必须全文公开，包含原始数据、否定结论、偏差分析，禁止只公示合格结论、隐匿无效数据。

早期独立复核过渡规则：E3阶段前，若设备资源客观稀缺、无法获取完全无共享设备的复核主体，可采用未参与实验设计、未产出原始数据的独立审核人执行复核，必须完整公开设备共享情况、潜在利益冲突、复核局限性、边界风险。所有过渡复核记录永久入链存档，不得用于掩盖利益关联、不得规避独立审计要求。

NT风险触发响应
任一NT风险触发后，对应EP/BP链路立即暂停迭代，启动独立复核。
复核确认风险污染核心结论，对应主张降级或标记CONTROVERSY。
复核判定误报，恢复链路并完整记录误报原因、误差来源、边界限制。
全部NT事件、处置流程、复核结论永久写入审计日志，不可删除。

NT4熔断处置刚性规则：一旦检测Root-O与Root-N哈希锚定、隐性借证、跨链引用派生，立即触发NT4通道越权熔断。熔断后双链彻底终止相互引用、映射、背书。已生成违规哈希记录永久留存，不得删除、不得覆盖。后续重建双链映射关系必须发布全新版本预注册，公开越权溯源、影响范围、风险评估、整改结论。

五、Claim Registry 主张生命周期规则｜可量化 · 无僵尸主张
所有科学主张统一登记入Claim Registry，强制执行生命周期管理。
登记日起十二个月无新增有效证据，标记STALE停滞。
连续二十四个月无有效进展，转入ARCHIVED归档，退出活跃主张列表。
归档主张重启必须重新预注册、重新积累有效证据链，禁止旧存档结论直接复用升格。

有效证据刚性定义
有效证据必须同时满足：完成预注册备案、具备完整审计日志、唯一时间戳、SHA256哈希存证、全程可溯源、可第三方复核。
无存档、无哈希、无时间戳、不可复核、重复截图、临时记录、未标准化数据，一律不计入有效证据。

六、FailureMemory 反例归档规范｜完整留存 · 不可抹除 · 判定透明
所有可靠反例强制七要素入链存档：
原始观测数据、实验条件参数、文档脚本版本、结论置信度、影响证据层级、处理降级记录、SHA256哈希固化。

可靠反例刚性判定规则
满足预注册实验条件、数据完整可溯源、无明确操作失误、可独立复核，即可判定为可靠反例并入链。
提交方与主张方不一致，自动进入CONTROVERSY流程，正反双证据永久并存归档。
存在操作缺陷、数据残缺、不可复核，标记REJECTED，写明驳回理由存档，不纳入体系定级依据。

误报与无效数据强制归档规则：经复核确认的设备故障、操作失误、数据污染、脚本bug、环境扰动、测试异常，必须统一标记FALSE_ALARM或INVALID入链归档。此类记录不触发降级、不纳入证据判定，但永久不可删除，保证审计链路完整无选择性过滤。

脱敏数据核验可逆铁律+隔离沙箱标准化定义（保密与求真绝对闭环）
对因工艺保密、合作约束、知识产权保护无法公开的原始实验数据，必须强制留存带可信时间戳的哈希摘要、完整数据字段清单、标准化脱敏方法说明、审计接口核验描述。
脱敏操作严禁掩盖、剔除、篡改能够影响实验结论、统计判定、层级定级的关键核心变量。
所有脱敏数据必须保留标准化可逆审计接口，且核验流程强制执行独立可信隔离沙箱机制：

1. 核验沙箱必须为独立物理隔离硬件或纯虚拟化隔离环境，与主张方生产设备、存储集群、网络链路、操作系统完全物理隔绝、权限隔绝、数据隔绝；

2. 原始敏感数据仅可在沙箱内加载、不可导出、不可外传、不可落地至外部介质；

3. 核验全程全自动录屏、操作日志全记录，录屏文件与沙箱操作日志实时哈希固化，绑定全局审计日志存证；

4. 核验结束后沙箱自动销毁全部原始数据副本，无残留、无缓存、无备份；

5. 审计方签署保密协议后可进入沙箱完成脱敏前后数据映射核验，验证脱敏未篡改、未剔除关键变量。
拒绝提供隔离沙箱可逆核验、无法完成映射比对、无录屏存证的脱敏记录，统一标记 UNVERIFIED，彻底失效、不得作为任何等级有效证据，永久记入审计风险记录。

公开权限原则
归档不可篡改不等于全量公开原始数据，公开范围遵从知识产权、合作协议、安全规范、法律法规。
所有归档记录禁止静默删除、禁止后台篡改、禁止覆盖替换、禁止隐性销毁。
七、证伪判定规则｜逐条明确 · 无豁免空间
