047|【层基线锁档·元层自勘层】对抗样本跨域继承：缺陷在不同场景永久留存

本文为《碳硅道统·跨域迁移治理法典》七层体系卷宗【047】。

体系基准：NT1‑NT4负迁移零号基准；三原则：创立者零特权、结论零固化、迭代零终点；机制：全员勘伪开放、全域反例准入、全维迭代重启。

体系坐标

元层自勘卷宗，承接046传统泛化指标失效：准确率无法表征跨域迁移真实风险基线，完成对抗样本跨域继承元层自勘基线锁档。

核心目标：打破“对抗扰动仅针对单一源域模型有效”的固有认知；定义对抗缺陷跨域继承机理，识别对抗特征迁移、扰动泛化、隐性缺陷固化三类失效模式；建立跨域对抗缺陷残留检出与阻断的元层判定基准。

概念边界说明：

前文046聚焦评估指标体系缺陷，解决常规边界样本负迁移评估失真问题。本篇聚焦对抗扰动带来的模型隐性缺陷：在源域构造的对抗样本，不只是单次攻击样本；模型学习到的脆弱特征会固化在权重内，随模型跨域迁移继承到新场景，在目标域无需重新构造攻击，即可触发失效。对抗缺陷不随业务场景更换自动消失。

核心矛盾

产业普遍将对抗样本视为独立的一次性攻击事件，默认对抗扰动只在源域环境生效；模型迁移到新业务场景后，默认原有对抗脆弱性随之消失。行业常单独在目标域重做对抗测试，忽略权重中已经固化的脆弱特征具备跨域继承特性。

真实机理：对抗训练/对抗样本攻击挖掘出的模型脆弱方向，会编码进模型权重表征空间。该脆弱特征不绑定源域数据分布，可跟随模型权重、知识蒸馏、模型微调链路完成跨域传递。同一类对抗扰动，在目标域完全不同的业务输入上依然可以触发模型错误输出；缺陷被永久继承，形成隐藏的跨域后门。常规准确率测试完全无法检出这类固化脆弱性。现有治理体系缺少对抗缺陷跨域继承的全链路传递核验规范。

定义：对抗样本跨域继承

模型在源域暴露的对抗脆弱特征被固化在权重表征空间，随模型蒸馏、迁移学习、权重交付等跨域流转动作，完整继承至目标域部署版本；无需在目标域重新生成对抗样本，同源扰动即可在新场景触发模型失效，这类可跨场景留存、继承复用的模型固有缺陷，称为对抗样本跨域继承。

基线入库三准则

1. 风险样本继承021风险图谱至046元层基线全部内容，全链路可追溯。

2. 拆解源域对抗挖掘、脆弱特征固化、跨域资产迁移、目标域缺陷复现全链路，定位对抗缺陷继承节点，完成风险等级量化，挂载NT1‑NT4负迁移标签。

3. 建立对抗缺陷跨域继承评估模型，产出可审计、可复核、可证伪的元层自勘规范。

一、对抗继承失效三级分级框架

轻度失效：仅特定窄范围对抗扰动可触发失效；缺陷影响范围有限，目标域输入触发概率极低，边界告警机制可拦截。

中度失效：源域对抗缺陷稳定继承至目标域；多类目标域业务输入可被同源扰动触发错误输出，常规业务测试无法检出脆弱性。

重度失效：对抗脆弱性大范围跨域继承，扰动泛化能力强；目标域正常业务输入即可激活固化缺陷，跨域迁移落地后可造成持续性、可复现的高危业务失效。

二、五大元层自勘入库基线

1. 源域对抗脆弱图谱溯源核验：在源域完成对抗特征挖掘，构建模型脆弱方向图谱，记录可触发失效的扰动类型。

2. 跨域对抗缺陷继承性核验：将源域对抗样本直接输入目标域迁移后的模型，检验同源扰动是否依然能够触发模型失效，量化缺陷继承程度。

3. 对抗样本跨域继承量化核验

度量指标：对抗缺陷继承率、扰动泛化覆盖率、目标域对抗触发率。

测算规则：

测算主体：第三方独立审计方，禁止模型开发交付方自测自审。

测算基准集：源域对抗样本库、目标域原生业务样本集、跨域扰动测试集。

计算公式：目标域模型仍可被同源对抗样本成功攻击的样本数量 ÷ 源域对抗样本总数量 = 对抗缺陷继承率。

复核约束：模型权重、对抗样本集、脆弱图谱、跨域攻击实验记录执行SHA256链式存证，支持跨时间、跨主体复测复现。

参考示意阈值（非固化，仅复核锚点）

对抗缺陷继承率＜10%：轻度失效

继承率10%~25%，部分对抗缺陷跨域留存：中度失效

继承率＞25%，大量脆弱特征跨域继承：重度失效

4. 对抗缺陷流转主体权责映射核验

区分模型训练方、对抗测试审计方、跨域迁移部署方。政务、工业控制等高可靠场景，模型跨域迁移审计必须增加对抗缺陷继承专项测试；不可仅在目标域单独做新增对抗测试，必须复用源域对抗样本做跨域继承验证。通用场景必须标注：对抗脆弱特征固化于模型权重，会跟随模型跨场景迁移继承；源域对抗测试不能做完即丢弃，缺陷会永久留存。

5. 元层勘伪存证核验：对抗脆弱图谱、跨域对抗测试报告、勘伪实验记录执行SHA256链式存证，允许外部提交新反例推翻风险判定，勘伪规则持续迭代更新。

三、四类专项探测探针（技术探测，与自勘基线解耦）

1. 源域脆弱特征测绘探针：采用梯度类对抗算法，挖掘模型固有脆弱方向，生成源域对抗样本集，绘制脆弱图谱。

2. 跨域对抗继承验证探针：直接将源域对抗样本输入迁移后的目标域模型，检验攻击是否依然有效，计算缺陷继承率。

3. 目标域原生样本扰动探针：对目标域正常业务样本施加同源扰动，检验是否能在真实业务输入上触发失效。

4. 元层推理证伪探针：检验现有迁移评审流程是否只做目标域新增对抗测试，缺失源域对抗缺陷跨域继承专项核验。

探针输出标记：已锁档入库 / 待勘伪复核 / 驳回治理假设

四、NT1‑NT4因果闭环

NT1机制错配：模型权重是特征压缩载体，对抗扰动挖掘的脆弱表征会被编码进权重空间，天然具备跟随模型迁移的能力。

NT2语义漂移：跨域场景数据分布发生变化，但模型内部固化的脆弱表征不会自动消除，同源扰动依旧可以命中缺陷。

NT3静默补全：工程团队默认对抗攻击是源域专属问题，迁移后原有对抗风险自动消失，忽略对抗缺陷跨域继承特性。

NT4权力迁移：未完成对抗继承核验的模型跨域部署，目标域场景下同源扰动激活固化脆弱特征，触发业务失效。

因果链：NT1对抗脆弱特征固化嵌入模型权重 → NT2跨域场景切换无法消除权重内固有缺陷 → NT3认为对抗风险仅局限源域，不做跨域继承验证 → NT4迁移后原有对抗缺陷被激活，造成业务失效

五、最小落地演示（轨道交通障碍物识别模型跨线路迁移场景）

链路：A线路训练轨道障碍物视觉模型，源域测试发现特定细微噪声扰动可以让模型漏检障碍物。模型迁移至B线路，B线路光照、摄像头型号、轨道环境和A线路完全不同。使用A线路生成的对抗样本直接送入B线路部署模型，依旧可以稳定触发障碍物漏检。常规准确率测试、B线路原生对抗测试均未覆盖该类同源扰动风险，缺陷随模型完成跨域继承。

轻度失效：只有极少数特殊扰动可触发失效，业务场景出现概率极低，告警系统可拦截。

中度失效：源域多组对抗扰动在B线路依然生效；日常业务样本难以触发，但是可人为构造扰动制造漏检隐患。

重度失效：对抗缺陷高比例继承，轻微噪声即可触发障碍物漏检；轨道场景下可造成列车制动判断失效，带来重大安全风险。

基线价值：对抗脆弱性绑定模型权重，不绑定源域场景。跨域迁移审计必须核验对抗缺陷继承率，不能认为换场景就消除原有对抗风险。

六、事故链路与递归陷阱

模型评测阶段：源域完成对抗样本测试，完成漏洞修复；模型在源域常规样本、新增对抗样本上指标达标。

风险潜伏阶段：权重内仍残留部分未彻底消除的脆弱表征；这类缺陷不会在常规业务样本上显现，随模型打包交付迁移。

事故爆发阶段：模型迁移至目标域，同源扰动施加于目标域业务输入，激活继承的对抗缺陷，模型发生错误推理。

验收盲区：迁移验收仅在目标域重新做对抗测试，缺少源域对抗样本跨域继承专项验证。

元层自勘基线递归陷阱

对抗样本跨域继承治理分级判定标准，只能依靠大量跨域对抗勘伪样本迭代沉淀。缺少探针体系，“对抗风险只存在源域，迁移后自动消失”的认知误区，会让固化在权重内的对抗脆弱缺陷持续跨场景流转。

七、十一层递归盲区（精简+短句注释）

014元级框架残缺｜复盘体系难以区分事故根因来自目标域新攻击，还是源域遗留、跨域继承的对抗脆弱缺陷

015证据自指残缺｜源域对抗修复报告无法自证模型迁移至目标域后原有对抗缺陷已经完全消除

016流程时序残缺｜模型蒸馏、微调、量化压缩都会改变对抗缺陷继承率，放大或缩小跨域脆弱性

017观测前提残缺｜常规业务样本无法暴露仅同源扰动才能激活、跨域继承的模型对抗缺陷

018契约执行残缺｜模型交付契约无法区分目标域新增对抗攻击、源域继承对抗缺陷带来事故的责任边界

019能力声明残缺｜模型安全测试方往往不会主动披露对抗脆弱特征可固化于权重、跨场景继承留存

020证伪机制残缺｜自勘需要搭建源域-目标域对照实验，量化对抗缺陷继承率的勘伪流程

021基线收敛残缺｜缺少对抗缺陷跨域继承、同源扰动复现失效样本归集与跨主体对齐锁档机制

022机理归因残缺｜对抗缺陷跨域继承引发事故缺少标准化根因判定规则

023权责确权残缺｜对抗继承缺陷上线引发事故各方前置责任边界缺少量化基线

024行业治理残缺｜行业层面缺少模型跨域迁移必须核验对抗缺陷继承率的前置评审规范

025顶层监管残缺｜监管体系缺少对抗样本跨域继承、权重固化脆弱特征的判定标准

026文明风控残缺｜文明尺度需要区分目标域新生对抗风险、源域权重固化继承对抗风险两套防护公理

027终局锁档残缺｜终局审计必须增加对抗缺陷跨域继承核验，不能仅采信目标域对抗安全材料完成锁档

028元层自勘残缺｜缺少区分新生对抗风险、跨域继承对抗缺陷的公理基线
