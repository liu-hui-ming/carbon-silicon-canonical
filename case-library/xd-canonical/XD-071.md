071|AI生成迁移数据资产属性定性

本文为《碳硅道统·跨域迁移治理法典》七层体系卷宗【071】。

体系基准：NT1‑NT4负迁移零号基准；三原则：创立者零特权、结论零固化、迭代零终点；机制：全员勘伪开放、全域反例准入、全维迭代重启。

体系坐标

接续070衍生知识包多次确权谱系基线，聚焦AI生成迁移数据资产的定性分类问题。核心痛点：AI生成数据混合原生真实数据、模型幻觉样本、重组衍生样本；资产属性边界模糊，分不清原生采集、AI生成、混合重组；迁移流转时混装打包，权属、风险、合规约束混在一起；幻觉、偏差类缺陷随数据集跨域迁移，形成NT3静默数据污染，且核验抽样无统一标准，仲裁阶段易因抽样方案争议导致判定失效。

概念边界

• AI生成迁移数据资产：包含AI原生生成样本、真实数据经AI变换/增广样本、真实与生成混合数据集，用于跨域迁移训练、推理、知识库构建的数据资产包。

• 资产属性定性：对数据集内样本逐类标记属性标签，划分为【原生采集】【AI合成】【AI增广】【混合重组】四类基础属性；同步标记幻觉风险等级、来源血统。

• 数据血统绑定：每一类属性样本必须锚定上游确权谱系，AI生成样本不可脱离基础数据源血统单独确权。

• 数据熔断：数据集刻意隐匿AI生成样本比例、伪造样本属性标签，检出后触发资产熔断，禁止跨域迁移分发。

• 抽样核验方法基线

数据集规模≤10万样本时，抽样比例不低于5%；规模＞10万时，采用分层随机抽样，每类属性标签样本至少抽取200条。核验手段包含四项：文本一致性比对、元数据溯源校验、生成痕迹检测（困惑度异常、重复模式识别）、人工复核抽检。抽样方案、抽样原始记录、核验结果一并归档，作为勘伪仲裁法定依据。

定义

本卷宗为AI生成数据跨域迁移勘伪规范，建立四类属性定性标记、成分占比申报、幻觉风险分级、数据血统绑定、标准化分层抽样核验机制；联动065血统存证、070衍生贡献度量化规则，解决AI生成数据“真假难分、属性混装、来源隐匿、核验方案不可复现”问题，实现数据资产属性可定性、成分可核验、污染可溯源、核验过程可仲裁。

基线入库三准则

1. 继承全部前置卷宗基线，复用血统、确权、勘伪、熔断体系，术语统一，治理链路连续。

2. 拆解数据集构建、属性打标、成分申报、抽样核验、跨域迁移、下游使用全链路，定位样本混装、属性造假、隐性幻觉污染、抽样方法不规范节点，挂载NT1-NT4标签。

3. 建立AI生成数据资产定性勘伪范式，可审计、可抽样核验、风险可分级、核验流程可复现。

一、AI生成迁移数据失效三级框架

轻度失效：属性标签局部漏标，无刻意造假、无高风险幻觉样本；暂停迁移分发，补全属性标记与成分申报、补齐抽样归档记录。

中度失效：AI生成样本占比申报与抽样实测偏差超过20%，或低等级幻觉样本未标注、抽样方案不合规；限制使用场景，依据数据血统与成分占比划分各方责任。

重度失效：刻意隐匿AI生成样本、伪造样本属性标签，或携带高风险幻觉数据跨域迁移造成下游决策污染；触发数据熔断，丧失技术通道豁免，数据集制作方承担主责。

二、五大元层自勘基线

1. 数据资产定性准入核验：所有待跨域迁移数据集，上线迁移前必须完成样本属性分类打标，禁止原生/AI生成数据无标记混装迁移。

2. AI数据定性核验流水线：上游血统哈希校验 → 样本四类属性分类标记 → AI生成占比申报 →【标准化分层抽样核验】→ 幻觉风险分级 → 定性报告+抽样方案归档。

3. 法典统一量化阈值

指标：数据集资产属性标记完整率

＞0.90：合规合格

0.70~0.90：轻度失效

＜0.70：中重度失效

4. 多方权责映射

原始数据供给方：提供原生采集样本血统、真实边界，标注可用于AI增广、合成的授权范围。

数据集制作方：完成【原生采集】【AI合成】【AI增广】【混合重组】四类定性标记，申报AI生成成分占比；申报值与抽样实测偏差超过20%判定为中度失效。AI生成样本必须标注幻觉风险等级；AI衍生部分同步适用070四维贡献度量化确权规则。不得删除、掩盖基础数据源血统；抽样方案必须遵循抽样核验方法基线，完整留存抽样记录。

多级流转平台：分发迁移数据集前核验属性定性报告、成分占比、血统谱系、抽样归档文件；标签造假、标记残缺、抽样方案不合规数据集禁止流转。跨境迁移场景，定性争议以069主权勘伪锚点为终审依据。

元层勘伪仲裁：严格依照归档抽样方案开展复核，以实测结果作为定性裁决依据；数据集未按基线开展抽样核验，则由数据集制作方承担举证不能的主要责任。

硬约束：AI生成样本不具备脱离底层原始数据源的独立完整血统；AI合成数据产生的权属约束、风险约束，随属性标签显性传递至下游，不自动豁免。

5. 勘伪存证核验：样本属性标签、成分占比申报文件、抽样方案、抽样原始记录、幻觉风险清单、上游血统谱系永久归档，开放反例迭代。

三、四类专属探测探针

1. 数据血统溯源探针：向上追溯数据集底层原始来源，识别血统剥离、隐匿上游数据源行为。

2. AI样本属性分类探针：自动识别原生、AI合成、AI增广、混合重组四类样本，核验标签一致性。

3. 成分占比偏差探针：按照分层抽样基线测算AI生成样本实际占比，比对申报数值，检出20%以上偏差。

4. 幻觉风险审计探针：筛查高风险幻觉样本，识别未标注隐性错误样本，阻断NT3静默数据污染。

四、NT1-NT4因果闭环

NT1错配：原生数据与AI生成数据生成逻辑、误差特性、权属约束完全不同，混装迁移后原有风险边界失效。

NT2语义漂移：数据集制作方认为AI生成数据一经产出即为全新独立资产，忽略底层原始数据权属与幻觉缺陷的传递性；同时认为抽样核验可随意自定义，不认可标准化基线。

NT3静默：AI幻觉、隐性偏差嵌入数据集，无明显异常标记，跨域迁移后持续污染下游模型与研判系统，长期潜伏。

NT4迁移：隐匿AI生成占比、抹除样本属性标签，自定义宽松抽样掩盖数据缺陷，混装对外分发；下游接收方无法区分数据类型，污染爆发后核验方法本身产生争议，溯源困难。

因果链：原生数据与AI生成样本特性、权属边界不一致→制作方认知漂移，混装打包不标记属性，随意设计抽样方案→NT3幻觉偏差随数据集静默迁移污染下游→NT4隐匿属性、采用不合规抽样掩盖缺陷，事故发生后核验判定产生争议。

五、落地场景精简版

1. 合规迁移：样本四类属性完整标记、成分申报与实测偏差≤20%、抽样方案符合基线、幻觉分级标注、完整血统归档，可在授权范围跨域迁移。

2. 轻度失效：少量样本漏标属性或抽样记录缺失，暂停分发，补齐标记与抽样归档后恢复迁移。

3. 中度失效：AI成分申报偏差超20%、低风险幻觉未标注、抽样方案不满足基线；限制使用场景，依据数据属性与血统划分责任。

4. 重度失效：伪造属性标签、刻意隐瞒AI样本，高风险幻觉数据迁移造成下游污染；触发数据熔断，数据集制作方独立承担主责。

六、递归陷阱

将AI生成数据视为完全独立新资产，切断底层原始数据血统；原生与AI样本混装不做标记；自定义简化抽样方案规避核验；只核验表面数据格式，忽视幻觉样本跨域传递带来的NT3静默污染；仲裁时质疑核验抽样方法，以此规避责任。

七、十一层递归盲区（精简对齐法典格式）

014元层残缺｜无法区分数据风险来自原生数据源、AI合成生成、属性标签造假、抽样方案不合规、混装迁移

015证据自指｜数据集格式正常，无法自证样本属性标注真实、AI成分申报准确、抽样流程合规可复现

016时序残缺｜多轮二次迁移中，AI属性标签、抽样核验记录逐步丢失，数据属性信息随流转衰减

017观测残缺｜常规数据质量校验无法识别内嵌AI幻觉、隐性偏差样本

018契约残缺｜数据集流转协议缺少样本属性定性、成分申报、标准化抽样核验、偏差追责硬性条款

019认知残缺｜低估AI幻觉样本跨域迁移，对下游系统形成长期静默污染

020证伪残缺｜缺少AI数据隐匿生成属性、幻觉污染、抽样造假跨域迁移事故反例库

021基线残缺｜缺少AI生成数据四类属性定性、分层抽样核验、成分偏差核验统一归集基线

022机理残缺｜AI数据混装迁移、属性造假、抽样不合规的负迁移事故缺少标准化根因判定规则

023权责残缺｜混合数据集原生/AI多主体之间、抽样不合规场景下的责任划分基线不足

024行业残缺｜缺少AI生成迁移数据资产属性定性、标准化抽样核验专项治理规范

025监管残缺｜缺少AI数据集属性标记、成分申报、分层抽样核验、幻觉风险分级判定标准

026风控残缺｜无法区分原生缺陷、AI生成幻觉、标签造假、抽样失效、混装污染五类风险

027终局残缺｜终局勘伪必须核验样本属性标记、成分实测报告、符合基线的抽样归档记录、完整数据血统

028元层残缺｜混合AI迁移数据多属性、标准化抽样核验分层根因公理基线缺失

071AI数据定性残缺｜补全分层抽样核验基线后，AI生成迁移数据资产定性体系100分永久锁档

卷宗结语

本篇新增分层抽样核验方法基线，把核验动作标准化、可复现，消除仲裁阶段抽样方案争议点。和070四维贡献量化、20%偏差阈值保持法典内部规则统一；形成「血统确权→衍生贡献量化→AI数据属性定性+标准化抽样」连续治理链路。

至此058–071 十五卷全部锁档闭环，覆盖模型资产、衍生迭代、数据集三大AI资产载体，通用、未成年人、政务、跨境四大场景。
