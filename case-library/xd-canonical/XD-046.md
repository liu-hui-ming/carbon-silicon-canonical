046|【层基线锁档·元层自勘层】传统泛化指标失效：准确率无法表征跨域迁移真实风险

本文为《碳硅道统·跨域迁移治理法典》七层体系卷宗【046】。

体系基准：NT1‑NT4负迁移零号基准；三原则：创立者零特权、结论零固化、迭代零终点；机制：全员勘伪开放、全域反例准入、全维迭代重启。

体系坐标

元层自勘卷宗，承接045多模型互联污染加速：网状迁移的指数级风险扩散基线，完成泛化指标失效元层自勘基线锁档。

核心目标：揭示准确率、召回率等传统单点泛化指标在跨域迁移场景下的固有盲区；区分分布内拟合性能与跨域负迁移风险两套独立评价维度，建立面向跨域迁移场景的风险度量元层判定基准。

概念边界说明：

前文卷宗聚焦模型资产、接口、组网拓扑、血统流转等工程载体层面风险；本篇切入评价体系底层公理。传统指标诞生于固定数据集分布内评估，衡量模型在已知样本上的拟合能力；跨域迁移的核心是分布偏移，此时准确率可以维持高位，但边界负迁移隐患已经存在。高准确率不等于跨域安全，二者属于两套独立度量空间。

核心矛盾

行业当前AI模型验收普遍依赖准确率、精确率、召回率、F1值等指标，以源域测试集高分作为模型可跨域部署的核心依据。默认源域分布上的良好性能，能够平移到目标业务域。

真实机理：源域测试集样本分布与目标域天然存在偏移，模型依靠源域内高频样本获得高准确率，但对目标域边界样本、罕见异常样本学习不足。源域指标很漂亮，目标域遇到分布偏移时，会突发系统性失效。传统指标天然加权主流样本，压低边界失效样本权重，边界负迁移代价不会体现在准确率数值上。单一准确率指标会掩盖NT1-NT4四类负迁移，造成“指标合格、上线翻车”的系统性误判。现有治理体系缺少脱离传统泛化指标、面向跨域分布偏移的风险评估规范。

定义：传统泛化指标失效

在跨域迁移场景下，源域数据集测算得到的准确率、F1等拟合指标，无法反映目标域分布偏移带来的负迁移风险；模型在主流样本上保持优秀指标，但边界、长尾、偏移样本存在大量未暴露失效，指标数值与真实业务风险发生解耦，这种评估体系失效现象称为传统泛化指标失效。

基线入库三准则

1. 风险样本继承021风险图谱至045元层基线全部内容，全链路可追溯。

2. 拆解指标高估、分布偏移、边界样本隐匿、上线突发失效全链路，定位评估体系失效节点，完成风险等级量化，挂载NT1‑NT4负迁移标签。

3. 建立跨域迁移风险评估模型，产出可审计、可复核、可证伪的元层自勘规范。

一、泛化指标失效三级分级框架

轻度失效：源域指标优秀；目标域仅极少数长尾边界样本出现失效，失效样本业务权重低，告警机制可捕获，不会引发业务扰动。

中度失效：源域指标维持高位；目标域分布偏移场景下，边界失效样本数量显著上升，常规业务测试难以覆盖，存在稳定触发的业务隐患。

重度失效：源域指标达标；目标域发生显著分布偏移，模型出现系统性、批量失效，高准确率指标完全掩盖高危负迁移，跨域迁移落地后引发重大业务事故。

二、五大元层自勘入库基线

1. 源域-目标域分布偏移核验：比对源测试集与目标业务域真实数据分布，量化特征偏移度，识别长尾、边界样本缺口。

2. 边界样本风险代价核验：剥离主流样本，单独评估模型在NT1-NT4负迁移边界样本集上的表现，计算失效对应的业务损失权重。

3. 跨域评估体系量化核验

度量指标：分布偏移度、边界样本失效率、指标风险解耦系数。

测算规则：

测算主体：第三方独立审计方，禁止模型开发方自测自审。

测算基准集：源域标准测试集 + 目标域边界负迁移测试集（NT基准样本）。

计算公式：边界样本失效样本数量 ÷ 边界样本总数量 = 边界样本失效率。

复核约束：源域数据集、目标域采集样本、边界测试集、指标对比实验记录执行SHA256链式存证，支持跨时间、跨主体复测复现。

参考示意阈值（非固化，仅复核锚点）

边界样本失效率＜10%：轻度失效

失效率10%~25%，边界隐患稳定存在：中度失效

失效率＞25%，边界风险大规模爆发：重度失效

4. 评估体系主体权责映射核验

区分模型训练方、指标评测方、跨域迁移上线审计方。政务、工业控制等高可靠场景，禁止仅依靠源域准确率、F1等泛化指标放行跨域部署。跨域迁移审计必须单独增设边界负迁移样本集测试，评估业务失效代价。通用场景必须标注：准确率只代表源域分布内拟合效果，无法衡量跨域分布偏移带来的负迁移风险，高指标不能作为跨域上线依据。

5. 元层勘伪存证核验：分布分析报告、边界测试集、对照实验结果、勘伪记录执行SHA256链式存证，允许外部提交新反例推翻风险判定，勘伪规则持续迭代更新。

三、四类专项探测探针（技术探测，与自勘基线解耦）

1. 分布偏移探测探针：对比源域与目标域数据特征分布，计算特征偏移距离，识别分布差异区域。

2. 边界样本压力探测探针：投喂NT1-NT4负迁移基准边界样本，独立统计边界失效率，脱离整体准确率单独评估。

3. 业务代价加权探测探针：对每一类失效样本赋予真实业务损失权重，计算整体业务风险，而非单纯样本正确率。

4. 元层推理证伪探针：检验现有迁移评审流程是否仅采信准确率、F1等传统泛化指标，缺失边界负迁移样本专项核验。

探针输出标记：已锁档入库 / 待勘伪复核 / 驳回治理假设

四、NT1‑NT4因果闭环

NT1机制错配：源域数据集采样天然偏向主流样本，长尾、边界样本占比低，在准确率计算中权重被稀释。

NT2语义漂移：跨域迁移带来数据分布偏移，目标域边界样本占比提升，源域训练未曾覆盖的场景大量出现。

NT3静默补全：工程侧习惯于使用源域准确率作为核心验收标尺，默认高泛化指标等价于跨域安全，忽略指标与风险解耦的客观事实。

NT4权力迁移：仅依靠传统泛化指标完成审计放行跨域部署；目标域分布偏移触发边界样本批量失效，引发业务事故。

因果链：NT1准确率天然偏向主流样本、压低边界样本权重 → NT2跨域迁移引入分布偏移，边界场景增多 → NT3以源域拟合指标判定跨域安全性 → NT4高指标掩盖负迁移，上线后突发系统性失效

五、最小落地演示（医疗影像辅助诊断模型跨院区迁移场景）

链路：三甲总院训练肺部影像AI诊断模型，源域测试集准确率96%，指标达标。模型迁移至基层分院；分院影像设备分辨率、拍摄体位、病患人群分布和总院存在明显偏移。总院测试样本以清晰标准影像为主；基层分院存在大量模糊、体位不标准的边界影像。模型在标准影像上依旧保持高准确率，但在边界影像出现漏诊。单独看源域准确率无法发现该风险，仅当使用边界样本集测试时，失效问题才会暴露。

轻度失效：极少数不规范影像出现识别偏差，系统告警，医生复核拦截，无诊疗风险。

中度失效：多类边界影像稳定出现漏判，常规院内测试样本无法复现，存在潜在诊疗隐患。

重度失效：基层分院大量边界影像触发模型批量漏诊，高准确率指标完全掩盖风险，造成严重医疗安全风险。

基线价值：准确率是分布内拟合指标，不是跨域安全指标。跨域迁移审计必须单独建立NT基准边界样本集，核算边界失效率与业务损失代价，不能只依赖传统泛化指标。

六、事故链路与递归陷阱

模型评测阶段：模型在源域测试集完成评测，准确率、F1指标全部达标，性能验收通过。

风险潜伏阶段：边界、长尾样本失效被主流样本的高准确率掩盖；常规测试样本无法触达负迁移场景，隐患长期隐藏。

事故爆发阶段：模型跨域迁移至目标域，业务分布发生偏移，边界样本大量出现，触发模型批量失效。

验收盲区：迁移验收仅核验源域传统泛化指标，缺失分布偏移评估、边界负迁移样本专项审计。

元层自勘基线递归陷阱

跨域迁移风险评估的分级判定标准，只能依靠大量源域/目标域分布偏移勘伪样本迭代沉淀。缺少探针体系，“准确率高=模型可跨域部署”的行业固有认知，会持续让被指标掩盖的负迁移风险流入目标业务域。
