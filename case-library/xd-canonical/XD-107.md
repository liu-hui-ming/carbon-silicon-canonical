107｜行业迁移规则全部例外场景反例校准（精简精髓定稿）

本文为《碳硅道统·跨域迁移治理法典》七层体系卷宗【107】永世终稿。

体系基准：NT1‑NT4负迁移零号基准

三原则：创立者零特权、结论零固化、迭代零终点

机制：全员勘伪开放、全域反例准入、全维迭代重启

体系坐标

接续卷宗106《全行业迁移风险五级分层适配模型》。106确立五级刚性定级主框架，本篇作为配套校准卷宗，专门收纳、勘伪、归档所有例外场景，解决“规则有刚性、现实有特例”带来的口径冲突；建立反例准入、核验、更新、冻结全流程机制，防止例外被滥用为绕开五级风控的后门。本卷宗不修改106五级基线主规则，仅提供受控例外校准通道。

核心定义

• 例外场景：满足两项条件方可认定。①客观存在特殊约束，无法直接套用标准五级迁移流程；②经多方联合勘伪，证明不引入新增NT3/NT4负迁移隐患。

• 反例校准：对例外案例做复现、根因拆解、风险重定级，提取边界约束写入规则注释；反例仅拓展规则适用边界，不推翻原有五级基线。

• 例外滥用后门：假借场景特殊，人为压低风险等级、绕过前置审计、放宽L5/NT4铁律。L5极危等级不存在任何例外场景。

例外准入刚性前置条件

1. 例外申请必须附带完整资产血统、场景约束清单、潜在负迁移风险推演报告。

2. 必须独立第三方勘伪复核，单一主体无权自行判定例外。

3. 所有例外、临时豁免仅设置有效期，到期自动失效，重新复核定级。

4. L5（NT4极危）永久无例外。零在线、零联网、零数据回流铁律不可突破，不存在任何例外申请通道。

可受理例外场景分类

类型1：应急救灾临时推理（L3/L4限定例外）

场景定义：重大地震、洪水等突发灾害，无充足时间完成完整前置审计，需要临时调用跨域模型辅助灾情研判。

约束条款：

• 仅短时启用，设置硬时间锁，灾害应急阶段结束立即关停模型跨域链路。

• 推理日志、特征向量全部本地隔离封存，事后强制完整勘伪复盘。

• 不允许模型权重、隐层参数跨边界传输；仅调用推理接口，禁止微调。

• 一旦检出NT3隐性偷渡，立刻切断链路，终止例外权限。

类型2：同源多分支模型受控迁移（L1/L2为主）

场景定义：同一源底座、同一训练数据集，仅做轻量化裁剪、蒸馏，部署到同行业不同子场景。

约束条款：

• 权重哈希基线必须可溯源，证明无新增域外训练数据注入。

• 仅允许L1、L2场景申请例外简化审计；若评估触及L3及以上风险，取消例外，执行完整标准审计。

类型3：科研隔离对照实验（L1-L3限定）

场景定义：高校、科研机构开展封闭对照实验，仅用于机理研究，不投入生产、公众服务。

约束条款：

• 实验环境独立隔离，禁止实验生成数据回流至生产模型。

• 研究成果发布不得附带模型权重、敏感隐性特征。

• L4、L5场景科研实验不享受例外机制，严格执行标准最高等级审计。

类型4：法定强制合规核验场景

场景定义：法律法规要求开展跨域比对、溯源核查，例如跨区域证照比对、风险联合核查。

约束条款：

• 例外范围严格限定在法定职责边界，不得扩大模型使用范围。

• 全程存证，由监管方参与勘伪，留存全链路探针时序记录。

禁止受理例外清单（永久不可申请）

1. L5/NT4军民交叉涉密模型相关场景，无例外。

2. 以降本、提速、项目工期紧张为由申请简化审计。

3. 仅依靠“专家主观判断”，无量化探针证据支撑的例外申请。

4. 计划通过例外通道开展模型增量微调、跨域持续迭代。

5. 例外申请目标为永久豁免审计，不设有效期。

五大元层自勘基线

1. 例外申请前置勘伪基线

例外申请提交后，对照五级基线做二次风险重估，核验是否落入禁止受理清单；生成例外资产快照，记录有效期、边界限制、熔断触发条件，文档附带SHA256哈希归档。不符合条件直接驳回。

2. 例外运行动态监测基线

部署探针：例外边界越界探针、风险等级上浮探针、隐性特征偷渡探针、审计旁路探针。一旦超出约定场景范围、风险等级向上漂移，自动触发熔断，收回例外权限，启动事故勘伪。

阈值沿用卷宗106对应风险层级标准，例外不放宽偏差容忍阈值。

3. 例外失效与事故勘伪确权基线

例外场景一旦发生负迁移事故，调取资产血统、例外审批记录、探针时序、推理会话快照。

• 申请方：未恪守例外边界、擅自扩大使用范围，承担主要过失责任。

• 勘伪复核方：复核疏漏，兜底连带责任。

• 运维管控方：熔断机制缺失，平台边界失效责任。

4. 反例入库校准基线

例外案例分为两类归档：①有效受控例外，提取边界约束更新规则注释；②例外滥用事故，标记为负面反例，纳入079反例库，用于后续例外申请预审拦截。L5负面反例仅归档推演，禁止任何试验。基线主规则不被反例改写。

5. 例外全生命周期存证基线

例外申请材料、勘伪报告、探针日志、到期复核记录全部SHA256永久归档。L4级别例外额外启用多主体联合存证。例外到期自动标记失效，归档封存。

四类专属探测探针

1. 例外边界越界探针：监测模型使用场景、范围、时长超出申请约定。

2. 风险等级上浮探针：持续监测运行过程风险等级向更高层级漂移。

3. 隐性特征偷渡探针：识别跨域推理过程中源域隐性先验持续迁移累积。

4. 审计旁路探针：监控人为篡改例外有效期、关闭监测探针、私自扩大使用范围。

NT1-NT4因果闭环

NT1：场景局部分布差异，客观存在特例，标准化流程存在冗余。

NT2：业务方希望简化流程，混淆“特例”和“通用场景”边界。

NT3：例外通道管控不严，隐性假设偷渡在边界缝隙潜伏累积。

NT4：例外机制被滥用，高危场景借特例绕开审计，触发不可逆体系污染。

终极因果链

现实场景存在客观特例 → 设置受控例外校准通道 → 若缺少边界锁止，例外演变为风控后门 → NT3隐患持续累积，高危场景突破L5铁律 → 事故发生后，例外审批权责界定混乱。

落地场景精简版

1. 所有例外场景必须提交勘伪申请，L5极危场景永久不开放例外通道。

2. 获批例外附带有效期与使用边界，探针持续监测越界与风险上浮，触发熔断立即收回权限。

3. 例外场景发生负迁移事故，调取全链路存证，划分多方责任。

4. 正反两类反例入库校准预审规则，主五级基线保持不变。

5. 私自创设例外、借用特例绕过五级审计，判定多方过失追责。

递归统一陷阱

场景特殊就可以豁免审计；例外获批后永久有效；科研实验不受五级风控约束；只要是应急场景就可以放开模型参数跨域流转；例外校准可以修改L5的零在线铁律。
