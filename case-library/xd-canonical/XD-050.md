050|【层基线锁档·元层自勘层】迁移技术不可适用场景全集与反例校准

本文为《碳硅道统·跨域迁移治理法典》七层体系卷宗【050】。

体系基准：NT1‑NT4负迁移零号基准；三原则：创立者零特权、结论零固化、迭代零终点；机制：全员勘伪开放、全域反例准入、全维迭代重启。

体系坐标

元层自勘卷宗，承接049迁移测试集结构性缺陷：无法覆盖目标域隐性边界基线，完成迁移技术不可适用场景全集与反例校准元层自勘基线锁档。

核心目标：破除“迁移学习万能适配”的产业预设，建立迁移技术边界图谱；定义不可适用场景三大类别：分布彻底割裂、因果机制反转、安全阈值不可逆；识别场景错配、因果混淆、反例被过滤三类失效模式；构建不可适用场景全集持续收录、反例迭代校准的元层判定基准。

概念边界说明：

049聚焦评测底座——测试集的结构性盲区；本篇上升至迁移方法本身的适用边界。迁移学习、知识蒸馏、模型微调等跨域技术存在天然边界，不是任意源域知识都可以迁移至目标域。当源域与目标域底层因果关系反转、物理机制完全割裂时，强行迁移会直接触发高强度NT负迁移。即便测试集完备、探针齐全，迁移方法本身已经不适用，所有调优手段都无法消除根本性风险。需要持续收录不可适用场景全集，并利用真实反例动态校准边界判定规则。

核心矛盾

行业普遍将迁移学习作为降本提速的通用方案，默认只要有少量目标域数据，就可以做迁移微调；很少前置判定当前场景是否属于迁移技术不可适用域。工程实践中习惯优先做迁移，出现失效后才归因于数据、模型，忽略最底层问题：场景本身不支持知识迁移。

真实机理：迁移技术成立的前提，是源域与目标域共享底层不变因果机制。一旦底层因果反转、物理规则发生质变、风险阈值不可逆，源域习得的表征、决策逻辑不再具备可迁移性。强行迁移会将源域错误因果关系注入目标域系统。不可适用场景边界不是静态固定集合，需要持续接纳真实业务反例，迭代校准边界判定规则；若过滤掉失败反例，边界图谱会持续失真。现有治理体系缺少迁移技术前置适用性判定、不可适用场景归档、反例动态校准的规范。

定义：迁移技术不可适用场景全集与反例校准

源域与目标域底层因果机制断裂、物理规律反转或安全约束不可逆，源域知识无法向目标域有效传递，强行迁移必然触发系统性负迁移；持续归集该类场景形成全集，并依托真实业务失效反例，不断校准迁移适用边界判定标准，该体系称为迁移技术不可适用场景全集与反例校准。

基线入库三准则

1. 风险样本继承021风险图谱至049元层基线全部内容，全链路可追溯。

2. 拆解场景前置判定、因果机制核验、迁移尝试、失效反例归档校准全链路，定位场景错配根节点，完成风险等级量化，挂载NT1‑NT4负迁移标签。

3. 建立迁移适用性前置评估模型，产出可审计、可复核、可证伪的元层自勘规范。

一、迁移不可适用场景三级分级框架

轻度失效：局部子任务不可迁移，主任务不受影响；可拆分任务，剔除不可迁移子模块即可规避风险。

中度失效：目标域部分核心机制与源域存在差异，强行迁移会出现间歇性负迁移；调参无法根治，仅能降低触发概率。

重度失效：源域与目标域底层因果完全反转，属于迁移技术不可适用全集；任何迁移方案都会带来系统性失效，禁止开展模型迁移。

二、五大元层自勘入库基线

1. 源域-目标域底层因果对齐核验：梳理两侧物理机制、因果链路、安全约束，判定底层不变量是否存在，识别因果反转区域。

2. 不可适用场景全集比对核验：将当前业务场景与已归档不可适用场景全集比对，匹配同类历史反例。

3. 迁移不可适用场景量化核验

度量指标：因果不变量重合度、不可适用特征匹配度、反例校准置信度。

测算规则：

测算主体：第三方独立审计方，禁止迁移方案开发方自测自审。

测算基准集：不可适用场景归档库、历史失效反例库、源域目标域因果图谱。

计算公式：目标域与源域保留的底层因果不变量数量 ÷ 源域全部核心因果不变量总数 = 因果不变量重合度。

复核约束：因果图谱、场景比对记录、反例失效报告、校准迭代日志执行SHA256链式存证，支持跨时间、跨主体复测复现。

参考示意阈值（非固化，仅复核锚点）

因果不变量重合度＞80%：轻度失效

重合度40%~80%，部分因果断裂：中度失效

重合度＜40%，底层因果显著割裂：重度失效

4. 场景适用性主体权责映射核验

区分业务需求方、迁移算法设计方、审计勘伪方。政务、工业控制等高可靠场景，模型跨域迁移立项前必须完成前置适用性判定；一旦匹配进入不可适用场景全集，禁止启动迁移训练。通用场景必须标注：迁移学习不是通用万能方案，底层因果断裂场景强行迁移会引发系统性负迁移。

5. 元层勘伪存证核验：因果分析报告、场景全集档案、反例校准记录、勘伪实验记录执行SHA256链式存证，允许外部提交新反例推翻原有边界判定，勘伪规则持续迭代更新。

三、四类专项探测探针（技术探测，与自勘基线解耦）

1. 因果不变量测绘探针：分离源域与目标域可变特征、不变因果特征，绘制因果图谱，定位因果反转区域。

2. 不可适用场景匹配探针：检索不可适用场景全集，匹配场景特征，查找同类历史反例。

3. 小样本迁移预验证探针：小范围受控实验，验证是否会稳定触发负迁移，用于更新场景边界。

4. 元层推理证伪探针：检验现有迁移评审流程是否直接启动模型训练，缺失前置因果核验、不可适用场景比对专项核验。

探针输出标记：已锁档入库 / 待勘伪复核 / 驳回治理假设

四、NT1‑NT4因果闭环

NT1机制错配：迁移学习生效依赖源域目标域共享底层因果不变量；因果断裂场景天然不满足迁移前提。

NT2语义漂移：跨域场景底层物理、因果规则发生反转，源域学到的决策逻辑在目标域变为错误逻辑。

NT3静默补全：工程团队优先采用迁移方案降本，跳过前置因果校验，默认迁移可以适配新场景。

NT4权力迁移：在不可适用场景强行开展模型迁移，上线后触发大规模NT系列负迁移事故。

因果链：NT1迁移学习依赖共享因果不变量作为基础 → NT2目标域因果机制反转，源域知识失效 → NT3前置场景判定缺失，直接启动迁移开发 → NT4不可适用场景强行迁移，引发系统性负迁移

五、最小落地演示（化工反应预测模型跨反应器迁移场景）

链路：A反应器训练化工反应状态预测模型，A反应器内是常压反应体系。计划迁移至B高压反应器，二者反应机理发生质变，压力改变分子反应路径，底层因果关系反转。团队直接采用迁移微调，少量B域数据做训练。模型在有限测试样本上表现尚可；真实工况下，对反应风险判断持续出错，存在爆炸预警误判风险。该场景属于迁移技术不可适用全集，任何迁移方案都无法消除底层因果错配。

轻度失效：仅次要副反应预测不可迁移，主反应预测稳定可靠，隔离子模块即可。

中度失效：部分工况区间因果偏移，预测偶发失效，风险可控但无法彻底根除。

重度失效：反应底层因果完全反转，强行迁移带来持续的高危误判，属于迁移禁止场景。

基线价值：跨域迁移第一步不是采集数据训练模型，而是判定场景是否在迁移技术适用范围内。不可适用场景全集与持续反例校准，是迁移立项的前置闸门。

六、事故链路与递归陷阱

方案立项阶段：业务团队评估数据量，认为可以使用迁移学习降低开发成本，直接进入模型开发。

风险潜伏阶段：底层因果机制差异未被识别，场景没有归入不可适用全集；迁移模型在有限测试集指标达标，风险被隐藏。

事故爆发阶段：模型部署至目标域真实工况，因果错配问题持续暴露，模型输出系统性错误预测。

验收盲区：迁移立项缺少前置因果核验、不可适用场景匹配审计，直接进入模型训练与测试环节。

元层自勘基线递归陷阱

迁移适用边界判定标准，只能依靠持续新增业务反例迭代校准。缺少探针体系，“迁移学习可以降本、少量数据即可复用旧模型”的固有认知，会促使团队在不可适用场景强行开展迁移，埋下系统性负迁移隐患。

七、十一层递归盲区（精简+短句注释）

014元级框架残缺｜复盘体系难以区分事故根因来自模型、数据集缺陷，还是场景本身属于迁移不可适用域

015证据自指残缺｜迁移模型在测试集合格的报告，无法自证当前场景不属于迁移技术不可适用全集

016流程时序残缺｜因果不变量提取方式、反例收录规则会修改迁移适用边界的判定结果

017观测前提残缺：常规样本测试无法暴露底层因果反转带来的系统性负迁移

018契约执行残缺｜项目交付契约无法区分场景错配、算法缺陷、数据缺陷导致事故的责任边界

019能力声明残缺｜算法方案方往往不会主动评估并披露目标场景属于迁移不可适用全集

020证伪机制残缺｜自勘需要搭建源域目标域因果对照实验，持续收集反例校准场景边界的勘伪流程

021基线收敛残缺｜不可适用场景全集、失效反例库持续归集与跨主体对齐锁档机制

022机理归因残缺｜场景因果错配引发迁移失效缺少标准化根因判定规则

023权责确权残缺｜不可适用场景强行推进迁移上线引发事故各方前置责任边界缺少量化基线

024行业治理残缺｜行业层面缺少迁移项目立项前必须核验场景适用性的前置评审规范

025顶层监管残缺｜监管体系缺少迁移技术不可适用场景、因果反转风险的判定标准

026文明风控残缺｜文明尺度需要区分模型缺陷、数据集缺陷、场景底层因果不匹配三类风险公理

027终局锁档残缺｜终局审计必须增加场景因果核验与不可适用场景比对，不能仅采信模型指标报告完成锁档

028元层自勘残缺｜缺少区分模型失效、数据集失效、场景不可迁移失效三类根因的公理基线
