084|医疗隐私跨域溢出、脱敏失效、隐性泄露治理

本文为《碳硅道统·跨域迁移治理法典》七层体系卷宗【084】。

体系基准：NT1‑NT4负迁移零号基准；三原则：创立者零特权、结论零固化、迭代零终点；机制：全员勘伪开放、全域反例准入、全维迭代重启。

体系坐标

接续083|医疗知识迁移金融场景：道统标杆事故全域治理规范。

083完成异构知识跨域迁移标杆场景的全链路验证。本篇聚焦医疗数据跨域迁移另一类高危害风险：隐私溢出、脱敏失效、隐性泄露。医疗数据自带强个人身份属性，即便经过脱敏处理，在跨域迁移、特征提取、模型蒸馏过程中极易发生隐式身份信息逃逸；这类泄露无明显报错，属于典型NT3静默负迁移。本篇复用082三维风险定级模型、081锁档术语、075–083权责基线，构建从数据迁出前置校验、脱敏有效性探针监测、泄露溯源勘伪到权责确权的完整治理规范，补齐医疗跨域迁移隐私安全维度。

概念边界

• 医疗隐私跨域溢出：医疗原始数据、中间特征、模型记忆信息，超出预先审批的目标域边界向外扩散，流向未授权业务、第三方系统。

• 脱敏失效：采用匿名化、掩码、差分隐私等脱敏手段后，数据/模型特征仍保留可用于个体重识别的信息。

• 隐性泄露：不直接输出明文身份证、姓名，依靠特征组合、模型记忆、交叉比对，反向还原自然人身份；无告警日志，常规数据审计难以捕获。

• 隐私治理规范：数据迁出前置校验、脱敏有效性动态监测、溢出阻断、泄露取证、勘伪定责、反例入库整套流程，可嵌入数据迁移流水线。

定义

本卷宗建立医疗隐私跨域迁移治理框架，定义隐私溢出、脱敏失效、隐性泄露三类风险判定标准；部署隐私类专项探针，联动三维风险定级模型，确立隐私泄露场景取证、勘伪、权责划分规则；形成可机读、可审计、可勘伪的医疗隐私跨域迁移基线规范。

基线入库三准则

1. 继承全部前置卷宗基线，复用资产血统SHA256、铜脉报文体系、四级过失、证据分级、基线锁档、锁档术语、三维风险定级模型，全文术语与081锁档词典严格对齐。

2. 拆解数据迁出审批、脱敏校验、模型特征迁移、运行监测、隐性泄露爆发、取证勘伪、反例入库全链路；捕获静态脱敏校验流于形式、忽略特征记忆泄露、缺少重识别风险评估等风险节点，挂载NT1-NT4标签。

3. 隐私泄露判定规则可证伪；任何人可提交隐私泄露场景反例，通过079反例校准流程优化基线阈值，不改动法典底层公理与NT1-NT4零号基准。

一、标杆场景原生风险识别（套用082三维定级模型）

场景简述：医疗机构将脱敏后的患者特征数据集迁移至外部AI服务商训练模型；仅做字段掩码，未评估特征组合重识别风险，模型蒸馏后记忆个体特征，发生隐性身份泄露。

三维指标逐项评估：

1. 可逆性：不可逆。一旦自然人身份被重识别，隐私损害永久留存，无法撤回已泄露关联信息。

2. 影响范围：全域跨主体。涉及患者、医疗机构、第三方AI服务商，具备社会性传导与合规处罚风险。

3. 自主权限：无自主权限。隐私信息流出后，机构无法单方面抹除第三方系统内模型记忆。

三维综合判定：三级（高风险）。

按照082规范：三级风险禁止自动跨域迁移，必须人工专项勘伪审计，审批后方可小范围试运行，预置硬熔断开关。

本场景四类负迁移机理

• NT1错配：静态脱敏规则仅针对明文字段，无法覆盖高维特征空间，字段脱敏不等于特征脱敏，两套校验体系错位。

• NT2语义漂移：业务方将“掩码字段”等同于“完成脱敏”，混淆字段脱敏与全维度隐私保护术语边界。

• NT3静默负迁移：没有明文外泄日志，系统无报错；依靠多特征交叉推理实现个体重识别，属于隐性泄露，常规审计无法检出。

• NT4系统性迁移失效：迁移流水线缺少隐私校验关卡，数据、特征、模型逐层携带隐私残留，整套迁移链路持续传导隐私风险。

二、五大元层自勘基线

1. 迁出前置隐私勘伪基线

医疗数据/特征/模型迁出前强制执行三维风险定级与隐私专项审计，生成隐私评估快照并入资产血统。三级隐私高风险，必须提交脱敏有效性评估报告、重识别风险测算报告、隐私阻断方案、铜脉隐私探针部署方案；审计不通过禁止启动迁移。审计文档引用081锁档术语与082全域定级总表，并标注基线哈希。

2. 迁移全链路动态隐私监测基线

部署多维度隐私专项探针持续监测：脱敏有效性探针、特征隐私溢出探针、模型记忆重识别探针。当检测到个体重识别成功率高于阈值，触发078动态权责适配流程，自动冻结数据/模型扩量权限，启动隐私风险重校验。

铜脉隐私信号持续采集，一旦检出NT3隐性泄露特征，触发分级熔断。

重识别告警阈值：个体重识别成功率高于5%，强制暂停迁移任务。初始值，经反例校准收敛。

3. 隐私泄露事故勘伪与权责确权基线

一旦发生隐私溢出或隐性泄露，启用077取证规范采集一级证据：资产血统链、数据迁出审批记录、脱敏校验原始日志、隐私探针时序数据、模型权重快照。

按075~080权责基线拆分责任：

• 源域医疗机构：未完成全维度脱敏有效性核验，低估特征重识别风险，承担兜底责任。

• 迁移运营方：三级隐私高风险场景，简化隐私专项审计放行迁移，承担主要过失责任。

• 迁移平台方：流水线未嵌入隐私探针校验关卡，允许高风险资产自动迁出，平台免责边界失效。

4. 隐私场景反例入库校准基线

本隐私泄露标杆案例可复现，完整一级证据齐全，判定为真反例，按079流程入库。仅对医疗隐私跨域迁移场景的前置审计、探针阈值边界做局部规则校准，底层公理、NT基准保持不变。新版本基线仅适用于后续新项目，不回溯推翻本次勘伪结论。

5. 法典统一量化阈值

医疗隐私相关的数据、特征、模型跨域迁移，默认初始定级为三级高风险，不得自动降为二级。

试运行阶段迁移样本容量上限：不超过总样本量5%；任何扩量操作必须重新触发隐私场景变更重校验。

6. 勘伪存证核验

隐私风险定级快照、脱敏审计报告、隐私探针日志、泄露勘伪报告、反例入库记录全部SHA256哈希归档，纳入077证据体系，开放反例迭代。

三、四类专属探测探针（适配本医疗隐私场景）

1. 脱敏有效性探针：校验脱敏处理后残余个体识别信息，通过k-匿名最小等价类计数、差分隐私ε-delta预算测算量化脱敏强度。

2. 特征隐私溢出探针：监测高维特征携带身份关联信息向目标域溢出，基于属性推断攻击，计算特征推断出敏感身份属性的成功率量化泄露量。

3. 模型记忆重识别探针：检测模型是否记忆个体样本特征，采用成员推理攻击，计算区分训练集/非训练集样本的AUC衡量模型记忆风险。

4. 隐私扩量旁路探针：监控绕过隐私审计私自扩大迁移样本规模，含流量突变检测，覆盖人为故意旁路与配置错误两类场景。

四、NT1-NT4因果闭环

NT1错配：字段级脱敏规则无法适配高维特征、模型记忆空间，静态脱敏手段天然无法覆盖模型迁移场景。

NT2语义漂移：业务方混淆“字段掩码”与“隐私脱敏完成”，简化隐私评估流程。

NT3静默负迁移：无明文泄露日志，依靠特征交叉推理完成个体重识别，隐性泄露长期潜伏。

NT4迁移：缺少医疗隐私跨域迁移专项治理规范，流水线缺少隐私校验关卡；泄露事故发生后，各方对泄露等级、责任划分产生巨大勘伪争议。

因果链：字段脱敏与模型特征隐私保护体系天然错配→项目方简化隐私评估，混淆脱敏概念→NT3隐性重识别风险静默潜伏，系统无告警→NT4缺少隐私场景治理基线，事前校验缺失，事后勘伪口径冲突。

五、落地场景精简版

1. 合规隐私迁移：前置三维定级判定三级高风险，隐私专项勘伪审计，小流量试运行，隐私探针持续监测。

2. 监测触发重校验：重识别成功率超标，自动冻结扩量，启动动态权责重评估。

3. 隐性隐私泄露爆发：采集一级证据，依据整套权责基线完成多方责任拆分。

4. 真反例入库校准：案例可复现、证据完整，纳入反例库，微调医疗隐私迁移场景审计边界。

5. 违规强行迁出：跳过三级隐私专项审计直接迁移，勘伪判定多方过失追责。

六、递归陷阱

完成姓名身份证掩码即认定脱敏完成；静态脱敏一次校验永久有效；模型蒸馏不会记忆患者隐私；小样本试运行不存在隐私重识别风险；隐私迁移不部署成员推理探针。
