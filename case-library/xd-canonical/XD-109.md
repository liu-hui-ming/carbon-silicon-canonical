本文为《碳硅道统·跨域迁移治理法典》七层体系卷宗【109】永世终稿。

体系基准：NT1‑NT4负迁移零号基准

三原则：创立者零特权、结论零固化、迭代零终点

机制：全员勘伪开放、全域反例准入、全维迭代重启

体系坐标

接续卷宗108《【层基线锁档】全行业统一迁移安全基线定型》。卷宗108完成安全基线哈希锁档；本篇完成整套法典治理层术语全集固化，统一所有卷宗、探针、勘伪流程的语义边界，消除文字歧义、同词异义、同义异词问题。术语锁档后，新增注释、案例、行业细则仅可补充释义说明，核心术语定义本体永久固化，修改必须经过多主体联合勘伪终审并更新全局术语哈希锁档。

核心定义

• 术语锁档：对法典整套治理体系核心名词、缩写、判定概念做唯一语义锚定，生成术语集SHA256哈希固化。任何卷宗、勘伪报告、探针日志必须严格沿用本套术语；不得自行创造别名、篡改内涵、随意简写。

• 治理层术语：用于风险定级、勘伪审计、权责确权、基线校验的概念集合，区别于底层硬件、算法模型技术名词。

• 术语迭代边界：案例说明、场景举例可增补；NT系列负迁移定义、五级风险层级、资产血统、勘伪、反例等内核术语，语义永久锁死，不可变更。

道统核心术语固化全集

负迁移基准术语（永久锁死）

1. NT1 轻度负迁移：样本空间轻度分布错配，仅产生局部经济性偏差，不存在隐性特征偷渡。可逆。

2. NT2 范式负迁移：认知范式漂移，业务逻辑系统性偏离，偏差显性可控，无潜伏链式传导风险。可逆。

3. NT3 隐性负迁移：隐性先验、特征范式静默偷渡；模型输出表象合规，隐患长期累积，可诱发民生、公共安全事故。局部可逆。

4. NT3+ 链式负迁移：属于NT3子类，单点偏差具备链式放大传导能力，可触发区域性公共事件。大多不可逆。

5. NT4 体系级负迁移：跨域权重/特征污染不可逆，侵蚀涉密、国家安全体系基底，损害永久不可清除。零容错。

五级风险分层术语（永久锁死）

1. L1低风险：NT1，轻微分布偏移，仅经济损耗，无公共安全影响，标准审计后可全量上线。偏差容忍≤10%。

2. L2中风险：NT2，范式认知漂移，扰动业务流程，损失可控，限定范围上线。偏差容忍≤5%。

3. L3高风险：NT3，隐性假设偷渡，可造成民生误判，强制人工勘伪终审、小点位试点。偏差容忍≤1%。

4. L4重大风险：NT3+链式传导失效，极小受控试点，内置硬熔断，禁止规模化落地。偏差容忍≤0.1%。

5. L5极危风险：NT4不可逆体系污染。零在线、零联网、零数据回流、零试运行、零跨域参数交互；仅允许物理断网离线沙箱静态核验，无任何例外通道。

勘伪与基线体系术语（永久锁死）

1. 勘伪：基于探针时序、资产血统、实测证据，复现风险、核验负迁移根因、校验规则一致性的审计行为；勘伪不等于主观评审。

2. 反例：与预期规则输出不一致的真实或可复现案例，分为正向校准反例与负面事故反例；反例用于校准注释，不直接改写内核基线与术语。

3. 资产血统：模型、数据集、推理会话完整溯源链路，包含源域快照、哈希记录、流转审批、探针时序、历次勘伪文档，不可截断。

4. 层基线锁档：安全基线集合通过SHA256哈希固化，基线本体修改需多主体联合勘伪，注释文档独立归档。

5. 探针：可机读的量化监测单元，持续采集特征残留、风险漂移、越界操作时序数据，输出可审计证据。

6. 审计旁路：人为操作绕过前置定级、基线校验、监测探针等风控流程。

7. 例外场景：满足刚性前置条件、不引入NT3/NT4隐患，经第三方勘伪复核，授予限时、限定范围的受控豁免；L5场景不开放例外。

8. 硬熔断：触发阈值后自动切断跨域推理链路、冻结模型调用权限的强制保护机制，不可由业务方单方面关闭。

跨域迁移基础术语（永久锁死）

1. 源域：模型原生训练空间、数据分布、隐性先验、任务约束构成的基准场景。

2. 目标域：模型计划复用、部署的新业务、地理、行业场景。

3. 跨域迁移：模型权重、特征向量、知识范式、推理逻辑从源域复用至分布、约束、目标存在差异的目标域。

4. 隐性先验：模型在源域训练习得、未显式写入代码与文档的环境假设、统计阈值、特征偏好。

5. 风险降级偷渡：模型隐性先验自动压低目标域风险判定等级，表象指标正常，隐患隐匿。

术语变更管控刚性流程

1. 术语增补提案：新增术语仅允许作为扩展注释，内核术语不接受内涵修改提案。

2. 多主体联合勘伪：若提案涉及新增治理层核心术语，必须三方独立勘伪复核。

3. 哈希锁档更新：术语集定稿后重新计算全局术语SHA256哈希，旧版本术语哈希永久归档留存。

4. 全卷宗同步：术语集更新后，所有卷宗、探针规则、勘伪模板同步对齐；未对齐文档视为无效。

NT、L1-L5内核术语，不接受任何内涵修改提案。

五大元层自勘基线

1. 术语前置一致性勘伪基线

所有跨域项目、勘伪报告、探针日志撰写前，必须对齐本套锁档术语；术语使用不一致，直接驳回定级与勘伪申请。生成术语一致性校验快照纳入资产血统。

2. 术语动态一致性监测基线

部署术语越界探针，持续检测文档、日志、推理记录中出现未备案自定义术语、篡改术语内涵的行为；检出立即告警，冻结勘伪流程，启动复核。

3. 术语误用事故勘伪与权责确权基线

勘伪、定级过程发生术语误用，造成风险误判：

• 文档撰写/勘伪人员：错误使用术语，承担主要过失责任。

• 复核勘伪方：术语一致性校验疏漏，承担兜底连带责任。

• 运维管控方：缺少术语校验机制，平台边界失效责任。

4. 术语注释反例入库校准基线

收集术语歧义、误用案例归入079反例库，用于补充术语释义注释；注释不改动术语本体定义。

5. 术语集永久存证锁档基线

术语全集、历次版本哈希、勘伪复核文档SHA256永久归档，L4、L5相关勘伪文档启用多主体联合存证。

四类专属探测探针

1. 术语越界探针：检测私自创建别名、篡改核心术语内涵、随意简写内核概念。

2. 术语一致性探针：比对勘伪材料、日志与锁档术语语义匹配度。

3. 资产血统标签探针：校验资产血统记录使用规范术语标记风险等级与负迁移类型。

4. 审计旁路探针：监控人为刻意篡改术语描述，实现绕开风险定级的违规操作。

NT1-NT4因果闭环

NT1：场景描述缺少统一词汇，轻度语义差异造成定级沟通偏差。

NT2：团队自定义名词，同概念不同描述，业务流程判定口径混乱。

NT3：术语定义模糊，人为偷换概念掩盖隐性先验偷渡隐患。

NT4：核心语义无固化锚点，高危场景篡改术语内涵，人为降级L5风险，诱发不可逆体系污染。

终极因果链

治理体系缺少统一术语锚定 → 各方自行定义名词，语义割裂 → 模糊词汇被利用掩盖NT3潜伏隐患 → 高危场景偷换概念突破L5铁律 → 事故勘伪时概念无法对齐，权责难以判定。

落地场景精简版

1. 法典所有卷宗、勘伪材料、探针日志强制使用本锁档术语集，禁止私自造词改义。

2. 术语越界探针持续监测文档与日志，检出术语篡改、误用，立即冻结流程并复核。

3. 勘伪定级出现术语误用引发事故，调取存证记录划分多方责任。

4. 术语误用案例入库补充释义注释；内核术语永久锁死，修改必须走联合勘伪哈希更新流程。

5. 刻意篡改术语内涵，人为压低风险等级，判定多方重大过失追责。

递归统一陷阱

术语可以在项目文档里简化改写；口头沟通可以自定义别名；注释补充等同于修改术语本体；L5定义可以通过换词弱化约束；短期不出事故就代表术语歧义无害。
