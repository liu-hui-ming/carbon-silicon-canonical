088|科研AI跨域学术造假、结论偷渡、边界膨胀治理

本文为《碳硅道统·跨域迁移治理法典》七层体系卷宗【088】。

体系基准：NT1‑NT4负迁移零号基准；三原则：创立者零特权、结论零固化、迭代零终点；机制：全员勘伪开放、全域反例准入、全维迭代重启。

体系坐标

接续087|科研仿真知识迁移现实世界：理想化前提偷渡决策风险（NT3）。

087完成科研仿真理想化假设偷渡的治理规范。本篇聚焦科研AI跨域复用衍生风险：源域有限数据集训练得到的AI结论，未经外推性校验，跨场景扩大适用边界，隐性偷渡局部结论，催生学术造假、夸大推论，属于NT3静默负迁移。复用082三维风险定级模型、081锁档术语、075–087权责基线，搭建科研AI迁出前置推论边界审计、结论膨胀动态探针监测、造假溯源勘伪至权责确权的精简治理规范。

概念边界

• 科研AI源域模型：基于限定样本、窄范围实验条件训练，结论仅在源域数据集内成立。

• 科研AI跨域边界膨胀：将窄域实验结论不经外推验证，直接迁移至更大研究范围、其他学科场景，人为扩大结论适用边界。

• 结论偷渡：源域模型局限、样本偏差未显性标注，局部结论被直接当作普适规律引用，形成隐性学术失真，衍生学术造假风险。

• 治理规范：模型迁出前置推论边界审计、运行期边界膨胀监测、失真阻断、取证勘伪、反例入库，嵌入科研AI成果发布流水线。

定义

本卷宗构建科研AI跨域迁移结论偷渡与边界膨胀判定框架；部署推论边界专项探针，联动三维风险定级模型，确立学术失真事故取证、勘伪、权责划分规则；形成可机读、可审计、可勘伪的科研AI跨域引用基线规范。

基线入库三准则

1. 继承前置卷宗基线，复用资产血统SHA256、铜脉报文体系、四级过失、证据分级、基线锁档、锁档术语、三维风险定级模型，术语与081锁档词典对齐。

2. 拆解模型迁出审批、源域结论边界核验、跨域外推校验、运行监测、结论膨胀显现、取证勘伪、反例入库链路；捕获仅看模型指标、忽略样本域局限、缺失外推测试等风险，挂载NT1-NT4标签。

3. 失真判定规则可证伪；任何人可提交边界膨胀场景反例，经079反例校准流程更新阈值，不改动法典底层公理与NT1-NT4零号基准。

一、标杆场景原生风险识别（套用082三维定级模型）

场景简述：科研AI在小样本限定实验数据集上获得良好指标；团队直接将结论推广至全域场景，未做域外验证，论文夸大结论普适性，造成学术结论失真。

三维指标逐项评估：

1. 可逆性：部分可逆。模型权重可回滚，但失真结论公开传播造成的学术公信力损害不可逆。

2. 影响范围：全域跨主体，覆盖科研共同体、期刊、产业应用方，具备学术链条传导风险。

3. 自主权限：受限自主。论文撤稿、结论更正需要期刊、科研机构多方协同，模型研发团队无法单方面撤销传播结论。

三维综合判定：三级（高风险）。

按照082规范：三级风险禁止自动跨域迁移，必须人工专项勘伪审计，审批后方可小范围试运行，预置硬熔断开关。

本场景四类负迁移机理

• NT1错配：源域AI结论绑定窄样本边界；目标域样本分布、实验条件完全不同，两者适用空间天然错位。

• NT2语义漂移：将“源域实验有效”等同于“普遍成立”，混淆局部实验结论与普适科学规律边界。

• NT3静默负迁移：模型在源域指标优异，无报错；边界膨胀隐性发生，论文文本不标注局限，同行复核初期难以识别外推失效。

• NT4系统性迁移失效：模型表征空间只适配源域样本，单纯微调输出无法消除样本域偏差，持续输出夸大推论。

二、五大元层自勘基线

1. 迁出前置推论边界勘伪基线

科研AI成果向外跨域推广前强制执行三维风险定级与推论边界专项审计，生成结论边界评估快照并入资产血统。三级高风险场景，必须提交源域样本边界清单、域外泛化测试报告、边界膨胀阻断方案、铜脉推论探针部署方案；审计不通过禁止跨域推广。审计文档引用081锁档术语与082全域定级总表，并标注基线哈希。

2. 试运行全链路推论边界动态监测基线

部署推论边界专项探针持续监测：源域样本边界残留探针、结论外推偏差探针、适用范围膨胀探针。当检测域外预测偏差高于阈值，触发078动态权责适配流程，冻结结论跨域引用权限，启动边界失真重校验。

铜脉科研信号持续采集，一旦检出NT3静默结论偷渡特征，触发分级熔断。

域外泛化偏差告警阈值：域外样本预测偏差高于11%，强制暂停迁移任务。初始值，经反例校准收敛。

3. 结论偷渡事故勘伪与权责确权基线

一旦发生结论偷渡、边界膨胀引发学术失真事件，启用077取证规范采集一级证据：资产血统链、成果推广审批记录、推论边界审计原始清单、探针时序数据、模型快照。

按075~087权责基线拆分责任：

• 源域研发方：未显性披露模型样本局限与结论适用边界，未标注跨域外推风险，承担兜底责任。

• 迁移推广方：三级高风险场景，省略推论边界审计，夸大结论适用范围，承担主要过失责任。

• 迁移平台方：流水线未嵌入推论边界探针校验关卡，允许带边界局限的科研AI结论跨域扩散，平台免责边界失效。

4. 边界膨胀场景反例入库校准基线

本标杆案例可复现，证据齐全判定为真反例，纳入079反例库。仅对科研AI跨域推广场景的前置审计、探针阈值做局部校准，底层公理、NT基准不变。新版本基线仅适用于新项目，不回溯推翻本次勘伪结论。

5. 法典统一量化阈值

窄样本科研AI模型向更广研究领域、产业场景外推，默认定级三级高风险，不可自动降为二级。

试运行阶段域外验证样本上限：不超过目标域样本总量5%；任何扩界推广必须重新触发场景变更重校验。

6. 勘伪存证核验

推论边界风险快照、泛化审计报告、探针时序日志、勘伪报告、反例记录全部SHA256哈希归档，纳入077证据体系，开放反例迭代。

三、四类专属探测探针（适配本科研AI边界膨胀场景）

1. 源域样本边界残留探针：核验模型对源域样本依赖程度，通过分布外OOD样本测试，量化源域样本分布带来的结论偏移。

2. 结论外推偏差探针：监测结论向外域推广后的预测误差，采用域外分层抽样测试，计算源域、目标域性能落差量化外推失效程度。

3. 适用范围膨胀探针：核查文档、论文中结论描述扩张程度，使用文本语义比对，对比原始边界声明与对外表述的语义偏移量。

4. 扩界旁路探针：监控绕过推论边界审计私自扩大结论适用范围，含流量突变检测，覆盖人为故意旁路与配置错误两类场景。

四、NT1-NT4因果闭环

NT1错配：科研AI结论受源域样本约束，目标域分布发生偏移，两套样本空间天然冲突。

NT2语义漂移：科研推广方混淆局部实验结论与普适规律，刻意模糊适用边界。

NT3静默负迁移：源域指标完美，边界隐藏在论文描述内，短期同行审阅难以察觉失真。

NT4迁移：缺少科研AI跨域外推治理规范，流水线缺失边界校验；学术失真爆发后，各方对失真根源、责任划分产生勘伪争议。

因果链：源域窄样本约束与目标域开放场景天然错配→项目方省略域外泛化审计，人为放大结论适用范围→NT3结论偷渡隐性进入学术传播链路，源域指标无异常→NT4缺少科研推论边界风控基线，事前校验缺失，事后勘伪口径冲突。

五、落地场景精简版

1. 合规科研AI外推：前置三维定级判定三级高风险，推论边界专项勘伪审计，小范围域外验证，边界探针持续监测。

2. 监测触发重校验：域外泛化偏差超标，冻结跨域引用权限，启动动态权责重评估。

3. 结论偷渡边界膨胀爆发：采集一级证据，依据权责基线拆分多方责任。

4. 真反例入库校准：案例可复现，纳入反例库，微调科研AI跨域推广审计边界。

5. 违规直接扩界：跳过三级推论边界审计直接对外推广，勘伪判定多方过失追责。

六、递归陷阱

源域指标达标即结论普适；论文简单标注样本局限就可无限外推；少量域外样本验证足够证明结论通用；短期同行评审无异议即不存在边界膨胀；仅校验模型精度，无需核查结论文本边界。
