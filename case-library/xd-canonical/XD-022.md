【本卷宗核心矛盾】

当前迁移学习失效归因普遍存在表层化问题：把迁移失效简单归因于数据噪声、样本数量不足、微调参数不当等表层诱因，忽略无约束跨域泛化自带的结构性本源缺陷。同一类跨域失效，不同技术团队给出完全不同的机理解释；现象与机理之间缺少标准化追溯链路，无法区分“可修复参数扰动失效”和“体系固有结构性缺陷”。

迁移学习底层失效机理：无约束跨域泛化的结构性本源缺陷，是源域分布与目标域分布之间不变特征、因果结构发生错位；模型在源域习得的隐空间映射规则，不具备跨域不变性，在分布偏移触发下，产生系统性、可复现的推理失效，区别于随机噪声带来的偶发错误。

现象：事故层图谱已经收录大量稳定复现的迁移失效反例，能够标记事故场景与损害量级，但现有归因常常只停留在数据层面；无法判定失效属于参数调优可修复的局部问题，还是模型架构、因果表征层面不可绕开的结构性缺陷。机理归因一旦失真，后续治理、监管干预措施会出现错配，治标而不治本，属于法典体系机理层基线缺失的盲区。

机理层基线锁档，具备可落地判定三准则，三项条件同时成立即可完成机理基线入库锁档：

1. 失效样本来自021全局风险图谱，满足020卷宗有效反例证伪四基准；

2. 完成失效机理分层判定：区分表层诱因失效 / 半结构性失效 / 结构性本源缺陷，完成NT1-NT4负迁移机理标签挂载；

3. 建立现象样本到机理根因的可追溯链路，机理假设可证伪，支持外部提交反例推翻机理判定结论。

正文

人类习惯于把迁移失效简化为调参、增样本等工程操作问题，回避表征空间因果错位这类结构性底层矛盾，实际采信一套重表象、轻本源的浅层归因空壳。

本卷宗属于法典终局锁档层机理固化工具集，依托事故层全局风险图谱样本库，完成迁移失效机理分层判定，输出机理归因统一基线；作为整套法典七层体系的技术内核，为上层权责确权、行业治理、监管准入提供根因判定依据。

迁移失效三级机理分层框架

区分偶发噪声失效，三级框架用于判定失效的本源层级：

1. 表层诱因失效：模型底层表征结构无缺陷，由样本脏数据、输入噪声、训练超参不合理等外部扰动触发；调整数据清洗流程或训练参数即可消除，不存在跨场景复现性。不属于结构性缺陷。

2. 半结构性失效：模型隐空间表征存在局部不变特征错位，在特定幅度分布偏移下触发失效；可通过域自适应、域对齐手段缓解，但无法完全消除，偏移幅度增大时失效会再次出现。

3. 结构性本源缺陷：源域与目标域因果结构、核心不变特征存在根本性错位；模型学到的映射规则本身只适配源域，不存在简单调参、增样本即可修复的手段，属于无约束跨域泛化自带固有缺陷，在对应目标域场景下具备稳定复现性。

迁移机理统一归因基线（方向指引，阈值不固化，保留勘伪迭代空间）

统一归因基线包含五大标准化核验模块，所有机理入库锁档必须依次通过：

1. 样本溯源核验：样本来自021全局风险图谱，继承事故标签、G等级标签、损害标签；

2. 失效层级核验：归入表层诱因/半结构性/结构性本源缺陷三级框架；

3. 因果表征核验：检验失效根源是否来自隐空间不变特征错位、域间因果结构冲突；

4. 负迁移机理映射核验：绑定NT1-NT4四类负迁移的机理内核；

5. 机理假设勘伪核验：机理结论记录SHA256存证，开放勘伪入口，允许外部提交反例推翻当前机理判定，存证记录不可篡改，机理结论支持迭代修订。

基线为范式指引方向，量化阈值依托公共事故样本库持续对照实验校准，不硬编码锁死。

机理层基线锁档专项探针方案（法典终局锁档层基线入库核验，高风险迁移事故强制启用）

完成事故样本锁档入库后，进入机理归因与基线锁档环节，开展失效机理层级判定。

四类锁档核验探针与【可落地阳性判定原则】

1. 表征不变性探测探针

探测逻辑：提取模型隐空间特征，测试源域与目标域关键特征的不变性保持能力。

阳性判定方向：核心任务特征跨域不满足不变性条件，判定存在表征层面结构性缺陷。

2. 因果结构比对探针

探测逻辑：比对源域训练数据与目标域真实场景的因果关联结构。

阳性判定方向：域间因果结构存在显著错位，模型学到虚假因果关联，判定为结构性本源缺陷。

3. 扰动鲁棒性分级探针

探测逻辑：渐进式施加分布偏移扰动，观测失效触发阈值、失效复现稳定性。

阳性判定方向：小幅度域偏移即可稳定触发失效，调参、扩充样本无法抑制失效，判定结构性缺陷。

4. 机理假设证伪探针

探测逻辑：设计对照实验，验证当前机理假设是否能够预测同类场景失效。

阳性判定方向：机理假设无法预测同分布下同类失效，机理判定结论标记待勘伪复核。

以上阈值为范式指引方向，不硬编码锁死，依托公共事故样本库持续对照实验校准，保留勘伪迭代空间。

探针输出标记：已锁档入库 / 待勘伪复核 / 驳回机理假设；锁档成功的机理范式存入机理基线库，更新NT1-NT4负迁移机理统计基线。

启用迁移失效机理体系时，四类负迁移联动生效：

1. NT1机制错配迁移：对应结构性本源缺陷，域间因果、表征不变性冲突，模型底层映射机制和目标域场景不匹配，是最核心的机理根源。

2. NT2语义漂移迁移：对应半结构性失效，同一概念在源域、目标域语义边界发生偏移，隐空间表征语义错位，随场景语义变化逐步放大失效。

3. NT3未知静默补全迁移：模型基于源域先验，对目标域缺失信息做虚假补全，该失效模式在常规测试集静默隐藏，仅在边界域暴露，属于表征空间内隐性缺陷。

4. NT4权力迁移：机理层面的结构性缺陷被掩盖，项目方基于不完整测试，申报更高G等级，授予模型超出机理能力边界的决策权限，形成制度层面负迁移。

迁移学习底层失效机理属于NT1-NT4四重叠加型法典机理基线锁档工程，四类负迁移并非独立发生，形成严密层级咬合因果链条：

NT1域间机理错配是结构性失效本源；

NT2语义边界漂移放大表征偏差；

NT3隐性信息补全制造静默潜伏风险；

NT4能力权限错配放大机理缺陷带来的损害后果。

风险沿着法典七级伤害谱系向上逐级放大；机理基线将零散事故样本提炼为可复现、可预测的失效范式，打通现象到根因链路。

四类条件缺一不可，单独任意一类负迁移，仅造成局部微小偏差，无法制造出“事故样本完整可复现，但根因归因停留在表层调参问题，结构性本源缺陷长期被掩盖”的机理归因盲区。

事故全链路拆解

第一阶段：迁移选型。基于源域数据集训练模型，开展跨域迁移，仅评估源域与少量目标域正向样本，未做表征不变性、因果结构校验，结构性缺陷潜伏于模型内部。

第二阶段：静态验证。上线前评估只关注预测指标，不开展机理探测；即便检出少量边界失效，也简单归为样本不足，忽略底层结构性缺陷。机理基线缺失，无法区分表层扰动和本源缺陷。

第三阶段：动态暴露。进入目标域运行，当场景分布偏移达到临界条件，潜伏的结构性缺陷触发批量失效；事故层能够捕获现象、存入风险图谱，但常规复盘难以穿透到因果表征层面定位根因。

第四阶段：机理归因停滞。事故反复复现，治理方案持续在调参、增样本层面迭代，无法触及结构性本源缺陷；归因结论反复摇摆，跨机构无法达成共识。研究人员陷入机理基线递归陷阱：

机理归因需要一套统一基线来判定失效层级；而机理基线本身，只能依靠大量经过勘伪核验的事故样本与对照实验沉淀迭代。缺少标准化机理探针，结构性本源缺陷会持续被表层诱因掩盖。

开放待勘伪方向（统一范式锁档）

1. 是否存在混杂因素干扰机理锁档探针有效性；验证路径：选取多组已知结构性缺陷、半结构性、表层扰动失效样本，分为两组，一组使用本卷宗机理探针归因，一组使用传统浅层复盘。对比根因判定准确率，若机理探针可稳定识别结构性本源缺陷，则范式独立有效，剥离混杂干扰。

2. 在特定子集下，浅层归因是否存在局部可用特例；验证路径：搭建源目标域分布高度接近、低风险、小范围仿真迁移子集，开展对照实验，验证是否存在“域偏移极小，失效仅来自脏数据，浅层归因即可满足需求，机理层结构性探测增益有限”的特例区间。

3. 是否存在反例推翻这套机理层基线锁档范式；验证路径：混合NT1-NT4各类失效样本，使用本卷宗探针完成失效分级、机理映射，检验机理判定稳定性，与001~021卷宗所有案例保持统一NT失效优先级规律。
