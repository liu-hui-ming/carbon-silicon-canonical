074|【道统工程规范】铜脉接口：字段结构、握手协议、拦截拒绝熔断机制

本文为《碳硅道统·跨域迁移治理法典》七层体系卷宗【074】。

体系基准：NT1‑NT4负迁移零号基准；三原则：创立者零特权、结论零固化、迭代零终点；机制：全员勘伪开放、全域反例准入、全维迭代重启。

体系坐标

接续073铜脉接口风险信号标准化翻译协议，从语义层规范下沉至工程层落地规范。073解决风险信号翻译、版本锁定、语义可回溯；本篇074定义铜脉接口底层通信握手、报文强制字段、异常拦截、拒绝策略与分级熔断触发机制，明确接口连接建立、心跳保活、报文校验、异常断开全流程工程规则。

解决工程落地痛点：异构系统对接时握手无标准、报文字段缺失无统一拒绝逻辑、异常流量/篡改报文处理规则不一致；避免因接口通信层面缺陷，破坏上层风险信号证据链、血统哈希、映射版本锁等勘伪基线。

概念边界

• 铜脉接口握手协议：接入方与铜脉中继节点建立通信会话的标准化流程，包含身份核验、版本协商、能力宣告、会话保活、会话销毁。

• 铜脉报文字段结构：区分强制核心字段、可选扩展字段、审计留痕字段；核心字段缺失直接触发报文拒绝。

• 拦截拒绝机制：报文校验失败时的分级处置策略，分为报文拒收、会话临时限流、会话强制断开三档。

• 铜脉熔断机制：接口侧识别批量异常报文、信号篡改攻击、版本不兼容风暴时，触发接口本地熔断，隔离故障接入端，防止异常流量污染全域风险信号池。

• 会话存证：每一次握手建立、心跳、报文收发、会话销毁，全部生成会话日志，绑定会话唯一哈希，纳入勘伪归档。

定义

本卷宗为铜脉接口工程落地规范，建立标准化报文字段结构、四阶段握手协议、分级拦截拒绝策略、接口侧分级熔断整套工程机制；联动073语义版本锁、中继签名规则、可信度权重基线，实现铜脉接口通信过程可校验、可拦截、可熔断、可审计，保障风险信号跨域传输链路的工程可信。

基线入库三准则

1. 继承全部前置卷宗基线，复用血统SHA256、映射版本锁定、中继签名、四级过失、分级熔断体系，术语、阈值、责任判定完全对齐。

2. 拆解会话握手、报文传输、报文校验、异常拦截、熔断隔离、会话销毁全通信链路，捕获身份伪造、字段缺失、报文篡改、版本不兼容、批量异常攻击节点，挂载NT1-NT4标签。

3. 建立铜脉接口工程勘伪范式，协议可机读、可代码实现、可自动化仿真测试。

一、铜脉接口报文字段结构规范

1）强制核心字段（缺失直接拒收报文，不可降级处理）

1. copper_msg_id：铜脉报文唯一ID（UUID）

2. session_hash：当前通信会话哈希值

3. asset_sha256：资产血统SHA256哈希

4. map_version：语义映射表版本号（继承073版本锁）

5. signal_source：信号来源主体与探针类型

6. raw_evidence_ref：原始证据索引

7. nt_class：NT1/NT2/NT3/NT4负迁移分类

8. fault_level：过失等级（一级~四级）

9. fuse_suggest：熔断建议等级

10. confidence：信号可信度权重0~1.0

11. relay_signature：中继节点签名

12. msg_timestamp：报文生成UTC时间戳

2）可选扩展字段（缺失不拒收，标记在审计日志）

• custom_metadata：业务侧自定义元信息

• trace_chain：跨系统追踪链ID

• remark：人工勘伪备注

3）审计留痕字段（由铜脉中继自动填充，接入方不可写入）

• receive_timestamp：中继接收时间

• check_result：报文校验结果

• reject_reason：拒收原因（校验失败时填充）

• relay_node_id：中继节点编号

硬约束：强制核心字段不可删减、不可置空；扩展字段不得覆盖、篡改核心字段内容。

二、铜脉四阶段握手协议

1. 身份宣告阶段：接入端发起Hello报文，携带接入主体ID、公钥、支持的铜脉协议版本号、能力清单（是否支持中继签名、版本锁、可信度字段）。

2. 版本与能力协商阶段：中继校验接入主体备案信息；协商双方共同支持的最高协议版本；若版本不兼容，直接返回拒绝，会话终止。

3. 会话建立阶段：双方协商会话密钥，生成session_hash会话指纹；返回会话成功报文，约定心跳周期（默认30s）。

4. 保活与销毁阶段：接入端定时发送心跳包；连续3次心跳超时，会话自动销毁；接入方主动发送Bye报文执行优雅关闭；异常断连自动写入审计日志。

握手全程日志归档；未完成握手的节点，禁止发送任何风险信号报文。

三、分级拦截、拒绝机制

1. 一级拦截（报文拒收）：单条报文核心字段缺失、字段格式非法、签名校验失败；单报文丢弃，写入审计日志，会话保持。

2. 二级拦截（会话限流）：同一接入端1分钟内拒收报文超过5条；触发流量限流，限制报文吞吐速率，告警记录。

3. 三级拦截（强制断连）：短时间批量篡改报文、伪造中继签名、伪造资产哈希；直接销毁当前会话，标记接入主体风险，触发审计预警。

四、铜脉接口分级熔断机制

1. 接口轻熔断（接入端隔离）：单一接入节点持续触发二级/三级拦截；切断该接入方会话，其余接入节点通信不受影响。等待接入方完成整改审计后方可重新接入。

2. 接口局部熔断（中继分片隔离）：某一中继分片出现大量异常报文、版本风暴、信号伪造；隔离该中继分片，其余中继节点正常工作。

3. 接口全域熔断（全局停服）：多中继节点同时遭受大规模信号篡改攻击；全域暂停铜脉信号转发，仅保留审计存证写入，人工介入勘伪。

约束：铜脉接口熔断只阻断风险信号的跨域转发，不自动触发下游业务系统熔断；下游业务系统熔断决策仍由本地治理策略独立判定，防止通信层故障传导至业务层。

五、五大元层自勘基线

1. 接入握手准入基线

所有主体接入铜脉中继前必须完成备案；未备案主体握手请求直接拒绝；协议版本不兼容直接终止会话。

2. 报文校验基线

中继收到报文，优先校验强制核心字段完整性、中继签名、资产血统哈希、映射版本号；任意核心校验失败，执行对应分级拦截策略。

3. 通信生命周期基线

完整链路：握手协商 → 心跳保活 → 报文收发校验 → 异常拦截/熔断判定 → 会话销毁 → 全链路日志归档。

4. 法典统一量化阈值

• 心跳超时阈值：连续3次心跳包丢失，会话销毁

• 一级拦截触发：单报文核心字段校验失败

• 二级拦截触发：1分钟内拒收报文≥5条

• 轻熔断触发：连续5次会话被强制断连

5. 多方权责映射

接入发送方：对报文内核心字段完整性、原始数据真实性负责；伪造报文、伪造签名，按073、072规则判定四级过失。

铜脉中继节点：负责握手校验、报文字段校验、拦截熔断执行、会话日志存证；中继私自绕过校验放行异常报文，中继方承担主要责任。

下游接收方：校验收到报文中继签名与会话哈希；接收异常报文未上报，纳入审计记录。

元层勘伪仲裁：以完整握手会话日志、报文原始报文、校验记录作为勘伪仲裁依据；通信日志缺失，由中继运营方承担举证不能主责。

6. 勘伪存证核验

握手报文、心跳记录、全部业务报文、拦截事件、熔断事件、会话销毁记录，全部做SHA256哈希归档，永久存证，开放反例迭代。

六、四类专属探测探针

1. 握手合规探针：检测未备案接入、协议版本不兼容、伪造身份发起握手。

2. 报文字段探针：扫描报文强制核心字段缺失、格式错误、字段篡改。

3. 流量异常探针：监控短时间大量拒收报文，识别异常流量与攻击行为。

4. 熔断状态探针：持续监测中继分片、接入节点熔断隔离状态，记录熔断触发与恢复理由。

七、NT1-NT4因果闭环

NT1错配：异构系统通信协议、报文格式天然不一致，缺乏统一握手与字段规范，通信链路底层不兼容。

NT2语义漂移：工程团队简化报文字段、省略握手校验，认为只要能传输数据即可，弱化勘伪所需审计字段。

NT3静默：报文篡改、字段悄悄缺失不会触发业务报错；异常风险信号静默跨接口传输，污染下游系统。

NT4迁移：无标准化拦截熔断机制，异常报文、伪造信号可批量全域扩散；事故发生后缺少通信层完整日志，无法复现通信过程，责任判定困难。

因果链：异构系统通信底层协议天然不统一→工程侧为简化对接省略握手校验、删减强制字段→NT3篡改/残缺报文静默通过接口扩散→NT4无分级熔断隔离机制，伪造信号全域传播，事故后缺少通信审计证据。

八、落地场景精简版

1. 合规通信：握手备案成功、协议版本匹配、报文核心字段完整、签名校验通过、心跳正常，风险信号可正常跨域转发。

2. 一级过失：少量扩展字段缺失，核心字段完整；无信号失真，补齐扩展字段归档即可。

3. 二级过失：频繁缺失非核心审计字段，短时间少量报文拒收；整改报文模板，限制接口调用配额。

4. 三级过失：刻意删减核心字段，绕过报文校验，批量发送不合规报文；触发接口轻熔断，接入主体承担主要责任。

5. 四级过失：伪造握手身份、伪造中继签名，批量注入伪造风险信号；触发局部/全域熔断，接入方全责追责。

九、递归陷阱

为对接简便，省略握手备案、跳过报文核心字段校验；心跳保活机制关闭，会话无生命周期管理；熔断触发后自动恢复而不留审计记录；将铜脉接口熔断等同于下游业务熔断；扩展字段覆盖核心字段。

十、十一层递归盲区（精简对齐法典格式）

014元层残缺｜无法区分风险来自握手伪造、核心字段缺失、报文篡改、接口熔断失效

015证据自指｜报文传输成功，无法自证握手合规、核心字段完整、签名校验通过

016时序残缺｜长期迭代，接入方逐步简化报文，悄悄删减强制核心字段

017观测残缺｜残缺、伪造报文不会触发业务报错，NT3隐性伪造信号静默流转

018契约残缺｜缺少握手备案、核心字段强制保留、分级拦截熔断硬性工程条款

019认知残缺｜低估通信层漏洞对上层勘伪证据链的破坏，误以为能传输即可信

020证伪残缺｜缺少握手伪造、报文篡改引发跨域风险信号污染的事故反例库

022机理残缺｜接口通信层面缺陷导致负迁移证据链失效的根因判定缺失

023权责残缺｜接入方、中继运营方在握手、报文校验、熔断处置中的责任边界模糊

025监管残缺｜缺少铜脉会话审计、报文校验、分级熔断触发判定标准

027终局残缺｜终局勘伪必须核验握手日志、原始报文、签名校验记录、熔断事件归档
