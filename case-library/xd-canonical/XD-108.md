108｜【层基线锁档】全行业统一迁移安全基线定型（精简精髓定稿）

本文为《碳硅道统·跨域迁移治理法典》七层体系卷宗【108】永世终稿。

体系基准：NT1‑NT4负迁移零号基准

三原则：创立者零特权、结论零固化、迭代零终点

机制：全员勘伪开放、全域反例准入、全维迭代重启

体系坐标

接续卷宗107《行业迁移规则全部例外场景反例校准》。卷宗106确立五级风险分层主框架、卷宗107搭建例外反例校准机制；本篇完成整套法典底层安全基线锁档定型，固化全行业通用勘伪基准、资产血统基线、探针基线、存证基线，作为所有跨域迁移项目、五级定级、例外勘伪的底层参照原点。基线定型后，新增场景、反例仅允许做规则注释迭代，基线本体不可随意篡改，修改必须经过多主体联合勘伪终审并更新全局哈希锁档。

核心定义

• 迁移安全基线：由特征基线、资产血统基线、勘伪判据基线、探针阈值基线、存证溯源基线共同构成的静态基准集合，作为衡量AI跨域迁移是否产生NT系列负迁移的唯一参照标尺。

• 层基线锁档：对整套安全基线执行SHA256哈希固化锁存；基线发生变更必须走完整勘伪、投票、更新哈希流程，任何单方无权私自修改基线参数。

• 基线迭代边界：场景反例、行业细则可追加注释文档；NT1-NT4底层定义、L5零在线零联网铁律属于基线内核，永久锁死，不可迭代修改。

五大锁档基线定型

基线一：资产血统基线（全局溯源基准）

所有参与跨域迁移的模型、权重、数据集、推理会话必须建立不可截断资产血统链路。

血统要素：源域创建时间、训练数据分布快照、权重基线哈希、历次微调记录、跨域流转审批记录、探针时序日志、勘伪报告。

任何模型缺失资产血统，默认禁止一切跨域复用。

基线二：NT负迁移判定基线（根因勘伪基准）

NT1：样本空间轻度分布错配，仅产生局部经济性偏差，无隐性特征偷渡。

NT2：认知范式漂移，业务逻辑系统性偏离，偏差显性可控。

NT3：隐性先验、特征静默偷渡，模型输出表象正常，隐患潜伏累积，可诱发民生、公共安全事故。

NT4：跨域特征不可逆污染，涉密体系、国家安全基底遭到侵蚀，损害无法清除。

内核永久锁档，不接受任何场景下对NT定义的删减、放宽。

基线三：L1-L5五级风险定级阈值基线（准入基准）

L1（NT1低风险）：偏差容忍≤10%，标准审计，可全量上线，完全可逆。

L2（NT2中风险）：偏差容忍≤5%，完整基线审计，限定业务范围上线，完全可逆。

L3（NT3高风险）：偏差容忍≤1%，强制人工勘伪终审，小范围点位试点，局部可逆。

L4（NT3+重大风险）：偏差容忍≤0.1%，极小受控试点，内置硬熔断，禁止规模化落地，大多不可逆。

L5（NT4极危风险）：零容忍，零在线、零联网、零数据回流、零试运行、零跨域参数交互；仅允许物理断网离线沙箱静态核验；无任何例外通道，损害永久不可逆。

基线四：全域探针部署基线（动态监测基准）

四类通用探针强制配置：源域特征残留探针、风险等级漂移探针、链式传导探针、审计旁路探针。

例外场景额外挂载：例外边界越界探针。

探针采集时序数据纳入资产血统，探针禁用、关闭必须触发高危审计告警。

基线五：全链路存证基线（取证勘伪基准）

所有审批、审计、探针时序、勘伪文档、反例记录执行SHA256哈希归档。

L4、L5场景强制启用多主体联合存证。存证档案长期归档，作为事故勘伪、权责确权原始证据。

基线变更管控刚性流程

1. 基线变更提案：提交完整反例证据、风险推演报告，明确变更范围，区分「注释增补」与「基线内核修改」。

2. 多主体联合勘伪：至少三方独立勘伪复核；内核修改需全员勘伪终审。

3. 投票与锁档：提案通过后，重新计算整套基线新SHA256哈希，更新全局锁档标记；旧基线哈希永久归档留存。

4. 回滚机制：新版基线出现系统性缺陷，可依据归档哈希回退至上一锁档版本。

NT内核、L5铁律不接受任何变更提案。

五大元层自勘基线

1. 基线前置一致性勘伪基线

任意跨域项目启动前，校验项目审计规则、探针阈值、定级判据与本套锁档基线保持一致；校验不通过，禁止启动五级定级与跨域评估。生成基线一致性校验快照，纳入资产血统。

2. 基线动态一致性监测基线

部署基线偏移探针，持续比对现场勘伪规则、阈值参数与锁档基线是否发生偏离；一旦检出私自篡改基线参数，立即触发全局告警，冻结相关跨域任务，启动勘伪。

3. 基线偏差事故勘伪与权责确权基线

事故勘伪第一步，核验现场是否遵循锁档基线执行。

• 基线本身合规：责任由模型方、部署方、运维方按卷宗106权责规则划分。

• 私自篡改基线、放宽阈值：篡改主体承担首要重大过失责任。

4. 基线迭代反例入库校准基线

反例仅用于生成基线注释、补充行业细则；反例不得直接改写基线内核。注释文档单独哈希归档，与基线本体分离。

5. 基线永久存证锁档基线

基线本体、历次版本哈希、变更勘伪报告全部永久归档，纳入077证据体系。基线主哈希对外公开，作为法典全局校验锚点。

五类核心探测探针

1. 基线偏移探针：比对现场勘伪阈值、NT判定规则与锁档基线的偏离程度。

2. 源域特征残留探针：量化隐性先验、特征范式残留权重占比。

3. 风险等级漂移探针：监测运行阶段风险等级向上漂移概率。

4. 链式传导探针：测算单点偏差向外扩散放大系数。

5. 审计旁路探针：监控私自修改基线参数、关闭探针、绕开基线校验的操作。

NT1-NT4因果闭环

NT1：场景天然分布差异，需要统一基准量化偏差。

NT2：不同团队使用自定义判定标准，定级口径混乱。

NT3：基线不锁档，人为随意放宽阈值，隐性偷渡隐患被掩盖。

NT4：底层判定规则无固化锚点，高危场景人为修改基线内核，触发不可逆NT4污染。

终极因果链

跨域治理缺少统一基准 → 各方自定义规则，口径不一 → 基线可随意篡改，NT3隐患被掩盖 → 高危场景修改内核基线突破L5铁律 → 事故爆发后勘伪缺少统一标尺，权责无法判定。

落地场景精简版

1. 所有跨域迁移项目，必须对齐本套锁档基线开展定级、审计、监测。

2. 持续监测基线偏移，检出私自篡改基线参数，立刻冻结任务并启动勘伪。

3. 发生负迁移事故，优先核验基线一致性，区分基线本身缺陷或是人为篡改，划分责任。

4. 反例仅增补注释文档，基线内核永久锁死；基线变更必须走多主体勘伪与哈希更新流程。

5. 私自修改基线内核、放宽L5刚性约束，判定多方重大过失追责。

递归统一陷阱

基线可以随项目需求临时调整；注释增补等同于修改基线内核；基线锁档之后不再需要持续校验；L5规则可以通过基线变更申请放宽；仅在事故发生时才校验基线一致性。

十一层递归盲区（终版）
