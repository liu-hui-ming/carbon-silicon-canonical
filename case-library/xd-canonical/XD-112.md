112｜监管沙盒跨域适用边界与失效条件（精简精髓定稿）

本文为《碳硅道统·跨域迁移治理法典》七层体系卷宗【112】永世终稿。

体系基准：NT1‑NT4负迁移零号基准

三原则：创立者零特权、结论零固化、迭代零终点

机制：全员勘伪开放、全域反例准入、全维迭代重启

体系坐标

接续卷宗111《监管权限跨域继承风险：监管模型自身必须经过迁移审计（NT4）》。卷宗110、111完成监管主体、监管AI模型的递归勘伪约束；本篇聚焦监管沙盒这一治理工具本身，划定沙盒跨域复用刚性边界，明确沙盒何时自动失效、强制终止试验。堵死将沙盒当成永久豁免通道、跨域直接照搬沙盒结论的漏洞。沙盒结论仅在沙盒限定域内有效，不可天然跨行业、跨地域、跨风险等级继承。

核心定义

• 监管沙盒：受控隔离试验环境，在限定范围、限定时长、熔断机制完备前提下，对AI跨域迁移项目开展有限试点采集探针时序数据，用于勘伪评估，不等于项目合规许可。

• 沙盒跨域适用：将A场景沙盒试验结论、风险评估报告，直接复用至B不同源域场景，视作B场景已经通过勘伪定级。

• 沙盒失效：触发预设条件时，沙盒试验自动终止，沙盒内所有推理链路切断，沙盒结论作废，不可继续引用。

• 沙盒跨域负迁移：沙盒在源域得到的风险边界、阈值经验属于源域隐性先验，未经迁移审计直接跨域继承，产生NT系列负迁移。

NT1：源域与目标域轻微分布差异，沙盒评估结论小幅偏差，无公共损害。

NT2：沙盒范式漂移，源域沙盒经验不适配目标域业务范式，评估系统性偏离。

NT3：沙盒隐性先验偷渡，直接套用源域沙盒结论，掩盖目标域潜伏风险隐患。

NT4：高危场景直接复用沙盒结论放行L5级项目，造成不可逆体系污染。

核心公理：沙盒试验结论具备域绑定属性，不具备天然跨域可迁移性；沙盒仅为勘伪数据采集工具，不是永久豁免证书。L5极危场景不开放任何监管沙盒通道。

监管沙盒跨域适用刚性边界

1. 同源域有限复用边界

仅当源沙盒域与目标域满足：训练数据集同源、业务分布可量化对齐、风险要素清单高度重合、风险等级同为L1/L2，才可申请沙盒结论有限复用；仍需要做简化迁移勘伪核验，不能直接全盘采信。L3及以上场景不允许沙盒结论跨域复用。

2. 空间边界

沙盒试点地理范围固定，不得未经勘伪自动扩大覆盖区域；跨地域复用沙盒结论，必须重新执行五级定级与迁移审计。

3. 主体边界

沙盒授权绑定申请主体，不可转让、移交至其他主体继续使用沙盒试点权限。

4. 时间边界

沙盒设置固定有效期，到期自动失效，如需继续试点，必须重新提交勘伪复核。

5. 风险等级边界

沙盒仅可用于L1、L2、L3、L4场景受控试点；L5（NT4）永久禁止启用监管沙盒，不存在任何沙盒试点方案。

沙盒自动失效强制触发清单（不可豁免）

1. 风险等级上浮：试点过程探针检出项目风险等级向上跃迁，例如L2漂移至L3、L3上浮至L4，沙盒立即失效，切断推理链路。

2. 超出预设边界：业务范围、用户规模、推理场景、调用流量突破沙盒申请时约定上限。

3. 检出NT3及以上负迁移：探针捕获隐性先验偷渡、风险降级偷渡，出现可复现公共风险隐患。

4. 熔断机制失效：硬熔断、探针采集、资产血统存证组件出现故障，无法持续采集可审计时序证据。

5. 沙盒环境越界：沙箱内数据、特征向量、模型权重向外流出；外部数据违规回流进入沙盒。

6. 主体变更：项目主体、运维主体、勘伪复核主体发生变更，未提前提交复核备案。

7. 人为旁路：出现审计旁路操作，人为关闭探针、篡改沙盒阈值、隐瞒事故样本。

8. 有效期届满：沙盒预设试验周期到期，无论试点进度如何，自动失效。

五大元层自勘基线

1. 沙盒准入前置勘伪基线

沙盒申请前必须完成五级风险定级，核验是否落在沙盒允许范围内；L5直接驳回沙盒申请。生成沙盒边界快照纳入资产血统，写明空间、时间、规模、风险边界与失效触发条件。

2. 沙盒跨域动态监测基线

部署四类沙盒专属探针：沙盒边界越界探针、风险等级上浮探针、沙盒结论跨域复用探针、审计旁路探针。一旦触碰失效条件，自动触发硬熔断，沙盒权限即时作废，启动专项勘伪。

阈值对齐法典底层基线，L4沙盒零容忍隐性偷渡。

3. 沙盒失效事故勘伪与权责确权基线

沙盒试点期间发生负迁移事故：

• 沙盒申请方：突破沙盒边界、隐瞒风险，承担主要过失责任。

• 勘伪复核方：沙盒边界评估疏漏，承担兜底连带责任。

• 监管运维方：熔断、探针监测机制缺失，平台边界失效责任。

4. 沙盒边界失效反例入库校准基线

沙盒越界、跨域滥用、提前失效案例归入079反例库，用于沙盒申请预审拦截；反例仅补充注释细则，NT内核、L5铁律不可修改。NT4沙盒滥用案例仅归档推演，严禁任何试验复用。

5. 沙盒全生命周期存证基线

沙盒申请材料、边界快照、探针时序、勘伪报告、失效记录全部SHA256永久归档；L4沙盒启用多主体联合存证。沙盒失效后，沙盒内全部日志、样本封存，不得随意销毁。

四类专属探测探针

1. 沙盒边界越界探针：监测业务范围、调用规模、使用场景超出沙盒约定边界。

2. 风险等级上浮探针：持续监测试点过程项目风险等级向上漂移。

3. 沙盒结论跨域复用探针：识别未经勘伪，直接将源域沙盒结论套用到新目标域。

4. 审计旁路探针：监控人为关闭探针、篡改沙盒参数、隐瞒事故样本等操作。

NT1-NT4沙盒跨域负迁移因果闭环

NT1：源域与目标场景存在轻微分布差异，沙盒评估结果小幅偏差。

NT2：直接照搬源域沙盒范式评估新场景，评估体系系统性偏离真实风险。

NT3：沙盒源域隐性先验被直接跨域继承，目标域风险被低估，隐患长期潜伏。

NT4：高危场景违规启用沙盒，或者直接复用沙盒结论放行L5项目，造成不可逆体系污染。

终极因果链

将沙盒试点结论误认为通用合规背书 → 未经迁移审计直接跨域复用沙盒评估结果 → NT3隐性偷渡隐患持续累积 → 违规对L5场景启用沙盒，触发NT4体系级污染 → 事故爆发后沙盒边界、失效条件缺少固化判定依据，权责难以界定。

落地场景精简版

1. 监管沙盒为域绑定受控试验工具，沙盒结论不可天然跨行业、跨地域复用；L5场景永久禁止沙盒试点。

2. 沙盒试点预先锁死边界与失效触发条件，探针持续监测，触碰失效条件自动熔断，沙盒权限作废。

3. 沙盒试点发生负迁移事故，调取沙盒存证快照与探针时序，划分多方主体责任。

4. 沙盒越界、滥用案例纳入全域反例库，优化沙盒预审规则；内核基线永久锁死。

5. 私自扩大沙盒边界、跨域套用沙盒结论、违规为L5项目申请沙盒，判定重大过失追责。

递归统一陷阱

沙盒试点通过=项目永久合规；沙盒结论可以跨行业直接采信；沙盒有效期内可以无限扩大业务规模；沙盒内数据可以自由对外输出；L5场景可以申请特殊沙盒试点。
