029|【层基线锁档·元层自勘层】分布外输入失控：目标域天然自带的未知风险边界

本文为《碳硅道统·跨域迁移治理法典》七层体系卷宗【029】。

体系基准：NT1‑NT4负迁移零号基准；三原则：创立者零特权、结论零固化、迭代零终点；机制：全员勘伪开放、全域反例准入、全维迭代重启。

体系坐标

元层自勘补充卷宗，承接028道统核心判定公理基线，完成分布外输入风险的元层自勘基线锁档。

核心目标：厘清分布外输入失控的底层成因，识别目标域原生未知边界带来的跨域迁移失效，建立分布偏移风险审计的前置判定基准。

核心矛盾

模型在源域数据集完成训练，其有效行为边界被源域样本分布约束。当部署至目标域，天然存在大量训练未覆盖的分布外输入。这类输入并非人为构造攻击，而是目标域原生存在的客观样本。模型面对分布外样本会产生不可预测输出，常规测试集只能覆盖已知样本空间，无法穷尽目标域未知边界。工程实践常默认目标域分布与源域近似，忽略分布外原生风险，现有跨域迁移体系缺少目标域天然未知边界的统一判定基线。

定义：分布外输入失控

模型从源域迁移至目标域后，遭遇目标域原生存在、未纳入源域训练分布的输入样本，引发表征空间失稳，输出偏离预期，属于目标域边界带来的原生负迁移失效。

基线入库三准则

1. 风险样本继承021风险图谱至028元层公理全部基线，全链路可追溯。

2. 拆解源域-目标域分布偏移链路，定位分布外触发节点，完成风险等级量化，挂载NT1-NT4标签。

3. 建立分布边界评估模型，产出可审计、可复核、可证伪的元层自勘规范。

一、分布外输入失控三级分级框架

轻度失控：少量分布外输入出现局部输出偏差，不影响主任务执行，错误可快速识别过滤。

中度失控：目标域多场景持续出现分布外样本，输出偏差具备一定规律性，会干扰业务判断。

重度失控：目标域大范围分布外输入触发系统性输出紊乱，业务逻辑失效，人工甄别成本极高。

二、五大元层自勘入库基线

1. 分布边界溯源核验：比对源域训练集与目标域真实样本，定位分布差异区域。

2. 表征偏移核验：量化输入样本在模型表征空间偏离源域核心分布的距离。

3. 分布外风险量化核验

度量指标：分布外样本占比、表征偏移距离、任务输出错误率。

参考示意阈值（非固化，仅复核锚点）

分布外样本占比＜5%：轻度失控

占比5%~20%，输出错误可复现：中度失控

占比＞20%，引发系统性任务失效：重度失控

4. 工程主体权责映射核验

区分模型训练方、部署实施方、运维监测方。工业控制、医疗诊断等高可靠场景强制开展目标域分布普查；通用场景需明确标注分布边界局限，划定业务使用范围。

5. 元层勘伪存证核验

全部分布采样数据、表征测算记录执行SHA256存证，允许外部提交对照实验推翻风险等级判定，勘伪规则持续迭代更新。

三、四类专项探测探针（技术探测，与自勘基线解耦）

1. 分布距离探测探针：测算输入样本相对源域分布的偏移程度。

2. 跨域传导探针：测试分布外样本带来的输出偏差是否扩散至后续推理。

3. 场景边界适配探针：匹配业务场景，动态调整分布外风险定级。

4. 元层推理证伪探针：检验现有迁移方案是否低估目标域原生分布外风险，补齐评估盲区。

探针输出标记：已锁档入库 / 待勘伪复核 / 驳回治理假设

四、NT1‑NT4因果闭环

NT1机制错配：源域与目标域的数据分布天然存在异构，目标域存在源域无法覆盖的样本空间，是分布外失控的底层根源。

NT2语义漂移：分布外输入持续牵引模型表征，逐步偏离源域习得的稳定映射关系。

NT3静默补全：模型无法识别自身认知边界，强行对未知样本生成通顺但错误的输出，掩盖认知失效。

NT4权力迁移：工程团队将模型部署至未充分评估分布边界的目标域，采信模型错误输出开展业务决策，触发跨域迁移事故。

因果链：NT1存在域分布异构空间 → NT2输入牵引表征偏移 → NT3模型强行生成无效输出 → NT4业务采信造成损失

五、最小落地演示（工业视觉质检场景）

链路：源域标准样本训练 → 目标域出现异形工件分布外输入 → 识别判断失效

轻度失控：少量异形工件识别出现微小偏差，人工复核可快速筛除。

中度失控：多种非常规工件持续出现识别错误，干扰质检判定流程。

重度失控：大量目标域原生非标工件引发大面积误判，质检体系失去效用。

基线价值：在中度失控阶段触发边界告警，补充目标域样本或限制模型适用范围。

六、事故链路与递归陷阱

训练阶段：模型在源域标准样本中学习映射关系。

静态潜伏：源域测试集表现良好，目标域潜在分布外风险无法被发现。

动态失效：上线后遭遇目标域原生分布外样本，模型输出失控。

自勘停滞：迁移评估大多只验证源域测试集，缺少目标域天然未知边界评估基线。

元层自勘基线递归陷阱

分布外风险评估需要分级判定标准；但标准只能依靠大量勘伪后的目标域样本迭代沉淀。缺少探针体系，目标域原生未知边界风险会长期隐藏在跨域迁移项目之中。
