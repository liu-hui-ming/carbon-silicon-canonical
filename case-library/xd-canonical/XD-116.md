116｜跨域迁移事故强制上报机制与时限标准（精简精髓定稿）

本文为《碳硅道统·跨域迁移治理法典》七层体系卷宗【116】永世终稿。

体系基准：NT1‑NT4负迁移零号基准

三原则：创立者零特权、结论零固化、迭代零终点

机制：全员勘伪开放、全域反例准入、全维迭代重启

体系坐标

接续卷宗115《监管科技（RegTech）迁移场景专用工具集规范》。卷宗115完成RegTech勘伪工具集工程规范；本篇构建跨域迁移事故分级强制上报体系，定义事故判定口径、分级上报时限、上报要件、漏报瞒报的勘伪追责规则。消除“事故自行消化、隐性事故不上报、上报口径不一”的盲区，事故样本统一汇入079反例库，作为整套法典迭代更新的事实基底。

核心定义

• 跨域迁移事故：AI知识包、模型、监管自动化组件发生跨域复用，触发NT系列负迁移，造成可量化损害、公共风险、系统性判定偏差的事件。

• 强制上报：达到阈值的跨域迁移事故，责任主体不享有自主不报选择权，必须在规定时限提交标准化事故卷宗，纳入监管与元勘伪存证链路。

• 事故上报负迁移：事故上报环节本身出现NT类失效，掩盖真实风险。

NT1：低风险事件上报存在小幅延迟，无实质损害，仅流程瑕疵。

NT2：上报范式漂移，上报材料只罗列表象，不按照法典标准化卷宗格式填报，信息系统性缺失。

NT3：隐性瞒报偷渡，隐匿事故样本、压缩损害范围，风险隐患持续潜伏。

NT4：系统性掩盖重大事故，批量隐瞒L4/L5级负迁移事件，造成治理体系基准失真，不可逆体系污染。

核心公理：事故损害大小不改变上报义务；时限刚性不可随意延长；上报材料必须附带资产血统快照与原始探针时序；瞒报、迟报、伪报单独追责，独立于事故本身责任。

事故分级与强制上报时限标准

L1｜NT1低风险迁移事故

风险特征：轻微分布偏移，仅产生经济损失，无公共安全、人身与社会影响。

上报规则：7个自然日内完成备案上报；提交简化事故卷宗，基础资产血统摘要、探针简要记录。

约束：一旦复核发现实际风险等级高于L1，自动升级上报级别，启动专项勘伪。

L2｜NT2中风险迁移事故

风险特征：范式漂移，业务判定系统性偏差，有限范围影响，无链式扩散能力。

上报规则：3个自然日内完成上报；提交完整基线审计记录、资产血统卷宗、事故复现步骤。

约束：上报后持续更新事态进展，直至风险闭环。

L3｜NT3高风险迁移事故

风险特征：隐性先验偷渡，可造成民生、公共服务误判，具备局部扩散潜力。

上报规则：24小时内上报；完整勘伪报告、全量探针时序、资产血统快照同步提交。

约束：持续滚动报送事态演化、熔断处置、样本新增情况，直至风险终止。

L4｜NT3+重大迁移事故

风险特征：链式传导风险，可引发区域性公共事件，批量产生错误判定。

上报规则：4小时内紧急上报；多方联合勘伪介入，全量原始探针数据、模型/知识包哈希快照同步封存提交。

约束：实时报送处置进展，元勘伪自动启动并行复核。

L5｜NT4极危迁移事故

风险特征：不可逆体系污染，触及国家安全、治理基底破坏。

上报规则：即时上报（1小时内）；立即切断跨域推理链路，同步封存全部资产与日志，元勘伪委员会自动触发最高等级复核。

约束：任何延迟上报行为直接触发最高等级追责，无豁免通道。

事故上报标准化卷宗要件

1. 事故基础元信息：发生时间、部署域、跨域来源、项目五级定级快照。

2. 资产血统卷宗：模型/知识包哈希、版本记录、迁移审计记录、历次勘伪报告。

3. 探针原始时序数据：事故发生前后完整探针采集序列，不可裁剪过滤。

4. 事故复现路径：可复现步骤、触发条件、NT负迁移类型判定。

5. 损害评估：影响范围、受影响主体、量化损失、风险扩散边界。

6. 处置动作记录：熔断、隔离、关停、回收、数据封存全部操作日志。

7. 根因初步判定与临时风控措施。

免上报、上报失效、重报触发条件

1. 低于L1阈值的微小扰动事件，免于强制上报，但纳入内部日志留存，可被元勘伪抽样调取。

2. 上报材料缺失核心要件、探针数据被篡改、资产血统断裂 → 上报判定失效，要求限时重报并启动审计旁路核查。

3. 事故演化升级，风险等级向上跃迁 → 自动触发升级上报，按更高等级时限补报完整材料。

4. 事后发现上报材料存在隐瞒、伪造、删减证据 → 上报作废，启动瞒报专项勘伪。

5. 跨主体、跨司法域联动事故，各责任主体分别独立上报，不可由一方代为全部上报。

五大元层自勘基线

1. 事故上报前置校验勘伪基线

提交事故卷宗时自动校验要件完整性、资产血统与探针数据一致性；材料缺失判定上报无效，推送补报预警。上报卷宗纳入永久存证。

2. 事故上报全周期动态监测基线

部署四类事故上报专属探针：事故瞒报探针、上报时限逾期探针、上报材料裁剪探针、审计旁路探针。检出瞒报、迟报、伪报，立即触发元勘伪专项核查。

L4、L5事故零容忍瞒报与人为证据篡改。

3. 事故上报失当勘伪与权责确权基线

跨域迁移事故发生，同步核查上报义务履行情况：

• 项目运营方：瞒报、迟报、伪造事故材料，承担事故上报主要过失责任。

• 勘伪复核方：已知事故却协助隐匿、压缩风险等级，承担连带责任。

• 监管运维方：上报接收链路故障，未及时预警逾期上报，承担平台运维责任。

4. 事故上报违规反例入库校准基线

瞒报、迟报、伪报案例归入079反例库，优化事故识别预审规则；仅增补注释细则，NT内核、L5铁律不可修改。NT4级瞒报案例仅归档推演，严禁复用。

5. 事故卷宗永久存证基线

事故上报卷宗、探针时序、处置记录、勘伪复核结论全部SHA256永久归档；L4、L5事故卷宗启用多主体联合存证。

四类专属探测探针

1. 事故瞒报探针：比对日志、告警记录与上报清单，识别应当上报却未提交的跨域迁移事故。

2. 上报时限逾期探针：监控各类等级事故上报时间窗口，识别超时上报行为。

3. 上报材料裁剪探针：比对原始探针数据与上报材料，识别证据删减、损害范围刻意缩小。

4. 审计旁路探针：监控人为关闭告警、删除事故样本、阻断上报链路的操作。

NT1-NT4事故上报负迁移因果闭环

NT1：低风险事件小幅上报延迟，流程瑕疵，无实质风险。

NT2：上报材料范式不统一，只描述表面现象，缺失资产血统与探针证据，信息系统性残缺。

NT3：主体刻意隐匿事故、压低损害等级，事故样本无法进入反例库，同类隐患持续潜伏。

NT4：L4/L5重大事故系统性瞒报，法典反例基准失真，治理标尺失效，造成全域不可逆体系污染。

终极因果链

事故上报依赖企业自愿申报，无强制时限与标准化卷宗约束 → 主体选择性隐瞒事故、裁剪证据，NT3隐患持续累积 → L4/L5重大跨域迁移事故被隐匿，无法汇入反例库迭代治理基线 → 同类事故反复爆发，治理体系失去事实支撑。

落地场景精简版

1. 跨域迁移事故按L1-L5分级设置刚性上报时限；风险等级上浮自动升级上报等级。低于L1微小扰动免于上报，但日志留存备查。

2. 上报卷宗必须附带资产血统快照与原始探针时序；瞒报、迟报、伪造证据单独追责。探针持续监测瞒报、逾期、证据裁剪行为。

3. 事故勘伪同步核查上报履约情况，划分事故责任与上报违规责任。

4. 上报违规案例归入全域反例库优化事故预审机制；内核基线永久锁死。

5. 人为阻断上报链路、篡改探针数据、系统性隐瞒L4/L5事故，判定重大过失追责。

递归统一陷阱

小型内部事故可以不用上报；事故处置完毕之后再提交材料即可；上报时可以隐去部分敏感探针原始数据；风险等级判定之后不会发生变化；事故可以由合作方代为统一上报。

十一层递归盲区（终版）

014元层残缺｜无法区分微小扰动、上报材料范式缺失、刻意隐瞒事故、人为阻断上报链路四类偏差

015证据自指｜短期无事故上报记录，不能证明不存在未被发现的隐性跨域迁移事故

016时序残缺｜隐性事故瞒报潜伏期长，常规抽样核查难以暴露NT4级治理基准失真后果

017观测残缺｜表面无上报记录，后台存在未披露事故样本，无显性告警提示

018契约残缺｜跨域迁移事故分级强制上报、刚性时限、标准化卷宗的刚性条款缺失

019认知残缺｜内部处置闭环，就可以替代对外事故上报义务

020证伪残缺｜瞒报迟报诱发跨域迁移重大事故的标杆反例库缺失

021基线残缺｜跨域迁移事故分级上报时限、卷宗要件标准化基线缺失

022机理残缺｜事故自愿上报机制，重大事件系统性瞒报诱发NT4治理基准失真根因闭环缺失

023权责残缺｜项目运营方、勘伪复核方、监管运维方上报环节责任边界模糊

024行业残缺｜AI跨域迁移事故分级强制上报治理规范缺失

025监管残缺｜瞒报、逾期上报、证据裁剪行为监测判定标准缺失

026风控残缺｜无法区分微小扰动、材料不全、刻意瞒报、上报旁路四类风险

027终局勘伪｜核验事故卷宗、资产血统快照、探针时序三要素完整链路
