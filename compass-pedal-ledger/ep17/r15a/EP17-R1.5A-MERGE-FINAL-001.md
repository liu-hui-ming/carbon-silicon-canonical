## 一｜道统命题

EP17 的根本目标，不是给出一套解读低维拓扑材料物性的拟合框架，而是建立一套可证伪、可审计、可回滚、可分支存续的科研元方法论：对「自由度如何升格为解释维度、证据如何被观测压缩、模型如何发生简并、共识如何固化为新偏见、审计规则如何反噬其审查对象」实施全链路治理。

可信域不是预先铺展在高维同质流形之中的真理区域，而是依附于命题、证据集合与约束条件的动态集合：

𝒯(H|E,C) = { x ∈ 𝒳 | x 与 H, E, C 相容 }

当证据更新、条件迁移、模型假设更换、社会采信权重漂移、治理规则修订时，可信域扩张、收缩、分裂、迁移，甚至置为空集。**不存在全域、永恒、唯一的可信域。**

全域系统为异构乘积状态空间：

𝒳 = 𝒳_O × 𝒳_S × 𝒳_M × 𝒳_C × 𝒳_G

- **𝒳_O 物理本体空间**：晶格、电子多体态、界面、缺陷、输运通道、热力学与量子自由度
- **𝒳_S 观测空间**：仪器、采样窗口、噪声、测量算子、数据筛选、扫描参数
- **𝒳_M 模型空间**：泛函、基矢截断、近似、参数集合、竞争性机理假设
- **𝒳_C 社会知识生产空间**：资助、评审、传播、专利、赛道激励、引用偏好
- **𝒳_G 治理元空间**：维度注册、审计版本、权限、申诉、分支台账、复审规则

该乘积仅代表耦合架构，**不强制所有子空间共享连续、可微、同量纲的流形结构**；部分子空间为离散状态机、概率测度、网络动力学或版本谱系。实际可达状态是受多重约束切出的子集。

## 二｜浅层误区｜勘伪锚点清单

本卷不再把隐喻当作公理。所有下列表述降格为修辞，不再作为数学定义：

1. 「全部认知误差都等价于相空间吸引子」——勘伪：吸引子适合动力学收敛；很多认知偏差来自采样截断、模型简并、制度筛选，不具备动力学不动点结构。
2. 「所有研究对象、观测、制度、治理共同属于单一高维流形」——勘伪：变量分属不同数学类型；强行嵌入同一微分流形会抹平量纲、因果方向、时间尺度、可干预性差异。
3. 「耦合矩阵强度等价于因果效力」——勘伪：相关 ≠ 机制；机制 ≠ 可控干预；矩阵仅承载带区间不确定性的关系标记。
4. 「耦合矩阵本征值直接判定相变与全局失稳」——勘伪：相变判定需要控制参数、自由能、临界标度、滞后、有限尺寸校正；耦合矩阵的敏感方向仅为候选预警。
5. 「全部盲区都是尚未测绘的子流形」——勘伪：盲区分为原理不可观测、采样缺失、简并不可辨识、模型遗漏、社会筛选、元治理偏见，只有一部分可被几何化。
6. 「体系应当维持全域连通」——勘伪：强制连通会催生虚假统一；科研体系应允许竞争分支、互斥相、不可比对证据链长期并存。
7. 「维度应当持续解耦至完全独立」——勘伪：完全解耦不是普适目标；不可辨识本身就是重要结论。
8. 「维度可以自由命名、自由升格」——勘伪：维度注册必须通过独立信息增益、可操作性、可反驳性、非重复性审查。

## 三｜破局演算｜四阶演进

- **一阶 单点锚定**：以材料对象、原始测量、证据链核查为主；解决「数据真假」。
- **二阶 平面联动**：打通物理、计算、工程、产业、制度传导链路；刻画误差逐层放大路径。
- **三阶 立体观测**：多视点正交约束，求取证据交集；抑制单一视角自洽造假。
- **四阶 动态维度治理**（本轮主线）：不再只审查研究结论，转而审查维度本身的生成、折叠、合并、冻结、退役，同时将审计规则纳入被审计对象；解决科研体系自我驯化、偏见固化、证据垄断。

**四谱系永久保留，不合并、不排序真值优先级**：
- D-O 本体谱系：物质固有自由度，不随观测与评审直接改写
- D-S 观测谱系：人类与仪器施加的采样、扰动、筛选
- D-M 模型谱系：人工假设、近似、参数空间、解释竞争
- D-Meta 元递归谱系：维度注册、算子日志、分支、复审、权限制衡

## 四｜动态维度：注册、生命周期、停止规则

候选变量升格为独立有效维度，须全部通过**六条准入门槛**：
1. **可定义性**：语义边界清晰，不与已注册维度别名重叠
2. **可操作性**：具备测量、干预、估计、记录方案
3. **增量信息**：在目标命题下提升解释、预测或机理区分能力
4. **可反驳性**：存在明确失效条件、证伪场景
5. **稳健性**：在合理数据扰动、模型替换下，增益不瞬间崩塌
6. **非重复性**：不是单位变换、人为拆分、已有机制的重命名

**状态机**：PROPOSED → DEFINED → TESTING → ACCEPTED；注册生效后进入运行态 ACTIVE / FROZEN / DOWNWEIGHTED / MERGED / SPLIT / SUSPENDED / RETIRED / REOPENED。

**铁律**：
- RETIRED：仅代表该变量不再作为独立解释坐标，不代表现实变量消失
- MERGED：必须附带信息损失清单、适用域、回溯拆分条件
- FROZEN：必须附带解冻触发阈值，禁止永久固化
- SPLIT：必须留存原混合变量映射，避免无依据裂解

**停止注册触发**（任一成立即冻结准入）：新增变量无独立信息增益仅冗余叠加；无法操作/观测/设计证伪；复杂度开销显著高于解释收益；仅在极端特例成立、跨条件不稳定。

## 五｜八大维度算子（可审计、可回滚）

强制登记字段：`operation_id, target_dimension, operator, reason, preconditions, method, expected_effect, observed_effect, uncertainty, rollback_condition, timestamp, parent_version`

| 算子代号 | 名称 | 核心产出 |
|---|---|---|
| DIM-REGISTER | 维度注册 | 维度卡、增益报告、证伪边界 |
| DIM-SPLIT | 维度分裂 | 新旧映射、拆分论证 |
| DIM-MERGE | 维度合并 | 信息损失报告、合并映射 |
| DIM-FREEZE | 维度冻结 | 冻结条件、解冻阈值 |
| DIM-RELEASE | 维度解冻 | 对照实验、偏差校正 |
| DIM-DECOUPLE | 维度解耦 | 可辨识性报告、干预方案 |
| DIM-DOWNWEIGHT | 维度降权 | 敏感性、风险权重 |
| DIM-RETIRE | 维度退役 | 封存台账、历史锚点 |

算子不是数学变换的简写，而是科研治理的原子动作；任何修改维度定义、耦合权重、状态归属，**都必须经由算子入链，不允许隐式变更**。

## 六｜耦合分层与因果辨识

耦合标记：K_ij^(t) ∈ [K_ij^(t)下界, K_ij^(t)上界]；i,j 维度对；t 耦合类型；区间承载不确定性；**无证据时标记 UNKNOWN，不得默认置零**。

**四类耦合，效力逐级抬高**：
1. 统计耦合——协同变化；工具：相关、互信息、条件冗余；仅提示关联
2. 机制耦合——存在已提出物理机理，辅以谱学、结构、计算证据
3. 因果耦合——可控干预、对照、自然实验；改变输入定向改变输出
4. 制度耦合——资源分配、评审、传播激励改变采信概率

**稀疏/稠密/强/弱/未知的严格定义**：稀疏=当前证据仅支持少量关系；稠密=多条关联获独立证据支撑；强耦合=扰动在目标输出上高敏感性；弱耦合=在指定扰动包内输出变化受控；未知耦合=实验设计不足以判定。

**禁止**从材料类别直接推定矩阵形态；**禁止**将对称耦合矩阵的本征值直接作为相变判据。相变必须配套：控制参数、自由能或等效势、临界标度、滞后、多稳态、有限尺寸校正。

## 七｜解耦与可辨识性分层

放弃「全域完全解耦」作为终极目标，建立五级判定：
1. 实验可分离：变量可独立操纵、独立施加扰动
2. 统计可辨识：现有数据足以分离各自贡献
3. 机制可区分：存在互斥假说，且可设计差异化实验
4. 条件性解耦：仅在指定尺度、温度、边界下近似独立
5. 当前不可分离：受量子约束、系统拓扑、测量极限限制

**核心结论**：解耦失败本身可以是合格科研产出。当多个自由度在当前证据下简并，治理规则要求保留竞争性解释，禁止强行单一归因。

## 八｜六类盲区台账

统一字段：`blindspot_id, description, affected_claims, evidence_gap, test_plan, owner, status, review_date`；状态集 IDENTIFIED / UNDER_TEST / BOUNDED / UNRESOLVED / REOPENED。

- **不可观测盲区**：原理层面测量限制；目标：划定边界，寻找间接约束通道
- **未采样盲区**：参数窗口、样品、构型覆盖缺失；目标：补扫描、负样本登记
- **不可辨识盲区**：多模型输出等价；目标：差异化干预设计
- **模型遗漏盲区**：机理未纳入；目标：模型竞争、残差审计
- **社会选择盲区**：发表偏好、资本、评审过滤；目标：负结果库、独立复现通道
- **元治理盲区**：审计基线、维度准入规则自带偏差；目标：外部复核、异议分支

**三条强制区分**：不可观测 ≠ 不可知；未采样 ≠ 不可观测；不可辨识 ≠ 物理不存在。

## 九｜反事实维度核验

所有进入主链的关键维度，须通过六重反事实测试；按证据强度分级：**真实干预实验 > 受控对照 > 统计模拟 > 纯模型推演**。

1. 修改该维度，目标结论是否定向改变
2. 固定该维度，其余变量关联是否稳定
3. 删除该维度，体系解释力损失可量化
4. 更换观测通道，结论稳健
5. 更换模型假设，预测边界可控
6. 跨批次、多样本、独立团队可复现

反事实不是为了证明维度「绝对独立」，而是划定其采信权重与适用域。

## 十｜风险传播张量

风险不再简化为两两之间的标量，而是结构化传播链：
- 风险节点：单维度固有不确定性
- 风险边：跨维度耦合偏差
- 风险路径：误差传导序列
- 风险回路：自我强化闭环
- 风险干预点：熔断、隔离、校正位置

**标准高危传播链（CPHN 典型）**：物理微结构差异 → 观测窗口遗漏 → 模型简并拟合 → 单一叙事社会放大 → 审计基线固化 → 后续采样持续偏移

每条风险边登记：`source_node, target_node, mechanism, direction, evidence, confidence, feedback_loop, intervention_point`；证据不足的链路仅入假说台账，不并入主结论。

## 十一｜分支治理：放弃虚假统一

治理目标不是把所有证据收拢到单一连通流形，而是保证：**分支可追溯、证据可比对、迁移条件明确**。

允许：多竞争模型长期共存；不同相、不同合成路径各自成立；部分分支暂时不可比对；新实验建立跨分支迁移关系。

**禁止**为理论美观抹平冲突；**禁止**强制归并证据不相容的分支。当两条分支在当前条件下不可比对，应标记「不可直接合并」，而非选择其一作为正统。

## 十二｜元递归制衡

元层解决「审计者如何避免垄断证据定义权」，强制落地：
- 规则版本全谱系存证
- 审计权重变更完整日志
- 独立异议分支永久存续，不被主链覆盖
- 利益冲突强制披露
- 定期外部复核触发
- 申诉、重置、撤销链哈希封存
- **治理域不得成为不动点**

元递归不是无限自扰，而是防止审计体系固化为新教条；当规则本身成为稳定偏见源，体系必须提供重启与重审入口。

## 十三｜CPHN 实证锚定组

本套方法论的唯一实测载体锁定在碳多环拓扑纳米带（CPHN），设四大标准化任务：
- **INTERFACE-001**：骨架/衬底/吸附层/端点/探针接触维度解耦辨识
- **TOPO-001**：五七环拓扑、宽度、长度、缺陷的增量验证与冗余筛查
- **SCALE-001**：长度、温度、有限尺寸、边界态的反事实与标度检验
- **TRANSFER-001**：批次复现、独立团队、跨衬底、器件集成稳健性核验

**执行流水线固定**：DIM-REGISTER → 耦合分层 → DIM-DECOUPLE → 反事实核验 → 盲区登记 → 风险链路归档 → 分支判定。所有原始条件、误差、假设、失效样本一并入档；**不筛选只保留「漂亮」结果**。

## 十四｜卷宗封存、勘误与哈希规范

版本冻结时必须归档：文件清单、版本标识、SHA-256、时间戳、责任主体、变更说明、审查状态、未决台账、异议分支、撤销链。

**SHA-256 仅证明字节一致性，不担保科学真值。** 原始证据链保持可追溯；解释、权重、分支归属允许修订，修订必须生成独立勘误卷宗，不就地抹除旧判断。勘误链独立于主线，可回溯但不自动改写历史版本。

## 十五｜最终命题（合并正本）

EP17-R1.5-A 不再宣称可以构造一张容纳全部真理的固定高维地图。它提供一套动态勘录体系：识别有效自由度，设立维度准入与退役机制，区分相关、机理、因果与制度耦合，分层处理可辨识性，登记全部盲区，追踪风险闭环，保留互斥证据分支，并让治理规则持续接受外部审计。

核心价值不在于对拓扑材料物性给出又一套拟合语言，而在于把「证据如何被制造、压缩、选择、采信、固化」变成一组可登记、可核验、可熔断、可分支存续的操作。

**终极原则**：不以维度扩张代替证据增长；不以模型复杂度代替可辨识性；不以理论统一代替分支验证；不以治理权威代替可重复实验。

我们不追求封闭完备的真理空间；我们建造一个持续自我勘伪、自我破局、永久开放的科研文明治理容器。
