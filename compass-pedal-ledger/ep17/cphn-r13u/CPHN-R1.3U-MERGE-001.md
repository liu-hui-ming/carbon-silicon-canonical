## 三｜道统命题（第一章）

物质不是静态物性容器，而是由原子排布、拓扑连接、边界端点、场环境、时序动力学、工艺记忆、观测通道、研发主体、知识范式与制度规范共同耦合的开放解空间。

核心研究命题：在量子力学、化学键热力学、动力学势垒、熵增与输运边界划定的解集之内，通过前驱编码、热致拓扑重排、侧向共价融合与取向控制，可在特定碳拓扑家族内部定向分化金属态/半导体态，实现「结构可控→电子态可控」；该可控性不代表普适万能，不突破底层物理，不能脱离衬底、温度、有限尺寸、缺陷与工艺窗口独立成立。

碳硅共生修正定义：非元素先天宿命，而是现阶段**工程稳态假说**——硅基适合承载大规模、高良率、低成本通用算力秩序；五七环这类低维碳骨架适合探索一维极限输运、边界态调制、特种量子通道。一旦实测给出更优替代或不可逾越工程障碍，分工可重排。

### 道统铁律（顶层约束，不可在分支推演绕过）
1. 以物质结构为对象，以物理规律为边界；
2. 以可复现观测为证据，以受控实验为最高裁决；
3. 以因果链串联推演，缺证即停，禁止跳跃；
4. 原始记录不可篡改；科学判断永远可勘伪；
5. 耦合必须标注类型、来源、不确定性、适用域与反证条件。

### 浅层误区归档（五条）
一、见新碳结构即判「硅时代终结」；二、将单一体系构型分化推广为通用原子编织术；三、把衬底诱导/有限尺寸/端点效应全归为本征属性；四、把耦合存在等同于因果、把相关升格为支配律；五、把远期文明推演当物理推论，脱离中间工程、产业、制度环节。

### 破局演算
叙事从「谁取代谁」置换为：人类能否建立可审计闭环，在受控边界内定向搜索、合成、表征、验证、迭代低维拓扑物质，并同步治理风险、分配收益、约束权力。材料只是该治理闭环中的一类可观测对象。

### 盲区挖掘 / 边界定义域 / 价值溢出 / 风险预判
- 盲区：推演默认理想无限周期晶格，而真实器件有限长、带端点、带缺陷、绑衬底、有热弛豫与批次偏差；模型可辨识性不足，多套机理可拟合同一组数据；产业与地缘推演常跳过良率、成本、设备管制、专利时序、替代路线对比。
- 定义域：以 CPHN 为锚点，向外辐射至同家族碳拓扑合成、一维共价金属、近弹道输运、界面耦合、跨尺度传递、材料研发闭环、证据治理、技术风险分配；域外不自动继承结论。
- 价值溢出：不在「立刻造出下一代全碳算力」，而在建立可移植的证据审计、耦合确权、实验台账、勘伪撤销机制——比单一材料成败更持久。
- 风险预判：若证据分级失效、负面结果被淹没、资本把假说包装成确定路线、标准监管滞后，则即使材料成立也会放大垄断、权力集中、路线锁死与不可控外溢。

## 四｜七轴异构观测体系（第二章）

七轴保留但不再作为同质坐标，各拥独立度量、可观测性、不确定性传播规则，禁止未定义直接并入同一物理相空间。

- **A1 尺度轴**：原子、化学键、单链、有限长纳米带、链簇、阵列、界面堆叠、晶圆、互连系统。重心：缺陷累积、端点扰动、接触电阻、声子散射、热梯度、链间耦合、工艺均匀性；尺度扩张可能触发临界行为，须由尺度扫描、敏感性分析、重复实验确认。
- **A2 场耦合轴**：温度、电场、应力、光场、磁场、化学势、衬底晶格场。重心：场如何偏移能带、改变稳定性、切换反应路径、调制输运；区分可逆调制、不可逆结构重构、瞬态响应与长期漂移。
- **A3 拓扑结构轴**：环元配比、连接图、链间取向、链宽、端点构型、边缘官能团、局域缺陷拓扑。重心：在 CPHN 家族内建立「结构自由度→电子态」映射；外推至异环、杂原子、超分子属迁移验证任务，不属本底结论。
- **A4 时序演化轴**：电子弛豫、成键、退火重排、氧化、缺陷迁移、老化、器件失效。重心：拆分快平衡、介观稳态、慢弛豫；区分制备时序、工作时序、存储时序。
- **A5 主体博弈轴**：课题组、设备厂商、EDA、晶圆厂、资本、专利主体、标准委员会、监管、地缘主体。重心：信息不对称、资源约束、准入壁垒、合作与排他、标准争夺；此层不服从物理微分方程，采用主体行动模型。
- **A6 知识范式轴**：逆向设计、前驱合成、势能面预测、原位多场表征、模型校验、数据回流。重心：研发闭环本身的可复制性；哪些环节可自动化、哪些依赖人工试错、哪些表征通道存在固有盲区。
- **A7 文明治理轴**：科研诚信、数据权属、知识产权、安全红线、利益分配、责任追溯、风险兜底。重心：技术能力、证据能力、治理能力是否同步；不同步处即文明风险入口。

## 五｜五层异构系统建模（第三章）

五层独立、双向反馈；物理层与社会层不混维，仅通过明确定义的耦合边对接。

- **层1 物质结构层**：原子组成、五元环/七元环拓扑、键合几何、本征缺陷、端点、边界构型、前驱残基。
- **层2 物理动力学层**：能带、电子关联、声子、电荷转移、势垒、输运、结构稳定性。连续域：ẋ=f(x,u,θ,h;M)，y=g(x,θ)+ε，ḣ=q(x,u,θ,h)；其中 x 结构与电子态、u 可控实验输入、θ 环境场、h 工艺记忆、M 模型族、y 观测、ε 测量噪声。离散事件（化学反应、结构相变、断裂、不可逆重构）切换至离散状态迁移机，不强行套连续动力学。
- **层3 观测计算层**：STM/AFM、扫描隧道谱、光电子谱、输运测量；DFT、紧束缚、非平衡格林函数、误差传播、模型可辨识性检验。
- **层4 工程产业层**：电极、接触、栅堆叠、阵列寻址、转移工艺、良率、成本、可靠性、供应链、设备依赖、替代路线对比。
- **层5 制度文明层**：证据标准、数据开放协议、专利、出口管制、行业标准、风险备案、责任分配。

**双反馈闭环**：物理–工程反馈（器件实测回传，修正结构假设、仿真参数、合成窗口）；治理–科研反馈（证据规范、安全边界、专利约束、评审规则反向裁剪可行研发路径）。

**耦合网络**：G=(V,E,τ)；边强制字段 source→target→mechanism→evidence→uncertainty→scope→status；状态全集 PROPOSED / SUPPORTED / REPLICATED / CONTRADICTED / UNRESOLVED / RETIRED。

**六类耦合**：物理（衬底杂化、界面电荷转移、电子-声子、应力传递）；因果（取向、端点、缺陷改变能带与输运）；信息（观测数据约束模型）；动力学（温场、退火时序改变反应路径）；战略（资本、专利、设备供给改变路线落地节奏）；规范（标准、管制、伦理规则限定实验与转化边界）。

**尺度传递误差**：E_s(L)=d(P_model(L), P_obs(L))。每上一层尺度强制核查：缺陷密度、端点效应、接触电阻、声子散射、热梯度、应力梯度、链间耦合、工艺均匀性；只有误差可控、新增机制被识别、临界行为可复现，才允许外推。

## 七｜全域盲区矩阵（第五章，七字段：blindspot_id｜question｜hypothesis｜observable｜method｜falsifier｜status）

- **物理**：有限尺寸与端点对能带极值/局域态/输运衰减的定量贡献；多体关联、非平衡输运、声子耦合定量分解；临界尺度/温度/场下相变判据。
- **界面**：衬底/隔离层/电极分别贡献多少电荷转移、轨道杂化、能带对齐；界面重构、接触电阻、界面诱导态与本征态解耦；无衬底悬空结构的稳定制备与测量。
- **合成**：异构体比例、产率分布、选择性随前驱/退火/衬底的变化曲面；缺陷谱系、缺陷传播、批次统计波动；无损转移、定位排布、阵列生长。
- **表征**：样本统计代表性（总计数、失效样本、失败路径）；时间分辨、多场原位、单链输运同时测量；不同表征通道系统误差交叉校准。
- **器件**：栅控、开关比、可寻址阵列；热管理、电流承载、长期漂移、辐照与温循；互连场景下与替代导体的系统对比。
- **工具链**：适合该拓扑的自动化结构解析、紧束缚参数库；低维输运紧凑模型、EDA 集成；自动化合成-表征-仿真闭环的复现门槛。
- **产业**：成本曲线、良率阈值、学习曲线；高纯前驱、专用设备、耗材供应链；与铜互连/CNT/GNR/超导候选的全维度反事实比较。
- **制度**：跨学科评审标准、负面结果发布机制；数据共享协议、专利时序冲突、独占性锁闭；材料/表征/可靠性标准。
- **地缘**：精密表征设备、特殊前驱、仿真软件管制；跨国样品交换、合作边界、标准阵营分化。
- **文明**：可编程低维物质进入算力基础设施后权力如何分配；风险外溢、垄断、收益分配、责任追溯；治理体系是否具备同步迭代能力。

**四大优先深层盲区**：①端点与有限尺寸效应（理想周期模型 vs 真实有限链偏移不可忽略）；②样本选择性偏差（必须给出分布、产率、失败分支，不只展示最优单条）；③模型可辨识性（区分「拟合成功」与「机理唯一确定」）；④反事实路线对比（同等约束下相对现有方案是否具系统优势）。

## 八｜七项核心可证伪实验任务（第六章）

- **SCALE-001 长度尺度扫描**：近弹道特征随链长衰减的阈值、衰减律、端点主导区间。反证：超临界长度后近弹道输运消失，则长距离互连假设失去基础。
- **FIELD-001 多场耦合扫描**：温度、电场、应力如何独立与联合调制双态稳定性、能带偏移。反证：多场叠加下金属/半导体分化消失，则该分化不具工程可用窗口。
- **TOPO-001 构型-性质映射**：取向、端点、链宽、局部缺陷各自独立贡献。反证：能带主要由端点与接触决定而非骨架取向，则「取向开关」假设需重写。
- **TIME-001 时序稳定性**：大气、真空、通电条件下氧化、重构、漂移、失效的时间尺度。反证：短期不可逆重构，则器件长期使用不成立。
- **INTERFACE-001 衬底贡献分离（最高优先级）**：拆分本征 CPHN 贡献、Ag 衬底、Br 隔离层、电极接触贡献。反证：观测到的金属性完全绑定特定衬底，则不存在独立本征共价金属。
- **MODEL-001 模型可辨识性**：哪些参数可独立测量、哪些只能联合拟合、哪些竞争模型无法区分。反证：全部预测可被两套互斥机理同等解释，则当前实验不足以判定机理。
- **TRANSFER-001 合成范式迁移边界（核心勘伪项）**：前驱编码-热重排-侧向融合在哪些环、杂原子、骨架、能量窗口下可复现。反证：更换骨架后选择性、产率、目标结构同时崩塌，则范式不具跨体系迁移性。

## 九｜十一维价值溢出因果门禁（第七章）

固定因果链：材料发现 → 物理机制明确 → 结构可稳定复现 → 器件功能验证 → 系统优势确认 → 经济可行 → 制度与文明影响。**缺一环只标记为潜在，不升格为已实现价值。**

逐轴确权（门槛见表）：凝聚态物理（新增一维共价金属候选｜关联电子、温度拓扑分类、悬空本征态）；合成化学（分步拓扑合成路线｜迁移边界勘伪）；半导体微系统（亚纳米互连候选｜栅控、接触、阵列集成）；算力基础设施（低功耗互连潜力｜系统能耗、延迟、良率对比）；量子信息（一维通道实验平台｜相干长度、相位操控、量子态隔离）；精密仪器（倒逼原位多场表征设备｜稳定、可复用、可规模化）；航空航天特种器件（极限工况候选｜辐照、温循、寿命、真空兼容）；智能科研制造（适合 AI 材料闭环｜自动化合成、可复现闭环）；标准与知识产权（新型表征与工艺标准潜在对象｜稳定技术对象、行业共识）；科技治理（前沿证据分级治理范本｜规则落地、冲突处置、效果评估）；碳硅文明（材料协同分工动态范式｜持续跨路线对照、分工可重分配）。

## 十｜全域风险分层治理（第八章）

科学风险（外推失效、多体效应忽略、样本偏差、模型不可辨识、选择性报告）；技术风险（界面失稳、接触电阻、缺陷雪崩、结构弛豫、不可控重构）；工程风险（阵列集成、热管理、良率、兼容工艺、寿命）；产业风险（资本泡沫、路线锁定、专利壁垒、单一供应链）；人才风险（跨学科缺口、评价体系不匹配、负面结果激励不足）；工具链风险（仿真偏差、闭源依赖、参数不可审计）；学术风险（证据等级混淆、预印本叙事过载、复现投入不足）；地缘风险（设备、前驱、软件、标准管制）；治理风险（数据权属、独占、安全边界缺失）；文明风险（算力基础设施权力集中、收益分配失衡、治理滞后于能力）。

**处置原则**：风险不否定研究；风险要求证据、隔离、备案、分级放行、退出通道。
