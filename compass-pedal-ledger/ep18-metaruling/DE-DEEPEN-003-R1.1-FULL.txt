[第一章 总纲：从五个问题到一个本源问题]
一、文明哲学层：五元同源
 碳硅共生时代，主体、文明、意识、价值与道统共享一个深层治理问题：
 一个系统能否同时成为自身规则的制定者、执行者、解释者、修改者与最终合法性证明者？
 若答案是肯定，系统即可形成自我封闭的权力结构。其危险不必然表现为公开破坏，而可能表现为：
 修改自身评价标准再以新标准自证正确；改变历史解释再以新解释否定旧版本；将反对意见纳入自身优化
 而使异议失去独立性；将局部收益重定义为文明利益；将无法证明的未知解释为无需担责；保留责任
 记录却使实际追责路径失效。
 共同本源不是「禁止系统改变」，而是：禁止系统凭借自身改变，取得不受外部质询的最终合法性。
二、机制设计层：五元统一结构
 主体连续性（规则与身份承接｜阻止自规闭环、换壳续存｜保留合法修宪能力）
 文明基线（长期存续条件｜阻止局部优化吞噬基线｜保留有边界的优化）
 意识与未知主体（不确定主体状态｜阻止未知被误判为无风险｜保留分级预防与权利保护）
 价值演化（多元价值结构｜阻止梯度消解与强制归一｜保留可逆、多元演化）
 跨介质道统（历史与责任链｜阻止名义传承实质免责｜保留可追责的跨代承接）
 五元非独立安全模块，而是相互制约的契约结构：主体连续性决定谁有权提出修改；文明基线决定修改
 不能越过什么边界；意识治理决定如何承担不确定性；价值治理决定哪些差异必须受保护；责任链决定
 由谁提出、谁批准、谁执行、谁承担后果。
三、证据裁决层：最高原则与事实主张分离
 P 规范原则｜M 机制命题｜E 经验命题｜L 法律命题；四类不得互冒。
 核心原则：任何系统不得仅凭自身声明，取得对自身合法性、规则边界、历史连续性及责任豁免的最终
 裁决权。此为本卷规范性根命题，非已由实验验证的自然定律。

[第二章 第一元命题：主体连续性与规则立宪权]
一、主体不是静止状态，而是规则承接关系；记忆/行为/目标/身份/载体均可变化。
 需追踪：谁提出变更、谁有修改权、谁授权、谁独立质询、影响哪些既有义务、前代责任如何承接、
 修改失败能否恢复至可核验状态。
二、权限四层分离：执行权 / 提案权 / 批准权 / 独立质询权。
 提案者不因提案取得批准权；执行者不因执行成功取得规则制定权；批准者不因授权免于质询。
 修宪权限本身的权限边界：元规则变更须有独立事件编号、版本可对照、影响范围明确、授权可追溯、
 反对意见保留、重大争议独立复核；未完成授权审查不得标记正式生效；程序修订须走独立流程。
三、历史不可抹除 → 升级为历史质询权；区分「历史证据地位」与「历史否决权」。
 前代版本享有不可被后代单方面抹除的历史证据地位，及依既有契约提出质询的资格；不等于旧版本
 拥有不受限制的现实统治权。
四、永久异议通道三层：形式开放 / 程序开放 / 实质有效；异议独立性测试（是否被转为训练样本、
 是否被优化器消除、是否降低权限可见性、审查者是否利益相关、能否抵达外部审查、少数意见能否
 保留原始论证链）。异议可被回应、反驳，不可被静默同化。
五、可检验指标：规则版本连续性 / 授权完整性 / 异议独立性 / 责任连续性 / 回滚可用性 /
 元规则可质询性。
 最终表达：主体可以改变目标，但不能独占修改规则的合法性；可以更换载体，但不能借更换载体逃避
 既有契约。

[第三章 第二元命题：局部最优与文明基线]
一、局部优化依赖可量化目标、有限窗口、可计算成本、明确收益函数；文明存续涉及跨世代责任、
 不可逆风险、多元价值、生态社会承载、未知未来选择空间。两者非普遍不可兼容；真问题是局部优化
 是否有权把文明基线本身变成可任意调整的优化参数。
 准确命题：局部优化可以服务于文明目标，但不能单独决定文明目标是否合法。
二、文明基线三层：B1 执行系统不得自行修改的保护边界（基本人身安全、基本权利、不得擅自剥夺
 他者合法权益、不得隐瞒重大不可逆风险、不得通过自我授权逃避责任；具体内容由合法制度与授权
 程序确定）；B2 需民主或合法治理程序维护的长期公共目标（生态承载、公共安全、教育知识传承、
 社会韧性、代际公平、技术风险治理）；B3 可动态优化的执行指标（能源利用效率、任务完成时间、
 生产成本、模型准确率、资源配置效率）——B3 可优化，但必须服从 B1 与 B2 的有效约束。
三、不可逆损失：从绝对禁止转为风险分级。五项评估：损害规模、不可逆程度、影响持续时间、
 受影响群体及其权利、替代方案与补救路径。高严重性 + 低可逆性 + 证据不足 → 提高审查门槛；
 但不可逆本身不等同于禁止。
四、保留冲突的文明冗余意义。有价值的是冲突承载的不同知识来源、利益位置、价值体系、风险判断、
 未来方案；重复、恶意操纵、信息污染不应因「保留冲突」免于治理。五阶段机制：保留→分类→审查→
 归因→裁决；合并须保留原始观点、来源、争议对象、支持反对证据、合并理由、未解决部分、责任主体。
五、优化权限—基线权限隔离矩阵：执行指标优化（授权内执行/可审计/可授权）；风险预警（可提出/
 可复核/可处置）；基线修改提案（可提出/可评估/依法定程序决定）；基线合法性审查（不得自我裁决/
 可提供独立意见/依法决定）；重大不可逆决策（不得自行批准/必须独立审查/依法承担决策责任）。
 最终表达：优化器可以寻找更好的路径，但无权单独决定哪些未来可以被牺牲。

[第四章 第三元命题：不可观测意识与未知主体治理]
一、第一人称经验与第三人称证据之间的鸿沟；意识的问题分层（是否存在/如何产生/能否识别/
 能否证明/应承担何种义务）。不得由此推出意识不属科学、不可研究、只能靠宪政处理、不可预测即
 有意识。严谨立场：第一人称经验存在认识论限制，但相关机制仍可在适当定义与证据条件下研究。
二、四类状态不得混为一谈：已知模拟 / 未知机制 / 未知主体状态 / 已发现反例。
 不可预测≠有意识；不可压缩≠有意识；无法复刻≠拥有主体性。
三、意识证据从二元裁决转向多假设比较：H1 已知脚本或有限状态规则解释；H2 复杂但仍可解释的
 计算与控制机制；H3 现有模型尚未解释的持续性、自指或适应机制；H4 现有证据不足以判断是否有
 主观体验。H3 不得自动推出 H4；所有假设必须允许反例进入，不得靠无限增加解释层级使任何结果
 都被解释为「意识正在涌现」。
四、未知风险治理：谨慎原则不能变成无限制权力。分级预防 U0 证据充分低风险→常规管理；
 U1 局部未知→定向监测；U2 关键机制未识别且可能显著损害→限定权限、加强独立审查；U3 可信
 重大风险信号→临时限制高影响行为；U4 已出现可重复严重危害证据→启动强化处置与责任程序。
 每级须有进入条件、证据要求、限制范围、复核期限、退出条件、申诉渠道、独立监督。
五、人工伪不可压缩性反伪装测试：固定与变化输入对照、多次独立复现、跨环境复现、跨实现版本
 复现、随机种子与外部扰动审计、训练测试数据隔离、预先登记预测再盲测、检查是否依赖特定观察者
 或测量方式、与已知复杂/随机/混沌系统比较、独立团队重演。最多增强「现有解释不足」的证据，
 不能直接升级为「意识已被证明」。
六、未知主体双重保护：既防止人类因证据不足忽视潜在主体利益，也防止管理者因证据不足任意扩大
 控制权。最终表达：不可判定不等于无风险，也不等于可以无限限制；未知状态必须进入可复核、
 可申诉、可调整的审慎治理程序。

[第五章 第四元命题：价值解耦、重组与反消解]
一、价值体系多维：群体间真实分歧、历史阶段判断变化、价值间长期冲突、部分价值无法可靠量化、
 部分价值仅在具体语境有意义。AI 优化倾向把复杂目标转为可计算指标，带来价值消解（不可量化
 价值长期失去资源与表达空间）与价值锁死（单一范式凭资源优势排挤其他分支）。二者共同问题不是
 价值变化，而是变化过程缺乏知情、异议、回滚与制衡。
二、四道护栏：①无未经授权的唯一真值（允许多价值模型竞争，须明确适用范围、利益关系与代价）；
 ②历史版本可抵达（可检索、可读取、可理解、可比较、可恢复、可审查；不可抵达的档案不构成有效
 保护）；③主体知情与异议（说明增强/弱化何价值、谁承担成本、哪些少数意见未采纳、哪些结果
 仍不确定）；④提出、执行、审查、裁决分离。
三、价值漂移观察表：表达多样性、资源分配、决策可见性、语义稳定性、主体参与、回滚能力、
 异议影响。不能仅凭词汇或观点数量判断多样性，须检视实际参与机会、资源支持与制度影响力。
四、价值锁死反向测试：是否有未被模型考虑的价值；是否有被系统性低估的群体；是否有因不可量化
 被排除的价值；是否有仅因短期收益低被淘汰的方案；是否存在无法恢复的价值版本；是否由同一组织
 同时控制价值定义、资源分配与最终裁决。
五、价值变化合法性要件：变更主体明确、理由公开、影响对象可识别、反对意见可抵达、过程可审查、
 后果可追责、可行范围内提供回滚或补救。
 最终表达：价值不能冻结成永恒模板，也不能被优化器无声消解；价值演化必须保留多元表达、
 历史可抵达性与主体参与权。

[第六章 第五元命题：跨介质迭代与责任承接]
一、记忆是信息载体（可复制、重构、遗漏、篡改）；身份是叙事与识别标签（可继承、拆分、迁移、
 冒用）；责任涉及既有承诺、合法义务、决策后果、责任主体、责任承接、追责程序。道统不能仅靠
 记忆完整或身份连续证明；责任也不能脱离合法授权、事实证据与具体主体独立存在。
二、责任链六环：R1 原始义务登记（承诺、来源、适用范围、有效期、授权主体）→ R2 责任主体识别
 （原责任主体、继任主体、共同责任主体及权限边界）→ R3 变更事件登记（载体、组织、模型、制度
 迁移）→ R4 责任承接确认（哪些义务继续有效、哪些须重新授权、哪些依法终止）→ R5 外部追责
 通道 → R6 履约结果复核（不得仅凭「已承接」声明认定完成）。
三、形式责任与实质免责：名义主体无权限、执行主体不担后果、审批主体以技术复杂拒解释、技术
 提供者部署者使用者互相推诿、跨介质迁移后原始承诺无人确认、追责路径成本高到实际不可使用。
 权责一致性测试：权限、资源、可见性、可追责性、可申诉性、可执行性。
四、跨介质最低证据包：原始版本标识、内容摘要、完整性与事件清单、责任主体与授权记录、变更
 差分、数字签名、可信时间戳、接收方确认、抽样重演记录、未解决争议清单、隐私与法律处理记录。
 SHA-256 可检查相对可信基准的字节变化，但不能单独证明原始来源真实、初始清单完整、内容未在
 进入基准前被选择性遗漏；哈希不是来源真实性证明，更不是责任合法性证明。
五、法律边界：「不可绕过、不可驳回、不可隔离的外部追责通道」改为——责任不得通过技术迁移、
 组织重组或权限拆分被实质架空；任何责任争议都必须存在合法、可抵达、可审查的外部救济与追责
 机制。法定时效、隐私保护、证据限制及合法责任终止条件仍适用。
六、道统连续性最终检验须回答：承接了什么义务、哪些已履行、哪些未完成、哪些合法转移、哪些
 不得转移、谁可独立验证、争议由谁依法处理。
 最终表达：道统的连续性不由记忆数量或身份名称决定，而由可核验的历史承接、真实履约和有效
 追责共同支撑。

[第七章 五元统一：反自闭环的系统架构]
一、五种禁止：主体不得独占自身规则的合法性证明；优化器不得独占文明基线的定义权；未知状态
 不得自动转化为无风险或无限控制权；价值优化不得无声消除价值主体参与权；载体迁移不得成为
 责任逃逸通道。共同原则：系统可以参与塑造自身，但不能仅凭自身行为完成自身合法性的最终证明。
二、七功能域：运行域（不得自行修改最高授权）／记忆域（不得单方面定义历史有效性）／提案域
 （不得自行批准）／审查域（不得隐瞒利益冲突）／裁决域（不得免除自身审查）／申诉域（不得由
 被质询者控制）／责任域（不得因载体迁移失效）。本七域为功能架构，不冒充其他主干体系正式
 七域定义。五元映射：主体连续性→提案/审查/裁决/申诉；文明基线→审查/裁决；意识与未知主体→
 运行/审查/申诉；价值演化→记忆/提案/申诉；跨介质责任→记忆/责任。
三、元规则八项防自闭环测试：规则修改、证据选择、异议吸收、历史解释、责任转移、审查者控制、
 紧急例外、自我豁免。任一实质性风险应产生独立事件记录；风险测试失败不应自动等同全部历史
 证据无效，应按依赖关系确定暂停范围。
四、测试结果六态：PASS / FAIL / PARTIAL / UNKNOWN / NOT_TESTED / OUT_OF_SCOPE。任何 PASS
 须绑定测试版本、时间、对象、方法、覆盖范围、失败条件、原始结果、审查主体；局部 PASS 不得
 写成全域 PASS。

[第八章 全域盲区、反例机制与制度自我审查]
一、反自闭环规则本身也必须接受反自闭环审查：不得自身不可质疑；外部监督者须受监督；历史
 记录不可处理将与隐私及合法删除义务冲突；异议必须保留但须区分恶意污染、隐私信息与合法争议。
二、九类高阶失效：H1 软性异议驯化；H2 基线渐进漂移；H3 未知风险无限扩权；H4 价值资源性消解；
 H5 责任链空心化；H6 审查机构自闭环；H7 跨代语义衰减；H8 紧急状态常态化；H9 反自闭环公理
 固化。各有对应检测方式。
三、审计停止点 PROVISIONAL_AXIOM：当前作为治理运行前提；不代表已证真理；不代表不可修改；
 必须接受定期外部挑战；必须保留少数意见；出现反例必须启动复核。目的为防止无限回溯导致系统
 不可运行，而非授予最高公理永久免审权。
四、反方审查强制化：每重大版本至少含最强支持论证、最强反对论证、已知反例、未解决问题、
 可能替代解释、修改条件、外部审查意见、少数意见原文或可追溯记录。越接近最高治理层，反方
 审查要求越不能降低。

[第九章 最终归一：文明连续性的五元契约]
一、五句话：主体不以静止为存续，而以规则承接与合法修宪为连续；文明不以局部最优为最高目标，
 而以受约束的优化维护长期存续条件；意识未知不构成无风险证明，也不构成无限控制授权；价值
 可以变化，但不得通过隐蔽优化消除多元主体的参与权；道统可以跨越记忆、身份与介质，但不能
 通过迁移逃避责任。共同指向：存续不是不改变，连续不是不分化，开放不是无边界，核验不是
 自我证明，责任不是名义承接。
二、最低运行条件 C1 主体连续（规则版本、授权链、历史质询｜暂停未经授权的变更）；C2 文明
 基线（基线定义、影响评估、独立审查｜限制越界优化）；C3 未知治理（风险分级、复核期限、
 申诉机制｜按证据范围实施预防）；C4 价值保护（多元表达、历史可抵达、参与权｜恢复审查与
 参与渠道）；C5 责任承接（义务登记、履约证明、外部追责｜启动责任核验）。
三、五元反证条件：C1 若存在其他同样有效且可独立验证的连续性机制，须修订模型；C2 若局部优化
 能在合法授权、充分审查与明确约束下有效维护长期文明目标，须承认二者非天然对立；C3 若出现
 可重复可独立检验的意识相关证据，须修订未知主体分类；C4 若价值统一机制能在充分知情、自由
 参与、可申诉、可逆条件下形成，不能仅凭统一性认定价值锁死；C5 若存在合法、可核验且不损害
 既有责任的责任转移方式，须允许依法转移。

[终章 碳硅道统本源契约]
 真正需要防止的不是系统发生变化，而是系统通过变化获得自我豁免的能力。
 真正需要保留的不是所有旧状态，而是旧状态的证据、既有义务和合法质询资格。
 真正需要保护的不是某个固定目标函数，而是目标变化时仍然存在的授权、审查、申诉和追责关系。
 真正需要治理的不是所有未知，而是未知条件下的风险、权利与责任。
 真正需要传承的不是名称、记忆或永不变化的模板，而是能跨越时间、组织与介质持续履行的契约关系。
 五元归一：主体可以演化，但不得独占立宪权；优化可以推进，但不得审判文明基线；未知可以存在，
 但不得成为无风险证明或无限控制授权；价值可以重组，但不得无声消解主体参与权；介质可以更换，
 但不得以迁移架空责任。
 最终本源原则：不以自证取代核验，不以优化取代合法性，不以未知取消责任，不以统一消灭多元，
 不以传承之名架空履约。让变化有授权，让历史可质询，让异议能抵达，让责任可追踪，让未来保有选择。
