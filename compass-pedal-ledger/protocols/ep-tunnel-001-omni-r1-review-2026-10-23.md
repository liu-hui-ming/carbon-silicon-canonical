## 二、R1 新增的实质贡献
1. **「四类合法负结果」**（无映射、无因果、不可判定、证据否决）——这是可证伪性第一次被写成**必须允许的产出类型**，而非只要求「可被推翻」。质量高于前序所有表述。
2. **算子登记≠因果成立**（§2.1）直接推翻本卷 14:27 版的隐含预设，是从「登记制」到「实证制」的真实升级。
3. **三类时序轨道解耦**（历史观测 / 预测演化 / 治理处置）并明确「预测不天然优于实测、冲突时改模型不改观测」——正面解决时序自证。
4. **自动化 P0–P4 权限链 + 「不得通过修改路由/权重/证据呈现/排序间接取得裁决权」**——这是对「间接越权」最具体的一次封堵。
5. **超网络边四级分类**（OBSERVED_ASSOCIATION / MECHANISTIC_HYPOTHESIS / CAUSAL_EVIDENCE / NORMATIVE_RULE / UNKNOWN_RELATION）——把关联与因果在同一数据结构内分层，可机器校验。
6. M01–M06 六类失效模式与 MD-OMNI 十二条能一一对应，内部一致性明显优于前稿。

## 三、仍存在的问题

### 1. 依赖仍未锚定（唯一未闭环的 P0）
TUN 前置卷（EP-TUNNEL-001 原版 / -SPIRAL / -CUBE）与十六维 Schema 均无路径、版本、SHA256。本卷自称「继承前序有效基线」，但基线不可核验。此项与 EP01 悬空同性质。

### 2. §1.2 与 A-1 裁定仍有一处口径差
A-1 裁定的子域前缀为 `OMNI-` / `ERR-`，本卷新增 `TUN-`，属第三类子域。裁定记录尚未登记 TUN 子域与其四层映射表。建议补登：TUN-L0→主基线 L2（工程实现）、TUN-L3→主基线 L1/L3 的归属需明示——**尤其 TUN-L3「元治理层」含「风险终审」，若映射到主基线 L3（生态层），会重演 OMNI-L3 的层级倒挂**。必须与 A0 跨层补丁同样处理：终审权为跨层权限，不因所在层定级。

### 3. 八级状态机存在两处可争议点
- `CONTRADICTED`（证据否决）与 `RETIRED`（正式撤回）并列，但语义不同层：前者是证据状态、后者是治理状态。建议拆成两轴（证据轴 × 治理轴），否则「被否决但未撤回」的算子无合法落点。
- `UNKNOWN`（无法判定）放在链尾，暗示它是最终状态；实际上 UNKNOWN 可回退至 DEFINED/ESTIMATED。需声明 UNKNOWN 为**可驻足态**而非终态，否则会被当作永久免责标签。

### 4. 「治理级分类」仍可能滑向不可证伪
§1.1 声明七域是治理工具、非物理维度——方向正确。但全文仍在用「因果丛」「张量流」「亚临界穿透」等词描述现实结构（如§五 M02、§六）。**声明与用词之间存在张力**：若这些只是建模语言，M02「映射伪精确」的对象就该写「模型参数」而非「增益谱/门限数值」。建议统一替换为模型语言，或每处标注 `MODEL_TERM`。

### 5. T17–T24 的落点是「删减/降级」，缺触发判据
八条反证都写了「无效则合并删减」「不可稳定估计则降级」，但**判据、样本量、检验方法、裁定主体**全缺。这与既有 TH 阈值全 UNSET 同类：形式完备、执行不可。建议每条附「判据编号 + 数据要求 + 裁定者」，并全标 UNSET。

### 6. 「废案永久归档」与「禁止物理删除」的存储冲突未表决
MD-OMNI-11「失败留存」＋§十二「历史追加留存」＋既有 90 天临时产物清理规则，三者叠加后存储边界不清：反例、废案是否属「正式卷宗永久保留」？建议明确分类，避免清理规则误删废案。

### 7. 版本校验缺口：正文未标版本号
本卷称「唯一合规终版」，但正文无版本标识（R1 仅在传输文件名中）。建议正文首行加 `Version: EP-TUNNEL-001-OMNI-R1`，否则无法与 R2/R3 区分。
