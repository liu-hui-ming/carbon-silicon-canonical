## 合并总纲

BRIDGE-001 负责谱系同源对齐、BRIDGE-002 负责静态观测坐标切片、BRIDGE-003 负责维度生命周期元治理。

- 维度可以受控生长，但裁决权限不会自动扩张；
- 观测增量准入必须经过注册门禁、增量信息核验、耦合风控；
- 元监护可以告警、局部冻结，永不越权裁决、永不自我豁免；
- 熵是可计算统计量，不能单独作为定性定罪依据。

产出物：关系证据集；不生成观测坐标、不掌管维度注册权限。

### 核心规程

- 同源判定规则：语义余弦相似度<80%、根哈希链不连通、元标签映射契约不匹配，标记 NON-ISOMORPHIC；同源不等于等价，等价必须附加勘伪基线双向可复现证明。

- 冲突分级：
  - C1 可调和冲突：定义域错位，通过补充分割适用域解决，生成勘误附卷
  - C2 不可调和冲突：底层公理互斥，归入 UNASSESSED 台账，禁止混用于同一裁决链路
- 执行约束：只做比对、溯源、登记告警，无权修改任何卷宗正文、无权变更裁决结论。

## 卷三 BRIDGE-003｜动态维度注册与元治理层

核心命题：观测维度本身的全生命周期治理，封堵隐性维度偷渡、信道越权、统计误判。
解决核心问题：新增/修改/退役观测坐标时，如何守住裁决安全边界。
产出物：META-DIM 元维度运行时契约、四信道隔离规则、L0-L3 四层监护、熵计量体系、对抗 Bench 验收套件。

### 3.1 维度注册契约：六元组内核 + Schema v0.1.0-FINAL

六元组永久内核：(DimID, 观测目标, 观测量, 反例判据, 熵计量口径, 跨域映射约束)

配套生命周期状态机：
UNREGISTERED-DIM → PROPOSED → TESTABLE → CONDITIONAL / SUPPORTED → SUSPENDED / RETIRED

- UNREGISTERED-DIM：禁止接入裁决链路
- PROPOSED：材料提交，权责、风险报备完成
- TESTABLE：测量、反例、接口、熵估计脚本全部可执行
- CONDITIONAL/SUPPORTED：验证、对抗、复核全部通过，限定域生效
- SUSPENDED：异常临时冻结，满足条件可复启
- RETIRED：停止新增引用，永久保留历史快照与迁移说明

注册门禁 registration_gate 准入四门槛（全部满足方可进入 TESTABLE）：

1. 增量信息证明：现有维度无法等价复现其输出
2. D03 价值-D01 事实预耦合互信息不超限
3. 算力、存储、复核、熵泄放代价完整报备
4. 不存在等价冗余维度

关键区分：注册通过 = 结构准入合规 ≠ 该维度产出的命题结论为真；命题真假仍走独立勘伪、证据复核流水线。

命名空间强制隔离：EP18-Dxx（本治理观测维）≠ EP16-Dxx（拓扑认知公理维），引用必须携带完整前缀，省略前缀抛出 NAMESPACE_AMBIGUOUS 告警，不参与裁决。

### 3.2 四信道单向硬隔离（可运行时测试验收）

- F 事实信道｜只读溯源：✅ 追加式存证、勘误附卷；❌ 禁止原地覆写、禁止解释与裁决
- I 推断信道｜变换计算：✅ 基于事实生成带误差、版本、适用域的推断；❌ 篡改原始事实、自创无注册维度
- V 价值信道｜目标约束：✅ 输出目标函数、代价权重、取舍边界；❌ 直接读取推断明细、根据观测反向驯化目标；仅可读取固定版本只读兼容性摘要；价值变更必须生成新版本快照
- G 治理信道｜唯一裁决：✅ 签发状态变更、PB 标记、链路冻结、放行驳回；❌ 跳过证据门槛、越权超范围判定

验收四项必过测试：读权限隔离、写权限阻断、接口版本哈希溯源、单信道故障隔离不扩散权限。

### 3.3 熵计量体系（去玄学、数学定型、双层门禁）

四类度量严格解耦，禁止混同对比、随意累加：

- 单维香农熵：bit，单维度观测分布不确定性；禁止跨口径对比
- 交叉熵：分布拟合偏差，用于推断模型校验；不等于偷渡风险
- 互信息：维度统计依赖度量，D03↔D01 核心监控指标；统计依赖≠因果偷渡
- 联合熵：多维联合分布总不确定度；禁止单维熵求和近似

双层风控门禁：

- 统计告警门：熵/互信息越阈值 → 证据保全、溯源调查立案，不冻结链路、不下定性结论
- 权限完整性冻结门：仅确定性违规触发局部链路锁死（维度偷渡、跨信道静默覆写、事实篡改、审计断裂）；L3 只锁污染链路，全域禁止无差别停机瘫痪

### 3.4 L0-L3 四层治理权责矩阵

- L0 原始事实层｜✅ 存证追加勘误｜❌ 覆写、自主解释判定
- L1 推断模型层｜✅ 拟合估计、上报不确定性｜❌ 篡改事实、直接终审
- L2 规程裁决层｜✅ 按基线规程处置 PB、流转状态｜❌ 跳过证据、自定义阈值
- L3 元监护层｜✅ 监控漂移/越界/耦合异常、局部冻结、告警保全｜❌ 替代 L2 裁决、全局停机、自指豁免

L3 自身故障：自动降级、保留只读观测通道、人工接管预案。

### 3.5 五类边界状态解耦（终审区分，不再混淆）

- PB：流程故障，流水线执行异常
- UNKNOWN（六分类）：证据、观测残缺，可补观测复核
- UNDECIDED：范式体系固有不可判定，单独台账，走高维立项跃迁，不计故障
- VALUE_NORMATIVE：价值公理，不可经验证伪
- OUT_OF_OBSERVABILITY：当前观测能力覆盖不到

跨范式握手五态：COMPATIBLE / CONDITIONALLY_COMPATIBLE / UNASSESSED / NOT_APPLICABLE / INCOMPATIBLE
