## 一、顶层架构：十维收敛为三条正交主线

| 主线 | 归属维度 | 核心命题 |
|---|---|---|
| A 命题与裁决 | D1 公理、D3 形式演算、D6 动态边界 | 命题生灭、状态迁移、生效与失效条件可控可审 |
| B 证据与反证 | D2 对抗勘伪、D4 证据审计、D8 时序心跳、D10 风险演化 | 结论须可证伪、可反例、可溯源、可复测、可风险公示 |
| C 权限与外部监督 | D5 元治理、D9 跨域迁移 | 定义权/执行权/裁决权/治理权/迁移权解耦 |
| 贯穿（无裁决权） | D7 熵计量、三级心跳链 | 仅观测存证，严禁熵值驱动裁决 |

架构铁律（拟入 Canonical 元标签）：
1. 维度可横向扩展，但权力必须纵向分层；
2. 观测可贯穿全域，但不得因此取得裁决权；
3. 数据可跨域引用，但不得自动继承原域结论资格。

## 二、结构性校准要点

- 统一元字段：`authority_scope` 权限域 + `evidence_dependencies` 证据依赖 + `failure_semantics` 失效语义。
- D1：三套解耦状态机（命题成熟度 / 证据结论 / 治理版本），冻结仅锁变更权限、不锁真伪判定。
- D2：六类对抗路径用例模板（HR0065-ADV-001~006），字段全部强制，含变异测试自检。
- D3：强类型算子 + 失败语义 + 幂等契约；禁 UNKNOWN 自动折叠为 ALLOW、禁冲突自动择优。
- D4：三层对象解耦（SourceRecord / EvidenceCard / AssessmentRecord）；禁加权合并为单一置信分。
- D6：硬条件（权限/来源/版本/授权）直接阻断；统计条件仅触发复测；风险授权走人工终审。
- D8：三态分离（存活 / 完整 / 正确）；新增时间锚点字段（时钟源、单调序号、偏差阈值、丢失标记、版本绑定）。
- D9：迁移向量 M=(S,R,E,T,A,O)；机制可迁移，历史结论有效性不可迁移。
- D10：四类变更区分（RISK_CHANGE / KNOWLEDGE_CHANGE / DETECTION_CHANGE / MODEL_CHANGE）。

## 三、L3 域外独立复核（四重独立性）

## 四、八大铁律（四条原有 + 四条新增）

原有：证据不跨类代偿｜愿景不替代验收｜观测不升公理｜维度不越权偷渡。
